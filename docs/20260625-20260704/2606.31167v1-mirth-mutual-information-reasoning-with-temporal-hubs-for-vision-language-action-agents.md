## 摘要
VLA模型已成为将网络规模数据的语义知识迁移到物理机器人控制中的强大范式。然而，当前单帧架构存在固有局限性：丢弃历史动态的时间近视、高层指令与低层电机命令之间的推理鸿沟，以及自回归标量解码导致的推理效率低下。在这项工作中，我们提出MIRTH，一个旨在解决这些挑战的统一框架。MIRTH通过三项关键创新增强预训练VLA骨干：（1）双尺度时序记忆枢纽，将长期场景演变和短期运动趋势压缩为紧凑嵌入；（2）通过互信息目标优化的潜在推理令牌，刻画出语义规划空间以对齐多模态上下文与动作轨迹；（3）并行动作解码方案，用向量级预测取代自回归生成以最大化控制吞吐量。在LIBERO仿真基准和真实世界LeRobot平台上的广泛评估表明，MIRTH实现了最先进的性能，并展现出新兴的错误恢复能力。代码和收集的数据集发布于http://github.com/kiva12138/mirth。

## Abstract
VLA models have emerged as a powerful paradigm for transferring semantic knowledge from web-scale data to physical robotic control. However, current single-frame architectures suffer from intrinsic limitations: temporal myopia that discards historical dynamics, reasoning gaps between high-level instructions and low-level motor commands, and inference inefficiency due to autoregressive scalar decoding. In this work, we propose MIRTH, a unified framework designed to address these challenges. MIRTH augments a pretrained VLA backbone with three key innovations: (1) dual-scale temporal memory hubs that compress long-term scene evolution and short-term motion trends into compact embeddings; (2) latent reasoning tokens optimized via a mutual-information objective carving out a semantic plan space to align multimodal context with action trajectories; and (3) a parallel action decoding scheme that replaces autoregressive generation with vector-wise prediction to maximize control throughput. Extensive evaluations on the LIBERO simulation benchmark and a real-world LeRobot platform demonstrate that MIRTH achieves state-of-the-art performance and exhibiting emergent error recovery capabilities. The codes and collected datasets are released at http://github.com/kiva12138/mirth.

# MIRTH 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

当前基于单帧视觉-语言-动作（VLA）模型（如 OpenVLA、RT-2）在短期任务中表现良好，但存在三个关键缺陷：

- **时间短视（Temporal Myopia）**：仅依赖当前帧观测，丢弃历史动态，导致物体被遮挡后失去跟踪，无法处理长程依赖。
- **推理鸿沟（Reasoning Gap）**：高层自然语言指令与低层电机命令之间缺乏中间语义桥接。直接映射缺乏可解释性，离散动作令牌则存在“多对一”映射问题（多种语言描述对应相同物理动作）。
- **解码效率瓶颈（Inference Inefficiency）**：标准 VLA 将连续动作量化成离散令牌，每个自由度需自回归生成，导致高延迟，无法满足实时控制需求。

**论文目标**：提出 MIRTH 统一框架，在不显著增加计算量的前提下，解决上述三大挑战，实现高效、鲁棒、长程依赖的机器人操作。

## 2. 方法论：核心思想、关键技术细节

MIRTH 基于预训练 VLA 骨干（如 OpenVLA），引入三个核心组件：

### 2.1 双尺度时间记忆枢纽（Dual-Scale Temporal Memory Hubs）

- **工作空间记忆（长程）**：采用 K 个指数移动平均（EMA）不同衰减率 β<sub>k</sub>，累积场景布局。每个 patch 的混合权重由当前帧与运动统计量预测。
  - 公式：M<sub>t,k</sub> = (1-β<sub>k</sub>) M<sub>t-1,k</sub> + β<sub>k</sub> V<sub>t</sub>，其中 V<sub>t</sub> 为 patch 嵌入。
- **短程记忆（短程）**：维护最近 w 帧的循环队列，通过时间注意力（含 Recency bias）加权求和，捕获近期运动。
- **融合**：每 patch 由 sigmoid 门控融合两记忆，输出固定长度的记忆令牌（不计上下文长度增加）。

### 2.2 互信息优化的潜在推理令牌

- 在输入序列中插入 m 个可学习推理令牌，置于条件（视觉+指令）与动作令牌之间。
- 通过 InfoNCE 损失最大化推理表示与上下文（观察）、动作表示之间的互信息：
  - L<sub>ra</sub>：推理与动作互信息
  - L<sub>rx</sub>：推理与上下文互信息
- 总 MI 损失 L<sub>mi</sub> = λ<sub>ra</sub> L<sub>ra</sub> + λ<sub>rx</sub> L<sub>rx</sub>，与行为克隆损失联合训练。
- 推理嵌入在无监督下自发形成语义聚类（如开容器类、抓放类），无需显式文本标注。

### 2.3 并行动作解码（Parallel Action Decoding）

- 每个动作向量（含所有自由度）由一个令牌表示，而非逐自由度自回归。
- 使用轻量两层投影头，将动作令牌隐藏状态直接映射为连续动作向量（L1 回归损失）。
- 整个动作块可批量并行解码，避免自回归开销，大幅提升吞吐量。

### 训练与推理

- 骨干网络冻结，仅通过 LoRA（rank 32）微调 LLM 部分；记忆枢纽、推理令牌、动作解码器端到端训练。
- 总参数约 80.2 亿，训练参数约 4.82 亿（6.01%）。
- 推理时，记忆通过 EMA 增量更新，仅需编码当前帧 + 一次前向即可输出整块动作。
