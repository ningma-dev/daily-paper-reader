## 摘要
开放环境下的桌面机器人操作要求系统具备语义理解、精确的几何位姿估计和高频动作生成能力。虽然端到端的视觉-语言-动作（VLA）模型在语义泛化方面表现出色，但它们通常缺乏细粒度任务所需的显式几何约束，并且需要昂贵的训练。为了弥合高层语义与低层物理执行之间的差距，我们提出了OpenSPM，一种开放环境空间持久记忆框架，由空间位姿记忆和流匹配动作生成模型组成。OpenSPM首先利用语义条件3D感知和卡尔曼滤波来跟踪连续的6D位姿。然后，它从人类演示中提取关键空间位姿，并将其作为可迁移的、以物体为中心的空间持久记忆条目。在推理过程中，OpenSPM根据自然语言指令检索相关的记忆条目，使用SE(3)变换将空间位姿转移到新场景，并通过轻量级条件流匹配模型生成高频动作块。结合实时本体感知状态反馈和终端残差校正，该系统有效抑制了轨迹误差累积。在十个LIBERO-GOAL任务上的评估表明，OpenSPM实现了85.6%的成功率和1033.3 Hz的等效控制频率，同时需要极低的推理AI计算能力。大量的消融实验表明，结构化的空间持久记忆和闭环残差校正在可靠的高频机器人操作中起着关键作用。

## Abstract
Open-environment tabletop robotic manipulation requires systems to possess semantic understanding, precise geometric pose estimation, and high-frequency action generation. While end-to-end vision-language-action (VLA) models excel at semantic generalization, they often lack explicit geometric constraints for fine-grained tasks and require costly training. To bridge the gap between high-level semantics and low-level physical execution, we propose OpenSPM, an open environment spatial persistent memory framework consisting of spatial pose memory and flow-matching action generation model. OpenSPM first leverages semantically conditioned 3D perception and Kalman filtering to track continuous 6D poses. It then extracts key spatial poses from human demonstrations, keeping them as transferable, object-centric spatial persistent memory entries. During inference, OpenSPM retrieves relevant memory entries in terms of natural language instructions, transfers the spatial poses to new scenes using SE(3) transformations, and generates high-frequency action chunks via a lightweight conditional flow-matching model. Combined with real-time proprioceptive state feedback and terminal residual correction, the system effectively suppresses trajectory error accumulation. Evaluated on ten LIBERO-GOAL tasks, OpenSPM achieves an 85.6% success rate and an equivalent control frequency of 1033.3 Hz, while requiring minimal inference AI computing power. Extensive ablations illustrate that structured spatial persistent memory and closed-loop residual correction play a crucial role in reliable, high-frequency robotic manipulation.

- 依赖大规模数据和昂贵训练，难以在**少样本、低算力、高频控制**场景直接部署。

**OpenSPM** 的核心思路是**将高层语义与低层几何执行解耦**：用语义模型解析任务并检索经验，用轻量级几何生成模型完成局部动作。通过引入**关键空间位姿**（Key Spatial Pose）作为中间表征——即末端执行器相对于目标物体的相对位姿，可在新场景中通过SE(3)变换保持局部交互几何不变。

### 2. 方法论
#### 2.1 核心思想
以**物体中心的空间持久记忆**为中心，将长时程演示压缩为阶段标记的相对位姿点，推理时依据语言指令检索并迁移到当前场景，再通过**闭环流匹配**生成高频动作块，并用终端残差校正抑制误差累积。

#### 2.2 关键技术细节
1. **语义条件3D感知与卡尔曼状态估计**  
   - 多视角图像 + 文本提示 → 语义分割（如SAM）→ 3D重建（SAM 3D）得到物体点云 → 结合相机参数得到世界坐标系下的6D位姿。
   - **卡尔曼滤波**：将位姿估计看作状态空间问题，预测-更新连续状态，输出平滑的6D位姿，减少视觉抖动。状态向量含平移、线速度、方向误差、角速度。观测协方差由分割置信度、多视图一致性等决定。最终输出经轻量平滑（指数移动平均）。
2. **关键空间位姿记忆库构建**  
   - 从演示轨迹中通过三种证据选取候选关键位姿：**夹爪状态切换**、**速度/方向变化**、**多模态模型（如Qwen3-VL）的语义判断**。
   - 每个记忆条目包含：检索键（操作类型、目标物体等）、语言描述、**相对位姿序列**（每个关键位姿为相对于锚定物体的SE(3)变换）、阶段标签、置信度等。
   - **可迁移性核心**：存储相对位姿 \( \Delta T_{o\to e}^j = ({}^w T_o)^{-1} {}^w T_{e,j} \)，保证在演示场景与测试场景物体位姿满足刚性变换时，局部交互几何不变（论文定理1）。
3. **相对位姿迁移**  
   测试场景中估计出物体新位姿 \( {}^w T'_o \)，则目标末端位姿为 \( {}^w T'_{e,j} = {}^w T'_o \Delta T_{o\to e}^j \)，之后进行可达性、姿态跳变、最小距离检查。
4. **条件流匹配动作生成**  
   - 输入条件：当前实际末端位姿、下一个目标位姿、相对误差、段内进度。
   - 模型结构：条件编码器 + 共享解码器（约24万参数），输出长度为5的动作块（平移增量+轴角旋转增量+夹爪指令）。
   - 训练：线性插值路径 \( a_\xi = (1-\xi)a_0 + \xi a_{\text{data}} \)，学习速度场 \( v_\theta \)，损失为MSE。
   - 推理：从高斯噪声出发，ODE积分生成动作块。
5. **闭环执行与终端残差校正**  
   - **段间闭环**：每个动作块的起始条件使用**实时本体感知位姿**，而非理想计划点。
   - **终端残差校正**：在接近抓取/放置节点时，若实际位置与目标位置偏差超过阈值，则重新生成校正动作块，直至收敛或达到最大迭代。

#### 2.3 算法流程（文字说明）
- **离线阶段**：对每个演示，执行语义3D感知→卡尔曼滤波→提取关键位姿→计算相对位姿→存入记忆库。
- **在线推理**：语言指令→解析任务元素→检索最佳记忆→根据当前物体位姿迁移关键位姿→按段循环：用当前实际位姿构造条件→流匹配生成H=5动作块→执行前几个动作→若接近关键节点且残差大则触发校正→直到全部关键位姿完成。

### 6. 主要结论与发现
- OpenSPM在LIBERO-GOAL上达到**85.6%成功率**，显著优于Diffusion Policy（68.3%）、TraceVLA（75.1%）、SpatialVLA（78.6%）、OpenVLA（79.2%）等，仅略低于WorldVLA（83.4%）。

- **关键空间位姿记忆不可或缺**：零样本多模态模型预测关键位姿成功率仅23.8%，说明结构化的几何先验比纯语义泛化更可靠。
- **闭环反馈和终端残差校正是成功率的关键**：开环流匹配仅3.0%，加入段间闭环提升至29.8%，再加入终端残差校正飙升至85.6%。这说明即使局部动作误差小，多段累积也会导致任务失败，必须通过实时状态反馈和主动校正来抑制。

### 7. 优点
1. **分解范式合理**：将复杂操作分解为语义检索、几何迁移、局部生成，避免了端到端大型模型的高成本和缺乏几何保证的问题。
2. **轻量高效**：动作生成模型仅24万参数，推理延迟毫秒级，适合高频实时控制。
3. **强可迁移性**：基于物体中心相对位姿存储，经SE(3)变换可直接适配新场景物体布局，无需重新训练。
4. **闭环鲁棒性设计**：段间闭环和终端残差校正有效将局部误差控制在物理允许范围内，尤其对抓取/放置等敏感阶段至关重要。
5. **实验对比全面**：覆盖了最新VLA和扩散策略基线，消融实验设计合理，结果差异显著，论证有力。
