## 摘要
视觉-语言-动作（VLA）模型在机器人操作中展示了强大的能力，但在长时程任务中由于累积误差传播，其性能显著下降。这一限制主要源于静态特征融合机制，该机制依赖固定权重来组合视觉、语言和动作表示，使得模型无法适应任务执行的不同阶段。为了解决这一限制，我们提出了S$^2$-VLA框架，引入了一种状态空间引导的自适应注意力（SSGAA）机制。SSGAA维护一个跟踪任务进度的信念状态，并生成动态门控权重，以自适应地融合来自三个互补源的信息：用于空间感知的视觉特征、用于高级任务规划的任务意图以及用于执行一致性的时间动作序列。这种自适应融合允许模型在整个任务执行过程中转移其注意力，与不同任务阶段不断变化的需求保持一致。尽管只有紧凑的2B参数规模，S$^2$-VLA始终优于更大的7B规模模型，并在长时程操作基准（包括LIBERO和SimplerEnv）上取得了最先进的性能，突显了自适应特征融合对于长时程机器人操作的重要性。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong capabilities in robotic manipulation, but their performance degrades significantly in long-horizon tasks due to cumulative error propagation. This limitation largely arises from static feature fusion mechanisms that rely on fixed weights to combine visual, language, and action representations, preventing the model from adapting to different phases of task execution. To address this limitation, we propose S$^2$-VLA, a framework that introduces a State-Space Guided Adaptive Attention (SSGAA) mechanism. SSGAA maintains a belief state that tracks task progression and generates dynamic gating weights to adaptively fuse information from three complementary sources visual features for spatial perception, task intents for high-level task planning, and temporal action sequences for execution consistency. This adaptive fusion allows the model to shift its focus throughout task execution, aligning with the evolving requirements of different task stages. Despite its compact 2B parameter size, S$^2$-VLA consistently outperforms larger 7B-scale models and achieves state-of-the-art performance on long-horizon manipulation benchmarks, including LIBERO and SimplerEnv. highlighting the importance of adaptive feature fusion for long-horizon robotic manipulation.

## S²-VLA: 状态空间引导的视觉-语言-动作模型用于长时程操作

### 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的视觉-语言-动作（VLA）模型在处理需要多步推理的长时程（Long-Horizon）机器人操作任务时，性能会显著下降。其根本原因在于这些模型普遍采用**静态特征融合机制**，即使用固定权重来组合视觉、语言和动作等不同模态的信息。这种刚性设计导致模型无法根据任务执行的不同阶段（如接近、抓取、放置）自适应地调整其对不同信息源的关注度，从而导致决策偏差。在长时程任务中，这些早期偏差会沿着动作链累积和放大（误差累积），最终导致任务失败。

- **整体含义**：该研究旨在解决VLA模型在长时程操作中的误差累积问题。论文的核心论点是，实现成功的长期操作需要一种**与任务阶段感知（phase-aware）的动态权衡机制**，以便在需要精确空间定位的关键视觉阶段和需要理解整体目标的规划阶段之间灵活切换。这一探索对于提升机器人在复杂、多步骤任务中的可靠性和泛化能力具有重要意义。

### 2. 方法论：核心思想、关键技术细节

论文提出的S²-VLA框架的核心是**状态空间引导的自适应注意力（State-Space Guided Adaptive Attention, SSGAA）** 机制。其核心思想是引入一个动态的“信念状态”（Belief State）来追踪任务执行的进度，并利用这个信念状态动态地生成门控权重，自适应地融合视觉、语义和动作序列这三种信息流。

- **信念状态建模（Belief State Modeling）**：模型维护一个内部信念状态$b_t$，用于总结任务的执行历史和当前所处的阶段。该状态通过一个轻量级的门控循环单元（GRU）进行递归更新，其输入是最近的动作序列和本体感受反馈。
  - 公式（2）描述了信念状态的更新过程：基于历史动作$A_{t-K:t-1}$和本体感受$P_t$，通过一个可学习的更新函数$f_\phi$（实现为GRU）生成新的隐藏状态，再通过线性层得到信念状态$b_t$。这个过程是端到端学习的，使信念状态能够隐式地编码任务阶段和执行的“好/坏”程度。

- **SSGAA机制**：基于信念状态$b_t$，SSGAA动态地调控三个并行的注意力通路的输出融合权重。
  - **三个注意力通路**：
    - **动作序列自注意力（Action Sequence Self-Attention）**：专注于预测的未来动作序列内部的时间一致性。
    - **低级视觉交叉注意力（Low-Level Visual Cross-Attention）**：从VLM的早期层提取细粒度的视觉特征，以提供精确的空间定位。
    - **高级意图交叉注意力（High-Level Intent Cross-Attention）**：从语言指令和可学习的意图令牌中提取任务语义，用于高级任务规划。
  - **信念引导的门控（Belief-Guided Gating）**：公式（7）和（8）展示了其核心逻辑。将信念状态$b_t$输入一个多层感知机（MLP）并通过Softmax函数，动态生成三个通路的软门控权重 $g_{vis}, g_{ite}, g_{act}$。最终输出的融合表示$H^{(l)}$是这三个通路输出的加权和。这个过程允许模型在“需要精确视觉”（例如，抓取前的对准阶段）、“需要语义规划”（例如，子任务切换）和“执行平稳动作序列”（例如，长距离移动）之间动态切换注意力焦点。

- **工作流程**：模型采用端到端训练。在推理时，它运行在一个时间递归循环中：在当前时间步，首先通过GRU更新信念状态，然后基于该状态计算门控权重，融合特征，最后预测并执行动作，然后进入下一个时间步。
