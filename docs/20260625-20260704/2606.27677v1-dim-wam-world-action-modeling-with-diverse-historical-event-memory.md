## 摘要
世界-动作模型通过联合预测未来的视觉状态和动作，在机器人操作任务中展现出良好的性能。然而，现有方法主要依赖短期历史信息和短视的未来预测，这对于长期任务而言是不足的，因为其正确执行依赖于早期的观察和任务进展。这类时间依赖任务需要有效利用互补的时间信息，包括近期局部上下文、跨阶段历史事件、即时未来动态以及全局任务进展。为了解决长期遗忘和对全局任务状态感知不足的问题，我们提出了DiM-WAM，一种记忆增强的世界-动作模型，它整合了多尺度历史上下文、局部未来动态和全局任务进展。记忆从真实观察中提取紧凑的视觉事件信息，通过基于相似性的独立合并更新多个记忆库，然后读取带有库标识和时间嵌入的长期上下文来条件化视频和动作去噪。一个进度监督目标进一步促使记忆令牌不仅编码已发生的历史事件，还编码当前任务阶段及其对剩余任务的影响。在RMBench基准上，DiM-WAM将平均成功率从LingBot-VA的28.4%提升至69.8%，超过了显式记忆的Mem-0基线的42.0%。在四个真实世界的Franka任务中，它将平均阶段成功率从70.7%提升至91.5%，完整任务成功率从52.5%提升至80.0%。项目页面：https://wangkai-casia.github.io/dim-wam/

## Abstract
World-action models have shown promising robot-manipulation performance by jointly predicting future visual states and actions. However, existing methods mainly rely on short-term history and short-horizon future prediction, which is insufficient for long-horizon tasks whose correct execution depends on earlier observations and task progress. Such temporally dependent tasks require effective use of complementary temporal information, including recent local context, cross-stage historical events, immediate future dynamics, and global task progress. To address long-term forgetting and poor awareness of the global task state, we introduce DiM-WAM, a memory-augmented world-action model that integrates multi-scale historical context, local future dynamics, and global task progress. The memory extracts compact visual event information from real observations, updates multiple memory banks through independent similarity-based merging, and then reads the bank-identity- and time-embedded long-term context to condition video and action denoising. A progress-supervision objective further encourages memory tokens to encode not only completed historical events but also the current task stage and its implications for the remaining task. On RMBench, DiM-WAM raises average success from 28.4% with LingBot-VA to 69.8%, exceeding the explicit-memory Mem-0 baseline at 42.0%. On four real-world Franka tasks, it improves average stage success from 70.7% to 91.5% and full-task success from 52.5% to 80.0%. ## 2. 方法论：核心思想与关键技术细节

### 核心思想
- 构建记忆增强的世界-动作模型 **DiM-WAM**，通过**多类型历史事件记忆**（Multi-Type Historical Event Memory）存储长期历史，并使用**任务进度监督**（task-progress supervision）使记忆令牌不仅记录事件，还编码全局阶段状态。
- 采用**读取-预测-交互-更新**的闭环流程：每次决策段从记忆读取信息，结合局部上下文预测未来视频和动作，执行后接收真实观察，更新记忆。真实观察纠正生成误差，避免错误积累。

### 关键技术细节

1. **多记忆库（Multi-Bank Memory）**
   - 使用 \(K\) 个并行记忆库，每个库有 \(N\) 个事件槽，固定容量 \(K \times N\) 个令牌。
   - 每个库独立进行相似度压缩：通过式 (5) 计算合并优先级 \(\rho_k(u,v) = \frac{1+\cos(m_{k,u},m_{k,v})}{2} \exp\left(-\frac{|t_u - t_v|}{\tau}\right)\)，选择最冗余的相邻历史对合并（质量加权平均，式 (6)-(7)）。新事件写入与否取决于与当前最新事件的冗余度阈值比较（式 (10)）。
   - 阅读时，令牌添加库标识嵌入和 RoPE 时间嵌入，按时间顺序拼接，作为视频和动作去噪的公共条件。这样不同库学习互补的历史子空间。

2. **任务进度监督**
   - 从聚合的记忆读取序列预测离散进度分布 \(p_i = \text{Softmax}(h_{\text{prog}}(\text{Pool}(R_i)))\)，使用交叉熵损失 \(L_{\text{prog}}\) 训练。
   - 进度标签根据当前段在完整任务中完成的物理比例归一化并分桶。此目标强制记忆承载当前阶段及其对剩余任务的含义，连接已完成事件与剩余工作。

3. **多样性损失**
   - 为防止不同库坍缩为相同表示，对库平均特征施加正交约束：\(L_{\text{div}} = \frac{1}{|\mathcal{P}|}\sum_{(k,l)\in\mathcal{P}} (\bar{m}_{i,k}^\top \bar{m}_{i,l})^2\)。

4. **总训练目标**
   - \(L = L_{\text{video}} + \lambda_a L_{\text{action}} + \lambda_{\text{div}} L_{\text{div}} + \lambda_{\text{prog}} L_{\text{prog}}\)，视频和动作损失沿用基础 WAM（LingBot-VA）的扩散去噪损失。

5. **算法流程**
   - 每段 i：从真实观察提取压缩视觉令牌 \(\tilde{u}_i = g_\phi(X_i)\)，独立更新各记忆库（保留初始锚点、最近事件，中间历史通过合并压缩）。阅读时，从各库取出有效令牌加库嵌入，按时间排序并加 RoPE，得到记忆条件 \(R_i\)。视频和动作去噪以 \(R_i\) 和局部上下文 \(C_i\) 为条件生成预测 \(\hat{z}_{i:i+H}, \hat{a}_{i:i+H}\)。执行动作后利用真实观察更新记忆。

## 6. 主要结论与发现

- DiM-WAM 在 RMBench 上平均成功率从 LingBot-VA 的 28.4% 提升至 69.8%，超过 Mem-0 的 42.0%。M(1) 任务从 22.8%→80.6%，M(n) 任务从 35.5%→56.3%。

## 7. 优点

- **结构设计创新**：多记忆库配合独立相似度合并，实现历史信息解耦，避免单库中异构信息竞争；库标识和 RoPE 时间嵌入实现可控阅读。
- **进度监督**：不直接预测未来，而是将历史事件与全局阶段关联，提供全局时间约束，增强长期一致性。
- **闭环修正**：记忆仅写入真实观察，生成状态不进入记忆，防止误差累积；阅读时临时 KV 缓存不扩展长期容量。
- **实验扎实**：协议审计确保评价公正；仿真和真实任务验证迁移性；消融覆盖关键组件；可视化行为分析直观展示记忆专业分化。
