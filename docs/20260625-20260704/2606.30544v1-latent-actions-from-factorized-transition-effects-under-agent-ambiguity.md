## 摘要
潜在动作模型（LAMs）从观察转移中学习类似动作的代理变量。然而，在多物体或干扰物丰富的场景中，这些视觉效应混合了智能体运动、干扰物、相机动态和背景变化，使得在没有监督的情况下潜在的动作源变得模糊。将这些混合结构化为可重用的转移效应提供了一种中间表示，从中可以更稳健地形成类似动作的潜在变量。我们提出了观察转移分解（OTF），它将每个转移分解为一组稀疏的观察转移基元。利用这些基元作为转移接口，我们提出了OTF-LAM，它在标准的逆前向动力学框架内将运动基元抽象为类似动作的潜在变量，以及OTF-LAM-Dino，一种无解码器的变体，在冻结的DINOv2表示空间中预测未来状态。实验上，OTF基元在受控的载体和形态变化中实现了零样本迁移，显示出可重用性。此外，在复杂的转移歧义下，下游策略学习的结果匹配或超过了基线方法。

## Abstract
Latent Action Models (LAMs) learn action-like proxies from observation transitions. However, in multi-object or distractor-rich scenes, these visual effects mix agent motion with distractors, camera dynamics, and background changes, making the underlying action source ambiguous without supervision. Structuring this mixture as reusable transition effects provides an intermediate representation from which action-like latents can be more robustly formed. We introduce Observed Transition Factorization (OTF), which decomposes each transition into a sparse set of observed transition primitives. Using these primitives as the transition interface, we propose OTF-LAM, which abstracts motion primitives into action-like latents within the standard inverse-forward dynamics framework, and OTF-LAM-Dino, a decoder-free variant that predicts future states in a frozen DINOv2 representation space. Empirically, OTF primitives transfer zeroshot across controlled carrier and morphology shifts, showing reusability. Furthermore, downstream policy learning results match or outperform baselines under complex transition ambiguity.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在多物体或干扰物丰富的场景中，无监督的潜在动作模型（LAMs）学习面临“智能体歧义”——观察到的像素变化混合了智能体动作、干扰物运动、相机动态、背景变化等，模型无从区分哪些变化由受控动作引起。
- **整体含义**：现有的LAMs（如LAPO）直接压缩观察对为单一潜在向量，在纯净场景下有效，但在复杂场景中会混淆动作源。作者认识到“观察转移效应”本身是可结构化的，提出将其分解为可重用的运动基元，再从中抽象出动作潜变量，从而在动作监督缺失时也能获得更鲁棒的潜在表示。

## 2. 论文提出的方法论

- **核心思想**：采用“自底向上”的分解策略——先学习一个**观察转移分解（OTF）**模块，将每个转移稀疏编码为一组可重用的局部运动基元；然后在这些基元之上构建**OTF-LAM**，通过状态感知的门控聚合得到紧凑的动作潜变量，用于逆−前向动力学框架中的预测。
- **关键技术细节**：
    1. **OTF模块（VQ-VAE风格）**：
        - 输入：运动中心信号（例如梯度变换后的帧间差） `ot`，减少外观语义。
        - 将 `ot` 划分为非重叠补丁，每个补丁编码为向量，通过最近邻量化分配到共享码本（K个基元），得到每个基元的占用图 `M_t^(k)` 和激活强度 `w_t^(k)`。
        - 利用占用图将码本嵌入放回空间网格，并结合当前帧 `xt` 解码重建 `ot`，促使码本学习局部运动效应而非物体外观。
        - 损失：重建损失 + 码本损失 + 承诺损失 + 正交正则化。
    2. **OTF-LAM**：
        - 冻结OTF，提取因子集合 `E_t = { (c(k), M_t^(k), w_t^(k)) }`。
        - 每个因子通过状态感知网络生成因子令牌 `rt,k`，然后由门控网络（sigmoid）输出相关性权重。
        - 加权平均得到因子级潜变量 `z_fac`，再线性投影得到最终动作潜变量 `z_act`。
        - 前向动力学：解码器从当前帧 `xt` 和 `z_act` 预测未来帧（残差式）。
    3. **OTF-LAM-Dino**：
        - 无像素解码器，使用冻结的DINOv2编码器将 `xt` 和 `xt+τ` 映射到特征空间。
        - `z_act` 通过交叉注意力与Transformer聚合得到，然后预测未来DINO特征。
        - 损失为特征空间中的L2距离。
    4. **策略学习**：
        - 用行为克隆学习从当前帧到 `z_act` 的策略。
        - 用少量动作标签（32条轨迹）训练动作解码器将 `z_act` 映射回真实动作。

## 6. 论文的主要结论与发现

1. **OTF基元是可重用的**：在DCS跨形态迁移和Moving MNIST跨数字迁移中，OTF的重建退化远小于全局VQ-VAE，表明码本捕捉到局部运动效应而非载体特有结构。
2. **OTF-LAM在复杂歧义下表现良好**：下游策略回报匹配或优于现有LAM基线（FLAM等），尤其OTF-LAM-Dino在cheetah-run上平均回报达到43.80，优于FLAM(4)的41.58。
3. **冻结DINO表示进一步受益**：OTF-LAM-Dino在两种环境下均优于像素预测的OTF-LAM，说明去除像素级干扰、在鲁棒特征空间中预测更有利于控制。
4. **码本大小影响**：cheetah-run中性能随K增大提升，walker-run中较稳定；OTF-LAM-Dino对所有K均优于OTF-LAM，但性能非单调。

## 7. 优点

- **方法创新**：将观察转移分解为可重用的局部运动基元，避免了依赖物体分割或滑动注意力等强先验，更适用于无结构场景。
- **两阶段设计**：分离“学习运动基元”与“抽象动作潜变量”，使基元可迁移，且下游只需冻结OTF即可适配新环境/载体。
- **灵活的无解码器变体**：OTF-LAM-Dino结合冻结DINOv2，既减少计算又利用预训练视觉知识，性能显著提升。
- **实验设计严谨**：系统性消融（输入类型、码本大小）、多基线对比、统计可靠（多种子+多轨迹），且量化了迁移退化。
