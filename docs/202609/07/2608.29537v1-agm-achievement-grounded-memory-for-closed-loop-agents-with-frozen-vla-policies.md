## Abstract
Frozen vision-language-action (VLA) policies offer broad manipulation skills but execute open-loop action chunks without tracking task progress, so the agent cannot reliably decide whether to continue, retry, or terminate. External memory is a natural remedy, yet it can be harmful when attempted actions are treated as completed progress, turning local execution errors into persistent task-state errors. We propose Achievement-Grounded Memory (AGM), a lightweight closed-loop framework for frozen VLA policies that represents a task as a subgoal sequence with a progress pointer and advances this memory only after the current subgoal is verified by physical evidence. Proprioceptive interaction cues decide when to verify, while coherent point tracking and language-conditioned cross-view comparison, sourced from frozen foundation models through a single 2.43M-parameter verification head, decide what was achieved. AGM thereby converts open-loop execution into a closed loop of execution, verification, and progress, keeping the policy frozen without test-time large-model inference. On the RoboMME Counting benchmark, AGM reaches on PickXTimes and on BinFill, surpassing the strongest memory-augmented baseline by points on average, and the framework yields equally decisive gains on a physical robot. Reliable embodied memory thus depends more on disciplined state updates than on memory capacity.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 视觉-语言-动作（VLA）模型能够将视觉观察和语言指令直接映射为连续动作，具备广泛的操控技能。
- 实际部署中，对每个下游任务进行微调成本高昂，因此常见方案是**冻结策略**，通过语言子目标组合已有技能。
- 但冻结 VLA 策略**以开环方式执行动作块**，不维护任务进度状态。在重复计数类操控任务中，不同阶段在视觉上高度相似（感知混叠），仅凭当前图像无法判断“这是第几次抓取/放置”，因此策略无法可靠决定继续、重试还是终止。
- 直观解决方案是引入**外部记忆**，但作者发现：如果把“尝试过的动作”直接当作“已完成的进度”写入记忆，反而可能比不加进度记忆更差——因为一次失败的抓取、滑落或未成功建立目标关系的释放会被永久记录为任务状态错误，把瞬时失败变成持久性错误。
- 因此核心问题从 **“记忆应该存什么”** 转变为 **“记忆应该在什么时机写入”**。

**论文核心主张：**
- 可靠的具身记忆更多依赖于**有纪律的状态更新**（何时写、基于什么证据写），而非记忆容量或模型规模。一个有序子目标序列加进度指针通常就是足够的状态表达，只要每次更新都有可观测的执行证据支持。

## 2. 方法论：AGM 框架

**总体结构：**
- 将任务指令确定性展开为有类型标注的子目标序列  
  `G = {(g_k, c_k)}_{k=1..T}`，其中 `c_k ∈ {grasp, place-rev, place-irrev, other}`。
- 维护紧凑任务记忆 `Mt = (G, p_t)`，其中 `G` 固定，`p_t ∈ {1..T}` 为动态进度指针，是唯一在线更新的持久状态。
- 冻结 VLA 策略始终以当前子目标 `g_{p_t}` 为条件生成动作块。

**核心思想——“先验证后写入”：**
- 将任务执行变成“执行 → 验证 → 推进”的闭环。
- 只有当前子目标被物理证据验证成功后，进度指针才推进；验证失败时指针保持不变（抓取失败）或回滚到关联的抓取子目标（可恢复放置失败）。

**关键技术与流程：**

1. **交互事件定位（何时验证）**
   - 使用带滞回特性的有限状态机（FSM），输入夹爪开度 `w_t`，输出事件 `e_t ∈ {∅, G+, R+, R0}`：
     - `G+`：稳定负载抓取成功闭合
     - `R+`：从负载状态释放
     - `R0`：空手释放
   - 兼容函数 `χ(e_t, c_p)` 只允许“抓取子目标收到 G+ 事件”和“放置子目标收到 R+ 事件”时触发验证；空释放和不兼容组合直接忽略。
   - 意图：交互事件只表明“可能发生了状态变化”，不等于“任务已达成”。

2. **抓取成功的验证（抓手运动学证据）**
   - 利用端到端位姿投影到前视图，在投影点周围生成 6×6 查询网格（36 点）。
   - 从抓取事件起缓冲“抬升视频片段”，直到末端执行器上升 0.03 m。
   - 使用冻结的 CoTracker3 追踪这些点的轨迹和可见性分数。
   - 提取有效轨迹（终点可见度 ≥ 0.5）的垂直位移，取位移最大的 1/3（至少 6 点）的中位数作为响应 `r^G_n`。
   - 若 `r^G_n ≥ δ_G`（4 px），判为抓取成功——即物体确实随夹爪一致向上运动，而非仅仅“夹爪闭合”。

3. **放置成功的验证（语言条件跨视角语义证据）**
   - 对每个放置子目标，由语言 `g_k` 生成标准化查询 `q_k`（去除重复序号）。
   - 释放前后分别从前置相机和腕部相机聚合 K=4 帧窗口，用冻结的 SigLIP 编码得到图像嵌入 `z^-`、`z^+` 和文本嵌入 `z_q`。
   - 构造特征向量：
     `f_n = [z^-_f; z^+_f; z^+_f − z^-_f; z^-_w; z^+_w; z_prop; z_q]`
   - 轻量 MLP 头 `h_ψ`（仅 2.43M 可训练参数）输出放置成功概率 `s^P_n`。

4. **进度指针更新规则（成果驱动的记忆写入）**
   - 抓取成功阈值与放置成功阈值分开设定：
     - 抓取成功：`r^G_n ≥ δ_G`
     - 放置成功：`s^P_n ≥ κ_c`，其中 `κ_c` 依放置类型而定
   - 指针转换公式：  
     - 验证成功 → 指针 `p` 前进 1（不超过总子目标数 T）
     - 验证失败且子目标为可恢复放置 → 指针回滚到该重复回合对应的抓取子目标
     - 验证失败且不可恢复放置 → 指针保持不变，但采用更宽松的接受阈值，并限制连续拒绝次数
   - 其他类型子目标（如 `other`）由冻结策略自行完成，AGM 不干预。

5. **防止死锁的机制**
   - 每类事件设有连续拒绝上限（可恢复放置最多 2 次、不可逆放置最多 3 次、抓取最多 3 次），到达上限后强制推进指针，保证永不死锁。
   - 若负载保持但未在 80 个控制步内抬升，触发 stuck timeout。
   - 终止前对最近一次可恢复放置做一次独立的“占用检测”（不依赖学习头），若失败则回滚。

**部署对齐验证器训练：**
- 验证头离线训练，使用官方 RoboMME 训练分割中采集的 788 条执行事件（384 grasp、278 place-rev、126 place-irrev），其中失败样本占 25.1%。

- 环境谓词仅用于离线打标签，评估时不可用。

## 6. 主要结论与发现

- **AGM 显著提升重复计数类任务成功率**：RoboMME Counting 四任务平均 55.96%，比最强记忆增强基线 MemER（48.83%）高 7.1 个百分点，几乎翻了冻结 π0.5 基线（28.78%）的一倍。
- **对夹爪交互锚定任务达到新 SOTA**：PickXTimes 100.00%，BinFill 84.00%。
- **增益来自“验证后写入”而非记忆容量或模型规模**：在 PickXTimes 上，同样的子目标接口和指针，验证写入达 100%，而尝试写入仅 32%，且尝试写入不比无指针（全指令）更好。
- **冻结策略本身具备所需技能**：π0.5 在 N=1 时近乎完美（100/90），但随 N 增大迅速崩溃到 0；AGM 弥补的正是任务进度状态缺失，而非底层技能。
- **框架跨骨干迁移**：几乎无法独立执行的 π0（12.5% 起，N≥2 为 0）在附加 AGM 后显著提高到 44.0%/8.0%，无需调整任何阈值。
- **消融表明**：点追踪视觉证据带来一致残余增益（BinFill +6 点）；可恢复感知阈值对不可逆放置尤为重要（BinFill +10 点，因展平阈值会误拒绝正确的不可逆释放，拖死指针）。
- **实体机器人验证一致**：PickXTimes 在全部 N 上达到 100%，BinFill 前两层 100%、N=5 时 60%，且失败集中在物理上更难的晚期放置而非进度跟踪。
- **当可逆/不可逆结构差异显著时，记忆价值差异也显著**：BinFill 中尝试写入几乎匹配 AGM——因为不可逆释放“天然自证”，而 PickXTimes 中失败间隙大，验证成为决定性因素。

## 7. 优点

**方法亮点：**
- **概念清晰**：明确区分“尝试”与“成就”，坚持以物理证据支持每次记忆写入，直觉上强而有力。
- **极简参数开销**：仅训练 2.43M 参数验证头，其余（VLA、点追踪器、SigLIP、文本编码器）全部冻结；部署时不需额外运行自回归大模型。
- **验证时机制设计巧妙**：用“夹爪负载状态机”决定何时验证，用点追踪的相干运动判断“物体是否随夹爪上升”，再用冻结 SigLIP + 跨视角差异 + 语言条件判断“放置关系是否建立”——充分利用了冻结基础模型各自的强项，无需训练即可使用。
- **指针更新规则细致**：支持前进、保持、回滚三种动作，并依据“可恢复 vs 不可恢复”设置不对称接受阈值；防止死锁的连续拒绝上限完全合理。
- **对训练数据的谨慎处理**：明确报告正负样本来源、训练/测试种子不相交、部署时间窗口与训练时间窗口对齐、留出集验证结果——方法论上相当严谨。
- **框架可迁移**：同一套规则在不同骨干间不需重调，实体部署也证明改动仅限平台接口层。

## 8. 不足与局限

**实验与覆盖局限：**
- **任务类别受限**：基准仅覆盖重复计数类任务，且子目标必须由夹爪交互（抓/放）锚定；推、滑、关节物体操作、持续抓握下的工具使用等不产生兼容事件，AGM 在这些场景退化为直接跟随冻结策略。
- **性能上界受验证器精度限制**：假接受会造成虚假进度，假拒绝会浪费预算，死锁上限本身牺牲了“绝对无差错”以保证活性。
- **物理实验范围较窄**：仅一种 6-DoF 平台、一种夹爪、一种物体类别（彩色塑料方块）；阈值在不同平台上需要重新标定，文中未声称跨平台零调参。
- **统计显著性不足**：每个配置只有 50 条仿真 episode、每计数 10 次实体 trial，未报告置信区间，也无法排除某些差异来自随机种子。
- **未尽任务未真正处理**：SwingXTimes 和 StopCube 被直接委托给基础策略，证明“不损害”，但没有体现 AGM 的适用范围扩展。
- **术语与外部细节**：依赖来自基准提供的子目标分解（尽管对比了指令解析器版本，但验证结论基于官方分解）。

**资源报告不足：**
