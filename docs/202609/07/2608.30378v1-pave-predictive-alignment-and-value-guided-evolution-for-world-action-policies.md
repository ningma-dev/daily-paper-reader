## 摘要
直接的视觉-语言-动作策略能够高效地生成连续机器人动作，但标准的行为克隆存在两个互补的不足：它们的表示没有被明确要求描述场景如何在多个时间尺度上演化，并且部署轨迹的质量参差不齐，常常被不加区分地重用，而未将有用的动态与不良行为分离。我们引入了\method，一种直接的世界-动作策略，将不依赖结果的预测学习与依赖结果的策略改进相结合。\method首先保留一个局部的固定偏移JEPA目标，并添加轨迹相对的、在剩余回合的25%、50%、75%和100%处的多视野转换对齐。这些仅用于训练的目标要求当前策略表示同时保留局部物理变化和较长期的任务进展，而不向动作头提供显式的未来标记。随后，\method在累积的部署轨迹上训练一个独立的分位数价值评论家，计算与动作块对齐的$N$步优势，并将其转换为正、负或空文本条件，用于流匹配执行器。因此，每条有效轨迹都能教授物理上发生了什么，而执行器仅在相对更好动作相关联的条件下被部署。多视野预测器和评论家在在线执行时被移除，保留从当前观察、语言指令和本体感觉中直接生成动作。\redclaim{在三个模拟基准测试中，\method在保持直接执行器在线执行路径的同时，实现了最强的整体性能。}

## Abstract
Direct vision-language-action policies generate continuous robot actions efficiently, but standard behavior cloning leaves two complementary gaps: their representations are not explicitly required to describe how the scene evolves over multiple time scales, and deployment trajectories of unequal quality are often reused without separating useful dynamics from undesirable behavior. We introduce \method, a direct world-action policy that combines outcome-agnostic predictive learning with outcome-aware policy improvement. \method first retains a local fixed-offset JEPA objective and adds trajectory-relative multi-horizon transition alignment at 25%, 50%, 75%, and 100% of the remaining episode. These training-only targets require the current policy representation to preserve both local physical changes and longer-range task progress, without supplying explicit future tokens to the action head. \method then trains an independent distributional value critic on cumulative deployment trajectories, computes action-chunk-aligned $N$-step advantages, and converts them into positive, negative, or null text conditions for a flow-matching actor. Thus, every valid trajectory can teach what physically happened, while the actor is deployed only under the condition associated with relatively better actions. The multi-horizon predictor and critic are removed from online execution, preserving direct action generation from the current observation, language instruction, and proprioception. \redclaim{Across the three simulation benchmarks, \method achieves the strongest overall performance while preserving the direct actor's online execution path.}

## 一、核心问题与整体含义（研究动机与背景）

### 研究动机

现有视觉-语言-动作（VLA）模型将视觉观察和语言指令直接映射为机器人动作，依赖行为克隆（behavior cloning）来学习。

论文指出这种直接策略存在**两个结构性缺陷**：

1. **表示缺乏时间演化的要求**：标准行为克隆只要求策略复现动作，并没有显式要求内部表示编码"所伴随的场景变化"，尤其是超出单一动作块的时间尺度。
2. **部署数据质量不加区分**：自主部署产生的轨迹质量悬殊——包含成功、失败、低效、恢复等多类行为。传统训练直接混用这些轨迹，未将有效动态与不良动作分离。

### 关键实质

- 仅有未来预测 → 行为无关：预测器可精确表示"坏动作的后果"，却不教模型避免坏动作；
- 仅有价值引导 → 未改善多时间尺度的转移表示。

### PAVE 的核心观点

> **从所有有效轨迹中学"发生了什么"，但从较优轨迹中执行动作。**

PAVE 在三个核心原则下构建：

- 保留直接的策略执行路径（推理时无搜索/规划）
- 用多层级预测目标塑造共享策略表示
- 用批判性价值评论家做离线数据筛选，以条件文本方式引导策略演化

## 二、方法论

### 1. 总体架构

PAVE 包含三部分：

- **Actor**：直接策略模型（Qwen2.5-0.5B + LoRA，带流匹配动作头），接收视觉观察、语言指令和"优势条件"文本；
- **多视野（multi-horizon）预测对齐分支**：仅在训练时使用，提供局部+轨迹级的世界状态监督；
- **价值分支（离线）**：分布性的状态价值批评器，从累积部署轨迹中计算 N 步优势，并将其转换为正/负/null 条件文本。

部署时仅保存：当前观察编码器 + 流匹配动作专家；预测器和价值批评器完全不出现在线上执行路径中。

### 2. 建模与输入

- 输入：全局镜头 + 手腕镜头（各 384×384）
- 视觉编码器：冻结的 V-JEPA 2.1 ViT-L/16，每个视角产生 24×24 补丁（576 tokens），两个视角共 1152 tokens（维度 896）
- 语言底座：Qwen2.5-0.5B（hidden=896），LoRA 秩 32
- 动作输出：64 个动作占位符，流匹配动作专家预测 20×7 的动作块（H=20），4 个 Euler 步

### 3. 多视野预测世界-动作学习

PAVE 在训练时加入两类预测目标：

**(a) 局部固定偏移 JEPA（Local transition alignment）**：

- 固定偏移 δ = 31
- 将所有当前帧与 t+δ 帧构成的两帧片段，用冻结的 V-JEPA 2.1 目标编码器生成联合嵌入（逐 token）
- 用预测器 Pδ 从当前隐藏状态预测未来嵌入，用逐 token 余弦损失监督

**(b) 轨迹相对多视野对齐（Trajectory-relative multi-horizon alignment）**：

- 在未来帧的比例处设定四个目标：ρ ∈ {0.25, 0.50, 0.75, 1.00}
- 目标位置由剩余回合比例计算：t + ρ·(T−t)，做裁剪
- 用共享 MLP P_MH + per-horizon 嵌入 e_k 预测未来联合嵌入
- 目标不跨越 episode、版本、来源或审查边界
- 损失：逐 token 余弦相似度加权和

### 4. 关键公式

**模型输入序列**（含正/负/null 优势文本条件 c_t）：

(Vt, Mt) = Qθ([w0; P(E(ot)); w1:L; ct; qa₁:₆₄])

- Vt：视觉 token 隐藏态（1152×896）
- Mt：占位符状态（64×896）→ 供给动作专家

**Flow matching 目标**：

xτ = (1−τ)ε + τ·a，u*(xτ, τ) = a − ε

L_FM = Σ m_a ⊙ ||uθ(xτ, τ, Mt, qt) − (a − ε)||² / Σ m_a

**局部和对齐的总 actor 损失**：

L_actor = L_FM + λ_local·L_local + λ_MH·L_MH

（λ_local = λ_MH = 0.5）

### 5. 价值引导的体验标注：价值评论家、分布性值函数、优势文本

- 评论家输入 s_t = (o_t, l, q_t)，输出分布在 [−1, 0] 上 201 个支撑的二进制 softmax
- 非终态奖励 r_t = −1；终态奖励：成功 0，失败 −C_fail
- 目标 y_t = G_t / (2 M_task)，范围 [−1, 0]
- N = H = 20，与动作块对齐
- 计算 N 步优势：A(N)_t = Ĝ(N)_t − Vϕ(s_t)
- 每个任务的块按优势降序排列：前 30% 得 positive 标签，其余 negative；可用人工修正轨迹并入 positive 集合
- 标签文本"Advantage: positive/negative"，训练时以 0.3 概率丢成 null
- 专家示范始终分配 positive

### 6. Advantage-Conditioned Policy Evolution（ACP）

- 累积经验池 D≤k = ∪ D1…Dk
- 每轮重新从同一固定 base π_base 初始化 actor（避免连续权重漂移）
- 训练集 D_train = D_demo ∪ D_evolved，示范：演化数据 = 3:1
- 每轮收集 96 条新增轨迹，共 3 轮（cumulative 288 条）
- 每轮批评器训练 8,000 次更新；actor 训练 30,000 次更新
- 部署时固定 positive 条件，直接采样动作块执行

## 六、主要结论与发现

### 1. 各基准的最终改进

与 JEPA-WAM 对比：

- **LIBERO**：平均提升 +2.6 分；
- **LIBERO-Plus**：平均提升 +6.0 分（其中背景变换下 +7.9，传感器噪声 +7.4）；
- **RoboTwin 2.0**：平均提升 +6.6 分（杂乱 +7.0，背景变化 +7.5）。

与 π*0.6（RECAP）对比：LIBERO +2.0、LIBERO-Plus +4.7、RoboTwin 2.0 +4.8。

### 2. 消融实验主要验证结论

- **无未来预测目标** + 只用 flow matching：结果最差（LIBERO-Plus 59.1 / RoboTwin 45.9）；
- **加局部固定偏移目标**：显著上升（→ 67.2 / 53.4），证明预测分支有效；
- **再加共享多视野目标**：进一步提高（→ 70.7 / 56.8）；
- **再加 ACP（完整系统）**：达到 73.2 / 60.0。完整配置相对"无 ACP 但带多视野预测"模式仍高出 2.5/3.2 分。

### 3. 系统效率结论

- PAVE 与 JEPA-WAM 在线参数量完全相同（1.29 B），GPU 内存 10.4 GB；
- 额外参数 4.63 M 全部分布在训练/离线分支；
- 在线延迟只增加 0.2ms（p50 与 p95 同时），可忽略不计；
- 证明训练时的预测+价值引导可以增强固定直接策略能力，而不损害在线执行成本。

### 4. 条件标注可迁移性结论

- Positive 部署条件是实现最优性能的核心：
  - Positive：66.6（LIBERO-Plus + RoboTwin 平均）
  - Null：64.2
  - Negative：47.6
  - 未标注多轮 BC：61.7
- Negative 条件的显著报废效果证明文本条件有意义的功能性解释性，而非空标签。

## 七、优点

### 方法亮点

1. **提出"预测-偏好分解"原则**——将"理解发生了什么"（预测）与"应当做什么"（价值判断）解耦训练，既有先验知识监督（预测世界动态），又不会让"坏轨迹的连贯性预测"导致模仿坏行为。
2. **多视野预测设计**——将原来单一的固定 offset 扩充为轨迹相对的四档比例（25%～100%），可适应不同长度 episode，既不依赖全局长度又覆盖了局部到完整轨迹的任务转移；预测目标始终不进入动作头，避免引入明确未来 token 对策略的表征污染。
3. **轻量高效在线架构**——训练时的预测器额外在线成本仅为 +0.2 ms，保留全部直接 VLA 推理路径。实际部署时不存在迭代规划/搜索，维持强闭环控制响应。
4. **利用离线经验方式简单且灵活**——价值标签以文本形式注入 prompt，无特殊参数、无复杂策略梯度算法，便于建立在已有预训练模型的流程上。
5. **在既有架构地基上做联合增强**——在流匹配输出 + LoRA 语言模型基础上直接增加多组未来目标，与现有 VLA/World-Action 生态高度兼容。
6. 核心经验落化清晰：解释了为什么失败轨迹不应被完全丢弃——其代表"状态转移的知识"仍可用于训练表示，只是不优的相对较差点将被 filter 为 negative 条件来断开模仿。

### 实验设计优点

- 对比方法论可靠：所有基线为作者在统一协议下复现；
- 对编码器影响、模型大小、推理耗时等做了全面的专题消融，使实验结论有较强的因果解释能力；
- 提供定性的机器人轨迹演示，展示"逻辑完整"的视觉特征（虽然不承诺定量精度）。

## 八、不足与局限

### 理论局限性

1. **锚点仅作为"时间进度"，并不包括语义子目标**——它们不提供"有没有完成任务"或"目标阶段是/否契合"的语义结果，部分可能在校准不佳的状态下收紧或在终点附近压缩；
2. **价值标签是

2. **价值标签是**基于离线轨迹内相对优势排序产生的（前 30% 为正），而非对每个动作绝对优劣的度量；这意味着当一批轨迹整体质量偏低、或评论家未能校准良好时，“positive” 也不代表全局最优，它只比同批其他轨迹好。类似地，“negative” 标签的功能更像是“去学习”的标记，其语义边界并不清晰，也未必能被语言模型完整内化为“应避免的负面示范”这一可泛化的概念。

3. **预测目标与价值条件在训练中共享同一策略表示，但在优化目标上可能相互拉扯**：预测分支要求表示编码足够的未来转移信息，而价值条件则试图把策略分布压向较优轨迹。论文通过损失加权缓解，但没有系统讨论两者的梯度冲突尺度，也没有给出敏感度曲线。对于预测损失占比更大的任务（或价值噪声更高的任务），条件效应可能会被稀释。

4. **文本条件“Advantage: positive/negative”是一种较为间接的条件化机制**：它依赖语言模型先验来理解优势文本与动作分布之间的相关性。实验中虽用 drop-out 模拟 null 条件，但文本本身并非自然语言指令，而是标记性短语；模型是否真正学到“条件控制”，而非仅仅将 positive/negative 当作两个额外的离散 embedding，在论文中没有被完全论证。消融显示 positive 显著优于 null 和 negative，但缺少对“无意义但不变的占位符文本”（例如“Condition: A/B”）的对照，因此无法完全排除条件文本本身引入的随机噪声。

### 实践与评估局限

1. **策略演化依赖部署数据自动标注闭环**：文中展示的 ACP 虽然能持续提升性能，但其前提是有一个可用的价值评论家，且演化数据来自策略自身 rollout。对于真实机器人，rollout 成本、安全性以及数据多样性都会限制演化轮次。论文没有讨论真实场景中“应当部署多少轮、收集多少条失败轨迹后停止”的准则。

2. **真实机器人评估严重不足**：整篇论文只有一段桌面擦拭的定性展示，没有真实环境的成功率、干预次数或任务完成时间等量化指标。所谓的“真实机器人定性演示”只说明系统能在一个特定场景下完成动作，不能支撑从仿真到真实的迁移声称。

3. **受限于任务结构相对简单的仿真基准**：LIBERO 与 RoboTwin 的动作空间平滑、状态可完全观测、干扰维度被显式枚举。PAVE 对多峰分布、长时程稀疏奖励、部分可观测状态、动态干扰物等现实机器人挑战仍未给出实证。特别是预测对齐对 V-JEPA 的依赖意味着视觉编码器本身需对场景变化敏感，在高度动态环境中其冻结特征是否仍能提供足够的未来监督尚不清楚。

4. **基线与数据复现的公平性细节不足**：作者声称所有基线均以相同训练设置复现，但对部分基线来说，“相同设置”未必是其最优设置。例如，带独立世界模型（world model）的 JEPA-WAM 类方法通常需要专门的训练调度或额外的未来 token 损失权重；统一按 PAVE 的 LoRA 与训练步数配置可能使基线处于不利地位。论文没有发布完整超参表，也没有提供逐任务的标准差矩阵，这限制了外部研究者复现与对比的粒度。

### 总体评价

PAVE 的价值在于清晰地分解了“世界动态理解”与“策略偏好塑造”二者的职责：前者来自所有有效轨迹的跨视野预测，后者通过离线价值评论家以文本条件注入策略演化过程。这种设计既保留了直接策略的快速执行路径，又使训练信号不再仅仅停留在单步动作复现层面。其在 LIBERO、LIBERO-Plus 与 RoboTwin 2.0 上的一致提升，以及在线开销几乎为零的实验证据，表明预测对齐与价值条件化可以作为通用增强模块嵌入现有 VLA 训练管道。

然而，PAVE 仍处于“表示层面先验增强 + 离线轨迹再筛选”的框架之内，其核心贡献更接近一种训练策略与数据选择策略的组合，而非对 VLA 架构根本性变革。真正的开放问题——如何让价值判断不依赖同策略滚动数据的标注、如何在真实环境中建立安全自动评估闭环，以及如何在稀疏奖励的长程任务中定义“轨迹相对优势”——都没有被完全回答。因此，论文的贡献可以概括为：**给出了一个高效、可直接部署的预测偏好联合训练范式，并在可控仿真中证明了其有效性；但其泛化上限仍取决于可信任的自动评价器与多样化的离线经验来源。**
