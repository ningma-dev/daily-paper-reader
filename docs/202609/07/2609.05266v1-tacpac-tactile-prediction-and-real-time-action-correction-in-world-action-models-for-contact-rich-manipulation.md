## 摘要
世界动作模型通过预测未来观察来指导动作生成，但以视觉为中心的预测忽略了决定丰富接触操作所需的局部接触线索。然而，在我们的实验中，简单地将未来触觉观察作为附加视图进行预测，仅恢复了可实现增益的三分之一。这一差距反映了时间上的不匹配：预测先于执行，而触觉反馈在执行过程中到达。我们提出了TacPAC，它将触觉预测转化为实时动作校正。一旦基础模型规划了一个动作块，TacPAC会缓存该规划所依赖的预测接触信息以及规划自身的表示，然后一个触觉专家将每个新观察到的触觉图像与该缓存进行比对，以校正尚未执行的动作。因此，反馈是针对规划预期而非孤立地进行解释，一次校正仅需对该缓存进行一次遍历，比分块重新生成便宜20.7倍。在涵盖精密插入、脆弱物体操作、物体重新定向和长时程操作的五个真实机器人任务中，TacPAC在每项任务上均取得领先，并将平均成功率从其仅视觉基础模型的22%提升至64%。代码可在https://github.com/LogosRoboticsGroup/TacPAC获取。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

## 1. 核心问题与研究动机

- **背景**：接触丰富的操作任务需要机器人根据物理交互调整动作，而非仅依赖可见场景几何。例如，插入充电插头需要精确对准，捏取薯片需要适度的抓取力。纯视觉观测无法捕捉局部形变、微小滑移或精密插入错位等关键接触线索。
- **核心问题**：视觉中心的世界动作模型（WAM）预测的未来观察以视觉为主，生成的动作用于接触丰富操作时可靠度不足。
- **现有方案局限**：
  - 将未来触觉观测作为附加视图直接预测（如 Dream-Tac），只恢复了可实现增益的三分之一。
  - 预测发生在动作执行前，而触觉反馈发生在执行中——这是一个**时间错配**问题。预测后的动作块在面临实际反馈时无法被修订。
- **本文工作**：提出了 **TacPAC**，将触觉预测转化为**执行过程中的实时动作校正**，从而把预测信息作为"预期接触"与实时"实际接触"做对比，在动作块执行期间实现高频修正。

## 2. 方法论

### 2.1 总体架构

- 基于 **Mixture-of-Transformers (MoT)** 架构，包含三个专家：
  - **视频专家**：预测未来视觉与触觉观测（多路触觉视图拼接进统一视频流）。
  - **动作专家**：在预测观测条件下生成规划的动作块行为。
  - **触觉专家**：在动作执行过程中，根据实时触觉图像与缓存信息进行动作微调，输出增量动作量。
- 视频流包含触觉视图，**触觉标记扮演双重角色**：既是未来预测的目标，也（经动作查询的注意力）是动作块生成的条件。

### 2.2 关键技术：预测锚定的触觉校正

- **动机**：只看到"当前触觉读数"不知道这读数是否符合原计划的期望。同样的触觉读数在不同执行阶段可能要求完全相反的动作响应。
- **缓存机制**：
  - 基础模型在完成去噪调度后，额外执行一次干净前向过程（流时间 \(\tau=0\)），存储逐层的注意力的键与值。
  - 缓存保留两组标记：**触觉视图**的 KV（编码了计划预测的接触信息）与**动作标记**的 KV（编码了计划在预测接触条件下的内部表征）。
  - 缓存针对每个动作块建立一次，后续所有校正共享读取。

- **触觉专家**：
  - 输入：当前执行的触觉图像 \(I_m\)、被更新的计划动作块（已执行前缀替换为真实发送到机器人的动作，未执行部分保留计划值，并加入执行状态嵌入）、执行偏移量 \(m\)。
  - 输出：**delta 动作** \(\Delta a = f(I_m, \hat{a}, m, C)\)。
  - 校正公式：\(\hat{a} + \Delta a\)。
  - 每层注意力同时关联缓存 \(C\) 与自身标记。
  - 共享基础模型专家的深度和注意力几何结构，保持参数对齐。

- **技术优势**：
  - 每次校正只需**单次触觉专家前向**，不重新运行视频专家或去噪流程，延迟低至 30.4 ms。
  - 每次校正基于原始计划块做加法，新校正覆盖旧校正，虚假校正不会向后传播。

### 2.3 两阶段训练

- **阶段一（Stage 1）**：训练视频专家 + 动作专家，目标为视频与动作的条件流匹配损失的加权和。
- **阶段二（Stage 2）**：冻结阶段一模型，只训练触觉专家。初始化自训练好的动作专家。
  - 每个训练回合：用冻结基础模型规划动作块 \(\hat{a}\) 并预先填充缓存 \(C\)；采样 \(K\) 个执行偏移量 \(m\)；用真实动作填充已执行前缀；只对**尚未执行的后缀**施加校正损失：
\[
\mathcal{L}_{tac} = \frac{1}{H-m} \sum_{i \ge m} \| \hat{a}_i + \Delta a_i - a_i \|^2
\]
  - 关键点：训练时让基础模型规划自己的动作块（而非使用真实块），消除"训练-部署路径不一致"问题。

### 2.4 异步推理

- 机器人动作块生成后立即执行；预填充缓存过程中机器人已开始动作。
- 每个新到达的触觉帧触发一次校正；延迟 \(d\) 内的动作步骤保持最近已提交值，校正只从 \(m+d\) 写回未执行部分。
- 实际测量中 98.4% 的校正都在机器人推进一个控制步之前返回，所以几乎全部校正可在完整未执行后缀上生效。

## 6. 主要结论与发现

- **核心结果与成绩**：TacPAC 在所有五任务中达到最高成功率，平均 64%，较最强基线的 48% 领先 16 个百分点。相对仅视觉的 WAM（22%）取得大幅提升。
- **逐任务观察**：
  - 触觉预测方法（Dream-Tac）在捏取类任务表现优（预估接触正确可在初始接触时避免捏坏物体），但在插入任务上受限（接触错误在动作块执行中才显现）。
  - 触觉反应式校正（T-Rex）在精确插入任务上表现好（错误发生后可以响应修正），但在易损伤类任务（损伤发生后无法恢复）失败。
  - TacPAC 在两组任务上均超过二者，符合"将触觉反馈与预测预期耦合可互补两者缺陷"的直觉。
- **关键结论**：单独依赖触觉预测不足；预测和校正是互补的；将实时反馈作为"预期与真实之间的偏差"来处理是解决这一问题的核心。
- 实验证明读缓存触觉键值的存在对触觉专家有效（相比无缓存变体，成功率提升 17 个百分点（47% → 64%）），支持了"预期感知对比"的有效性。
- 效率分析：与重新生成一个动作块相比，触觉校正仅需 30.4ms，相对便宜约 20.7 倍，能够在 32.9Hz 的速率下实时响应，绝大多数情况下不影响 30 Hz 的控制率。

## 7. 优点与亮点

- **问题定位精准**：把"预测先行、反馈滞后"的时间结构错配鲜明地提炼出来，并用数据诊断（4.9% 的帧拥有 18.6% 的触觉变化，触觉变化的峰值发生在动作块已经由预测决定之后）支持论点。
- **方法设计有新意**：把预测未来触觉从"训练时的辅助预测头"提升为"执行时的对照基准"，缓存了模型内表征而非解码帧，并以"预测与观察的差异"作为校正信号。
- **重视效率与实用性**：用缓存复用 + 单次前向校验避免重新生成，保证 32.9Hz 的实际反馈速率。
- **消融实验具备良好的区分度**：裁剪每一条路径并用简单的开关操作定量展示了每条路径的贡献（47%-64% 增益来自缓存）。
- **详细合理的问题驱动实验**：将实验组织成四个问题（Q1-Q4），逐层递进。
- **基于真实机器人的操作验证**（五个各有侧重的任务：插入、破损、脆弱物、姿态调整、误抓），结果可信度较高。

## 8. 不足与局限

- **基准测试规模偏小**：每个真实任务仅有 20 次试验，缺少统计显著性分析；一些任务间的差距在随机噪声下可能不稳定，需要更多置信度信息。
- **实验资源使用不清**：真实数据集的总收集量、阶段一与阶段二的训练时间均未明确。
- **无模拟或跨平台泛化研究**：缺少在更大规模多样传感器/对象上的评估，泛化性不可预测。
- **基础模型的局限继承**：手臂是在一个离散动作块中运动的，只能在本块内修正；若任务需要在更长流程顺序中进行不同子任务的重新计划，则需要多个动作块配合。现阶段评估的长时程任务是由 1-2 个块完成的。
- **依赖可行的触觉"预期"**：当触觉预测本身显著错误时，校正可能偏移在错误的预期附近——但论文没有给出预测质量在失败场景中的系统衡量。
