## 摘要
视觉-语言-动作（VLA）模型展现出强大的语义理解能力，但在部署期间会出现系统性失败。这些失败发生的条件，以及是否可以在不重新训练的情况下进行校正，仍知之甚少。在本文中，我们朝解决这一差距迈出了一步。我们提出了CorrectVLA，一个将任务级自然语言校正转化为加法性动作幅度调整的框架，无需修改策略权重。人类提供单一的任务级校正，统一应用于所有轨迹，无需逐集干预。在仿真中，CorrectVLA在分布内和分布外任务中均能恢复执行错位失败。在环境变化下的UFactory xArm7真实机器人实验中，CorrectVLA在基础策略几乎完全失效的情况下恢复了接近完美的成功率，并能泛化到不同的物体位置和身份。通过对LIBERO-90上失败模式的分类，我们发现执行错位失败（即策略到达正确目标但动作幅度校准错误）属于可校正的子集，而其他语义理解本身崩溃的失败模式则不适用于该方法。当策略具备策略正确性时该方法成功，而在缺乏基本理解时失败，这为推理时校正确立了一个实用的操作边界。

## Abstract
Vision-Language-Action (VLA) models demonstrate strong semantic understanding yet exhibit systematic failures during deployment. The conditions under which these failures occur, and whether they can be corrected without retraining, remain poorly understood. In this paper, we take steps toward addressing this gap. We present CorrectVLA, a framework that translates task-level natural language corrections into additive action magnitude adjustments without modifying policy weights. A human provides a single task-level correction, applied uniformly across all rollouts without per-episode intervention. In simulation, CorrectVLA recovers execution misalignment failures across both in-distribution and OOD tasks. In real-robot experiments on a UFactory xArm7 under environment shift, CorrectVLA restores near-perfect success where the base policy almost entirely breaks down, generalizing across object locations and identities. Through a taxonomy of failure modes on LIBERO-90, we find that execution misalignment failures, where the policy reaches the correct target but miscalibrates action magnitudes, represent the correctable subset, while other failure modes where semantic comprehension itself breaks down are not amenable to this approach. The approach succeeds when policies possess strategic correctness and fails when fundamental comprehension is absent, establishing a practical operational boundary for inference-time correction.

### 2. 论文提出的方法论

#### 核心思想

- 提出 **CorrectVLA** 框架，将人类提供的**任务级自然语言校正**（natural-language corrections）翻译成**加性的动作幅度调整**，**不修改策略权重**、**无需逐集干预**、**无需重新训练**。
- 由人类在观察一次完整失败的轨迹后给出**一条稀疏、回顾性的任务级校正**，该校正被统一应用于同一任务的所有测试轨迹（rollouts）。
- 核心前提：失败在时间上是**稀疏的**——错误集中在特定轨迹瓶颈时刻而非遍布整个过程——因此在少量时间步施加校正即可让策略自主完成后续动作。

#### 技术细节与流程

**三个阶段的语言-动作接合机制：**

- **Phase A：结构化参数抽取**
  - 使用 LLM（Claude Sonnet 4.5）从自然语言反馈中抽取四个结构化参数，构造结构化校正 `ck = (dk, sk, mk, t_start,k, t_end,k)`：
    - `dk`：作用维度（x/y/z/roll/pitch/yaw/gripper）；
    - `sk`：方向（+1/-1）；
    - `mk`：幅度词（slightly/more/much）；
    - `[t_start,k, t_end,k]`：时间窗口。
  - 例：“move left more in 1–2 seconds” → 维度=x轴，方向=+1（右），幅度词=“more”，时间窗=[1.0, 2.0]s。

- **Phase B：幅度量化**
  - 将语言幅度词映射到数值范围："slightly" → [0.3, 0.5]，"more" → [0.5, 0.8]，"much" → [0.8, 1.0]；
  - LLM 在相应区间内取值并匹配方向，生成有符号幅度 `wk ∈ [-1.0, 1.0]`（归一化至实际动作空间）；
  - 这些范围在一组保留的校正示例上经过了经验性验证。

- **Phase C：时间分布**
  - 构建分段线性包络函数 φk(t)：在校正窗口内从 0 渐进到峰值（窗口中点），再衰减回 0，窗口外为零影响。这样确保校正平滑融入策略的动态特性，并集中在关键轨迹时刻。

**完整的间接函数：**

- 对 K 条反馈实例，聚合各维度的校正（同一维度上的校正做加法叠加）：
  δd(t) = Σ_{k: dk=d} wk·φk(t)
- 校正后的动作 = 原始动作 + δd(t)：
  a_corrected(t,d) = a(t,d) + δd(t)

**真实机器人上的动作空间适配：**

- 校正用人类直观的笛卡尔空间定义（“向左移”“向上移”）；
- 而 xArm7 采用关节速度控制，因此通过**Jacobian 伪逆**将笛卡尔空间修正转换为关节速度：
  q̇ = J†(q)·ẋ

#### 与对比方法的本质区别

- ITPS 需要执行期间的实时物理引导；CorrectVLA 仅需事后一次的稀疏语言校正；
- FOREWARN 只能从采样的轨迹中选择而无法生成分布之外的纠偏；CorrectVLA 通过直接施加加性偏置可生成**原分布之外**的纠偏行为；
- 与偏好学习/共享自主等方法相比，CorrectVLA 不需要成对比较、多轮交互训练或在线意图推理。

### 3. 实验设计：数据集、场景、Benchmark 与对比方法

- 失败分类共覆盖 **133 个任务-模型评估组合**（73 个 OpenVLA-OFT + 60 个 π0.5），全部为 LIBERO-90 上的分布外任务。

- **Out-of-distribution（分布外）**：全部 90 个 LIBERO-90 任务 × 5 次试验/任务 = 450 条轨迹；

### 6. 论文的主要结论与发现

- **VLA 部署失败存在四类稳定的模式**（跨 OpenVLA-OFT 与 π0.5，在 LIBERO-90 OOD 任务上）：
  1. **任务误解**（Task Misunderstanding，约 47%/50%）：策略误读空间或关系语言后操纵错误物体——最常发生；
  2. **感知失败**（Perception Failure，约 25%/22%）：目标对象被完全忽略；
  3. **执行错位**（Execution Misalignment，约 23%/22%）：策略到达正确目标但动作幅度、夹持深度或推动力量校准错误；
  4. **多步规划失败**（Multi-step Planning，约 5%/6%）：第一步成功但第二步放弃。

- **只有执行错位失败可在推理时被有效校正**。这一模式的本质特征是策略具备“战略性正确性”（strategic correctness），仅需要在特定时间窗口内对特定动作维度做幅度修正。其余三类失败在语义理解层面已然崩坏，不适用于幅度级干预，需要训练级修正。

- **稀疏任务级校正足以恢复执行错位失败**：在仿真中，CorrectVLA 恢复 46.8%（65/139）的分布内失败和 10.1%（33/328）的分布外失败；LLM baseline 在两种条件下均无恢复。

- **在真实机器人环境变化下恢复近乎完美的成功率**：π0.5 在原始环境成功率 95%（19/20），在机器人基座位置改变后降为 10%（2/20）；CorrectVLA 经过单条任务级校正后恢复至 95%（19/20）总体成功率。任务级校正能泛化到同一任务中的不同位置/不同物体实例，无需逐集校正。

- **为推理时校正划定了实际的操作边界**：“当策略拥有战略性正确性（仅需幅度层面纠错）方法有效，当缺乏基础理解时方法无效”；该分类学为部署时间适应性干预提供了一种实用的“先诊断，后干预”原则。

### 8. 不足与局限

- **论文自述的三项限制**：
  1. Phase B 的幅度范围是从预设区间内抽样一次，可能引入“预期幅度”和“实际修正幅度”之间的不可控变化，且多种场景下可能需要多轮收敛；

  - 未能说明当执行错位与语义类轻微错误共存时，所提出的校正方法是否会失败。
