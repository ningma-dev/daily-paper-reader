## 摘要
灵巧操作需要协调的多指控制和有效的触觉反馈，然而由于缺乏大规模真实世界数据以及难以从稀疏触觉信号中提取有效表征，学习这些能力仍然具有挑战性。我们搭建了一个机器人平台和遥操作系统，收集了一个200小时的双臂灵巧操作数据集，其中包含同步的视觉、触觉和语言标注，涵盖65个任务的10,576条轨迹，其中69.5%涉及灵巧多指操作。我们进一步提出STAR，一种用于视觉-触觉-语言-动作（VTLA）模型的集成训练方案，通过视觉-触觉联合预训练、稀疏全局触觉token表征和稀疏未来触觉预测，来解决触觉信号在空间、时间和信息上的稀疏性。在该数据集上训练后，STAR在四个真实世界任务上平均成功率达到61%，每个任务使用100条后训练轨迹，展示了在任务特定后训练下的灵巧性能。

## Abstract
Dexterous manipulation requires coordinated multi-finger control and effective tactile feedback, yet learning these capabilities remains challenging due to the lack of large-scale real-world data and the difficulty of extracting effective representations from sparse tactile signals. We build a robot platform and teleoperation system to collect a 200-hour bimanual dexterous manipulation dataset with synchronized visual, tactile, and language annotations, comprising 10,576 trajectories across 65 tasks, 69.5% of which involve dexterous multi-finger manipulation. We further propose STAR, an integrated training recipe for vision-tactile-language-action (VTLA) models that addresses the spatial, temporal, and informational sparsity of tactile signals through visual-tactile joint pre-training, sparse-global tactile token representation, and sparse future tactile prediction. Trained on this dataset, STAR achieves a 61% average success rate across four real-world tasks with 100 post-training trajectories per task, demonstrating dexterous performance under task-specific post-training.

## 1. 核心问题与研究动机

- **背景**：灵巧操作（dexterous manipulation）要求多指协调控制与有效的触觉反馈，是机器人领域长期追求的目标。当前灵巧操作模型虽在特定任务上表现亮眼，但能力多集中于抓取放置等简单技能，难以泛化到通用接触丰富的操作场景。
- **数据瓶颈**：
  - 真实灵巧手数据难以规模化采集：灵巧手与触觉传感器鲁棒性有限、遥操作难度大。
  - 第一人称人类视频易扩展，但人手与机器人手之间存在具身鸿沟（embodiment gap），且缺乏力信息与指令动作，难以迁移到接触丰富的灵巧任务。
  - 仿真数据存在 sim-to-real 差距，难以精确建模接触、传感器噪声与长尾场景。
- **表征瓶颈——触觉信号的严重稀疏性**（论文核心洞察，见 Fig. 1）：
  - **空间稀疏**：灵巧手触觉传感器覆盖面积大，但多数时刻仅少量 taxel 被激活（论文数据集最高激活 taxel 比例仅 **24%**）。
  - **时间稀疏**：大量操作阶段（如接近物体时）触觉保持不活跃（激活触觉帧比例仅 **35%**）。
  - **信息稀疏**：触觉仅提供局部接触信息，缺乏全局上下文。
- **现有方法局限**：已有工作多只针对单一稀疏性问题（门控机制处理时间稀疏、世界模型预测未来触觉帧处理信息稀疏、区域划分处理空间稀疏），缺乏系统性方案；且当前 VLM 依赖海量数据与弱归纳偏置，而灵巧手触觉数据难以扩到同等规模，因此需要**更强的归纳偏置**。

## 2. 方法论

### 2.1 核心思想

构建机器人平台与遥操作系统采集 200 小时真实双臂灵巧手数据，并提出 **STAR** 集成训练方案，从触觉编码器预训练到策略训练，系统性地应对触觉的空间、时间与信息三重稀疏性。

### 2.2 问题建模

- 目标：建模 $p(a_t \mid o_t)$，观测 $o_t = \{I_t, T_t, s_t, l_t\}$，其中 $I_t$ 为多视角图像，$T_t$ 为多路触觉信号，$s_t$ 为本体感知状态，$l_t$ 为语言指令；$a_t$ 为长度 $H$ 的动作块。
- 动作生成采用**条件流匹配（conditional flow matching）**：
  - 训练速度场 $v_\theta(a_t^\tau, o_t, \tau)$，将高斯先验 $\epsilon \sim \mathcal{N}(0, I)$ 传输到目标动作分布；
  - 损失 $\mathcal{L}_{FM} = \mathbb{E}[\|v_\theta(a_t^\tau, o_t, \tau) - (a_t - \epsilon)\|_2^2]$；
  - 插值动作 $a_t^\tau = (1-\tau)\epsilon + \tau a_t$，$\tau$ 从 shifted beta 分布采样；
  - 推理时编码观测为 prefix token 并缓存 KV，使用 **10 步前向欧拉积分**生成动作。

### 2.3 机器人平台与遥操作系统

- **硬件**：双臂轮式移动机器人，腿部 2 DoF、腰部 3 DoF、每臂 7 DoF、头部 3 DoF；每只灵巧手 **10 个驱动 DoF（共 16 DoF）**，集成 **268 维压阻式触觉传感器**（覆盖掌心与手指内侧接触面，**指缘区域未覆盖**）。
- **传感配置**：左右腕部相机（640×528）+ 头顶相机（1280×800），左右手触觉，全部同步至 **30 Hz**。
- **遥操作**：骨架式手套 + 追踪器 + 踏板；采用 DexPilot 逆运动学，并做三项关键改进：
  - 调整手套 URDF 指尖位置以匹配灵巧手；
  - **加入朝向约束**（原算法仅优化指尖位置，导致拇指倾斜时机器人拇指仍直立）；
  - **禁用自动手指闭合机制**（避免干扰精细手指运动控制）；
  - 用 C++ 实现并集成到多进程流水线以提升响应速度。

### 2.4 三项关键技术组件（Fig. 3）

#### （a）视觉–触觉联合预训练（VTP）

- 将触觉信号表示为图像（268 taxel 分布于掌心与手指内侧，非 taxel 区域补零），分辨率统一为 224×224，切分为 196 个不重叠 token，加入二维 sincos 位置编码。
- 遵循 M2VTP，将图像 token 与触觉 token 拼接后做**联合掩码 token 预测**（两模态各随机掩码 **75%** patch），使用**逐 patch 归一化损失**：
  $$\mathcal{L}_{joint} = \sum_{m \in \{img, tac\}} \frac{1}{|P_m^{mask}|} \sum_{j \in P_m^{mask}} \|\hat{x}_m^{(j)} - \bar{x}_m^{(j)}\|_2^2, \quad \bar{x}_m^{(j)} = \frac{x_m^{(j)} - \mu_m^{(j)}}{\sigma_m^{(j)}}$$
- **动机**：仅用触觉模态预训练会因空间稀疏而退化为"预测全零"，联合视觉上下文使平凡解次优，促使编码器学到更具信息量的触觉表征并实现跨模态对齐。
- 左右手各用同一编码器处理对应的腕部图像–触觉对。

#### （b）稀疏–全局触觉 token 表征（SGTTR）

- 触觉编码器输出 196 个空间 patch token + **每手一个可学习全局触觉 token**（类似 CLS token，聚合整个触觉场）。
- 由标定触觉读数构建**接触门控**：当某 token 内任一 taxel 超过传感器特定接触阈值时视为激活。
- 仅对空间 patch token 施加门控：**保留激活 token、掩码未激活 token，全局触觉 token 始终保留**。
- **非对称注意力**：全局触觉 token 不允许关注视觉/语言/动作 token，但后者可关注它——既保持全局 token 的触觉特异性，又让其他模态按需访问触觉信息。
- 该混合表征在过滤冗余的同时保留细粒度触觉细节与全局接触信息。

#### （c）稀疏未来触觉预测（SFTP）

- 动机：历史触觉仅反映当前接触状态，预判接触演化对灵巧操作至关重要。
- 在固定 5 帧预算下，将预测目标**沿动作时域均匀分布**：$T_S = \{10, 20, 30, 40, 50\}$，$H=50$。
- 从 VLM 输出触觉 token 经 MLP 分别预测左右手未来力，逐 patch 损失：
  $$\mathcal{L}_{future} = \frac{1}{|T|}\sum_{t \in T}\frac{1}{|P_t^{tac}|}\sum_{j \in P_t^{tac}}\|\hat{x}_{tac}^{(j)} - x_{tac}^{(j)}\|_2^2$$
- 该辅助任务同时用于策略微调与后训练阶段，缓解信息稀疏。

### 2.5 训练流程

- 采用 π0.5 架构（PaliGemma Gemma-2B 视觉语言骨干 + Gemma-300M 动作专家），除动作层外由 π0.5 权重初始化；因原检查点面向 32 维动作空间，**丢弃并重新初始化动作输入/输出投影层**以匹配 64 维（其中 34 维有效：左右各 7 维末端位姿 + 各 10 维手部关节，其余零填充）。
- 全序列 1562 token：3 视角图像经 SigLIP So400m/14 编码为每视角 256 token（共 768）；触觉图像经预训练编码器产生每手 197 token（196 patch + 1 全局）；64 维本体状态离散化为文本，最大 350 token；动作后缀 50 token。

## 3. 实验设计

### 3.1 数据集

- **自建 200 小时真实双臂灵巧手数据集**：
  - **10,576 条轨迹，65 个任务**，全部同步至 30 Hz；
  - **69.5% 为灵巧多指操作**，20% 为抓取放置/插入等基础技能，10% 为长时程组合任务；
  - 包含三视角图像、双手触觉、机器人状态、指令动作、人工标注任务级语言指令。

### 3.2 评估场景（四个真实任务，Fig. 5）

| 任务 | 描述 | 触觉依赖 |
|---|---|---|
| **Earbud flipping** | 拇指与食指将耳机翻转 180° | 触觉密集 |
| **Stacked-book retrieval** | 食指勾出紧叠书本上缘，拇指与中指抓取 | 视觉定位为主，触觉稀疏 |
| **Postcard retrieval** | 将明信片滑到桌边，抓取放入盒中 | 中等 |
| **Multi-object grasping** | 每手用不同手指组依次收集两件垃圾并丢弃 | 触觉+协调 |

### 3.3 评价指标

- **SR（成功率）**：成功试验数 / 总试验数；
- **TCR（任务完成率）**：完成子任务数 / 总子任务数（各任务细分为 grasp/rotate/release、pull/grasp/retrieve/place、slide/grasp/place、以及多物体抓取的 8 个子任务）。

### 3.4 对比方法

- **GR00T N1.7**：混合真实机器人、合成、第一人称与互联网视频预训练；
- **LDA-1B**：30k 小时人类 + 跨具身机器人数据预训练；
- **π0.5**：大规模跨具身平行夹爪数据预训练（**无灵巧手数据、无触觉**）；
- **GR00T N1.7-Dex / LDA-1B-Dex**：用本文数据集额外微调后的版本；
- **π0.5-Dex w/o STAR**：用本文数据集微调但**不含 STAR 训练方案**。

### 3.5 实验协议

- 所有方法均从官方预训练权重初始化，使用官方推荐微调超参；
- 每任务 **100 条任务特定后训练轨迹**，评估物体从 200 小时预训练数据中**留出**；
- 每方法每任务 **20 次试验**，所有方法使用**相同随机初始场景配置**以保证公平。

### 3.6 消融实验

- **训练配方消融**（在 Earbud flipping 与 Stacked-book retrieval 两个任务上）：
  - Ours w/o STAR、w/o VTP、w/o STTR、w/o GTTR、w/o SFTP、w/o SFTP w/ DFTP；
- **触觉作用消融**：Ours w/o T（无触觉微调）、Ours mask T（推理时掩码触觉）。
