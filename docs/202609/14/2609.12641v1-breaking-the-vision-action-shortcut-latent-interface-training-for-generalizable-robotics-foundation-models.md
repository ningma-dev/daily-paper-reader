## 摘要
机器人基础模型在分布内表现强劲，但在视觉分布偏移下常常退化。当从预训练视觉表征学习生成动作时，模型可能利用与训练分布中演示动作相关的任务无关视觉线索。当这些相关性在分布偏移下发生变化时，此类视觉-动作捷径会损害泛化能力。缓解这些捷径需要约束视觉信息如何用于动作生成，同时保留任务相关的空间信息。我们提出潜在接口训练（LIT），一种与框架无关的两阶段策略：首先在不使用图像的情况下建立以空间目标为条件的动作先验，然后通过位姿监督的潜在接口约束视觉条件化。第1阶段训练动作专家以语言、机器人状态以及每个演示动作块的末端SE(3)末端执行器位姿为条件生成动作块，从而学习独立于视觉线索的目标导向动作生成。第2阶段引入一个潜在接口，聚合视觉与语义表征，并作为预训练动作专家唯一的视觉条件化通路。该接口被监督以重建先前用于第1阶段条件化的末端位姿，从而促使其保留动作生成所需的目标相关空间信息。在四种视觉-语言-动作与世界-动作架构（Pi0.5、MolmoAct2、FAST-WAM和ImageWAM）上，LIT将LIBERO-Plus总体成功率提升3.87-10.70个百分点，同时保持或提升平均LIBERO成功率。真实世界评估显示，在未见相机配置、光照变化和干扰物下，三个任务聚合成功率提升13.30-16.70个百分点。

## Abstract
Robot foundation models achieve strong in-distribution performance but often degrade under visual distribution shifts. When learning to generate actions from pretrained visual representations, models may exploit task-irrelevant visual cues that correlate with demonstrated actions within the training distribution. Such vision-action shortcuts can undermine generalization when these correlations change under distribution shifts. Mitigating these shortcuts requires constraining how visual information is used for action generation while preserving task-relevant spatial information. We propose Latent Interface Training (LIT), a framework-agnostic two-stage strategy that first establishes a spatial-goal-conditioned action prior without images, then constrains visual conditioning through a pose-supervised latent interface. Stage 1 trains the action expert to generate action chunks conditioned on language, robot state, and each demonstrated chunk's terminal SE(3) end-effector pose, learning goal-directed action generation independently of visual cues. Stage 2 introduces a latent interface that aggregates visual and semantic representations and serves as the pretrained action expert's only visual conditioning pathway. The interface is supervised to reconstruct the terminal pose previously used to condition Stage 1, encouraging it to retain the goal-relevant spatial information needed for action generation. Across four vision-language-action and world-action architectures (Pi0.5, MolmoAct2, FAST-WAM, and ImageWAM), LIT improves overall LIBERO-Plus success by 3.87-10.70 percentage points while preserving or improving average LIBERO success. Real-world evaluations show 13.30-16.70 percentage-point gains in success aggregated across three tasks under unseen camera configurations, lighting variations, and distractors.

# 论文总结：Breaking the Vision–Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models

## 1. 核心问题与研究背景

- **研究动机**：当前机器人基础模型（VLA 与世界-动作模型 WAM）在分布内（ID）操作任务上表现优异，但在视觉分布偏移（视角、光照、背景、传感器噪声等）下性能明显退化。
- **问题根源——视觉-动作捷径（vision–action shortcut）**：动作专家从预训练视觉表征生成动作时，可能利用与演示动作相关但**任务无关的视觉线索**（如特定背景纹理、场景布局）。这些相关性在训练分布中成立，但在分布偏移下失效，从而损害泛化。
- **关键张力**：视觉表征同时编码了动作生成所必需的任务相关空间信息。因此缓解捷径不能简单"屏蔽视觉"，而需**在降低对任务无关视觉变化敏感度的同时，保留对任务相关空间变化的响应能力**。
- **现有方法不足**：
  - 表征增强类（SpatialVLA、TraceVLA、MolmoAct、ECoT 等）只是**丰富输入信息**，并未约束动作专家**如何使用**这些信息，捷径空间依然存在。
  - 分阶段动作预训练类（Qwen-VLA、LA4VLA 等）虽先学无图像动作先验，但**缺少每个动作块明确的显式空间目标**，且引入视觉条件时未对其使用方式加以约束。
- **核心研究问题**：如何结构化地组织动作学习与视觉条件化，在缓解视觉-动作捷径的同时保留动作生成所需的任务相关空间信息？

## 2. 方法论：Latent Interface Training (LIT)

### 2.1 核心思想

- 提出**与框架无关的两阶段训练策略**：先建立"无图像 + 空间目标条件化"的动作先验，再通过**位姿监督的潜在接口**作为动作专家**唯一的视觉条件通路**。
- 两阶段共享同一空间目标（演示动作块的末端 SE(3) 位姿）：Stage 1 用它作为条件信号，Stage 2 用它作为重建目标，从而把"动作先验学习"与"视觉接口学习"连接起来。

### 2.2 问题设定

- 策略输入视觉观测 $o_t$、语言指令 $l$、机器人状态 $s_t$，输出长度 $H$ 的动作块 $A_t=(a_t,\dots,a_{t+H-1})$。
- 目标（goal）取每个演示动作块的**末端机器人状态**：$g_t=[p_{t+H};r_{t+H};q_{t+H}]\in\mathbb{R}^8$，其中 $p\in\mathbb{R}^3$ 为世界坐标系末端位置，$r\in\mathbb{R}^3$ 为轴角姿态，$q\in\mathbb{R}^2$ 为夹爪关节量。
- **该目标仅在训练中使用，推理时不需要**。

### 2.3 Stage 1：空间目标条件化的动作预训练

- 冻结的骨干网络只处理语言指令与机器人状态，输出各耦合层的语义表征 $H^{sem}_{\ell,t}$（**不使用图像**）。
- 用带 GELU 的三层可训练 MLP 将 $g_t$ 映射为目标 token $G_t$，与骨干表征拼接：$C_{\ell,t}=[H^{sem}_{\ell,t};G_t]$，经各架构原生条件化机制注入对应动作专家层。
- 采用**流匹配（flow matching）目标**：采样 $\tau\sim U(0,1)$、$\epsilon\sim N(0,I)$，构造带噪动作块 $\tilde{A}^\tau_t=(1-\tau)\epsilon+\tau A_t$ 与目标速度 $v^\star_t=A_t-\epsilon$；动作专家预测速度并最小化 $\mathcal{L}_{prior}=\mathbb{E}\|\hat{v}^\tau_t-v^\star_t\|_2^2$。
- **仅更新动作专家参数 $\theta$ 与 SE(3) 编码器参数 $\eta$**，骨干与其模态编码器保持冻结；所得动作专家参数用于初始化 Stage 2。

### 2.4 Stage 2：视觉–动作接口学习

- 引入可学习潜在 token $Z_0\in\mathbb{R}^{K\times d}$（$K=100$），所有输入共享同一初始化。
- 在每个耦合层 $\ell$，潜在 token 依次经过：**自注意力 → 语义交叉注意力 → 视觉交叉注意力**更新；潜在 token 充当 query，骨干表征充当 key/value。
- 参数效率设计：每 $m$ 个连续耦合层共享一组接口注意力参数（$q(\ell)=\lceil \ell/m\rceil$），但各自访问对应的骨干表征。
- 更新后的 token 通过各架构原生机制逐层条件化动作专家（此时动作专家由 Stage 1 初始化），动作损失 $\mathcal{L}_{act}$ 形式同 Stage 1。
- **位姿重建监督**：用 MLP 解码器 $D_\omega$ 从最终潜在 token $Z_{L,t}$ 重建 Stage 1 用过的同一目标 $g_t$：$\hat{g}_t=D_\omega(Z_{L,t})$，$\mathcal{L}_{pose}=\|\hat{g}_t-g_t\|_2^2$。
- 总损失：$\mathcal{L}_{stage2}=\mathcal{L}_{act}+\lambda_{pose}\mathcal{L}_{pose}$，取 $\lambda_{pose}=0.3$；重建损失在预处理状态空间计算并对有效目标取平均。
- Stage 2 **联合优化**骨干与其模态编码器、动作专家、潜在 token 与接口注意力模块、MLP 解码器。

### 2.5 框架集成与推理

- 在预训练骨干（VLM 或视频模型）与动作专家之间插入潜在接口，保留各架构原生的骨干、动作专家结构、动作表示、预测时域与动作生成目标。
- 推理时潜在接口保持激活，**Stage 1 位姿编码器与 Stage 2 位姿解码器均被移除**；策略仅需视觉观测、语言、机器人状态，遵循各框架原生采样与执行流程。

- **消融结论**：
  - 移除 Stage 1 或移除位姿监督均导致 OOD 泛化下降，验证二者缺一不可。
  - **允许动作专家直接访问骨干视觉表征**（LIT w/ direct visual access）退化最明显，直接证明捷径源于"动作专家可自由利用原始视觉表征"这一通路，而潜在接口正是阻断该通路的关键。
  - 仅保留潜在 token 聚合（无 Stage 1 与位姿监督）效果次之，说明潜在接口本身有聚合作用，但缺少空间目标锚定则不足以形成有效约束。
  - LA4VLA-inspired staged training 与 baseline w/ pose supervision 均不及完整 LIT，说明**显式的逐动作块空间目标 + 潜在接口**的组合优于仅分阶段训练或仅增加监督信号。

## 7. 局限性与讨论

- **监督信号依赖**：方法需要每个演示动作块的末端 SE(3) 位姿作为监督目标，对缺少位姿标注、或动作空间非末端位姿形式（如关节空间、非抓取类操作）的任务适用性受限。
- **额外结构开销**：潜在接口引入可学习 token、接口注意力模块与位姿解码器，带来额外参数与计算开销；论文未报告推理延迟或吞吐量的定量对比。
- **偏移范围有限**：OOD 评估集中于视觉与语言扰动，未覆盖动力学变化、新任务分布、跨本体迁移等更广义的分布偏移。
- **真实世界样本量偏小**：每条件每任务仅 10 次 rollout，统计显著性有限。
- **可复现性缺口**：未报告 GPU 型号/数量、训练时长等算力信息，也未给出接口参数共享间隔 $m$ 等关键超参，影响复现。
- **对比边界**：明确不微调已发布检查点，因此与文献已发表数值不可直接比较，结论的"绝对水平"意义有限，主要价值在于**同一骨干下的相对改进**。

## 8. 总体评价

- **核心贡献**：论文将 VLA/WAM 的 OOD 退化归因于"视觉-动作捷径"，并提出 LIT 这一**框架无关的两阶段训练策略**——以无图像、空间目标条件化的动作先验为起点，再以位姿监督的潜在接口作为动作专家**唯一的视觉条件通路**。这一设计同时回应了"降低无关视觉敏感度"与"保留任务相关空间信息"的张力。
- **方法优点**：两阶段共享同一空间目标（Stage 1 作条件、Stage 2 作重建目标），形成自洽的闭环约束；潜在接口以逐层交叉注意力实现，可插入多种异构架构而不改动其原生结构、动作表示与生成目标，通用性较强。
- **实证强度**：跨 4 种架构、2 个模型族（VLA/WAM）、仿真与真实机器人，配套组件消融、替代设计对照、行为机制分析与训练动态分析，论证链条较完整；ID 不退化、OOD 普遍提升的结果模式对"捷径"假说构成一致支持。
- **总体判断**：该工作属于"用结构化训练约束替代输入信息堆叠"的思路，对机器人基础模型的泛化研究具有方法论参考价值；其局限主要在于对位姿监督的依赖、算力信息缺失，以及 OOD 评估维度仍偏视觉一侧。后续可探索无需显式位姿标注的空间目标构造、将接口扩展到动力学/任务级偏移，并补充推理开销与更大规模真实世界评估。
