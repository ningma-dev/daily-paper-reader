## 摘要
预训练的生成式机器人策略能够从示范中学习具有表现力的动作先验。然而，现有的强化学习方法仅引导噪声空间，而无法在生成过程中调节中间动作表征，导致性能下降和效率低下。为解决这一局限，我们提出了一种新颖的双潜在空间强化学习（DLSRL）框架，它在初始噪声引导的基础上，进一步在冻结生成器内部实现表征级控制。具体而言，我们的 actor 网络预测两个不同的潜在变量：一个用于引导行为生成的初始噪声潜在变量，以及一个用于中间特征调制的动作表征潜在变量。此外，该表征潜在变量被映射为适配器特征，并通过残差连接巧妙地注入到中间动作 token 的隐藏状态中。我们的双控制设计能够在不更新基础策略的情况下直接调整动作表征。跨生成式策略架构和机器人操作任务的实验表明，DLSRL 有效加速了在线机器人策略自适应，并取得了有竞争力的性能。我们的代码可在 https://github.com/xianchaoxiu/DLSRL 获取。

## Abstract
Pretrained generative robot policies learn expressive action priors from demonstrations. However, existing reinforcement learning methods only steer the noisy space but fail to modulate intermediate action representations during the generation process, resulting in performance degradation and inefficiency. To address this limitation, we propose a novel Dual-Latent Space Reinforcement Learning (DLSRL) framework, which complements initial-noise steering with representation-level control inside the frozen generator. Specifically, our actor network predicts two distinct latent variables: an initial-noise latent variable that steers behavior generation, and an action-representation latent variable for intermediate feature modulation. Moreover, this representation latent variable is mapped to adapter features and ingeniously injected into the hidden states of intermediate action tokens via residual connections. Our dual-control design enables direct adjustment of action representations without updating the base policy. Experiments across generative policy architectures and robotic manipulation tasks show that DLSRL effectively accelerates online robot policy adaptation and achieves competitive performance. Our code is available at \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL}.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型与生成式策略（如 Diffusion Policy、RDT-1B、π0）通过大规模示范预训练获得表达力强的动作先验，能以去噪或流匹配方式从噪声生成连续、多模态的动作序列。
- **核心问题**：当下游任务与预训练分布不一致时（尤其长时序任务中微小的时空误差即可导致失败），策略需要在线自适应。全量微调对十亿级参数模型代价高昂；参数高效微调仍依赖离线示范与梯度更新。
- **现有 RL 适配的局限**：
  - **噪声空间引导类**（如 DSRL）：只学习观测条件下的初始噪声潜变量，仅改变生成的起点、间接影响后续表征，无法直接调制生成过程中的中间动作表征。
  - **残差策略类**（如 Residual RL、Policy Decorator）：在动作生成之后或解码过程中修正最终输出，未塑造内部动作表征的演化。
- **整体含义**：作者主张需要一个**兼具全局行为选择与中间动作表征直接调制**的 RL 机制，从而在**冻结基座生成器**的前提下实现更高效的在线机器人策略适配。论文定位为**首个将初始噪声引导与动作 token 隐藏状态调制相结合**的工作。

## 2. 方法论

### 2.1 核心思想

- 将噪声空间 actor 扩展为**双潜空间 actor**：同时输出
  - **初始噪声潜变量 \(z_t\)**：控制动作生成的起点，主要影响整体行为模式（全局行为选择）；
  - **动作表征潜变量 \(u_t\)**：经轻量适配器映射为特征，直接调制生成网络中间的动作 token 隐藏状态（表示级控制）。
- 基座策略 \(G_\phi\) 的参数 \(\phi\) **全程冻结**，只更新双潜空间 actor（\(\theta\)）与适配器特征映射器（\(\omega\)）。

### 2.2 关键技术细节与公式

- **问题设定**：观测 \(o_t=(I_t,q_t,\ell)\)（图像、本体状态、语言指令），生成动作块 \(a_t\in\mathbb{R}^{H\times d_a}\)；基座策略 \(a_t=G_\phi(o_t,z_t)\)，\(z_t\sim\mathcal{N}(0,I)\)。目标是最大化折扣回报 \(J=\mathbb{E}[\sum_{t=0}^{T-1}\gamma^t r_t]\)。
- **双潜变量采样**：\((z_t,u_t)\sim\pi_\theta(\cdot\mid o_t)\)。
- **适配器映射**：\(f_t=\mathcal{A}_\omega(u_t)\)，其中 \(f_t\in\mathbb{R}^{N_a\times d_h}\)，与动作 token 隐藏状态同形状。
- **带调制的前向生成**：\(a_t=G_\phi(o_t,z_t,f_t)\)。
- **动作 token 隐藏状态调制（残差注入）**：
  - 第 \(l\) 个冻结 Transformer 块输出 \(H^{(l)}_{t,k}=T^{(l)}_\phi(\tilde{H}^{(l-1)}_{t,k},e_t,k)\)（\(k\) 为扩散去噪步或流匹配积分步）；
  - 残差注入：\(\tilde{H}^{(l)}_{t,k}=H^{(l)}_{t,k}+\delta_t\)，其中 \(\delta_t=\lambda_{\text{inj}}f_t\)，\(\lambda_{\text{inj}}\) 为全局注入强度；
  - 同一适配器特征 \(f_t\) **在选定的多个 Transformer 块与所有生成更新步之间共享**；注入仅作用于动作 token 位置，不改变视觉、语言、本体等上下文 token，也不引入额外可训练层或投影层。

### 2.3 双潜空间策略优化（算法流程）

- **双评论家**（仅训练时使用）：
  - 动作空间评论家 \(Q^{\text{act}}_\psi(o_t,a_t)\)：用在线交互数据以标准 off-policy TD 学习；
  - 潜空间评论家 \(Q^{\text{lat}}_\nu(o_t,z_t,f_t)\)：通过**值蒸馏**从动作评论家学习，损失为
    \(\mathcal{L}_{\text{distill}}=\mathbb{E}[(Q^{\text{lat}}_\nu(o_t,\hat z_t,\hat f_t)-\text{sg}[Q^{\text{act}}_\psi(o_t,\hat a_t)])^2]\)，梯度只回传到 \(\nu\)。
- **actor 更新**：最小化熵正则化目标
  \(\mathcal{L}_{\text{actor}}=\mathbb{E}[\alpha\log\pi^z_\theta(z_t\mid o_t)-Q^{\text{lat}}_\nu(o_t,z_t,f_t)]\)。
  熵正则只施加于初始噪声分支，但潜空间价值对 \(z_t\) 与 \(f_t\) 的梯度会传播到两个 actor 分支与适配器映射器。
- **训练循环（Algorithm 1）**：采样 \((z_t,u_t)\) → 计算 \(f_t,a_t\) → 环境执行得 \((r_t,o_{t+1},d_t)\) 存入回放池 → 每轮迭代 \(K\) 次：更新动作评论家 \(\psi\)；采样 \(\hat z,\hat u\) 计算 \(\hat f,\hat a\)，仅更新潜空间评论家 \(\nu\)；重采样 \((z,u)\) 后仅更新 \((\theta,\omega)\)。
- **部署时**：只保留双潜空间 actor 与适配器映射器，两个评论家丢弃。

## 6. 主要结论与发现

- **加速在线适配**：DLSRL 在 RoboMimic Lift、Can、Square 的早中期训练阶段均表现出更快成功率提升；Can 任务后期达到约 99%，DSRL 约 90%；Square 上提升更快更稳定。其**主要优势是适配更快而非最终性能一律更高**（Lift 上 DSRL 后期可接近）。
- **可迁移到流匹配 VLA 策略**：在 LIBERO 六个任务上，DLSRL 通常更快提升并维持更高成功率，且在全部六个任务上取得更短的平均回合长度（减少 15.27%–25.40%），说明双潜空间控制的收益不限于扩散策略。
- **表征调制独立有效**：DLSRL-Rep（仅隐藏状态调制、无噪声引导）在 Can 上成功率从约 27% 提升至 52%，证明仅修改中间动作 token 表征即可改善冻结基座策略，也解释了双接口协同为何加速适配。
- **注入强度存在权衡**：\(\lambda_{\text{inj}}=0.09\) 初期提升最快但后期波动大；\(0.03\) 更平稳；\(0.06\) 在速度与稳定性间最佳，最终达到 100% 成功率——有效表征控制需要足够但不过度的扰动。

## 7. 优点

- **方法创新性**：首次将 RL 控制接口从"采样初始化阶段"扩展到"中间表示阶段"，在冻结生成器内部实现表示级调制，弥补了纯噪声引导与残差修正的空白。
- **架构友好、参数高效**：适配器特征与动作 token 隐藏状态形状对齐，通过共享的残差注入作用于多个 Transformer 块与生成步，**不引入额外可训练层、不改动基座网络结构、不更新基座参数**，部署时仅保留 actor 与映射器，开销小。
- **优化设计合理**：采用动作评论家→潜空间评论家的值蒸馏，避免了梯度穿越冻结生成过程；熵正则仅加于噪声分支，兼顾探索与稳定。
- **实验覆盖两种生成范式**：同时验证扩散策略（RoboMimic）与流匹配 VLA（π0 on LIBERO），提升了结论的通用性说服力。

- **效率指标补充**：除成功率外报告平均回合长度，从执行效率维度提供额外证据。
- **代码开源**，有利于复现与后续研究。
