## 摘要
主流机器人策略通常采用马尔可夫形式，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超越当前观测的长时程记忆。现有记忆机制通常依赖语言摘要、不断增长的视觉窗口或二者组合，因此可能丢失细粒度视觉证据，或在历史覆盖与执行效率之间面临权衡。我们提出 MaP-WAM，一种记忆即计划（Memory-as-Plans）框架，它将依赖记忆的世界-动作建模分解为基于记忆锚定的规划和计划条件化的执行，并将长期多模态情景上下文用作规划时证据，而不是让执行器反复以完整历史为条件。MaP-WAM 将记忆表示为已完成的分段记录，其中包含语言指令和稀疏视觉上下文，并将这种情景记忆转换为紧凑计划，计划由下一段级语言计划和相应视觉引导组成。世界-动作-进度（World-Action-Progress，WAP）模型在未知时长内执行每个计划，在推理时联合预测动作块与相应执行进度，并通过计划-观测对齐来校准预测进度，以实现自适应分段转换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，同时结构化注意力进一步在规划与执行中实现键值缓存。MaP-WAM 在 RMBench 上以 83.3% 的成功率取得最先进性能，并在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史增长，执行器推理延迟保持大致恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

## 1. 核心问题与研究动机

- **背景**：当前主流的机器人策略（VLA 模型、World-Action Model）大多采用**马尔可夫式建模**，仅以当前观测或固定短窗口历史作为条件进行动作预测。
- **核心矛盾**：许多真实操作任务本质上是**非马尔可夫、部分可观测**的——决策所需的关键信息可能已经离开视野（如物体被遮挡、按钮颜色已被盖住、需要记忆初始布局）。因此可靠的策略必须具备**超越当前观测的长时程记忆**。
- **现有记忆机制的两难**：
  - **语言记忆**（MemER、Mem-0、MEM 等）：将历史压缩为语言摘要或子任务指令，语义紧凑可解释，但**丢失细粒度视觉与空间证据**（如精确颜色、位置）。
  - **增长式视觉窗口**（如 Causal WAM / LingBot-VA）：保留逐帧历史，视觉证据丰富，但推理延迟与显存随轨迹长度**快速增长**（论文中全上下文执行器在 1700 帧时显存超 80 GB 而 OOM），形成"历史覆盖 vs 执行效率"的权衡。
  - **持续更新记忆**（潜状态、记忆库）：早期证据可能被压缩或覆盖。
- **核心洞察**：长时程视觉历史**不必在每个控制步直接输入执行器**；它主要用于确定"下一段级计划与期望的视觉演化"，而执行只需**遵循一个记忆锚定的计划**。这直接引出 MaP-WAM 的分解式框架。

## 2. 方法论

### 2.1 总体思想：Memory-as-Plans 分解
将依赖记忆的世界-动作建模拆分为两个解耦阶段：
- **记忆锚定规划（Memory-Grounded Planning）**：处理长时程多模态情景上下文，产出紧凑计划；
- **计划条件化执行（Plan-Conditioned Execution）**：仅以固定长度的计划前缀为条件生成动作。

形式化上，一般记忆依赖策略为 π(a_{t+1:t+h} | f_{≤t}, s_t, l)；MaP-WAM 改为：
- 规划：π_P(C_k | C_{<k}, l)
- 执行：π_E(a_{t+1:t+h} | C_k, f_t, s_t, l)，且 [t, t+h] ⊆ H(C_k)

执行器输入与历史长度**无关**，故上下文长度固定。

### 2.2 结构化多模态情景上下文
- 记忆由"已完成分段记录"构成：C_i = {l_i, G_i}，其中 l_i 为该段语言指令，G_i 为**稀疏视觉上下文**。
- G_i 构造方式：把该段观测序列均分为 8 个时间桶，取每桶**最后一帧**，得 N=8 帧；初始观测单独存为 G_0 = f_0。
- 规划段 k 时，前缀含 1 + 8(k−1) 帧，经 WAN-VAE 时间压缩为 1 + 2(k−1) 个潜时间步。

### 2.3 记忆锚定的语言-视觉规划
- **语言规划器**：微调 Qwen3.5-4B，输入全局指令 l、已完成分段指令 l_{<k}、紧凑关键帧集 f*（G_0 + 每段末帧），输出下一段语言计划 l_k：π^l_P(l_k | l_{<k}, l, f*)。
- **视觉规划器（CWM）**：由 WAN-2.2-5B 初始化并微调，用标准流匹配目标生成视觉计划 G_k：
  - L^v_P = L_FM(G_k, (G_{<k}, l_k, l))，条件 c=(G_{<k}, l_k, l)，目标 y=G_k。
- **块因果注意力**：token 按段分块，块 i 只能关注块 j ≤ i，防止未来信息泄漏，并让"已完成证据"成为**可缓存的静态前缀**。
- 语言计划 + 视觉计划共同构成记忆锚定计划 C_k = {l_k, G_k}，耦合任务语义与预期视觉演化。

### 2.4 World-Action-Progress（WAP）执行器
- **动机**：计划的执行时长事先未知（取决于任务与随机执行动态），因此需要显式的"进度"坐标。
- **架构**：以预训练视频 DiT 为基础，通过 **Mixture-of-Transformers（MoT）** 增加动作专家（1.02B 参数，隐藏维 1024）与进度专家（207M 参数，隐藏维 256），联合建模未来视觉动态、动作块与进度序列。
- **进度定义**：训练时为每段标注归一化进度 p_t = (t−i)/(j−i)。
- **输入/注意力结构**：视觉计划作为静态干净前缀，当前观测为干净状态 token，未来视觉/动作/进度为含噪预测目标；计划前缀与动态 token 解耦，可在整段执行中缓存复用；动作/进度 token 与未来视觉 token 之间双向屏蔽（未来视觉预测仅作辅助训练目标，推理时可省略）；交叉注意力中所有 token 关注语言计划 l_k，动态 token 额外条件于本体状态 s_t 与当前进度 p_t。
- **训练目标**：对 y_v=f_{t+1:t+h}、y_a=a_{t+1:t+h}、y_p=p_{t+1:t+h} 分别施加条件流匹配损失：
  - L^m_E = L_FM(y_m, c)，c = (G_k, l_k, f_t, s_t, p_t)
  - 总损失 L_E = λ_v L^v_E + λ_a L^a_E + λ_p L^p_E（实验中三者均为 1.0）

### 2.5 闭环规划与执行
- **计划-观测对齐（进度校准）**：部署时真值进度不可得，递归使用预测进度会累积漂移。视觉计划按归一化进度索引，故可检索当前估计附近的计划帧，用 RGB 空间**平均绝对像素差**（轻量、免训练）选出与执行后观测最相似的帧，将进度条件更新为 p_t 与该帧进度索引的均值。
- **进度门控分段切换**：对最近动作的预测进度取平均，超过阈值 τ（=0.95）即判定当前段完成，终止当前计划并触发下一段规划。
- **上下文更新**：切换后把**真实执行观测**（而非生成的视觉计划）均匀重采样为稀疏视觉上下文 G_k，追加进情景记忆 {l_k, G_k}，保持记忆锚定于真实观测。
- **推理流程**（Algorithm 1 概要）：提取关键帧 → 生成语言计划 → 生成视觉计划 → 预填充并缓存 WAP 计划前缀 KV → 循环（校准进度 → 生成动作与进度序列 → 执行并收集观测 → 计算完成分数 → 更新进度与时间）→ 段完成后重采样视觉证据并更新情景上下文、k←k+1。

## 3. 实验设计

- **仿真 Benchmark：RMBench**（Chen et al., 2026），专为长时程记忆依赖操作设计，要求策略推理当前观测中已不可得的历史信息。
  - 含 5 个 M(1) 任务（依赖一次过去观测）与 4 个 M(n) 任务（依赖多次）。
  - 协议：每任务 50 条官方专家演示训练，每任务 100 次评估 rollout，全局 seed 0。
  - 对比基线：DP、π0.5、X-VLA、Mem-0、WLA-0、LingBot-VA。

## 6. 主要结论与发现

- **性能**：MaP-WAM 在 RMBench 上取得 **83.3%** 总平均成功率，全面超越所有代表性基线（DP 5.8%、π0.5 10.4%、X-VLA 9.8%、Mem-0 42.0%、LingBot-VA 77.1%）。
  - Swap T（需记忆初始物体位置）达 96%，Press Button（需区分视觉相似但语义不同的执行阶段）达 96%。
  - 最难的 Observe and Pick Up 从最强基线的 9% 提升至 19%。
- **真机**：Find Button 88%、Press Buttons 68%，平均 **78.0%**；基线在 Find Button 上仅靠随机选择取得非零成功率，在 Press Buttons 上完全失败。
- **效率**：执行器采用固定计划前缀 + KV cache，**每动作块延迟约 827 ms，且随历史帧增长近似恒定**；相比之下全上下文执行器在 1500 帧时延迟约为零历史时的 4 倍，1700 帧时显存超 80 GB 而 OOM。
- **消融结论**：
  - 视觉计划与视觉记忆均不可缺：去掉视觉计划或改用当前观测条件的生成模型，在 Observe and Pick Up、Swap T 上成功率显著下降，说明细粒度历史视觉证据必须通过情景记忆进入规划。
  - 进度建模至关重要：classification 变体平均仅 37.0%；去掉进度条件在 Press Button 上从 96% 降至 18%（无法区分按下/松开阶段）；

- 去掉**进度校准**同样带来明显退化，说明仅靠模型自回归预测进度会累积漂移，而基于 RGB 像素差检索计划帧的免训练校准是把"计划进度"与"真实执行状态"对齐的关键环节。
- 综合来看，三项消融共同支持论文的核心主张：**长时程记忆的价值不在于每步喂入执行器，而在于塑造计划**；一旦计划（语言 + 视觉）与执行进度被正确锚定，执行器只需固定长度上下文即可完成长时程、非马尔可夫任务。

## 7. 局限性、风险与可讨论之处

- **对"分段"结构的依赖**：MaP-WAM 的情景记忆以"已完成分段记录 {l_i, G_i}"为原子单位，隐含假设任务可被自然地切分为若干带语言标注的子段。论文的仿真与真机任务均具有较清晰的分段语义（如"看白板→按左键→按中键→按右键"）。对于连续、无明确阶段边界的任务（如精细连续操控、装配中的连续力控），如何定义段、如何生成段级语言指令（是否仍依赖人工或强 VLM 标注）尚未充分讨论。
- **进度坐标的适用边界**：归一化进度 p_t=(t−i)/(j−i) 对"线性推进"的阶段成立，但对存在**回退、重复、条件分支**的任务（如需要反复尝试、失败后重试），单一标量进度可能不足以刻画状态；论文的 Press Buttons 涉及重复按键，属于较温和的情形，更复杂的非单调过程值得进一步验证。
- **规划器与执行器的训练不对称**：规划器（VLM + CWM）为多任务训练，而 WAP 执行器为单任务训练。这一设定虽声称遵循 MEM-0 的做法，但使得"跨任务泛化能力来自规划层还是执行层"难以从现有实验中分离；同时也意味着部署到新任务时需要为每个任务单独训练执行器，工程成本不低。
- **推理成本的实际量级**：论文强调执行器延迟随历史近似恒定（约 827 ms/动作块），但这一数值本身对高频闭环控制而言偏高（约 1.2 Hz 的有效决策频率）。虽然论文的对比焦点是"延迟不随历史增长"，但绝对延迟是否满足动态任务（如抓取移动物体、人机交互）的实时性要求，论文未展开讨论。此外，规划阶段仍需调用 4B 级 VLM 与 5B 级视频扩散模型，切换分段时的端到端停顿时间未被报告。
- **评测统计强度**：如第 5 节所述，仿真仅使用单一全局 seed，未报告多种子方差或置信区间；真机每任务 50 次试验、共 2 个任务，规模有限。83.3% 与 77.1%（LingBot-VA）之间的差距虽大，但缺少统计显著性检验，且基线数据主要来自各自论文报告而非统一复现，存在环境、训练数据与评测协议差异带来的混杂。
- **潜在的数据与标注成本**：情景记忆中的段级语言指令 l_i、训练时的进度标注 p_t 都需要额外监督信号。论文未明确说明这些标注是来自原始演示数据的既有结构、还是通过某种自动化流程生成，这直接影响方法在真实数据规模下的可扩展性。
- **失败模式与安全性**：进度校准采用"平均绝对像素差"检索最相似计划帧，当场景存在大面积纹理重复、光照突变或计划本身偏离真实演化时，该相似度可能被误导，进而导致进度估计错误并触发错误的段切换（τ=0.95）。论文未提供失败案例的定性分析或对该阈值的敏感性研究。

## 8. 总体评价与贡献定位

- **概念层面的主要贡献**：论文提出"**Memory-as-Plans**"这一分解视角，把"记忆该做什么"与"如何执行当前这段"解耦，从架构上把"上下文长度随历史增长"这一根本瓶颈转化为"计划前缀长度固定"。这一思想不局限于本文的具体实现，原则上可迁移到其他需要长时程记忆的具身策略（例如把规划器替换为更强 VLM、把执行器替换为其他动作头），具有较强的可扩展性。
- **技术层面的贡献**：
  1. **结构化多模态情景上下文**（段级语言 + 8 桶稀疏关键帧）在"语义紧凑"与"视觉证据保留"之间取得了比纯语言记忆或全帧窗口更实用的折中；
  2. **块因果注意力**使已完成证据成为可缓存的静态前缀，是把"记忆"从计算瓶颈变为"一次性预填充成本"的关键工程手段；
  3. **World-Action-Progress 执行器**引入显式进度坐标，并通过 MoT 在同一扩散框架内联合建模视觉动态、动作与进度，为"执行时长事先未知"这一问题提供了可学习、可校准的表示；
  4. **免训练的 RGB 进度校准 + 进度门控切换**构成一个轻量闭环，避免了递归进度预测的漂移累积。
- **实证层面的贡献**：在专为记忆依赖设计的 RMBench 上把总平均成功率从最强基线的 77.1% 提升到 83.3%，并在两个真机记忆任务上取得 78.0% 的平均成功率，同时给出量化的延迟/显存对比（执行器延迟不随历史增长、全上下文方法在 1700 帧 OOM），证据链在"性能—效率—消融"三个维度上是自洽的。
- **可改进的方向**：引入多种子与置信区间以增强统计说服力；在统一训练/评测协议下复现基线；扩展到无清晰分段、存在回退与分支的连续任务；报告端到端（含规划停顿）的实时性指标；补充进度阈值与相似度校准的敏感性分析及失败案例。
- **一句话总结**：MaP-WAM 的核心论断是——**长时程记忆应当用于"决定下一段要发生什么"，而不是"逐步喂给控制器"**；它用"记忆锚定的语言-视觉计划 + 固定前缀的 World-Action-Progress 执行器"实现了这一论断，并在记忆依赖操作任务上同时取得了更强的成功率和近似恒定的推理开销。
