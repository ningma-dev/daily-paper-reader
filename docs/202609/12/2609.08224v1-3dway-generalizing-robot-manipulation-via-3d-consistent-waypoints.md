## 摘要
中间表示是弥合可泛化操作策略与大规模预训练视觉-语言模型（VLM）之间模态差距的关键。其中，基于轨迹的表示能够紧凑地表示与运动相关的线索，但大多数现有方法在2D图像空间中预测轨迹，从而导致固有的3D歧义。此外，将2D轨迹与深度结合使用仍会使自由空间路点存在歧义，限制了可靠的3D推理。为解决这一问题，我们提出从多视角图像预测3D一致路点（3DWay）。通过将3D路点预测重新表述为生成多视角一致的2D路点，随后进行几何三角测量，我们实现了显式的3D运动指定，同时保留了预训练VLM的强大先验。预测出的路点可以引导现有VLA模型获得更好的泛化能力，或直接在简单任务上执行。大量实验表明，3DWay显著提升了3D空间定位和视觉-语言推理能力，展现出用于可泛化机器人操作的强大潜力。代码将发布于 https://github.com/ziqin-h/3DWay。

## Abstract
Intermediate representations are key to bridging the modality gap between generalizable manipulation policies and large-scale pretrained vision-language models (VLMs). Among these, trajectory-based representations compactly represent motion-relevant cues, yet most existing approaches predict trajectories in 2D image space, resulting in intrinsic 3D ambiguity. Moreover, using 2D trajectories with depth still leaves the free-space waypoints ambiguous, limiting reliable 3D reasoning. To address this, we propose predicting 3D consistent waypoints (3DWay) from multi-view images. By reformulating 3D waypoints prediction as generating multi-view consistent 2D waypoints followed by geometric triangulation, we enable explicit 3D motion specification while preserving the strong priors of pretrained VLMs. The predicted waypoints can guide existing VLA models for better generalization or be directly executed on simple tasks. Extensive experiments show that 3DWay substantially improves 3D spatial grounding and vision-language reasoning, demonstrating strong potential for generalizable robot manipulation. Codes will be released at https://github.com/ziqin-h/3DWay.

## 1. 核心问题与整体含义

- **研究背景**：机器人操作的核心挑战是跨任务、跨场景、跨本体泛化。模仿学习、强化学习通常依赖任务特定监督，难以脱离训练分布；而基于大规模预训练 VLM 构建 VLA 模型成为有前景的方向。
- **核心矛盾**：VLM 的视觉-语言模态是离散、Token 化、2D 感知的，而机器人动作是连续、高维、3D 空间的。直接微调 VLM 为 VLA 容易造成视觉-语言先验遗忘，泛化受限。
- **中间表示的作用**：为弥合模态差距，现有工作常引入中间表示。其中，基于轨迹的表示能紧凑编码运动意图，但多数方法在 2D 图像空间预测轨迹，存在固有深度歧义。
- **2D / 2.5D 的不足**：
  - 2D 轨迹只能提供投影域中的部分动作信息，缺乏 3D 物理空间指导。
  - 将 2D 轨迹用深度反投影为 2.5D 路点，虽引入深度，但自由空间中的 3D 点不唯一，且对深度噪声敏感。
- **论文目标**：提出 **3DWay（3D Consistent Waypoints）**，从多视角 RGB 图像预测多视图一致的 2D 路点，再通过几何三角化恢复显式 3D 路点，在保留 VLM 强视觉-语言先验的同时，实现可靠 3D 运动指定。
- **整体含义**：3DWay 既是可直接执行的中间表示，也可作为条件引导现有 VLA 模型，提升数据稀缺、新本体、新任务下的泛化能力。

## 2. 方法论

### 2.1 核心思想

- 不直接让 VLM 回归 3D 坐标，而是将 3D 路点预测**重构为多视图一致的 2D 路点预测**。
- 训练时利用已知相机内外参，将真实 3D TCP 轨迹投影到各视角，得到 2D 监督。
- 推理时，VLM 根据多视角图像和语言指令输出各视角 2D 路点，再通过**多视图三角化**恢复 3D 路点。

### 2.2 问题形式化

- 输入：多视角 RGB 图像 \(I=\{I_v\}_{v=1}^V\)、相机内参 \(K\)、外参 \(T\)、语言指令 \(\ell\)。
- 目标映射：  
  \[
  W_{3D} = \Phi(I, K, T, \ell)
  \]
- 训练监督：将真实 3D 路点投影为 2D：  
  \[
  W_{2D} = \pi(K, T, W_{3D})
  \]
- VLM 预测多视图一致 2D 路点：  
  \[
  \hat{W}_{2D} = VLM(I, \ell)
  \]
- 推理时三角化：  
  \[
  \hat{W}_{3D} = Tri(\hat{W}_{2D}, K, T)
  \]

### 2.3 关键技术细节

- **3DWay 定义**：机器人末端工具中心点 TCP 在世界坐标系中的简化 3D 点序列，同时编码末端执行器状态，如“Close Gripper”“Open Gripper”。
- **训练数据处理**：
  - 根据末端执行器模型和机器人状态计算原始 TCP 轨迹。
  - 使用 Ramer-Douglas-Peucker 算法对轨迹简化，得到稀疏路点。
  - 通过透视投影生成各视角 2D 路点监督。
  - 使用自动评分机制和开放词汇检测器过滤低质量数据。
- **VLM 微调**：
  - 基座模型采用 NVILA 系列，包括 2B、8B、15B。
  - 先在大规模空间 affordance 数据集 RoboPoint 上微调 1 epoch，增强像素级点预测能力。
  - 再在 RLBench、DROID、RH20T 上训练，约 290 个任务、134k 条轨迹。
  - 以文本格式表示 2D 路点坐标，使用语言建模目标进行监督，避免额外回归头或复杂损失。
- **执行方式**：
  - **直接执行**：3DWay-TD，使用固定 Top-Down 抓取和基于路点的运动规划，适合旋转不变简单任务。
  - **自适应路点引导集成**：将 3D 路点序列按当前末端状态选择局部时间窗口 \(W_{3D}^t\)，与机器人状态、视觉观测和语言指令一起输入 VLA：
    \[
    A = VLA(o_t, q_t, \ell, W_{3D}^t)
    \]
  - 以 π0 为基础 VLA，在分布内微调阶段集成 3DWay，无需修改架构。

## 6. 主要结论与发现

- **3DWay 具备直接可执行性**：
  - 在 RLBench seen 设置下，3DWay-TD 达到 84.8% 平均成功率。
  - 在 unseen 设置下达到 64.0%，显著高于 π0 的 12.0% 和 π0.5 的 18.8%。
- **3DWay 具备较强泛化能力**：
  - VLABench 五个维度平均成功率达 37.7%，超过 π0.5 的 31.3%。
  - 在 cross-category、common-sense、unseen texture 等维度表现较好。
- **3DWay 可增强 foundation VLA**：
  - 在 RLBench few-shot 中，标准微调 π0 仅 17.6%。
  - 零样本 3DWay 增强提升至 38.1%，少样本 3DWay 增强提升至 46.1%。
  - 仅用 20% 训练数据即可达到标准微调使用更多数据时的平均水平。
- **真实世界验证有效**：
  - 基本任务平均成功率从标准 π0 的 21.7% 提升到 3DWay-augmented π0 的 65.8%。
  - 视觉泛化任务从 6.7% 提升到 55.0%。
  - 语义描述任务从 2.5% 提升到 51.7%。
- **多视图一致性监督关键**：
  - 独立视角监督 D0 仅 22.0%，远低于多视图一致监督 A0 的 64.0%。
- **对相机外参和骨干规模较鲁棒**：
  - 15B 与 8B 差距不大，2B 仍有 50.1%。
  - 测试时相机外参小幅或大幅扰动下，成功率仍保持 61.6% 和 58.4%。
- **跨本体与相机配置稳定**：
  - 真实世界 3DWay-TD 在不同机器人、夹爪、相机配置下平均成功率约 43.9%–45.5%。

## 7. 优点

- **方法设计简洁有效**：将 3D 预测转化为多视图一致 2D 预测，再三角化，避免直接 3D 回归的模态鸿沟。
- **保留 VLM 先验**：在原始语言建模监督范式内输出 2D 坐标，避免复杂动作头，减轻视觉-语言能力遗忘。
- **无需深度传感器**：仅依赖多视角 RGB 和相机参数，规避深度噪声与自由空间歧义。
- **双重用途**：既可直接执行简单任务，也可作为条件增强 π0 等 foundation VLA。
- **多视图一致性监督**：通过训练数据构造和统一多视图监督，显著优于独立视角监督。
- **跨本体、跨相机鲁棒**：真实实验显示对机器人平台和相机布置具有较好迁移性。
- **实验覆盖较广**：涵盖 RLBench、VLABench、真实机器人、few-shot、消融和可视化分析。
- **开源承诺**：代码将公开，有利于复现和后续研究。

## 8. 不足与局限

- **未显式建模姿态**：当前主要生成平移路点，没有显式 SE(3) 姿态或方向，限制旋转相关、精细操作任务。
- **依赖预标定相机**：方法假设相机内外参已知，双视角验证为主，在遮挡、动态变化或未标定环境中鲁棒性可能下降。
- **集成策略仍属初步**：3DWay 与 foundation VLA 的联合推理潜力未充分挖掘，当前只是将局部路点窗口作为额外条件。
- **直接执行策略简单**：3DWay-TD 采用固定 Top-Down 策略，仅适合旋转不变或较简单任务。
- **基准选择偏差风险**：RLBench 主要选取旋转不变任务，可能有利于固定策略；未与同类型轨迹中间表示方法全面对比。
- **真实实验规模有限**：真实任务数量、演示数量、rollout 数相对有限，统计显著性和失败模式分析不够充分。
- **泛化边界未完全验证**：对杂乱场景、动态环境、长时序任务、多阶段推理、接触丰富任务的适用性仍待检验。
- **资源报告不完整**：仅给出 8×A100 和训练时长，缺少总 GPU 小时、能耗、不同模型规模成本等细节。
- **未来方向**：扩展至 SE(3) 姿态建模、层次子任务推理、自标定多视图三角化，以及更紧密可学习的 VLA-3DWay 集成机制。
