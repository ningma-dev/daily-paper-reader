## 摘要
潜在世界-动作模型通过在特征空间中预测与动作相关的视觉子目标，避免了渲染未来像素。LaWAM确立了这一公式，但其原始呈现将世界模型、多模态骨干和部署检查点紧密耦合在一起。我们引入了AcrossWAM1.0，这是对这一潜在世界-动作栈的模块化和缩放研究。我们并不将潜在子目标作为新算法呈现，而是明确模块边界：策略适配器产生潜在动作和动作生成上下文；保留的潜在世界解码器将预测的转移基于当前场景；流匹配专家生成连续动作块。我们进一步将仅训练用的教师模型与推理图分离，并提供可验证的部署导出。在2,000个配对的LIBERO片段上，将Qwen3-VL-2B骨干替换为Qwen3.5-0.8B，成功率分别为97.45%与98.00%（差异为-0.55个百分点；精确McNemar检验p=0.266）。这并不证明等价性，但满足预设的两点保留标准。紧凑的、推理可及的检查点包含1,472.6M个唯一参数，比原始2B策略少42.4%，而所有保留的张量与源检查点逐位相同。此外，使用MiniCPM-V适配器冒烟测试检查跨家族执行；闭环跨家族迁移仍是一个开放评估。因此，AcrossWAM1.0为紧凑的潜在世界-动作策略贡献了一个可审计的软件和评估边界，区别于LaWAM原始的潜在子目标贡献。

## Abstract
Latent world-action models avoid rendering future pixels by predicting an action-relevant visual subgoal in feature space. LaWAM established this formulation, but its original presentation left the world model, multimodal backbone, and deployment checkpoint tightly coupled. We introduce AcrossWAM1.0, a modularization and scaling study of this latent world-action stack. Rather than presenting latent subgoals as a new algorithm, we make the module boundary explicit: a policy adapter produces latent-action and action-generation contexts; a retained latent world decoder grounds the predicted transition in the current scene;and a flow-matching expert generates continuous action chunks. We further separate training-only teachers from the inference graph and provide a verifiable deployment export. On 2,000 paired LIBERO episodes, replacing a Qwen3-VL-2B backbone with Qwen3.5-0.8B yields 97.45% success versus 98.00% for the 2B model (a-0.55percentage-point difference; exact McNemarp=0.266). This does not prove equivalence, but it meets a prespecified two-point retention criterion. The compact, inference-reachable checkpoint contains 1,472.6M unique parameters, 42.4% fewer than the original 2B policy, while all retained tensors are bitwise identical to the source checkpoint. Cross-family execution is additionally checked with a MiniCPM-V adapter smoke test; closed-loop cross-family transfer remains an open evaluation. AcrossWAM1.0 therefore contributes an auditable software and evaluation boundary for compact latent world-action policies, distinct from LaWAM's original latent-subgoal contribution.

## 1. 核心问题与整体含义

**研究动机与背景：**
- LaWAM 此前确立了"潜在世界-动作模型"（latent world-action model）的计算范式：不渲染像素，而是在特征空间中预测与动作相关的视觉子目标，以避免像素生成的高算力开销。
- 然而，LaWAM 的原始实现将**世界模型、多模态骨干（VLM backbone）、部署检查点**三者紧耦合，使得模块边界仅停留在纸面上，代码层面难以替换或缩小骨干模型。
- 实际痛点在于：替换多模态骨干会牵动 token 约定、隐藏维度、图像调用接口、检查点可达性乃至词表处理等一系列连锁问题。
- AcrossWAM1.0 并不宣称提出新的潜在子目标算法，而是聚焦于一个**系统性与工程性问题**：如何让 LaWAM 式计算变得**模块化、紧凑、可审计**，从而支撑真正可部署的紧凑策略栈。

**总体含义：**
论文通过显式定义"策略-世界-动作"接口契约、隔离训练模块与推理模块、提供精确的部署导出与逐位张量验证，把一个算法层面的成果转变成一个**可复用、可审计的软件与评估边界**。

## 2. 方法论

### 2.1 总体架构
AcrossWAM1.0 将系统拆分为三个核心可推理模块（外加训练专用教师）：

1. **策略适配器（Policy Adapter）**：封装骨干差异，将 VLM/VAM 骨干的处理隔离在适配器内，通过固定接口返回两类上下文——切换上下文（transition context）与动作上下文（action context）。
2. **潜在世界解码器（Latent World Decoder）**：将预测的潜在动作 $\hat{z}_t$ 解码为与当前场景锚定的空间视觉子目标 $\hat{h}_{t+\Delta}$。
3. **流匹配动作专家（Flow-DiT Action Expert）**：基于语义上下文与潜在子目标，通过流匹配生成连续动作块。

### 2.2 概率公式
论文将策略分解为显式中间变量的联合概率：

$$p(a,\ \hat{h}_{t+\Delta},\ z_t \mid o_t, \ell, s_t) = p_\theta(z_t \mid o_t,\ell) \cdot p_\omega(\hat{h}_{t+\Delta} \mid h_t, z_t) \cdot p_\eta(a \mid c_\theta, h_t, \hat{h}_{t+\Delta}, s_t)$$

其中 $h_t = f_\psi(o_t)$ 是冻结的 DINOv3 patch 表征。

### 2.3 关键技术细节

**Stage 1——学习带动作语义的潜在世界模型（继承自 LaWAM）：**
- 冻结 DINOv3 编码器提取当前与未来帧特征；
- 逆动力学 Q-Former 将帧对压缩为 32 维潜在动作 $z_t$（变分高斯分布）；
- 潜在世界解码器使用 **AdaLN（自适应层归一化）**调制，由 $z_t$ 条件化每个 transformer 块的 self-attention 与 MLP，预测未来特征 $\tilde{h}_{t+\Delta}$；
- 损失 = 未来特征回归（SmoothL1）+ 状态位移回归 + KL 正则。

**Stage 2——从语言与视觉预测潜在动作：**
- 骨干中设置两组 query：**8 个潜在动作查询**（收集推断转移所需的上下文）与 **8 个流查询**（暴露上下文给动作专家）；
- 通过单查询交叉注意力映射器 $M_\rho$ 压缩得到预测潜在动作 $\hat{z}_t$；
- 蒸馏损失 $L_{\text{distill}} = \|\hat{z}_t - z_t^*\|_2^2$ 让策略先验对齐冻结教师的潜在目标；
- 由保留的世界解码器生成潜在子目标，并施加未来特征监督 $L_{\text{subgoal}}$。

**流匹配动作专家：**
- 使用 Flow Matching 在条件 DiT 中生成动作；两个条件流分别携带（a）骨干上下文和（b）当前+未来视觉 token 拼接；
- 推理时用 ODE 求解器从高斯噪声积分 10 步得到 50 维动作块（覆盖 1.2 秒）；
- Stage 2 总损失：$L_{S2} = L_{\text{flow}} + 0.1 \cdot L_{\text{subgoal}} + 0.1 \cdot L_{\text{distill}}$。

**模块边界与证据分层（3.6 节关键创新）：**
论文显式区分三个常被混为一谈的命题层级：
1. **接口兼容性**（adapter 能执行 I/O 契约，用两个 Qwen 变体 + MiniCPM-V 冒烟测试验证）；
2. **闭环骨干缩放**（同一模块契约下新训练策略保留任务性能，用 Qwen3-VL-2B vs Qwen3.5-0.8B 验证）；
3. **冻结跨家族迁移**（要求共享不变的世界解码器跨异构骨干迁移，论文明确**不声称**该层级）。
- 推理图只保留：骨干 → 潜在动作预测 → 世界解码器 → 流匹配动作专家；逆动力学教师、状态头、未来帧全部从推理中**移除**。

## 6. 主要结论与发现

1. **紧凑缩放有效**：Qwen3.5-0.8B 在 2,000 个 LIBERO 片段上达到 **97.45%**，比 Qwen3-VL-2B 的 98.00% 低 0.55 个百分点，满足预设的 2 点保留标准；精确 McNemar p = 0.266，未检测到配对差异（但不声称等价性）。
2. **参数量显著缩减**：部署导出的紧凑检查点仅含 **1,472.6M 个唯一推理参数**，较 2B 原始策略减少 **42.4%**；所有保留张量与源检查点**逐位一致**——模块切除不损害策略权重本身。
3. **模块边界可落地**：策略适配器、潜在世界解码器、流匹配专家三者形成了可替换、可验证的接口契约；训练教师（逆动力学 Q-Former、状态头）可干净地从推理图中移除。
4. **跨家族执行部分可行**：MiniCPM-V 适配器冒烟测试证明接口抽象有效（隐藏状态变化 0.33、训练损失下降、不依赖 Qwen 专有的图像参数），但暴露出词表无空余槽位等移植失败模式——**冻结的跨家族闭环迁移仍是开放的**。
5. **语言接地存在缺陷**：仅改左右指令时，基线策略只有 27.4% 的完成放置服从指令；语言 CFG 变体提升到 50.3% 但以非冲突指令下 1%→10% 的任务崩溃率为代价。

## 7. 优点

- **研究问题定位精准**：不重复 LaWAM 的算法贡献，而是解决"模块化/紧凑化/可审计性"这一真实工程空白，贡献边界清晰；
- **证据分层透明**：明确区分接口兼容、闭环缩放、冻结跨家族迁移三个层级，并明确声明哪些主张已被验证、哪些是开放假设——这种克制在机器人论文中少见；
- **部署验证严谨**：逐位张量检查（1,078 保留 / 321 移除 / 718 别名恢复）+ CPU 加载器验证，将"删除训练状态"从口头承诺变为可审计结果；
- **统计方法规范**：预设保留标准、配对 McNemar、报告不一致计数，避免了事后归因与弱等价性推断；
- **外部基准对比诚实**：明确标注参数与成绩转录自原文、账目口径各异，不做误导性的 SOTA 声明；
- **识别并报告了适配器契约的真实设计约束**（如 MiniCPM-V 缺少未用嵌入槽位、隐藏维度对齐需求）。

## 8. 不足与局限

- **闭环证据仅限 Qwen 家族与 LIBERO 单一基准**：MiniCPM-V 仅验证执行契约而非控制质量，尚无任何跨家族 AcrossWAM1.0 闭环结果；
- **不构成冻结世界解码器的跨骨干迁移证明**：紧凑实验中世界解码器被微调（非冻结），因此"一个冻结世界解码器适配异构骨干"的更强假设未经验证；
- **单一检查点无法覆盖训练种子方差**：配对设计控制了评估随机性，却未控制训练随机性；
- **缺少紧凑模型推理延迟与峰值内存数据**："紧凑"目前仅通过参数量定义，未证明推理效率或显存收益；
- **语言接地诊断范围窄**：仅在两个 RoboTwin 任务上、仅考察左右方向；同时揭示了智能体对语言指令的服从存在较严重问题（27.4%），这是潜在部署风险；
- **导出的检查点未完成加速器+仿真器的完整冒烟测试**，部署验证停留在状态字典与 CPU 加载层面；
- 算法本身未做消融（如 λp / λd 权重、查询数量、子目标监督的必要性等均无系统性敏感性分析）。

**总体评价**：这是一篇定位清晰、工程严谨的模块化/缩放研究。它的价值不在于新算法，而在于把 LaWAM 的潜在世界-动作计算整理成一个**可替换骨干、可切除训练模块、可逐位审计**的部署边界，并以受控的配对实验证明了紧凑骨干在此边界下可保留任务性能。其局限也正如作者自己反复强调的：当前证据支持 Qwen 家族内的紧凑缩放与跨家族接口执行，尚不支持冻结的、跨家族的、性能保持的可移植性假设。
