## 摘要
视觉-语言-动作(VLA)策略利用预训练的视觉-语言模型(VLM)来指导机器人控制的动作生成。VLM提供从局部视觉几何到抽象的、语言对齐语义的层级视觉-语义表示，这些表示随层变化；因此，不同的操作任务可能需要不同的层表示组合。同时，动作模块维护在动作计算过程中演化的中间表示，这些表示可能为后续决策提供有用信息。然而，现有的VLA接口在表示访问方面提供的灵活性有限：VLM信息通过每个动作层的固定层分配来暴露，而中间动作状态仅通过残差流隐式传播，没有显式的重用。我们引入了LayerRoute，一种动作条件化的表示路由接口，能够自适应地访问VLM层和动作表示。其层混合路由器动态地组合缓存的VLM表示，而动作状态重读则重用早期的动作表示。在多种仿真和真实世界基准测试中，LayerRoute持续改进StarVLA-π和π_0.5，在LIBERO Long上实现了高达7.2的提升，仅增加了0.31% / 3.87%的参数。消融研究验证了动作条件化层路由的益处，而路由分析揭示了跨动作层和任务设置的结构化分配模式。

## Abstract
Vision-Language-Action (VLA) policies leverage pretrained vision-language models (VLMs) to guide action generation for robot control. VLMs provide hierarchical visual-semantic representations that evolve across layers, from local visual geometry to abstract, language-aligned semantics; different manipulation tasks may therefore require different mixtures of layer representations. Meanwhile, the action module maintains intermediate representations that evolve throughout action computation and may provide useful information for subsequent decisions. However, existing VLA interfaces offer limited flexibility in representation access: VLM information is exposed through fixed layer assignments for each action layer, while intermediate action states are only propagated implicitly through residual streams without explicit reuse. We introduce LayerRoute, an action-conditioned representation routing interface that enables adaptive access to VLM layers and action representations. The Layer Mixture Router dynamically forms mixtures of cached VLM representations, while Action-State Reread reuses earlier action representations. Across diverse simulation and real-world benchmarks, LayerRoute consistently improves StarVLA-$π$ and $π_{0.5}$, achieving up to 7.2 gains on LIBERO Long with only 0.31% / 3.87% additional parameters. Ablation studies validate the benefit of action-conditioned layer routing, while routing analyses reveal structured allocation patterns across action layers and task settings.

### 1. 核心问题与整体含义（研究动机与背景）

当前 VLA 策略虽然将预训练 VLM 的视觉-语义先验用于机器人动作生成，但在**信息利用接口**上存在两大结构性限制：

- **VLM 分层表示暴露方式固定**：现有 VLA 架构中，每个动作层被暴露给预先指定的 VLM 层，无法根据当前动作计算需求或任务类型动态调整需要访问的 VLM 深度。然而，已有的表征分析表明，VLM 浅层包含纹理、几何、空间模式等细粒度视觉证据，深层包含语言对齐的抽象语义。不同操作任务（如抓取定位、接触敏感操作、指令接地、子目标选择）需要不同层信息的组合，固定分配难以适配这种多样性。
- **动作模块内部状态访问受限**：动作模块中早期动作中间状态只能通过残差流隐式传播，后续 block 无法直接重访早期中间表示。这种"仅残差"的访问模式在长时程任务中可能阻碍信息检索与利用。

为克服上述双层限制，论文提出 **LayerRoute**——一种动作条件的表示路由接口。其核心思想是：对缓存的多层 VLM 表示和动作模块自身的中间表示，应以一种**自适应、按需组合**的方式暴露给动作生成过程。

### 2. 提出方法与关键技术细节

#### 核心设计思想
LayerRoute 包含两大模块：**Layer Mixture Router（层混合路由器）** 和 **Action-State Reread（动作状态重读）**。前者解决 VLM 层的自适应选择问题；后者解决动作中间状态的显式复用问题。

#### （一）Layer Mixture Router（VLM 层混合路由）
在选定的动作层 s，基于**当前动作状态**决定如何组合多个候选 VLM 层特征：

- 输入：当前动作状态 a(s) 与候选 VLM 状态 {V_n}_{n∈C_s}。
- 对动作状态和每个 VLM 层状态分别做池化 → 归一化 → 投影到共享路由空间（维度 d_sel=256）得到 query q(s) 与 key k_n(s)。
- 通过缩放点积相似度计算路由 logits → softmax 归一化得到各 VLM 层的权重 α_n(s)。
- 输出：∑α_n(s)·V_n，作为后续交叉注意力的上下文。
- 特性：每个"动作层×样本"共享同一组深度分布，但该分布随动作状态而**动态改变**。初始化为均匀分布。

关键公式导向：
- q(s) = W_q LayerNorm(Pool(a(s)))
- k_n(s) = W_k LayerNorm(Pool(V_n))
- ℓ_n(s) = ⟨q(s), k_n(s)⟩/√d_sel
- α_n(s) = softmax(ℓ(s))
- Ṽ(s) = Σ α_n(s)·V_n

#### （二）Action-State Reread（动作状态重读）
在动作层 s，为每个动作 token 提供对**早期动作状态**的直接访问：

- 维护一个每层可学习的 query 向量 q_A(s)（跨 token 共享）。
- 对每个 token t，对其在不同来源状态（初始动作状态、若干保留的中间层状态、当前状态）上的表示计算兼容度 → softmax → 加权得到重读状态。
- 输出进入 FFN 之前，形成可读取的组合状态。
- 与 Layer Mixture Router 的关键区别：Router 对每个样本预测一组深度分布；Reread 产生**token 级**权重，允许同一动作序列中的不同 token 以不同方式选择历史状态。

#### 架构实例化

- **StarVLA-π**（Qwen3-VL + 36 层 DiT，含18个交叉注意力层）：
  - 保留 6 个 VLM 层状态 [5, 11, 17, 23, 29, 35]，所有 18 个交叉注意力层均可访问这些候选并进行动作条件路由。
  - 路由得到的 Ṽ(s) **直接替代**本来的固定编码器上下文；Action-State Reread 应用于全部 36 个 DiT block（含18个自注意力层）。

- **π0.5**（PaliGemma + flow matching 动作专家）：
  - 在线存储 VLM 边界状态 [2, 5, 8, 11, 14, 17]，受因果可用性约束。
  - LayerRoute 通过轻量的 8 头无共享交叉注意力适配器，将选出的 VLM 融合表示注入本地的原生前缀/后缀联合注意力之前。

### 6. 主要结论

- LayerRoute 在仿真基准上稳定提升两个代表性 backbone：
  - LIBERO Long：+7.2（StarVLA-π）、+3.6（π0.5）；
  - LIBERO Avg 4：+2.3（StarVLA-π）、+1.3（π0.5）；
  - SimplerEnv WidowX：+2.5（StarVLA-π）、+5.6（π0.5）；
  - RoboCasa-GR1：+1.2（StarVLA-π）、+5.5（π0.5）。
- 参数开销极小（0.31% / 3.87%），延迟增量（10.03% / 25.04%）换来明显收益，效率-准确度权衡良好。
- 真机测试中 π0.5 + LayerRoute 在 PnP / Wipe board / Clean Table 上分别提升 +8.0 / +4.0 / +6.0 pp。
- 消融证明：**动作条件**的路由（对比动作无关 query）带来稳定的额外提升；VLM 层路由与动作状态重读机制之间存在**互补性**。
- 路由分析显示：路由器学到的是**结构化的深度分配策略**——随训练越来越具选择性；随动作层推进从浅层转向中深层；不同任务套件呈现明确偏好（空间任务偏浅层、Goal 任务偏深层等），与 VLM 层功能的语义解释一致。

### 7. 优点

- **问题定位清晰**：识别出 VLA 两种表征访问受限根源（外部 VLM 层访问固定 + 内部残差流限制），并针对性设计。
- **方法轻量、即插即用**：总参数量仅增加 0.31%~3.87%，对两个架构集成方式进行了适配设计，无需额外训练损失或辅助监督。
- **实验设计严谨**：
  - 三个独立 seed；数据源与基线严格一致；不同变体间唯一差异是接口本身；
  - 多种对照控制很好地剥离了动作条件路由与固定路由的贡献；
  - 路由诊断中的熵、JS 散度测量和对任务套件偏好的分析为解释方法提供了机制上的可解释性。
- **跨骨干、跨场景验证充分**：验证范围包括架构（DiT vs flow matching）、VLM（Qwen2.5/3-VL、PaliGemma、MiMo、Cosmos）与机器人本体、任务族、仿真到真实场景的泛化。
- **真实机器人实验**补充了仿真结果的可转移性。

### 8. 不足与局限

- **计算开销与部署限制**：相比原始接口产生了可见的推理延迟（π0.5 达 +25.04%），在低算力边缘设备上的部署存在障碍，文中也承认这是潜在局限。
- **骨干覆盖仍有限**：仅评估 StarVLA-π 与 π0.5 两种 VLA 架构；对更多高吞吐、实时执行型 VLA 或扩散动作头是否适用仍需验证。
- **路由粒度选择的折中**：18 层粒度路由造成优化不稳定和更大开销，最终只采用 6 层粒度、每样本共享深度分布的方案；这种简化会损失 token 级动态匹配能力（token 级注意力权重只能在 Reread 中体现）。
- **真实机器人评测规模相对有限**：在每种任务中仅一个技能类型、固定物理场景；纳入更多任务/排列才可评估泛化到非固定场景的稳健性。
- **依赖中间状态访问**：方法依赖各层 VLM 和动作状态表示缓存，需要针对新的 VLA 架构做架构特定的设计，部分黑盒模型或不支持中间层导出的系统无法直接应用。
- **个别对照在解释上有细微混淆**：如表 13 的静态混合行同时禁用 Action-State Reread；作者明确指出了这一点，但仍需要注意解释限定路径。
