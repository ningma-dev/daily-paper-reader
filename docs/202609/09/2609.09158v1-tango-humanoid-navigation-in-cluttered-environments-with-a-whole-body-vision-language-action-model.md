## 摘要
我们研究了使用仿人机器人在杂乱室内环境中导航的问题。与将导航建模为2D路径规划问题的传统方法不同，仿人机器人在杂乱环境中的行进需要连续的、基于几何感知的全身适应性调整，包括协调的手臂放置、躯干调整和步态调节，以在复杂3D空间中实现无碰撞移动。我们引入了TANGO，这是第一个用于在杂乱环境中进行语言引导的仿人机器人全身视觉-语言导航框架。给定自然语言指令和以自我为中心的RGB观察，TANGO直接预测29自由度的关节空间动作，以支持下游全身控制。我们完全在仿真中训练TANGO，通过全局路径规划、运动学全身运动生成、考虑障碍物的运动编辑和基于强化学习的跟踪，合成多样的无碰撞行进行为。该流程为学习语言条件的全身策略提供了动态可行的动作监督。在广泛的仿真实验中，TANGO在视觉-语言导航中展现出最先进的性能，同时在需要障碍协商的挑战性场景导航中优于强大的模块化基线。最后，我们将TANGO零样本部署在Unitree G1仿人机器人上，并观察到在杂乱的真实世界场景中，无需任何真实世界导航数据训练即可实现稳健的语言引导行进。

## Abstract
We study the problem of navigating cluttered indoor environments with a humanoid robot. Unlike conventional methods that model navigation as a 2D path planning problem, humanoid traversal in cluttered environments requires continuous geometry-aware whole-body adaptation, including coordinated arm placement, torso adjustment, and gait modulation for collision-free movement through complex 3D spaces. We introduce TANGO, the first whole-body vision-language navigation framework for language-conditioned humanoid traversal in cluttered environments. Given a natural-language instruction and egocentric RGB observations, TANGO directly predicts 29-DoF joint-space actions for downstream whole-body control. We train TANGO entirely in simulation by synthesizing diverse collision-free traversal behaviors via global path planning, kinematic whole-body motion generation, obstacle-aware motion editing, and RL-based tracking. This pipeline provides dynamically feasible action supervision for learning language-conditioned whole-body policies. In extensive simulation experiments, TANGO demonstrates state-of-the-art performance in vision-language navigation, while outperforming strong modular baselines in navigating challenging scenes requiring obstacle negotiation. Lastly, we deploy TANGO zero-shot on a Unitree G1 humanoid robot, and observe robust language-guided traversal in cluttered real-world scenes without training on any real-world navigation data.

- **现有方法的不足**：
  - 传统导航方法将任务建模为 **2D 路径规划**问题，只关注机器人底盘的平面轨迹，缺乏对 3D 空间的几何感知与全身适应能力；
  - 现有视觉-语言-动作（VLA）模型大多局限于桌面级操作任务，没有充分探索语言引导的全身移动控制。
- **核心洞见**：需要一种直接把语言指令和第一视角RGB观测映射为全身关节动作的框架，让机器人在遇到低矮障碍、狭窄缝隙等场景时能自主做出“弯腰”、“侧身”、“用手拨开障碍物”等全身性适应行为。
- **解决思路**：提出 **TANGO**（首个全身视觉-语言导航框架），通过仿真合成大规模多样的无碰撞行进行为来训练策略，并直接预测 29 自由度（29-DoF）关节动作，零样本迁移到真实 Unitree G1 仿人机器人。

## 二、方法论

### 1. 总体架构
TANGO 是一个**语言条件的全身 VLA 策略**，以自然语言指令和仿真器/真实机器人上的第一视角 RGB 观测为输入，直接输出 29-DoF 关节空间动作（位置增量），供底层全身控制器跟踪执行。

### 2. 策略网络（VLA 主干）设计
- 采用预训练的 **生成式视觉-语言模型（GRID）** 作为骨干；
- 网络输入包括：
  - 语言指令的嵌入（embedding）；
  - 以自我为中心的 RGB 观测（经过视觉 tokenizer）；
  - 机器人本体状态（proprioception）；
  - 时间步嵌入（step embedding）；
  - 历史肢体动作嵌入。
- 输出：29 维关节目标位置增量。
- 训练方式：使用一套预训练权重（仅微调一部分），通过两个目标函数联合训练：
  - **GRID supervisor**：对学生策略输出的动作 token 进行监督；
  - **RL 优化**：通过最大化期望回报进一步微调策略；
  - 采用**按速度桶（speed bucket）条件训练**，使单一策略能适应多种步频/速度，提升灵活性。

### 3. 教师策略（Teacher Policy）—— 数据生成管线
由于手动标注全身关节级导航数据不可行，作者设计了全仿真数据生成流程，包括四个步骤：

- **全局路径规划**：使用 A* 搜索在已知地图上生成通往目标（由语言指令指定）的全局路径；
- **运动学全身运动生成**：基于有限的低层运动基元动作集（如前进、转弯、侧移、弯腰、伸手等），沿全局路径生成全身运动轨迹（含手臂、躯干、腿部动作），形成候选通道（corridor）；
- **考虑障碍物的运动编辑（Motion Editing）**：这是核心创新步骤——
  - 用胶囊体（capsules）近似机器人各身体部位；
  - 对生成的全身运动进行碰撞检测；
  - 若检测到某个部位即将与障碍物碰撞（如头部会撞到低矮物体、手臂会卡住），则启动**避障动作编辑器**，在该时间点前插入预变换的避碰动作序列（如低头、侧身、抬手拨开障碍物），对原有轨迹进行局部编辑修正；
  - 反复迭代直至产生无碰撞轨迹。
- **基于强化学习的跟踪**：将编辑后的运动学参考轨迹作为监督信号，训练一个 RL 跟踪器（教师策略）将其转化为动态可行的物理动作。

### 4. 模型训练监督流程
- 教师策略产生的**动态可行动作**作为动作监督信号，配合语言指令条件，共同训练最终的学生策略（即 TANGO 本体）；
- 该流程实现了“语言条件 + 碰撞规避 + 动态可行”三重目标的统一。
