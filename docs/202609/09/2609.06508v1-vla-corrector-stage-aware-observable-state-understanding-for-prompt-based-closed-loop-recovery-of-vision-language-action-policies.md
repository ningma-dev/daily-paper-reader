## 摘要
长期视野下的机器人操作任务若依赖视觉-语言-行动（VLA）策略，仍易受执行时偏差的影响，因为最终任务成功与否几乎无法为诊断和纠正由动作噪声、物体位移或目标错位导致的失败提供信息。我们提出了一种阶段感知的失败验证与提示恢复框架，使得固定的VLA策略无需参数更新或特权模拟器状态即可实现闭环纠正。该框架引入一个基于可观测历史的习得验证器，通过对多视角视觉观测、本体感觉状态和执行动作进行时序建模，联合估计操作进度与执行风险。为提供可解释的任务理解，我们用语义进度阶段（包括接近、对齐、抓取、搬运和放置）来表示操作执行过程，并识别各阶段特有的失败模式。一旦检测到异常执行，该框架保留原始指令并生成阶段条件的恢复提示，使得同一个冻结的VLA策略能够产生纠正动作。在LIBERO和LIBERO Plus上的多轮广泛评估表明，所提方法在多种扰动下显著提高了闭环可靠性。在不访问特权物体或目标坐标的情况下，习得验证器在评估设置中取得了与特权规则验证器相当的恢复性能。这些结果表明，可观测的视觉-本体感觉-动作历史足以推断潜在任务状态，并能为现有VLA策略实现实用化的失败恢复。

## Abstract
Long-horizon robot manipulation with Vision-Language-Action (VLA) policies remains vulnerable to execution-time deviations, as final task success provides little information for diagnosing and correcting failures caused by action noise, object displacement, or goal misalignment. We introduce a stage-aware failure verification and Prompt Recovery framework that enables closed-loop correction of a fixed VLA policy without parameter updates or privileged simulator states. The framework introduces an observable-history-based Learned Verifier that jointly estimates manipulation progress and execution risk by temporally modeling multi-view visual observations, proprioceptive states, and executed actions. To provide interpretable task understanding, we represent manipulation execution through semantic progress stages, including approach, alignment, grasp, transport, and placement, and identify stage-specific failure patterns. Upon detecting abnormal execution, the framework preserves the original instruction and generates a stage-conditioned recovery prompt, allowing the same frozen VLA policy to produce corrective actions. Extensive multi-round evaluations on LIBERO and LIBERO Plus demonstrate that the proposed approach substantially improves closed-loop reliability under diverse perturbations. Without access to privileged object or goal coordinates, the Learned Verifier achieves recovery performance close to that of the privileged rule-based verifier in the evaluated settings. These results show that observable visual-proprioceptive-action history is sufficient to infer latent task states and enable practical failure recovery for existing VLA policies.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：在长时程机器人操作中，Vision-Language-Action（VLA）策略虽然能够生成符合指令的动作，但缺乏对自身执行过程是否正确进行验证的能力——“知道该做什么，却不知道自己做得对不对”。
- **失败来源不一定是任务理解错误**：实际环境中的失败往往源于交互过程中的累积执行偏差，如微小动作噪声、物体位移、抓取不完美、目标区域偏移等。对于长时程任务，如果策略在这些偏离状态中继续盲目前行，往往没有足够的余裕进行自主恢复。
- **最终任务成功信号的信息量严重不足**：二元化的最终成功/失败反馈无法指出失败发生在哪个阶段、因何失败，难以指导纠正。
- **生物体的启示**：生物智能体通过持续自我监控来评估执行是否在正确轨道上，而当前 VLA 系统缺少这种“执行状态感知”能力。
- **核心研究问题**：智能体能否**仅从可观察的交互历史**中推断自身执行状态，并利用这种理解提升闭环可靠性——同时**不需要修改底层策略参数**，也**不访问特权环境信息**（如物体坐标、BDDL谓词、任务标志等）？
- **整体意义**：这项研究将“执行可靠性”从“策略能力”中解耦出来，为现有开环式 VLA 策略提供了一条低成本地获得闭环纠错能力的现实路径，对推动 VLA 从动作生成走向可靠具身智能具有重要意义。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架（VLA-Corrector）

- 采用**冻结的 VLA 策略**（π0.5，即 OpenPI 的 pi05_libero）作为基础控制器，不对其参数进行任何更新。
- 在策略之外增加一套**“检测-纠正”（detect-and-correct）回路**，实现闭环监控，流程可概括为：
  观测与指令 → π0.5 策略 → 动作块（action chunk） → 风险验证器 → 触发门控（trigger gate） → 提示恢复（Prompt Recovery） → 恢复原任务。

### 2.2 问题形式化

- 当前观测定义为一个元组：ot =（agent视图RGB、wrist视图RGB、8维本体感觉状态）。
- 可观测历史定义为：ht = {(Iai, Iwi, si, ui)}，其中有当前时刻以前的双视图图像、本体感觉向量和实际执行动作，严格按时间顺序，不含未来信息。
- 冻结策略映射为：Ut = πθ(q, ht)，即根据语言指令和观测历史输出长度为7的动作块。
- 风险标签与估计问题：定义二进制风险变量 ft（在预测时域内是否发生失败事件），验证器输出风险概率 pt = Pr(ft = 1 | ht)，经阈值 τ 得到二值判定。
- 恢复提示构造：q_rec = q ⊕ rt，即保留原指令、拼接阶段条件化的恢复片段；恢复动作仍由同一冻结策略生成；恢复完成后恢复原始指令。

### 2.3 特权规则验证器（Privileged Rule-Based Verifier）

- 用于构建“强化上界”与离线教师标签，仅限仿真内部使用。
- 追踪状态机：APPROACH（接近）→ ALIGN（对齐）→ GRASP（抓取）→ MOVE（搬运）→ PLACE（放置）→ SUCCESS（成功）。
- 利用模拟器提供的物体/区域位姿、末端执行器运动学、距离、抓爪状态、运动谓词、任务标志等特权信号，在出现规则定义失败或超时时输出结构化恢复记录（阶段，上下文）。
- 在线部署时不可用，作为对照的非部署型监视器。

### 2.4 学习验证器（Learned Verifier）——论文的核心技术

- **输入形式**：以每两个环境步骤采样一次的**8步历史窗口**；可选两种图像视图，存储分辨率 112×112。
- **视觉特征提取**：采用**无参数的统计特征化器**对每个视图做 3×4×4 的自适应平均池化，并与 RGB 均值、标准差拼接，每个视图得到 54 维特征；两视图拼接后投影到 64 维。
- **状态-动作投影**：15维状态-动作向量投影到 32 维。
- **时序融合**：将视觉和状态-动作特征拼接后送入**GRU（隐藏维64）**进行时序融合。
- **两个预测头**：
  - 执行风险头：σ(w⊤zt + b)，输出风险概率；
  - 阶段分类头：对五种非终止阶段 {APPROACH, ALIGN, GRASP, MOVE, PLACE} 做 Softmax 分类。
- **公式表达**：
  vt = Proj64(Visual(Iat, Iwt));
  xt = Proj32([st; ut]);
  zt = GRU([vt; xt]);
  pt = σ(wf⊤zt + bf);
  stage 输出 = argmax Softmax(Wstage·zt + bstage)。
- **教师监督方式的关键设计**：验证器不回归特权坐标，而是将特权信息转换为有语义的操作化标签：
  1. 阶段标签：五个非终止阶段；
  2. 风险标签：故障事件附近的窗口标记，min|e−t| ≤ 10 时标签为1；>20 时标签为0；中间模糊区间的样本被排除在训练之外。
- **在线触发门控**：阈值 τ = 0.40，需要连续4个窗口都超过阈值才确认触发，并设置10步冷却期（cooldown）防止冗余干预。每两个环境步骤查询一次验证器。
- **恢复路由**：根据预测阶段路由到对应阶段提示（如 approach、grasp 等），置信度低于 0.9625 则采用通用恢复提示（UNKNOWN_FAILURE）。

### 2.5 提示恢复接口（Prompt Recovery）

- 对特权规则验证器和学习验证器统一开放同一接口，保证比较公平。
- 恢复提示拼接格式为：“Immediate recovery: ” + 阶段指令；原有任务指令始终保留。
- 核心逻辑：保持同一策略、同样的执行接口，将“验证器触发通路”作为唯一变量，隔离性能差距来源。

## 6. 论文的主要结论与发现

- **恢复能力不需要特权状态**：仅通过可观测的视觉-本体感觉-动作历史即可推断潜在任务状态，达成接近特权验证器的恢复效果，性能差在2.4个百分点以内。
- **成绩提升显著**：
  - 标准 LIBERO：No Assistance 70.9% → Rule + Prompt 82.6% (↑11.7pp) → Learned Binary + Prompt 80.2% (↑9.3pp)。
  - LIBERO Plus 难度4：73.7% → 79.7% → 79.0%。
  - LIBERO Plus 难度5（Object 与 10 套件汇总）：66.7% → 73.6% → 72.6%。
- **对扰动的鲁棒性提升明显**：组合扰动条件下提升幅度最大（No Assistance 70.7% → Rule + Prompt 82.6%，Learned 80.2%）；物体位移和目标区域偏移是相比动作噪声更关键的收益场景。
- **检测质量**：学习验证器 Accuracy 93.1%、Recall 94.9%、Precision 61.1%、Positive F1 74.4%、AUROC 0.902、AUPRC 0.7123；在线门控后触发精确率提升到79.2%，确认约77.0%（Rule）与75.0%（Learned）的恢复成功率。
- **延迟极低**：验证器推理 p50 = 0.457ms，p95 = 0.589ms，能够支撑低成本实时监测。
- **消融证明设计合理**：完整模型（时序+融合）在Positive F1（74.35%）上大幅胜过单帧（59.33%）和其他掩蔽输入变体（视觉单独68.03%、状态-动作单独58.55%），验证了**时序与多模态互补信息**同时必要。
- **真实世界迁移有效**：平均成功率82.5%（基线）→ 88.3%（方法），绝对提升5.8个百分点，无需真实数据训练即可在新任务上转移部署。
- **总体判断**：执行风险检测可以可靠地委派给数据驱动模块；VLA-Corrector 为无法获得真值状态的真实环境提供了一种实用的闭环恢复路径。

## 7. 优点

- **问题选得好**：指出 VLA 策略“知道做什么、但不知道自己是否做对”的能力鸿沟，准确抓住了当前 VLA 系统与可靠具身智能之间被忽视的关键环节。
- **“冻结策略 + 外部监视器”的解耦设计**：无需重训大模型、无需新动作头、无需直接修改轨迹即可获得恢复能力，对已有 VLA 策略友好，工程落地价值高。
- **用“可观测历史推断潜在状态”而非“特权坐标回归”**：在问题设定上既前瞻又务实——在线只用 RGB + 本体感觉 + 动作，教师标签仅在离线构造验证器时使用。
- **语义阶段（approach/align/grasp/move/place）作为可解释中间表征**：既做风险检测又做恢复提示路由，比单一异常检测器更具可解释性；阶段预测被明确定位为“路由器”而非风险分类器，避免功能混淆。
- **实验设计与报告细致公平**：特权上界与可部署方法共用同一份 Prompt Recovery 接口；门控参数在验证集上固定；将最终成功率、触发质量、恢复成功率、动作成本分开报告，避免“只看准确率高分/成功率高”造成的误解；扰动协议可复现，且严格控制初始状态与种子。
- **反馈标签设计巧妙**：对时间窗口采用“10步内为正、20步外为负、中间区域剔除”的三段式处理，规避了失败边界模糊窗口带来的标签噪声。
- **推理速度极快 + 统计特征化器无参数**：显示出设计追求轻量部署的意识。

## 8. 不足与局限

- **真实世界实验范围有限**：仅3项任务、每任务40次试验，且只比较了No Assistance与Learned配置之间的最终成功率差异；没有在真实物理平台上运行特权规则验证器作为对照，也没有在真实场景中报告触发精度/召回或恢复失败的具体模式。
- **学习验证器训练数据不足的隐患**：只有120个收集回合、训练30轮、CPU训练，验证器对未见过场景、新物体、新扰动类型的泛化上限没有被系统性测试（尤其是跨任务迁移指标没有给出详细数据）。
- **高精度低召回报告方式不全面**：目标验证器 Precision 61.1%、Positive F1仅74.4%这一水平还偏低——虽然在线门控把触发精度提升到79.2%，但论文对误报可能打断正常执行的次数/代价没有做更多详细剖析。
- **真实世界对照中“80.2% vs 82.6%”的差距集中在某些子任务上时未被详细解释**：这个看似小的差距，是否在若干任务上分布不均，实际上值得在文中补充逐任务分解。
- **π0.5单模型依赖**：所有结论建立在单种基础策略上，排除了不同VLA架构的泛化性；机制上看似策略无关，但从实验层面没有给出第二种VLA策略的验证。
- **规则验证器的状态机设计场景通用性未知**：该状态机对操作程序较固定的LIBERO任务很适用，但对柔性物体、工具使用、非刚体交互等更难操作的任务是否还能保持充分有效性没有讨论。
- **扰动类型仅限平移与噪声**：没有旋转扰动、光照变化、遮挡、力反馈异常、多物体碰撞等实际操作中同样常见的扰动。
- **算力信息不透明**：论文没有说明训练验证器与跑完整仿真需要多少GPU时间，致使其他研究者难以评估复现的总成本。
