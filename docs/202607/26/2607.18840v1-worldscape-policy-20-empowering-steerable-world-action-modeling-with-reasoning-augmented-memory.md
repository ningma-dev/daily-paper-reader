## 摘要
世界动作模型（WAM）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了有前景的范式。然而，现有的WAM受限于有限的时间上下文、粗糙的片段级语言监督以及主要基于文本的条件设定，这阻碍了任务进度追踪和细粒度的语言-视频-动作对齐，同时限制了视觉上下文推理和跨实体迁移。在本文中，我们介绍了WorldScape Policy 2.0，一种具有推理增强型长短期记忆的可控WAM。其因果短期视觉记忆提供最近的观测作为DiT预填充，以保留局部交互动态，而其长短期事件记忆将历史VLM输出组织为全局历史、局部活跃和事件边界表示，用于进度感知检索。检索到的历史增强感知和自回归生成的规划令牌，为自主规划提供隐式子目标条件；语义强制进一步将事件级指令语义转移到这个潜在规划路径中。为了建立细粒度的多模态可控性，我们构建了ManipEvent-5M，一个事件基础的具身预训练数据集，包含近500万个事件片段，带有对齐的动作轨迹、片段级任务指令、片段级子任务描述、目标图像和视频演示。这些设计提供了一个统一的界面，用于从高级指令进行自主规划，以及从细粒度文本、目标图像或视频上下文提示进行可控执行。在仿真和真实世界平台上的实验展示了在长时域自主规划、细粒度指令遵循和上下文适应方面的卓越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**核心问题**：现有世界动作模型（WAMs）在三个方面存在显著局限：
- **时间上下文有限**：大多仅依赖当前观测或短窗口历史，无法感知任务进度（如相同桌面外观下，不同子阶段需要不同动作）。
- **语言监督粗粒度**：同一episode的不同段共享相同任务级指令，导致模型学习视觉捷径而非细粒度“语言-视频-动作”对齐，对原子动作变化不敏感。
- **交互界面单一**：仅支持文本提示，缺乏目标图像、演示视频等视觉模态输入，限制了视觉上下文推理和跨实体迁移。

**整体意义**：论文旨在将WAM从短时预测模型升级为可控的长时策略，使其能同时支持从高层指令自主规划、从细粒度文本/图像/视频提示可控执行，并在仿真和真实机器人平台上验证效果。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 提出**推理增强型长短期记忆（Reasoning-Augmented Long Short-Term Memory）**，包含两个互补的记忆：
  - **短期视觉记忆（Short-Term Visual Memory）**：因果DiT保留最近观测的VAE潜在作为预填充，维持局部交互动态。
  - **长短期事件记忆（Long Short-Term Event Memory）**：VLM分支将历史chunk组织为**全局历史（Global-History）**、**局部活跃（Local-Active）** 和**事件边界（Event-Boundary）** 三种内存视图，通过检索和门控融合增强当前推理令牌。
- **语义强制（Semantic Forcing）**：在自主规划模式下，通过将VLM隐式推理潜在与T5编码的细粒度子任务描述进行对齐（余弦相似度损失），将事件级语义传递到潜在规划路径中。
- 构建**ManipEvent-5M**数据集：近500万事件片段，包含动作轨迹、层次化文本、目标图像、视频演示。

### 关键技术细节
- **统一动作表示**：每个动作表示为相对于chunk首帧的delta位姿（平移差分 + 连续6D旋转 + 绝对夹爪指令），双臂为20维向量。
- **模态条件注入**：
  - 细粒度指令：T5嵌入→DiT交叉注意力。
  - 高层指令：VLM联合观测和事件记忆生成推理潜在→DiT条件。
  - 视觉提示（目标图像/演示视频）：作为持久视觉预填充，通过因果自注意力影响未来帧。
- **事件记忆构建**：
  - 每个历史chunk的VLM输出（感知令牌+规划令牌）经过注意力池化压缩为gist令牌，保留完整规划令牌。
  - 三类视图：全局历史（任务嵌入+均值池化压缩的全历史）、局部活跃（最近S_e个chunk）、事件边界（基于语义变化检测TopK选择）。
- **检索与门控融合**：对当前推理潜在q_t，与拼接的三种视图+压缩全历史进行交叉注意力，然后通过可学习门控γ_t调节注入量。
- **三阶段训练课程**：
  1. 事件级多模态WAM预训练：仅在ManipEvent-5M上训练视觉视频-动作DiT和动作编解码器，无事件记忆。
  2. 记忆感知中训练：引入VLM规划分支和事件记忆，使用语义强制损失将子任务语义对齐到推理潜在。
  3. 下游交互后训练：根据任务模式激活相应组件（自主规划/细粒度指令/视觉提示），适应具体实体和动作分布。

### 主要公式
- 联合损失：\( \mathcal{L} = \mathcal{L}_{act} + \lambda_w \mathcal{L}_{world} + \lambda_s \mathcal{L}_{sem} \)
  - \(\mathcal{L}_{act}, \mathcal{L}_{world}\)：动作和视频潜在上的流匹配L2损失（原始空间）。
  - \(\mathcal{L}_{sem}\)：归一化余弦相似度损失，固定T5目标并停止梯度，仅更新映射器。

1. **WorldScape Policy 2.0在RoboTwin 2.0的50个任务上取得平均94.3%成功率**，超过所有对比方法（如π0.5的79.8%和Fast-WAM的91.9%），且在干净和随机化下表现几乎一致，展现强鲁棒性。

## 7. 优点

- **统一的多模态可控界面**：一个模型同时支持自主规划、细粒度指令、目标图像、演示视频等多种输入模式，无需任务特定配置。
- **新颖的记忆架构**：因果短期视觉记忆与语义长短期事件记忆解耦，既保留局部动态又支持全局进度推理，并通过门控机制有效融合。
- **大规模事件级数据集ManipEvent-5M**：融合人/机器人多种数据源，提供层次化标注（任务级、事件级）、视觉目标、演示视频，填补了细粒度多模态WAM训练数据空白。
- **三阶段训练策略**：先学基础可控生成，再学记忆推理，最后适应下游，分离了不同能力的学习，降低了优化难度。
- **充分的实验覆盖**：仿真50任务、多种真实场景、多个baseline，消融设计清晰。

## 8. 不足与局限

- **真实实验规模有限**：仅5个真实场景，每个20次试验，统计稳健性不足；未对每个任务细粒度分析失败原因。
- **未报告随机种子或方差**：无法判断方法稳定性，对比可能受单次运行影响。
- **资源消耗未公开**：训练需要多GPU和大模型（5B DiT + 4B VLM），实际部署成本高，未讨论效率。
- **语义强制损失权重λ_s固定且很小（0.001）**：对推理潜在的对齐约束较弱，可能限制了子任务推理的精确性；未探讨权重敏感性。
- **事件记忆构建依赖VLM输出**：VLM质量直接影响记忆检索效果，对VLM（Qwen3-VL-4B）的依赖可能导致错误传播，尤其在领域外。
- **未见对高度动态或复杂接触任务（如开瓶、插拔）的专门测试**：RoboTwin 2.0任务可能偏向结构化操作，泛化到非结构化场景有待验证。
- **消融实验仅展示总成功率**：未按任务类型（长时vs短时、是否需要记忆）拆分，无法判断各组件在不同场景下的针对性贡献。
- **方法局限于双机械臂平台**：对单臂或移动操作平台可能需要调整动作表示，论文未讨论扩展性。
