## 摘要
非抓取操作常被用作机器人抓取的预备步骤，然而现有方法通常需要预先定义目标物体姿态。但在实践中，物体往往具有多种可抓取构型，且期望姿态事先未知。我们将面向抓取的非抓取操作重新定义为优化一个以物体为中心的可抓取性目标，而非达到特定姿态。我们从合成抓取中构建可抓取集，并定义一个可抓取性场，用于衡量物体构型对于成功执行抓取的适合程度。该标量度量为强化学习提供了密集的学习信号，并决定何时终止操作。这产生了一个由单一策略驱动的闭环操作-抓取流程。在仿真和真实机器人上的实验表明，该策略能可靠地将物体重新配置为可抓取状态，并过渡到抓取，无需外部规划器或手动指定的停止条件。预测的可抓取距离与真实世界抓取成功率相关，表明所学表征捕捉了物体构型的抓取可行性。

## Abstract
Non-prehensile manipulation is often used as a preparatory step for robotic grasping, yet existing approaches typically require a predefined target object pose. In practice, however, objects admit multiple graspable configurations and the desired pose is not known in advance. We reformulate non-prehensile manipulation for grasping as optimizing an object centric graspability objective rather than reaching a specific pose. We construct a graspable set from synthesized grasps and define a graspability field that measures how suitable an object configuration is for successful grasp execution. The scalar measure provides a dense learning signal for reinforcement learning and determines when to terminate manipulation. This yields a closed-loop manipulation-to-grasp pipeline driven by a single policy. Experiments in simulation and on a real robot show that the policy reliably reconfigures objects into graspable states and transitions to grasping without external planners or manually specified stopping conditions. The predicted graspability distance correlates with real world grasp success, which indicates that the learned representation captures grasp feasibility of object configurations.

- **问题**：非抓取操作（如推、滑）常作为机器人抓取的预备步骤，但现有方法（如CORN、DyWA）需要预先定义目标物体位姿。然而，实际物体往往存在多种可抓取构型，目标位姿事先未知，且将操作简化为到达一个特定姿态并不合理——它可能导致策略优化几何相似性而非抓取成功率，甚至使物体远离更容易抓取的构型。
- **动机**：作者提出应把非抓取操作重新定义为**优化一个以物体为中心的可抓取性目标**，而非到达预设姿态。通过定义一个可抓取性场（Graspability Field）来衡量当前物体构型对于成功抓取的适合程度，并以此驱动操作和终止决策，形成闭环操作-抓取流程。

## 2. 提出的方法论：核心思想、关键技术细节

- **核心思想**：放弃目标位姿，转而学习一个可抓取性场 \( \tilde{d}(s_o) \)，该场对物体构型空间中的每个点赋予一个标量距离（越小表示越适合抓取）。策略通过强化学习（PPO）最大化该场的下降，从而自然地引导物体进入可抓取区域。
- **关键技术细节**：
  1. **可抓取参考集构建**：使用现成的抓取合成模型（SE(3)-DiffusionFields）从物体点云生成多个候选抓取，再通过固定末端执行器姿态反算出物体参考位姿，形成可抓取集 \( S_g = \{\hat{s}^i_o\}_{i=1}^G \)。
  2. **可抓取性场定义**：
     - 计算当前物体构型与每个参考构型之间的几何距离 \( D(s_o, \hat{s}^i_o) \)（基于关键点欧氏距离）。
     - 使用 soft-min 聚合得到平滑距离 \( d_{\text{soft}}(s_o) = -\tau \log \sum_i \exp(-D(s_o, \hat{s}^i_o)/\tau) \)。
     - 加入时间锚定项 \( \lambda D(s_o, \hat{s}^{i^*}_o) \)（其中 \( i^* \) 是上一时刻最近的参考索引），增强一致性：\( \tilde{d}(s^t_o) = d_{\text{soft}}(s^t_o) + \lambda D(s^t_o, \hat{s}^{i^*}_o) \)。
  3. **奖励函数**：基于势能塑形（Potential-based Reward Shaping），奖励可抓取性场的下降：\( r_t = \gamma \Phi(\tilde{d}(s^{t+1}_o)) - \Phi(\tilde{d}(s^t_o)) \)，其中 \( \Phi(d) = k_1 \beta^{k_2 d} \)。
  4. **策略架构**：教师-学生框架。教师使用完整点云和PPO训练；学生使用部分点云（多视图渲染）和GRU处理部分可观性，预测操作动作、可抓取性距离和最终抓取位姿。学生通过行为克隆+距离回归+抓取位姿回归蒸馏。
  5. **操作-抓取过渡**：预测的距离经物体尺寸归一化后，若在时间窗口 \( K \) 内持续低于阈值 \( \epsilon \)，则终止操作并执行预测的抓取。无需外部规划器或手动停止条件。
