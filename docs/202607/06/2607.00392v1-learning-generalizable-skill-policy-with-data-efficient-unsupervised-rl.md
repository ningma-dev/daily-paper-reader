## 摘要
无监督强化学习旨在无外部奖励的情况下预训练可扩展的、以技能为条件的策略，作为下游控制任务的基础。尽管近期取得进展，但我们认为当前离策略的无监督强化学习方法受到两个被忽视的关键瓶颈的限制：（1）非平稳的技能语义和（2）脆弱的泛化能力。为解决这些挑战，我们提出GenDa（可泛化高效数据智能体），一个统一框架用于鲁棒的无监督强化学习。首先，我们引入一种技能重标注机制以缓解非平稳性并显著提升预训练的数据效率。其次，我们提出互补信息瓶颈，鼓励学得的技能策略聚焦于以自我为中心的特征，并对下游任务的分布偏移具有鲁棒性。通过多种实验，我们证明GenDa显著提升了无监督强化学习的可扩展性，并具有优越的泛化能力和数据效率。我们的代码和视频可在https://ihatebroccoli.github.io/official-GenDa获取。

## Abstract
Unsupervised Reinforcement Learning (URL) aims to pre-train scalable, skill-conditioned policies without extrinsic rewards, serving as a foundation for downstream control tasks. Despite recent progress, we argue that current off-policy URL methods are limited by two critical, overlooked bottlenecks: (1) non-stationary skill semantics and (2) brittle generalization. To address these challenges, we propose GenDa (Generalizable Data-efficient Agent), a unified framework for robust unsupervised reinforcement learning. First, we introduce a skill relabeling mechanism to mitigate non-stationarity and significantly improve data efficiency for pre-training. Second, we propose a Complementary Information Bottleneck (CIB), encouraging the learned skill policy to focus on ego-centric features and become robust to distribution shifts for downstream tasks. Through various experiments, we demonstrate that GenDa significantly enhances the scalability of URL with superior generalizability and data efficiency. Our code and videos are available at https://ihatebroccoli.github.io/official-GenDa.

## 1. 核心问题与整体含义（研究动机和背景）
- **研究背景**：无监督强化学习旨在无外在奖励下预训练可扩展的技能条件策略，作为下游控制任务的基础。近年来，离策略URL方法因能复用经验而具有数据效率潜力。
- **核心问题**：现有离策略URL方法面临两个被忽视的关键瓶颈：
  - **技能语义非平稳性**：在离策略学习中，同一技能标号 `z` 在不同训练阶段产生不同行为轨迹（语义漂移），导致重放缓冲中的样本过时，注入高方差噪声，降低数据效率。
  - **泛化脆弱性**：技能策略常直接以包含全局上下文信息（如绝对坐标、视觉背景）的完整状态为输入，导致策略过度拟合特定全局上下文，在分布偏移（如初始位置变化、背景变化）下执行同一技能时行为不一致，限制了技能的可复用性。
- **整体含义**：解决这两个瓶颈是实现URL可扩展性（预训练效率+下游鲁棒性）的关键，旨在为真实机器人学习等交互成本高的场景提供更实用的基础策略。

## 2. 方法论：核心思想、关键技术细节与算法流程
### 核心思想
提出GenDa统一框架，包含两个互补模块：
- **技能重标定**：动态对齐过去经验与演化中的潜在表示，解决语义漂移，提升数据效率。
- **互补信息瓶颈**：学习与`ϕ`（度量感知潜在表示）互补的嵌入`ℓ`，使策略仅关注自我中心特征，避免利用全局上下文。

### 关键技术细节
- **技能重标定（Relabeling）**：
  - **表示学习阶段**：不直接使用存储的原始技能`z_roll`，而是根据当前`ϕ`计算轨迹`τ`的终点潜在变化方向作为新标号`z_relab = unit(ϕ(s_T)-ϕ(s_0))`。然后固定`z_relab`（stop-gradient）优化`ϕ`，使每个轨迹与其当前语义对齐。
  - **防崩塌正则化**：由于`z_relab`分布不确定，引入均匀性正则项`L_unif`最大化`z_relab`在超球面上的熵，防止表示坍塌。
  - **策略学习阶段**：利用内在奖励`r = (ϕ(s')-ϕ(s))^T z`，通过重标定多步目标`z_c`（从未来状态对导出）混合原始`z_roll`和`z_relab`，丰富奖励信号，提升引导效率。
- **互补信息瓶颈**：
  - 训练编码器`q_ψ(ℓ|s)`和解码器`p_ω(ŝ|ℓ,ϕ(s))`，最大化`J_CIB = I(ℓ;s) - I(ℓ;ϕ(s))`。由于解码器可用`ϕ(s)`重建信息，`ℓ`被迫保留`ϕ`遗漏的互补信息（如自身关节状态），而丢弃全局上下文。
  - 将策略输入从原始状态`s`替换为`ℓ ∼ q_ψ(ℓ|s)`：`π(a|ℓ,z)`，在数据收集、训练和部署中一致使用，增强对全局上下文偏移的鲁棒性。
- **算法流程**（简化）：初始化策略、表示`ϕ`、EMA目标`ϕ_tgt`、CIB编码器`q_ψ`、拉格朗日乘子λ、重放缓冲B。每个epoch：采样技能`z`，用CIB嵌入收集轨迹存入B；随后多步梯度更新：用重标定数据更新`ϕ`（含L_base+L_unif），用混合批次（原始+重标定+多步目标）通过SAC更新策略，更新CIB（最大化J_CIB），更新EMA目标。循环。

### 公式与算法文字说明
- 表示学习损失：`L_ϕ = L_base + β L_unif`，其中`L_base`对应公式(3)，`L_unif`为对比均匀损失。
- 策略学习使用SAC，内在奖励为`r(ϕ,z)`。
- CIB目标：`J_CIB = I(ℓ;s) - I(ℓ;ϕ(s))`，通过变分下界优化。
