## 摘要
弥合仿真到现实的差距是部署习得操作策略的核心挑战。仿真到现实的学习具有吸引力，因为它可以用可扩展的合成数据替代昂贵的真实机器人演示，然而之前尚未有研究证明世界动作模型能从仿真迁移到真实机器人操作中。我们研究是否可以从合成先验训练一个世界动作模型，并在真实世界中零样本部署。为此，我们基于Cosmos Policy（一种针对视觉运动控制调整的视频扩散模型）进行构建。我们构建了具有广泛域随机化的仿真环境，并使用AnyTask运动规划流水线生成演示。我们在物体提升、抽屉打开和取放任务中评估了我们的方法，每个任务使用约800个合成演示，无真实演示。当在Franka机器人上零样本部署时，我们的策略获得了35%的平均成功率。据我们所知，这代表了世界动作模型在机器人操作中首次成功的仿真到现实迁移。

## Abstract
Bridging the sim-to-real gap is a core challenge in deploying learned manipulation policies. Sim-to-real learning is attractive because it can replace expensive real robot demonstrations with scalable synthetic data, yet world-action models have not previously been shown to transfer from simulation to real robotic manipulation. We study whether a world-action model can be trained from synthetic priors and deployed zero-shot in the real world. To this end, we build upon Cosmos Policy, a video diffusion model adapted for visuomotor control. We construct simulation environments with extensive domain randomization and generate demonstrations using the AnyTask motion planning pipeline. We evaluate our approach across object lifting, drawer opening, and pick-and-place tasks using ${\sim}800$ synthetic demonstrations per task and no real demonstrations. When deployed zero-shot on a Franka Robot, our policy attains a 35\% average success rate. To our knowledge, this represents the first successful sim-to-real transfer of a world-action model for robotic manipulation.

- **核心问题**：能否将世界动作模型（world-action model）完全从合成数据（仿真）训练，并在真实机器人上实现零样本（zero-shot）操作，而不依赖任何真实演示数据？
- **动机与背景**：真实世界的机器人操作数据收集成本极高，而仿真环境提供可扩展、廉价的替代方案。然而，仿真与真实之间存在的视觉和物理差异（sim-to-real gap）常导致策略迁移失败。现有工作虽已将世界动作模型应用于仿真到仿真或真实到真实的场景，但尚未证明其能跨越仿真到真实的鸿沟。本文试图填补这一空白，探索世界动作模型继承仿真学习核心优势（低成本、可扩展的合成数据）的可能性。

- **核心思想**：利用预训练的视频扩散模型（Cosmos-Predict2）作为先验，通过单阶段后训练（post-training）将其适配为机器人策略（Cosmos Policy）。策略同时预测未来观测和机器人动作，并在统一的扩散过程中编码动作、未来观测和值估计为潜在帧。
- **关键技术细节**：
  - **仿真环境构建**：使用GPU加速仿真器（Isaac Gym），并进行全面的域随机化，包括：

- **训练算力**：40块NVIDIA H100 GPU，训练32个epoch，约72小时。

## 5. 实验数量与充分性

- **实验数量**：四个任务各10次测试，共40次试验。另有一次分布外泛化定性测试。
- **充分性评估**：
  - **优点**：覆盖了多种操作类型（抬升、推拉、放置），且明确注明了试验次数（10次每任务），结果可重复。分布外测试增加了结论的稳健性。
  - **不足**：
    - 每个任务只有10次试验，统计显著性有限（例如成功率5/10 vs 4/10可能受随机性影响）。

## 6. 主要结论与发现

- 世界动作模型（Cosmos Policy）可以从完全合成的仿真演示训练，并在真实机器人上零样本部署，达到35%的平均成功率。
- 这一成功率高于用10个真实演示训练的DP（5%）和用50个真实演示训练的DP（25%），表明仿真数据在特定设置下可超越少量真实数据。
- 模型对未见过的物体（瓶子）具有一定的泛化能力，显示出习得通用视觉运动基元而非仅记忆训练目标。
- 这是首次成功实现世界动作模型从仿真到真实机器人操作的迁移。

## 7. 优点

- **方法创新**：首次将世界动作模型（视频扩散模型）成功应用于sim-to-real迁移，为生成式机器人策略提供新范式。
- **数据效率**：完全依赖可自动生成的合成数据，避免了昂贵的人工遥操作。每任务仅需约800个演示（而DP需要50个真实演示才能达到25%）。
- **域随机化充分**：纹理、相机、光照、物体放置的多样化随机化，使得模型能泛化到真实未见场景。
- **分布外测试**：验证了模型对新物体的泛化能力，增强了可信度。
