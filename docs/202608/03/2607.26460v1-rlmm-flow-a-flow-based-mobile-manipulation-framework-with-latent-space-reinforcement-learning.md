## 摘要
移动操控需要生成完整的身体动作块，这些动作块需同时满足目标到达、碰撞避免、基座运动学约束、机械臂关节限位以及轨迹平滑性。基于流的生成策略为从专家演示中学习多模态且时间上一致的运动先验提供了一种高效范式，但仅靠模仿训练无法在演示分布之外提升策略质量。我们提出RLMM-Flow，一种基于流的移动操控框架，结合专家流策略预训练与潜空间强化学习后训练。该框架首先学习一个从专家演示中捕获多模态全身运动先验的流策略。随后冻结预训练的流策略，同时一个潜空间转向网络将其初始噪声导向更高价值的动作块。为稳定高维潜空间优化，我们在联合训练潜空间评判器与潜空间行动器之前预热一个动作空间评判器，并引入由粗到细的潜空间转向，逐步将控制从水平共享的潜表示扩展至全维度残差表示。在移动操控运动规划基准上的实验表明，与仅模仿的流策略及现有强化学习后训练基线相比，RLMM-Flow显著提升了任务成功率、碰撞避免能力与轨迹质量，同时保持了基于流的高效推理。

## Abstract
Mobile manipulation requires generating whole-body action chunks that jointly satisfy goal reaching, collision avoidance, base kinematic constraints, manipulator joint limits, and trajectory smoothness. Flow-based generative policies provide an efficient paradigm for learning multimodal and temporally consistent motion priors from expert demonstrations, but imitation-only training cannot improve policy quality beyond the demonstration distribution. We propose RLMM-Flow, a flow-based mobile manipulation framework that combines expert flow-policy pretraining with latent-space reinforcement learning post-training. The framework first learns a flow policy that captures a multimodal whole-body motion prior from expert demonstrations. The pretrained flow policy is then frozen, while a latent steering network steers its initial noise toward higher-value action chunks. To stabilize high-dimensional latent optimization, we warm up an action-space critic before jointly training the latent critic and latent actor, and introduce coarse-to-fine latent steering that progressively expands control from a horizon-shared latent representation to a full-dimensional residual representation. Experiments on mobile manipulation motion-planning benchmarks show that RLMM-Flow substantially improves task success, collision avoidance, and trajectory quality over imitation-only flow policies and existing reinforcement learning post-training baselines, while preserving fast flow-based inference.

- **现有方法的困境**：
  - 经典规划器（如 CHOMP、Sequential Convex Optimization）可强制满足约束，但依赖精确模型和任务特定目标函数，泛化能力有限。
  - 生成式策略（扩散/流模型）能从专家演示中学习多模态、时间一致的动作先验，但**纯模仿学习无法超越演示分布**，生成的轨迹在分布外场景中可能出现碰撞或违反运动学约束。
  - 直接对多步生成式策略（扩散/流）做强化学习存在困难：似然评估、策略比率估计、信用分配、以及通过完整输运过程的梯度传播都不如单步策略直观。
  - 潜空间策略改进（如 DSRL）通过调控冻结生成器的初始噪声来避免上述问题，但应用到移动操作时面临三大新挑战：① 潜变量是高维全水平（full-horizon）动作块；② 基座与机械臂运动角色异构，存在依赖关系；③ 同时学习动作评论家与潜评论家会使潜评论家早期目标不可靠。
- **论文的核心主张**：将专家流策略预训练与潜空间强化学习后训练相结合，在保持流式生成高效推理的同时，使策略能够在示范分布之外进一步优化动作质量。

## 2. 方法论

### 2.1 整体框架
- **两阶段训练**：
  1. **阶段一（预训练）**：用专家演示通过流匹配（flow matching）预训练一个点云条件流策略，学习多模态全身运动先验。
  2. **阶段二（后训练）**：冻结预训练流策略，训练一个**潜空间转向网络（latent steering network）**，将初始噪声引导至更高价值的轨迹。
- **推理过程**：优化后的潜噪声作为冻结流策略的初始条件，经流输运生成最终动作块。

### 2.2 网络架构
包含四个网络：
- **流策略 πW_dp**：基于 Transformer 的条件流架构，以机器人中心点云、动作块噪声和流时间嵌入为输入，输出动作 token 的速度，定义从高斯噪声到专家轨迹的连续输运。
- **潜空间转向网络 πW**：级联 Transformer 架构。由于基座与机械臂运动角色不同，**先预测基座相关潜变量，再以基座预测为条件生成机械臂相关潜变量**，显式建模"全局导航 → 局部操作"的依赖。输出 (μW(s), log σW(s)) 参数化对角高斯分布，通过重参数化采样 w_raw = μW(s) + exp(log σW(s)) ⊙ ε。
- **动作评论家 QA**：评估解码后的全身动作块质量，输入为观测表示与动作块，输出标量动作价值。
- **潜评论家 QW**：结构与 QA 相同，但评估的是潜变量而非解码动作。

### 2.3 流策略预训练
- 每个专家轨迹被参数化为固定水平 H 的全身动作块：沿基座路径按弧长均匀采样 H 个路点，同步插值机械臂关节配置。
- 使用 **rectified flow** 训练目标：
  - 构造 a_t = (1−t)a₀ + t a₁，v* = a₁ − a₀；
  - 损失 L_FM = E[‖vθ(a_t, t, s) − (a₁ − a₀)‖²]。
- 受 EDM 启发，用 **logit-正态调度**替换均匀流时间采样：z ~ N(−1.2, 1.2²)，t = sigmoid(z)，强调更有信息量的中间噪声状态。

### 2.4 潜空间强化学习后训练
- **奖励设计**：将机器人身体近似为碰撞球集合，通过正运动学映射到工作空间，构造五项原始奖励：
  1. **r_goal**：末端执行器终端位置/姿态误差（基于抓手碰撞球集合与目标的均方根距离）；
  2. **r_lim**：基座非完整运动学约束（侧滑惩罚 + 曲率惩罚，κmax = 2.0 m⁻¹）；
  3. **r_colli**：基于 ESDF 的全身碰撞球安全间距惩罚（含安全缓冲区域）；
  4. **r_smooth**：所有碰撞球的二阶时间差分惩罚；
  5. **r_joint**：机械臂关节极限越界惩罚。
  - 各项在离线数据集上做统计归一化并裁剪（阈值 c=5），加权求和：r(τ) = 2.5·r_goal + 2.0·r_lim + 1.5·r_colli + 1.5·r_smooth + 2.5·r_joint。
- **混合质量离线数据**：预训练只用高质量专家轨迹；RL 后训练使用 D_RL（7,500 条高质量 + 1,500 条结构化次优轨迹），拓宽价值覆盖、提供高低质量对比，缓解评论家过估计。
- **QA 评论家预热（QA warm-up）**：针对 DSRL-NA 联合训练 QA、QW、πW 导致的"移动目标"问题，算法先在 N_pre = 20,000 步内**只更新 QA**（此时下一潜变量从固定标准高斯先验采样），待动作价值估计相对稳定后再激活潜评论家蒸馏与潜行动器优化。
- **由粗到细的潜空间转向（Coarse-to-fine latent steering）**：
  - **粗粒度阶段**：对 w_raw 沿水平维度做平均池化 w̄ = AvgPool_H(w_raw) ∈ R^dw，再重复得到 w_coarse ∈ R^(H×dw)。虽然形状恢复为 H×dw，但有效搜索维度仅为 dw，降低早期搜索复杂度，先学习轨迹级全局运动模式与基座-机械臂整体协调。
  - **细粒度阶段**：在切换步 t_cf = 50,000 之后，引入高维残差 w_res = w_raw − w_coarse，通过 w_π = w_coarse + λ_res·w_res（λ_res = 0.1）恢复逐时间步的独立调节能力，主要细化局部避障、末端精度、关节运动与平滑性。
