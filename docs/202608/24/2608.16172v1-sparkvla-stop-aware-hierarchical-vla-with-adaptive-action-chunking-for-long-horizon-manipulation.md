## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观察点，必须做出两个接口决策：何时终止当前子任务，以及执行所提出的动作块到何种程度。这两个决策相互依赖——最佳停止点取决于执行器计划做什么，而最佳执行长度取决于子任务边界在哪里——然而现有架构孤立地评估它们，这种不对称性是任何模块都无法单独克服的。我们提出了SparkVLA，一种停止感知的分层VLA，通过将两个决策表述为单一排序来解决这种相互依赖：停止与统一候选集中的每个动作前缀长度竞争，系统选择得分最高的选项，从而无需阈值调节，且仅需离线序数偏好。一个锚点条件上下文编码模块缓存历史感知的子任务锚点编码、起始状态记忆和目标语义，引导视觉标记剪枝朝向任务相关区域；一个停止感知的动作前缀选择头通过全自注意力对块边界处的所有候选进行评分以保证效率。在RoboCerebra上，SparkVLA达到了47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真机实验进一步验证了这些在物理硬件上的增益。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

## 论文总结：SparkVLA

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：现有的视觉-语言-动作（VLA）模型虽然在机器人操作上表现出色，但往往在长时程任务中难以组合多个技能。分层VLA架构通过高层VLM规划器（将任务分解为子任务）与低层VLA执行器（执行具体动作块）的协作来解决这一问题。
- **核心问题**：在分层VLA系统的每个重新观察点，系统必须做出两个相互依赖的接口决策：
  - **何时终止当前子任务**（停止决策）
  - **执行多长动作块**（执行长度决策）
- **关键洞察**：这两个决策并非孤立存在。最优的停止点取决于执行器后续计划，而最优的执行长度又取决于子任务的边界。然而，现有研究通常将二者分离处理，例如：
  - **停止决策**：使用二元分类器或VLM预测长度，无法感知执行计划。
  - **长度决策**：通过RL或启发式自适应选择动作块长度，但无法发出子任务完成的信号。
- **本文贡献**：SparkVLA通过将“停止”与“所有动作前缀长度”放入一个**统一的候选集**进行单一排序，从根本上解决了决策间的相互依赖问题，彻底消除了阈值调参并仅依赖离线顺序偏好。

### 2. 方法论：核心思想与技术细节

- **核心思想**：构建一个**联合评判**框架。将“停止”视为一个与所有动作前缀长度平等的候选，由同一个评分头进行打分。这样，终止决策可以感知执行计划内容，而执行长度决策也可以感知子任务边界的接近程度。

- **系统架构**：基于预训练的π0.5 VLA模型派生两个分支：
  - **高层分支**：保留VLM骨干，负责生成子任务命令（`c_k`），并托管动作前缀选择器。
  - **低层分支**：使用完整的π0.5 VLA，负责提出动作块（`A_t`）。

- **关键技术1：Anchor-Conditioned Context Encoding（锚点条件上下文编码）**
  - **历史感知子任务锚点（History-Aware Subtask Anchor）**：在每个子任务开始时，从规划器生成的子任务命令中提取一个“原始锚点”，并通过自注意力将其与过去子任务的锚点历史融合，形成一个携带跨子任务上下文信息的“历史感知锚点” `α_k`。它同时编码了起始状态记忆和目标语义。
  - **锚点引导的视觉剪枝（Anchor-Guided Visual Pruning）**：利用锚点 `α_k` 通过可微分的 Grid-Sampler 操作，将SigLIP编码器生成的大量稠密视觉令牌（N个）剪枝为任务相关的少量令牌（K个），减少了计算量并聚焦于关键区域。

- **关键技术2：Stop-Aware Action-Prefix Selection（停止感知动作前缀选择）**
  - **统一候选集**：定义一个候选集 `C = {0, 1, ..., H}`，其中0代表“停止”，`n >= 1` 代表选择动作块 `A_t` 的前n个动作。
  - **统一评分头（Unified Candidate Scoring）**：设计了一个全自注意力的Transformer评分头。将“停止”的嵌入向量、锚点 `α_k`、高层上下文特征 `m_t`，以及每个动作前缀末动作的嵌入向量作为输入令牌，通过多头自注意力让所有候选之间相互“沟通”，最终为每个候选输出一个标量分数。
  - **停止感知排序目标（Stop-Aware Ranking Objective）**：训练使用两个互补的损失函数：
    - `L_rank`（成对排序损失）：利用离线数据为不同候选分配优先级（如子任务完成后“停止”优先级最高，动作应覆盖到边界等），通过成对比较进行训练。
    - `L_stop`（停止感知辅助损失）：使用sigmoid对比"停止"分数与所有延续动作的log-sum-exp聚合，强化终止边界的梯度信号。
    - 总损失 `L = L_rank + λ_stop L_stop`。

- **推理流程**：在每个决策边界，选择分数最高的候选。如果是动作前缀，执行后重新观察；如果是“停止”，则生成下一个子任务命令，进入新循环。

### 3. 实验设计：数据集与Benchmark

- **仿真主Benchmark（RoboCerebra）**：
  - 包含1000条标注轨迹，覆盖100种任务变体（平均9.1个子任务，2972步）。
  - 评估六个条件：**Dynamic**（动态，含随机化/观察变化）、**Memory**（记忆，含探索/执行）、**Mix**（混合）和静态 **Ideal**（理想）。
  - 使用60个保留案例，每组10次，共600个episodes。

- **仿真辅助Benchmark（LIBERO）**：
  - 包括4个套件：Spatial、Object、Goal、Long，共40个任务，每个任务100个episodes。
  - 子任务标注来自LaRA-VLA。

- **真实机器人实验**：
  - 平台：AirbotPlay双机械臂平台。
  - 任务1（Shelf Arrangement）：6个子任务，重复的抓取-放置。
  - 任务2（Drawer Restocking）：6个子任务，涉及抽屉开关的关节交互。
  - 任务3（Tea Preparation）：12个子任务，包含探索、确认、倒水和长时程链式操作。为安全起见，倒水任务使用白色塑料珠代替液体。
  - 每个任务收集50条演示，并评估50次rollouts。

- **对比方法（Baselines）**：
  - **独立VLA**：OpenVLA-OFT、SmolVLA、π0.5。
  - **分层VLA**：HPE（官方RoboCerebra基线）、Mem-0（该作者复现的最新开源方法），以及将SparkVLA高层系统与OpenVLA-OFT和SmolVLA执行器配对的两个变体，用于测试泛化性。

### 6. 主要结论与发现

- **核心成果**：将停止决策和自适应动作块长度选择统一为一个排序问题，能够有效解决两者的相互依赖关系。
- **主要结果**：
  - **RoboCerebra**：SparkVLA达到**47.12%**平均成功率，超过官方分层基线HPE达**30.57%**，超过最强可复现方法Mem-0达**26.83%**。
  - **LIBERO**：平均成功率达到**98.5%**，在Long套件上相比π0.5提升5.6%。
  - **真实机器人**：平均成功率**69.3%**，显著优于π0.5（+21.3%），在12个子任务的Tea Preparation任务上优势最大（+30.0%）。
- **行为模式**：策略能够自适应调整执行长度，在粗放搬运和运输阶段使用长动作块，在精细对准/接触事件时切换到短动作块，任务完成时触发“停止”。
- **通用性**：SparkVLA的高层系统具有执行器无关性，与不同的低层VLA（OpenVLA-OFT、SmolVLA）结合均能带来显著的性能提升。

### 7. 优点

- **问题定义清晰**：明确指出了分层VLA系统中“何时停止”和“执行多长”的相互依赖性这一关键盲点，并给出优雅的解决方案。
- **统一决策框架**：将两个决策任务整合为一个单一排序问题，极大简化了系统的设计，并且**无需在线奖励信号或任何阈值调节**，只用离线排序偏好训练。
- **设计与实现一致性**：锚点条件编码和停止感知动作前缀选择头等模块，紧密地服务于解决核心问题的目标，设计巧妙。
- **计算高效**：通过在决策边界（而不是每一步）运行选择器，并结合任务相关视觉剪枝，系统在增加高层决策能力的同时，保持了相对较高的吞吐率（4.14 Hz，为单独π0.5的88%）。
- **实验验证充分**：不仅在大规模仿真Benchmark上全面评估，还通过真实机器人任务和多种基线对比验证了方法的有效性和泛化性。消融实验清晰地量化了每个组件的贡献。

### 8. 不足与局限

- **任务范围受限**：当前实验主要局限于**桌面操作**和**固定物体类别**，对于更广泛、开放世界的任务和未知物体泛化能力尚未验证。
- **训练模式受限**：整个训练流程是**离线的**，无法利用在线交互数据进行自我优化，面对环境变化时可能缺乏主动适应能力。
- **演示数据依赖性**：训练过程中的序数偏好依赖于对成功演示的边界标注，这在复杂任务中可能成本高且存在噪声，尽管文中用随机扰动来增加鲁棒性。
- **简化物理场景**：真实的倒水任务使用了干性替代物（塑料珠），虽保留了操作序列，但无法完全模拟液体物理，其对视觉和触觉反馈的复杂性降低，可能影响策略在实际流水场景中的适应性。
- **长篇长时程任务（如超过15分钟）**：虽然优于现有方法，但并未在极长时程（如本文提及的MEM任务）进行探索，其性能有待进一步检验。
