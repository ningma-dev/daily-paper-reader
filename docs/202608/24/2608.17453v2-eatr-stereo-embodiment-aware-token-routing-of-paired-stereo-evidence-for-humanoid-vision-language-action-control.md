## 摘要
长时程人形视觉-语言-行动（VLA）控制配备头戴式立体相机，需要能够利用互补视图同时保持与预训练表示兼容性的视觉接口。现有接口常常丢弃互补的立体证据，或在不保留天然主视图通路且不适应机器人具身的情况下融合额外观测。我们提出EATR-Stereo，一种具身感知的令牌路由框架，保留主视图令牌，并通过查询同步的辅助视图令牌序列构建主对齐的跨视图辅助令牌（CVAT）。一个身体分割的本体感觉编码器进一步基于机器人配置历史对逐令牌的辅助使用进行条件化，从而在动作生成过程中选择性纳入立体证据。路由的辅助流增强了预训练VLA的语言和主视觉上下文，同时保持其视觉-语言模型冻结。在一个具有37维本体感觉状态的33自由度物理人形机器人上，我们在超过100秒的搜索-接近-抓取-放置-返回任务中评估了九种配置。EATR-Stereo实现了60.0%的完整任务成功率，100.0%的抓取成功率和80.0%的阶段成功率。在严重不对称遮挡下，它将恢复率提高到80%，而仅使用CVAT时为30%。消融研究进一步表明保留主令牌以及将跨视图辅助特征与结构化本体感觉路由相结合的重要性。这些结果表明，选择性路由的成对立体证据改善了空间基础，以实现可靠的长时程人形VLA控制。

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

## 1. 核心问题与整体含义

### 研究背景与动机
- **部署场景的转变**：VLA（Vision-Language-Action）模型在机械臂+固定外部摄像头的场景中已有较好表现，但面对**双足人形机器人+头戴式立体相机**这一部署模式时，感知系统与机器人本体运动深度耦合——步态扰动、躯干摇摆、头部与腰部转动都会改变相机位姿，手臂运动也会造成与配置有关的自遮挡。
- **现有方法的缺陷**：
  - 单目输入丢失双目视差和遮挡区互补视图；
  - 简单地将多张图像的 token 拼接，不强制跨视图一致的空间推理；
  - StereoPolicy 虽显式关联双视图，但其 VLA 变体用融合表示替换了原生主视图 token，破坏了预训练的单目 token 结构；
  - SpatialVLA 依赖单目深度估计，但双足运动中单目深度时序不一致，且其实测采用固定/三脚架相机的机械臂场景；
  - 现有视觉-本体觉融合不会根据本体状态选择性地利用配对视图信息。
- **核心问题**：能否在不破坏预训练主视图语义通路的前提下，将同步立体视图的互补证据，以**具身感知（embodiment-aware）**的方式选择性地整合进预训练 VLA 模型，从而改善长时程人形操作任务的可靠性？

## 2. 方法论

### 核心思想
EATR-Stereo 的三大设计支柱是：(1) **保留主视图原生 token 通路**；(2) 构造**主对齐的跨视图辅助 token（CVAT）**；(3) 用**身体分段的本体感编码**对辅助 token 进行逐 token 路由（选择性门控），使立体证据的使用随机器人配置历史动态调整。

### 关键技术细节

- **输入与问题建模**：策略输入为同步立体图像对 $(I^L_t, I^R_t)$、语言指令 $\ell_t$ 和最近 $K$ 帧本体感历史 $S_t$；策略预测 $H$ 步连续动作块 $\hat{Y}_t = \pi_\theta(I^L_t, I^R_t, \ell_t, S_t)$。

- **跨视图辅助 token（CVAT）构建**：
  1. 冻结的 Cosmos VLM 同时编码主视图与辅助视图，输出主视觉 token 序列 $M_t$ 和辅助视觉 token 序列 $A_t$（两者在同一 VLM 隐空间）；
  2. 引入可学习的视图角色嵌入区分主/辅视图；
  3. 参考 StereoPolicy 的多头交叉注意力设计：**以主 token 作为 Query，辅助 token 作为 Key/Value**，使得每个主 token $M_{t,i}$ 从完整辅助序列聚合证据，生成主索引对齐（primary-indexed）的 CVAT token $C_{t,i}$；
  4. 主 token 序列保持不变，CVAT 是一条平行的、主对齐的辅助流。

- **具身感知路由**：
  - 将 37 维本体感状态划分为 5 个语义组：**腿、手臂、头、腰、整体位姿**；
  - 每个组的 $K$ 帧历史被展开后经 LayerNorm + 独立 MLP 映射为段表示 $z_{t,g}$，并加可学习的段类型嵌入；
  - 通过注意力加权+均值池化融合为全局具身状态 $h^s_t$；
  - 对每个主 token 索引 $i$，路由器以主 token、对应 CVAT token、二者的**绝对差与逐元素乘积**以及全局具身状态为输入，经轻量 MLP 输出一个 $(0,1)$ 区间的门控标量 $r_{t,i}$，逐 token 缩放 CVAT；
  - 路由器只缩放辅助流，主 token 不被动用。

- **VLA 集成与训练**：
  - 最终上下文为 $[L_t; M_t; \tilde{C}_t]$（语言 + 主视图 + 门控辅助），与原始本体感状态一起送入 GR00T N1.7 的 flow-matching 动作专家；
  - 使用 flow matching 目标函数 $\mathcal{L}_{FM}$ 训练，VLM 保持冻结，仅 CVAT 模块、分段状态编码器、路由器和动作专家被联合优化。

- **部署机制**：
  - 动作块异步预测并放入执行缓冲；
  - 在块切换边界使用**三次均匀 B 样条**拼接，保持动作与速度连续性（原始块切换存在跳跃）；
  - 外部 VLM 以慢时间尺度评估子任务完成度并更新语言指令（该外部分量不在学习方法范围内）。

## 3. 实验设计

### 测试平台与基准
- **物理人形平台**：33-DoF HONOR Omega 1.0 人形，37 维本体感状态（33 个关节 + 4 维基座方向四元数），头部安装 240×320 同步立体相机，BeyondMimic 整身控制；策略 10 Hz 运行、预测 30 步动作块。
- **任务**：超过 100 秒的**搜索→接近→抓取→语言条件放置（按颜色放入指定篮子）→返回起点**长时程任务。
- **仿真基准**：RoboCasa365，18 个任务，3600 次 Franka 机械臂 rollout，去除腕部相机观测，仅保留左右 agent 视图。

### 对比方法
- GR00T1.7-Mono（单目）、GR00T-Wide（宽宽高比输入）、GR00T（双图 token 拼接默认版）、StereoPolicy（适配同一骨干）；
- 消融变体：Main-XAttn（用交叉注意力修改主 token）、CVAT（保留主 token + 辅助流）、CVAT-Flat（扁平本体感编码）、Stereo-Route（用 StereoPolicy 融合替代 CVAT）、EATR-Stereo（完整方法）；
- 仿真额外对比 QwenPI0.5。

### 评估维度
1. 物理长时程性能；
2. 组件消融（表示保留、选择性路由、本体感编码方式）；
3. 位置泛化（ID/OOD）、语言遵从、严重不对称遮挡鲁棒性；
4. 方法排名在机械臂仿真中的可迁移性。

## 6. 主要结论与发现

1. **主对比（物理人形）**：EATR-Stereo 以 60.0% 全任务成功率、100% 抓取成功率、80.0% 阶段成功率全面领先——比 StereoPolicy 高 15 个百分点，比 GR00T 双图拼接高 25 个百分点；
2. **泛化能力**：OOD 阶段成功率 70%（StereoPolicy 为 50%），ID 到 OOD 的抓取率下降为 0（唯一达到此水平的），说明在未见位置仍保持稳定的空间定位；
3. **遮挡鲁棒性**：在主视图完全遮挡、辅助视图部分可见的严重不对称遮挡下，EATR-Stereo 以 80% 恢复率远超仅 CVAT 的 30% 和 CVAT-Flat 的 60%，平均恢复时间 22.4 s，显著快于其他变体；
4. **语言遵从**：左右指令遵从率 100%、颜色指令 80%，与最优基线持平；
5. **组件消融**：保留主 token（Main-XAttn→CVAT）+30.0 pp；平坦→分段本体感路由（CVAT-Flat→EATR）+5 pp 全任务 / +7.5 pp 阶段；显示表示保留、交叉视图建模与结构化具身路由三者的增益是互补的；
6. **效率**：以仅 5.8% 的额外训练时间超过双图 GR00T 22.5 pp 阶段成功率；与达到相同阶段成功率（80%）的 Estimated-Depth VLA 相比，训练成本低约 3.8 倍；
7. **仿真迁移**：EATR-Stereo 在 RoboCasa365 上也以 43.33% 成功率领先所有对比方法，方法排序与实物一致。

## 7. 优点

- **方法设计创新性强**：
  - 精准诊断了现有立体 VLA 接口的"破坏原生主视图通路"问题，并给出优雅的不动主 token、另建辅助流的解法；
  - 将"是否及如何使用立体辅助信息"与身体配置状态显式挂钩，实现逐 token、随时间与身体状态动态变化的条件化路由，充分响应"具身感知"命题；
  - 保持 VLM 冻结，训练代价极低，工程实用性突出；
  - 部署层面 B 样条拼接解决了动作块切换的连续性工程问题。
- **实验设计较严谨**：
  - 仿真（大样本、多任务）先验证，实物（真机长时程）再确认，且仿真与实物方法排序一致，增强了结论的可信度；
  - 消融设计细致，验证了每个核心设计组件的独立贡献；
  - 同时设计了"位置泛化"、"语言遵从"、"遮挡恢复"多维验证，不只报告单一指标。

## 8. 不足与局限

- **平台单一**：物理实验只在 HONOR Omega 1.0 一种人形上进行，未覆盖其他构型的双足/轮式平台，结论的跨平台推广性有待验证；
- **任务单一**：只有一种长时程任务（搜索-接近-抓取-放置-返回），物体类型、场景复杂度、语言指令多样性有限；
- **实物样本量偏小**：每配置 20 次试验，遮挡专项仅 10 次，未报告置信区间或显著性检验，统计功效有限；
- **OOD 范围有限**：仅变换瓶子位置（fixed order），未包含光照变化、物体外观变化、场景布局变动等更复杂的分布外情况；
- **外部 VLM 依赖**：子任务完成检测依赖外部 VLM，任务级编排不在学习方法内部，因此"任务级成功率"不能完全归因于策略本身；且外部 VLM 的错误会对所有方法施加相同但未量化的影响；
- **语言遵从率上限**：颜色指令 80% 的遵从率并不完美，说明跨视图信息增强空间定位的同时，语义多模态理解仍有提升空间；
- **设计选择**：CVAT 与 CVAT-Flat 的全任务成功率均为 55%，分段路由的增益主要体现在与平坦编码对比的全任务+5、抓取+10、阶段+7.5 上，判断分段的意义仍需更大样本验证；
- **未做深度/视差显式建模**：未使用相机标定参数，虽通过交叉注意力隐式建立对应关系，但与显式视差或几何重建结合是否进一步提升性能仍值得探索。
