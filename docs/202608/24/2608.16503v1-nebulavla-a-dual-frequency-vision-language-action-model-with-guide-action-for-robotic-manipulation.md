## 摘要
视觉-语言-动作（VLA）模型在实际部署中常受限于效率与性能的权衡、跨本体泛化以及执行平滑性。我们提出NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源与模块性。为弥合异构机器人间的语义鸿沟，我们引入GESTURE-7，一种统一的语言-接地动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人应用提供了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 一、论文的核心问题与整体含义

**研究动机**：VLA（Vision-Language-Action）模型正推动机器人操作从模块化管线走向端到端学习，但在真实部署中仍面临三大瓶颈：

1. **效率与性能的刚性权衡**：传统单频同步架构无法同时容纳低频语义推理（需要大模型，计算昂贵）与高频电机控制（需要低延迟响应）。
2. **跨本体泛化困难**：现有动作表示（离散token或连续回归）难以在异构机器人平台（如灵巧手、平行夹爪、机械臂）间统一动作语义。
3. **执行不平滑**：异步推理与动作块生成之间的时间错配，导致轨迹在块边界处出现明显抖动和中断。

**整体含义**：论文提出一种"快慢双系统"认知范式启发的双频架构，试图从系统层面同时解决上述三个问题——以"慢系统"（System 2）负责10Hz语义规划、"快系统"（System 1）负责20Hz动作控制的方式，实现计算效率与控制响应性的最佳平衡。

## 二、方法论

### 1. 核心思想：异构双频架构

- **System 2（10Hz）**：以Qwen3-VL为骨干，处理自然语言指令和稀疏视觉输入，通过可学习token提取隐藏层特征，输出抽象动作引导（action guidance）。
- **System 1（20Hz）**：以DiT（Diffusion Transformer）为生成器，结合高频视觉输入（DINOv2编码）与System 2的引导信息，通过去噪过程输出连续执行动作。
- 两个系统通过显式数据流规范解耦，支持异步通信和分布式部署，最小化交互延迟。

### 2. GESTURE-7：统一动作表示

- 将末端执行器状态编码为7维向量：**s = [x, y, z, r, p, w, g]**
  - (x, y, z)：笛卡尔坐标位置（整数厘米）
  - (r, p, w)：姿态角roll/pitch/yaw（整数度）
  - g：自然语言手势关键词（如"grasp"、"push"、"pinch"等）
- **关键设计**：不同本体执行相同动作时共享同一关键词（如平行夹爪和灵巧手的"抓取"都表示为 `grasp`），从而统一异构平台间的动作语义，并天然支持语言条件下的强化学习。
- 位置和角度采用整数量化以减少学习负担、缓解预测幻觉。

### 3. Guide Action机制

- **灵感来源**：图像外推（Image Outpainting）与图像修复中的掩码约束思想。让下一动作块的生成条件化在前一动作块中**未执行的轨迹锚点**上。
- 训练时引导动作数量从0到3随机采样，以适应不同推理延迟。
- **条件生成模型**：p_θ(At-1_full | At_full, A_prior, τ)，其中A_prior为已执行历史动作与待执行的引导动作。
- **掩码强制更新公式**：At-1_full = M ⊙ A(t-1)_prior + (1-M) ⊙ At-1_noisy，其中M[1..k]=1为严格保留的锚定区域，M[k+1..T]=0为模型生成的区域。
- 效果：确保新动作块的起始状态与上一轨迹对齐，实现无缝边界过渡，无需后处理平滑。

### 4. 三阶段训练流程

| 阶段 | 对象 | 方法 | 内容 |
|------|------|------|------|
| Stage 1 | System 2 | SFT | 空间定位（末端姿态回归+2D关键点回归）、轨迹预测（2D路径点+3D轨迹点）、推理规划（CoT子任务分解+未来GESTURE-7轨迹） |
| Stage 2 | System 2 | GRPO强化学习 | 保留与SFT相同的任务集，使用GESTURE-7距离、关键点定位奖励、路径点DTW距离、轨迹奖励、格式奖励 |
| Stage 3 | System 1+2联合 | SFT | 使用加权流匹配损失（L2损失），冻结视觉编码器，损失仅作用于掩码M=0的新生成区域 |

## 六、主要结论与发现

1. **双频架构有效**：NebulaVLA（异频）在真实世界任务中推理延迟仅42ms（远低于同频变体的115ms和InternVLA-M1的81ms），同时成功率最高（92.08%和92.5%），验证了异步双频解耦在计算效率和响应性上的优势。
2. **LIBERO-Plus上SOTA**：总成功率85.5%，超过InternVLA-M1（81.3%）4.2个百分点，大幅领先GR00T N1.5（59.0%）和π0.5（58.0%）。在Language、Robot Initial State、Layout等多项扰动维度上提升显著（最高约10%）。
3. **GESTURE-7带来跨本体泛化提升**：语言关键词映射有效统一了异构机器人的动作语义，并支持RL训练。
4. **Guide Action显著抑制抖动**：在全部7个关节上降低了平均jerk，平均降低25.6%，关节12和13分别降低41.2%和45.1%。
5. **三阶段训练逐级有效**：完整三阶段（ALL）比直接加载预训练权重高1.7%，比仅SFT高2.5%；S2 SFT在Layout维度带来+6.2%的提升。

## 七、优点

1. **架构设计创新**：快慢双频解耦的设计具有较高新颖性，从系统层面（而非仅模型层面）解决了VLA部署中的效率-性能悖论，并天然支持分布式部署（S1和S2可分设备运行），对边缘计算场景友好。
2. **GESTURE-7表示简洁巧妙**：通过自然语言关键词映射统一异构本体动作语义，兼顾连续运动学信息与离散语义抽象，且支持强化学习，在工程上具有良好的可扩展性。
3. **Guide Action机制有理论借鉴意义**：将图像修复/外推的掩码思想迁移至动作块生成，直接内化平滑约束于生成过程，避免了后处理平滑带来的语义不一致问题，视角独特。
4. **训练流程系统化**：从SFT到RL再到联合微调的三阶段管线逻辑清晰，且Stage 2的奖励函数设计包含格式奖励、DTW轨迹距离等细节，考虑较为周全。

## 八、不足与局限

### 论文自述的局限

1. **频率分配是静态经验值**：10Hz/20Hz的配置为经验确定，不同任务领域的最优频率可能不同，动态自适应调度仍是开放问题。
2. **Guide Action的延迟代价**：固定引导锚点在快速变化环境中会引入轻微响应延迟。
3. **工程部署挑战**：异构硬件同步、多传感器时间戳对齐、分布式时钟一致性仍是实际落地的工程难题。

### 其他值得指出的局限

1. **Camera扰动性能退化**：NebulaVLA在Camera扰动维度上低于InternVLA-M1，论文将其归因于GESTURE-7训练假设建立固定视觉-空间映射，但这个解释缺乏实验证明（如通过加入视角条件化来做对照验证）。
2. **动作表示覆盖有限**：GESTURE-7仅覆盖末端执行器的6DOF+手势，不包含双臂协调、全身运动或力控信息，对更复杂任务（如双手机器人全身操作）的表达能力有限。
3. **现实实验规模较小**：仅2个任务、10次试验，机器人平台单一（仅AgiBot A2）；未在多平台、多环境条件下验证跨本体泛化能力——这与其GESTURE-7的跨本体设计主张形成一定张力。
4. **对比方法存在时间差**：部分基线（如InternVLA-M1）是同期工作，采用不同训练数据和方法论，比较的公平性细节（如训练数据规模、算力差异）未充分讨论。
5. **算力报告不完整**：缺乏训练总时长、模型参数量、能耗等关键信息，不利于学术复现和工业评估。
6. **未见代码和权重开源声明**：仅在摘要中称"加速动作生成约2.7倍"，但对于复现性至关重要的实现细节、超参数设置、训练数据来源等，正文描述相对有限。
