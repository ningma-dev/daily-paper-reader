## 摘要
用于物理交互的世界模型通常被训练来预测未来的观测或潜在特征；然而，面向规划的模型必须回答一个根本不同的问题：候选动作是否产生与任务一致的未来，同时保持关键关系。整体状态表示模糊了底层实体，而标准的实例级对象槽仅识别存在什么，而不指定每个实体在任务上下文中扮演什么角色。为了弥合这一差距，我们提出了语义丰富世界模型（SR-WM），这是一个以任务为条件的世界模型，围绕五个功能角色构建：夹持器、目标物体、目标状态、关系和阶段。在SR-WM中，视觉实体编码器从预训练的补丁特征中提取软实体假设，使得分割掩码可以作为可选的提议先验，而不强制要求它们作为必要的状态表示或推理输入。随后，一个角色绑定器将这些假设映射到任务特定角色，同时一个以动作条件化的动力学模型预测角色转换以及细粒度语义，包括抓取/接触、谓词建立、关系保持、夹具状态和阶段变化。关键的是，这种统一的角色状态支撑了下游的多候选动作生成、阶段感知重排序和违规感知后缀重采样。我们全面的评估协议涵盖了所有四个LIBERO模拟套件、跨套件迁移、感知诊断和动作敏感性分析。最终，这种形式化将以对象为中心的预测转化为一个语义接口，将视觉动力学与面向规划的决策制定联系起来。

## Abstract
World models for physical interaction are typically trained to predict future observations or latent features; however, a planning-oriented model must answer a fundamentally different question: whether a candidate action produces a task-consistent future while preserving essential relations.Monolithic state representations obscure the underlying entities, while standard instance-level object slots merely identify \emph{what} is present without specifying \emph{what role} each entity plays in the task context. To bridge this gap, we present the Semantically Rich World Model (SR-WM), a task-conditioned world model structured around five functional roles: gripper, target, goal, relation, and phase.Within SR-WM, a visual entity encoder extracts soft entity hypotheses from pretrained patch features, allowing segmentation masks to serve as optional proposal priors without mandating them as required state representations or inference inputs.A role binder subsequently maps these hypotheses to task-specific roles, while an action-conditioned dynamics model predicts role transitions alongside fine-grained semantics, including grasp/contact, predicate establishment, relation preservation, fixture state, and phase change.Crucially, this unified role state grounds downstream multi-candidate action generation, stage-aware reranking, and violation-aware suffix resampling.Our comprehensive evaluation protocol spans all four LIBERO simulation suites, cross-suite transfer, perception diagnostics, and action-sensitivity analysis.Ultimately, this formulation transforms object-centric prediction into a semantic interface linking visual dynamics with planning-oriented decision making.

## 1. 核心问题与整体含义

- **研究动机**：现有世界模型大多被训练为预测未来的观测、像素或隐特征，但规划任务真正需要回答的问题是：**给定候选动作，它是否会产生与任务一致的未来状态，同时保持已满足的关键关系？** 低预测误差并不等于决策有用——一个看似合理的未来可能抓错物体、丢失抓取、误开夹具或过早释放。
- **现有方法的不足**：
  - 整体式（monolithic）状态表示模糊了底层实体；
  - 实例级对象槽（instance-level object slots）只回答“存在什么”实体，却不回答“实体在任务中扮演什么角色”（如哪个是目标、哪个是容器、抓取是否保持、需要满足什么谓词、何时释放）。
- **核心贡献**：提出 **语义丰富世界模型（SR-WM）**，将对象中心预测转化为“语义接口”，把视觉动态与规划决策直接连接起来。该模型围绕五个功能角色——夹持器（gripper）、目标物体（target）、目标状态（goal）、关系（relation）和阶段（phase）——构建任务条件的预测与规划状态。

## 2. 方法论

### 2.1 核心思想
- **实体与角色分离**：视觉实体编码器先从预训练 patch 特征中提取“可交换的软实体假设”（soft entity hypotheses），这些实体本身没有语义标签；随后由**任务条件角色绑定器**（task-conditioned role binder）将这些假设映射为五个非可交换的功能角色，形成统一的任务条件预测状态 \(Z_t\)。
- 同一个视觉实体在不同指令下可以绑定为 target、goal 或无关干扰物，而无需重新学习实体编码器。

### 2.2 关键技术细节
- **角色状态定义**：
  \[
  Z_t = \{ z^{\text{grip}}_t,\ z^{\text{tgt}}_t,\ z^{\text{goal}}_t,\ z^{\text{rel}}_t,\ z^{\text{phase}}_t \}
  \]
  - gripper：末端执行器位姿、开度、运动、接触与抓取状态；
  - target：任务相关物体或铰接部件及其几何；
  - goal：容器、表面、目的地或期望夹具状态；
  - relation：gripper–target、target–goal 之间的相对几何与谓词；
  - phase：approach、grasp、transport、align、release、completion 等进度。
- **软实体编码器**：基于 LeWM 的 ViT-Tiny 编码器（5M 参数），每个实体包含外观、几何、运动、置信度四个分量；查询跨多视角迭代更新，无需逐视角独立槽。
- **可选分割先验**：SAM/SAM2 的 proposal 仅作为注意力偏置，且训练时对 proposal 集合、掩码和偏置强度分别做 dropout；推理时 \(\lambda_{\text{seg}}=0\) 即完全无需掩码，从而支持无掩码推理。
- **角色绑定公式**：
  \[
  b_{r,n}=\mathrm{softmax}_n\!\left(\frac{q_r(\ell,q_t)^\top k(e_{t,n})}{\sqrt{d}}+u_r^\top g_{t,n}\right),\quad
  z^r_t=\sum_n b_{r,n}v(e_{t,n})
  \]
  其中 gripper 查询包含本体感觉，target/goal 查询依赖指令 token。
- **动作条件动力学**：将每个动作块（chunk）划分为 \(J\) 个有次序的子段，用角色 transformer 交替进行角色间自注意力和动作交叉注意力，采用带残差门控的更新：
  \[
  \Delta z^{r,k}_j = D_r^\theta(Z^{k}_{t,j-1}, E_a(A^k_{t,j}), \ell),\quad
  \hat z^{r,k}_{t,j}=z^{r,k}_{t,j-1}+\sigma(g^{r,k}_j)\odot \Delta z^{r,k}_j
  \]
  这样可以定位“最早违规边界”，供后缀修复使用。
- **语义转换监督**：在每一子段预测接触/稳定抓取、谓词建立、谓词保持、合取满足、阶段身份及合法阶段转换、夹具状态（抽屉位移、微波炉门角、炉灶激活）等。
- **硬负样本**：在保持观测和任务的前提下，构建打乱段序、反转 approach–grasp、替换轨迹、扰动释放时机的负样本，并采用 margin loss 排序，保证模型对动作时序和因果敏感。
- **候选生成与选择**：
  - 用 Flow-Matching（FM）头在角色状态下采样 \(K\) 个候选动作块；
  - 阶段感知选择器（stage-aware selector）综合接触、谓词建立/保持、夹具状态、角色预测和不确定性打分；
  - **违规感知后缀修复**：若最佳候选分数低于阈值或在 \(j^\star\) 处预测到违规，则固定有效前缀，仅用掩码动作修复（inpainting）重采样后缀，避免全块丢弃带来的破坏性重规划。
- **训练目标**：共 11 项损失，分三组：
  - \(L_{\text{rep}}\)：保留 LeWM 预测、角色绑定、状态动力学；
  - \(L_{\text{sem}}\)：接触/抓取、谓词建立、保持、阶段、夹具状态；
  - \(L_{\text{policy}}\)：FM 动作生成、打乱负样本排序、后缀修复。

## 6. 主要结论与发现

- **角色状态优于实例槽和整体隐状态**：将实体绑定到“gripper/target/goal/relation/phase”五个功能角色，显著改善生成质量和动作选择。
- **语义监督与硬负样本不可或缺**：缺少显式语义头或打乱负样本会使动作排序准确率大幅下降，说明模型必须真正理解动作时序与谓词保持，而非静态视觉匹配。
- **分割掩码只是可选先验**：无掩码或损坏掩码下仍有较高成功率，证明 patch-based 表示本身蕴含了任务关键语义几何。
- **跨套件迁移有效**：角色表示带来可迁移的物理语义，少量目标套件数据即可显著优于从零训练。
- **SR-WM 将对象中心预测重塑为规划接口**：统一角色状态直接支撑多候选生成、阶段感知重排序和违规感知修复，形成可部署的闭环物理交互规划。

## 7. 优点

- **方法论亮点**：

  - 掩码可选，兼顾感知稳健性与推理效率；

  - 硬负样本训练增强因果时序敏感性；
  - 违规感知后缀修复避免破坏性全块重采样。

## 8. 不足与局限

- **任务范围有限**：五角色本体主要适合单臂、目标导向的抓放/操作任务，不适用于双臂协同、可变形物体、工具使用或多目标并行任务，需要扩展为变基数的状态图。
- **监督标签获取成本**：谓词、接触、阶段和夹具状态标签在仿真中容易获得，但在真实物理系统中需要仔细标注或估计，存在标定风险。
- **感知限制**：可选分割先验只降低了对分割器的依赖，并不能消除遮挡或绑定失败；在极端遮挡下（如 peg-in-hole）可能误判谓词已建立。
