## 摘要
用于物理交互的世界模型通常被训练为预测未来的观测或潜在特征；然而，面向规划的模型必须回答一个根本不同的问题：候选动作是否会产生与任务一致的未来，同时保持关键关系。整体式状态表示掩盖了底层实体，而标准的实例级对象槽位仅识别存在什么，并未指定每个实体在任务情境中扮演的角色。为弥合这一差距，我们提出了语义丰富世界模型（SR-WM），这是一种围绕五个功能角色构建的任务条件世界模型：夹爪、目标、目的、关系和阶段。在SR-WM中，视觉实体编码器从预训练的补丁特征中提取软实体假设，使得分割掩码可作为可选的提议先验，而无需将其作为必需的状态表示或推理输入。随后，角色绑定器将这些假设映射到任务特定角色，同时动作条件动力学模型预测角色转换以及细粒度语义，包括抓取/接触、谓词建立、关系保持、夹具状态和阶段变化。关键在于，这种统一的角色状态为下游的多候选动作生成、阶段感知重排序和违反感知后缀重采样提供了基础。我们的综合评估协议覆盖全部四个LIBERO模拟套件、跨套件迁移、感知诊断和动作敏感性分析。最终，这一表述将对象中心预测转变为一种语义接口，将视觉动力学与面向规划的决策制定相连接。

## Abstract
World models for physical interaction are typically trained to predict future observations or latent features; however, a planning-oriented model must answer a fundamentally different question: whether a candidate action produces a task consistent future while preserving essential relations. Monolithic state representations obscure the underlying entities, while standard instance-level object slots merely identify what is present without specifying what role each entity plays in the task context. To bridge this gap, we present the Semantically Rich World Model (SR-WM), a task-conditioned world model structured around five functional roles: gripper, target, goal, relation, and phase. Within SR-WM, a visual entity encoder extracts soft entity hypotheses from pretrained patch features, allowing segmentation masks to serve as optional proposal priors without mandating them as required state representations or inference inputs. A role binder subsequently maps these hypotheses to task-specific roles, while an action conditioned dynamics model predicts role transitions alongside fine-grained semantics, including grasp/contact, predicate establishment, relation preservation, fixture state, and phase change. Crucially, this unified role state grounds downstream multi-candidate action generation, stage-aware reranking, and violation-aware suffix resampling. Our comprehensive evaluation protocol spans all four LIBERO simulation suites, cross-suite transfer, perception diagnostics, and action sensitivity analysis. Ultimately, this formulation transforms object-centric prediction into a semantic interface linking visual dynamics with planning-oriented decision making

## 2. 方法论

- **核心思想**：将视觉实体（entity）与任务角色（role）分离。实体是任务无关的可交换假设；角色绑定器在指令和机器人状态条件下，把实体映射为五个非可交换的预测状态组件：
  - **gripper**：末端执行器位姿、开合、接触与抓取状态；
  - **target**：任务相关对象或关节部件；
  - **goal**：目标容器、表面或期望的夹具状态；
  - **relation**：抓取器、目标、目的之间的几何与符号谓词；
  - **phase**：任务进度（接近、抓取、搬运、对齐、释放、完成）。
- **视觉实体编码**：在保留的 LeWM（15M 参数）基础上，从预训练 patch 特征中提取软实体假设（外观、几何、运动、置信度），多个视图通过交叉注意力竞争共享实体。
- **可选掩码先验**：SAM/Grounding DINO 生成的提议只作为注意力偏置，不替换 patch 上下文；训练时对提议、掩码和偏置强度进行 dropout，推理时 λ_seg=0 即为无掩码模式，因此**分割掩码不是必需输入**。
- **角色绑定**：语言条件查询通过交叉注意力从实体中聚合出任务角色状态，同一个实体在不同指令下可扮演不同角色或成为无关干扰物。
- **动作条件动力学**：动作编码器把候选动作划分为 J 个子段，角色 transformer 通过门控残差更新预测角色状态的中间转换，避免破坏未受影响的状态，并用于定位违规发生的最早边界。
- **语义转移监督**：预测接触/抓取、谓词建立、关系保持、合取满足、阶段转移和夹具状态；并通过“硬负样本”（打乱段序、反转接近–抓取顺序、替换轨迹、扰动释放时机）训练动作判别能力。
- **生成、选择与修复**：
  - 角色状态条件化 Flow-Matching（FM）动作头，生成 K 个候选动作块；
  - 阶段感知选择器根据预测的进度、接触、建立/保持、夹具有效性和不确定性进行排序；
  - 若最优候选分数低于阈值或预测到违规，则保留有效前缀并仅重采样后缀（“有损感知后缀重采样”），在匹配生成预算下与全块重采样对比。
- 训练目标包含 11 个具体损失项：LeWM 目标、角色绑定、状态动力学、接触/抓取、谓词建立、关系保持、阶段、夹具状态、动作流匹配、硬负样本排序和后缀修补损失。

## 6. 主要结论与发现

- **角色状态显著改善动作生成**：与 LeWM 单体潜变量相比，SR-WM 的 Candidate 0 平均成功率从 **45.5%↑62.8%**，Oracle@4 覆盖率从 **68.0%↑89.5%**。
- **语义选择器与后缀修复有效**：语义选择器将覆盖率转化为 75.3% 的 top-1 成功率；后缀修复进一步达到 **83.0%**。
- **显式语义监督对动作鉴别至关重要**：移除语义头或硬负样本会使动作排序准确率降至接近随机（53.7%–60.8%），完整模型达到 78.2% 排名准确率和 0.157 的 shuffle gap。
- **角色结构优于实例槽**：从五个实例槽（55.0%）逐步加入指令、目标/目的、关系、夹爪和阶段，最终达到 **83.0%**，证明功能角色的显式分解是可靠物理执行的关键。
- **分割掩码不是必需的**：无掩码 SR-WM 仍有 72.6% 的成功率，损坏掩码仅轻微下降到 70.8%；oracle 掩码给出 78.4% 的上限，验证了“软先验而非硬依赖”的设计。
- **跨任务迁移可行且高效**：Object 套件预训练在 Goal 套件上适配（74.6%）和 LIBERO-10 上适配（58.7%）均优于从零训练（66.3%和50.6%），联合预训练性能最佳。

## 7. 优点

- **概念创新**：将实例槽提升为“任务条件角色状态”，使世界模型直接服务于规划决策，而不是只做特征预测或事后重排序。
- **方法统一**：同一角色状态同时驱动动作生成、动力学预测、候选选择和违规修复，形成了闭环语义规划接口。
- **架构轻量**：保留 15M 参数的 LeWM 基础，完整系统仅 45.4M 参数，在单卡 A100 上可高效运行。
- **掩码可选性**：既利用分割先验提升性能，又通过 dropout 保证推理时不需要掩码，鲁棒于掩码缺失或损坏。
- **评估体系规范**：区分生成、覆盖、选择、修复、迁移和效率，明确 Oracle@K 的上限含义，训练与测试流程严格分离，消融设计清晰。
- **可解释性**：角色绑定权重和语义转移预测可直接诊断错误（如绑定错误、阶段错位），有利于失败分析。

## 8. 不足与局限

- **固定五角色本体**：适用于单臂、目标明确的抓放任务，但难以直接扩展到双臂操作、多目标同时操作、可变形物体、工具使用等复杂场景。
- **监督依赖**：谓词建立、关系保持和阶段标签在仿真中可由模拟器提供，但在真实物理系统中需要仔细标注或估计，部署成本较高。
- **感知失败仍存在**：可选掩码减弱了分割依赖，但不能完全解决严重遮挡或绑定错误；论文定性地指出“极端遮挡会导致目标几何中心跟踪失败”。
