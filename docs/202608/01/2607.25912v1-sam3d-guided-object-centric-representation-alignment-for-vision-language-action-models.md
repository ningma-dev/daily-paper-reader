## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作中展现出强大潜力，但大多数现有模型依赖2D视觉-语言骨干网络，缺乏对目标物体的细粒度3D理解，特别是在遮挡、姿态变化、尺度变化和精确空间交互情况下。我们提出了一个基于π_0的面向对象的3D表示对齐框架，使用SAM3D作为冻结的3D教师，在训练期间提供目标物体的3D先验。具体来说，我们使用物体识别模型定位与任务相关的物体，生成相应的物体掩码，并使用SAM3D提取密集的物体级3D表示，再将其与π_0的中间视觉特征对齐。这使得策略能够内化目标物体的3D信息，同时保留原始的RGB-语言到动作的推理流程，在测试时无需深度、点云、掩码、SAM3D或额外的3D模块。仿真实验显示了一致的改进，在LIBERO上达到99.1%，在CALVIN上平均长度为4.11。真实世界实验进一步证明，我们的方法在长时程操作场景中尤为有效，在这些场景中，机器人必须在多个子任务中关注不同的目标物体。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

### 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型通过将预训练的视觉-语言模型适配到机器人动作预测中，已成为通用机器人操作的重要方向。然而，绝大多数现有 VLA 模型仍主要依赖 **2D RGB 图像**，仅通过动作预测进行学习，缺乏对目标物体 **3D 属性**（形状、姿态、尺度、空间布局）的细粒度理解。
- **核心问题**：在遮挡、姿态变化、场景杂乱、精确物体放置等场景下，2D 视觉表示无法提供足够的目标物体 3D 先验，导致策略在复杂操作任务中表现受限。作者将此归纳为“**RGB 基础 VLA 策略的目标中心 3D 理解瓶颈**”。
- **关键挑战**：如何在**不修改原始输入输出接口**、测试时**不引入额外 3D 模块或输入**的前提下，将目标中心 3D 知识注入仅基于 RGB 的 VLA 策略。
- **与现有工作的不同**：已有 3D 增强方法或引入显式 3D 观测（深度图、点云等）、或注入估计的 3D 位置与空间动作网格、或侧重于**全局场景级**空间表示。本文聚焦于**目标物体级**的 3D 先验，且仅在训练期间注入，测试时完全保持原始 π₀ 推理管线。

### 二、方法论

#### 1. 整体框架与核心思想

- 基于 **π₀**（flow-matching VLA 模型）搭建，其骨干由 SigLIP 视觉编码器 + Gemma 语言模型组成。
- 使用 **SAM3D 作为冻结的 3D 教师网络**，在训练期间提供目标物体的密集 3D 几何先验（形状、表面结构、空间布局），并与 π₀ 中间层视觉特征进行对齐。
- 关键设计：**仅训练时使用 3D 教师，测试时完全移除**——推理仅需 RGB 图像与语言指令，无需深度、点云、掩码或 SAM3D 模块。

#### 2. 技术流程

- **物体掩码生成**：通过开放式词汇检测（Grounding DINO、YOLO）定位任务相关物体，再用 SAM2 生成二值掩码。
- **SAM3D 特征提取**：将多视角图像与对应物体掩码展平后送入冻结的 SAM3D 教师，提取物体级密集 3D 特征 Tₜ ∈ R^(BV×L_T×D_T)。
- **空间重采样**：将 SAM3D 特征序列重塑为 2D 特征网格，通过**双线性插值**调整到 π₀ 视觉 token 分辨率，使教师特征与学生视觉 token 空间对齐。
- **学生特征提取与投影**：从选定的 Gemma 层提取中间视觉特征 Sₜ，通过可学习的投影头 P_φ 映射到 SAM3D 特征空间。
- **掩码归一化对齐损失**：

```
L_align = MSE( Norm(^Tₜ)[Mₜ], Norm(T̄ₜ)[Mₜ] )
```

其中 Mₜ 是沿特征维度扩展的 token 级掩码，仅对目标物体 token 计算损失；特征经 ℓ2 归一化后计算 MSE，以调节 SAM3D 与 π₀ 间的尺度差异。

- **总训练目标**：

```
L = L_action + α·L_align
```

其中 L_action 为 π₀ 原有的流匹配动作损失，α 控制 3D 特征监督强度。

#### 3. 子任务感知数据处理（Subtask-aware Data Processing）

- 针对长时程任务，使用 LLM（GPT-4o）将高层指令分解为多个子任务。
- 每个子任务关联其对应的目标物体，生成**阶段特定的物体掩码**，从而在不同操作阶段提供不同的 SAM3D 3D 监督信号。
- 这使策略能够在多阶段操作中关注**不同阶段的正确目标物体**。

#### 4. 冷冻表示探测适配器（Frozen-representation Probing Adapter）

- 训练完成后，冻结整个 VLA 骨干，仅训练一个轻量两层 MLP 探测器 P_ω，用于从中间视觉特征预测 SAM3D 目标表示。
- 通过比较原始 π₀ 与 SAM3D-VLA 的探测性能，验证 3D 先验是否真正被编码进 VLA 表示中。

### 六、主要结论与发现

1. **显著性能提升**：
   - LIBERO 平均成功率 99.1%，其中 LIBERO-Long 达 98.4%（为所有对比方法中最佳）。

### 七、方法亮点与优点

1. **训练-推理不对称设计**：3D 教师仅训练使用，推理零额外开销，兼具 3D 信息增益与部署简洁性。
2. **对象中心视角**：区别于场景级空间监督，聚焦**任务相关目标物体**的 3D 先验，更精准地解决操作核心需求。
3. **子任务感知监督**：长时程任务中依据子任务提供阶段特定的物体 3D 监督，有效应对多目标切换挑战。
4. **使用冻结教师网络**：无需额外的 3D 标注数据，利用现成的 SAM3D 提供监督信号，训练流程简洁。
5. **归一化掩码对齐损失**：ℓ2 归一化 + token 级掩码的设计，能有效解决跨模型尺度差异并聚焦于目标区域。
6. **机制验证意识**：通过探测实验验证方法的有效性，而非仅依赖最终任务准确率，增加了结论的可信度。

### 八、不足与局限

1. **对上游模型的依赖**：训练流程依赖自动生成的子任务注释、物体检测和分割结果，分解/定位/分割的错误会传播为有噪声的监督信号。
2. **SAM3D 单图像限制**：SAM3D 仅支持单张图像处理，在严重遮挡、透明物体或较差视角下可靠性有限，且未能利用多视角信息。

7. **计算开销不透明**：SAM3D 教师特征提取的离线计算成本、训练时长等未详细披露。
