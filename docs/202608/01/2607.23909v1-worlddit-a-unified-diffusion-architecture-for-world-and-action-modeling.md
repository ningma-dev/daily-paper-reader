## 摘要
许多最近的机器人策略通过使用大型预训练视觉-语言模型（VLM）作为动作主干来追求更强的控制。我们提出了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并在没有大型预训练VLM动作主干的情况下实现了强劲的性能。在训练过程中，单个扩散Transformer生成连续的动作块，并从未来的相机帧中预测归一化的RGB补丁目标。在四个LIBERO模拟套件中，WorldDiT处于报告总模型参数和平均成功率的帕累托前沿上，这些方法报告了所有四个套件的结果。这些结果为未来的扩展研究提供了一个强大的十亿参数以下基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 论文提出的方法论

**核心思想：**

- WorldDiT 使用**单个共享的扩散 Transformer（DiT）骨干**，同时学习两个任务：①生成连续的机器人动作块（action chunk）；②预测未来相机帧中归一化 RGB patch 的流速度（auxiliary world modeling objective）。
- 与近期依赖大型 VLM 自回归生成动作 token 的世界-动作模型不同，WorldDiT 以统一的 flow matching 公式处理动作与视觉目标，避免了大型预训练 VLM 骨干的开销。

**关键技术细节：**

- **数据窗口设计**：使用长度为 N=10 步的轨迹片段，前 C=3 步为观测上下文，后续 H=7 步为待预测的动作块；未来 RGB patch 目标来自时间偏移 H 处的帧。
- **多模态编码**：
  - 冻结的 MAE 图像编码器处理主相机和腕部相机图像；
  - 共享 Perceiver Resampler 汇总视觉特征；
  - 冻结的 CLIP 文本编码器处理语言指令；
  - 可训练的机器人状态编码器分别编码手臂与夹爪状态并拼接投影为一个状态 token。
- **RGB patch 目标构造**：每张 CLIP 预处理的 224×224 RGB 帧划分为 16×16 patch，每个 768 维 patch 向量用自身均值与方差归一化，每台相机均匀保留 64 个 patch，两台相机共 128 个目标 token。
- **Flow matching 训练目标**：定义 x𝜏 = (1−𝜏)𝝐 + 𝜏y，损失函数为：

  L_flow = 𝔼[‖v_θ(x𝜏, 𝜏, c) − (y − 𝝐)‖²₂]

  总损失为动作流损失与 RGB patch 流损失的加权和：L_total = w_action·L_action_flow + w_rgb·L_rgb_flow，权重分别为 0.1 和 0.001。
- **推理部署**：仅走动作路径，RGB patch token 与预测头完全不参与推理图。动作从高斯噪声初始化，经 20 步 Euler 积分求解速度场，得到预测动作块后执行前 3 个动作，更新上下文窗口并重新规划（receding-horizon control）。

**模型配置**：DiT 骨干深度 4，隐藏维 1024，16 个注意力头，4 个 register tokens。

- **性能表现**：WorldDiT 在四个 LIBERO 套件上取得 Spatial 98.0%、Object 97.0%、Goal 92.8%、Long 91.8%，平均 **94.9%** 成功率。Long 仍是最难套件，符合其多阶段长序列任务特性。

## 7. 优点

- **架构统一且简洁**：单一 DiT 骨干以共享的 flow matching 公式同时处理连续动作与未来视觉预测，避免了多模型级联的复杂性。
- **参数高效**：以 399M 总参数量（仅 135M 可训练）达到与十亿级 VLM 骨干方法可比的性能，为资源受限场景提供了可行方案。
- **训练-推理解耦设计巧妙**：训练时未来 RGB patch 预测提供辅助监督信号，推理时完全裁剪该分支，保持动作路径紧凑高效，实现"世界模型辅助训练、动作专用部署"。
- **提供了清晰的扩展基线**：论文明确将自己定位为"亚十亿参数基线与扩展研究的起点"，而非声称展示缩放规律，学术定位诚实清晰。
