## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的可扩展方法引起了越来越多的兴趣。虽然这些模型是有效的动作预测器，但将它们部署为机器人智能体暴露了关键差距：缺乏失败恢复机制、长时间跨度内执行不一致，以及对观察、任务或实体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块分别解决这些限制，但所需的是一个通用框架，能够系统地将预训练的VLA转化为机器人智能体。我们提出了RoboBRIDGE，一个模块化框架，提供对五个协调模块（即Monitor、Perceptor、Planner、Controller和Robot Interface）的编排层，以从现成组件（包括预训练的VLA）组合出健壮的机器人智能体。Monitor将快速失败检测与分层恢复配对，在错误级联之前进行纠正。当环境偏离当前计划时，Planner触发重新规划，而Perceptor异步更新场景理解，避免执行停滞。在Controller内部，基本技能微调将操作分解为具有专用LoRA适配器的域不变基元，从而减少使用VLA时对域迁移的敏感性。在LIBERO、RoboCasa以及跨越多个机器人平台和VLA主干网的真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人智能体能力不仅仅来自扩展动作预测器，而是来自围绕它们的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 1. 核心问题与研究动机
- **核心背景**：视觉-语言-动作（VLA）模型在机器人操作中展现出强大的动作预测能力，但其本质仍是“动作预测器”而非“机器人智能体”。
- **关键鸿沟**：
  - **无失败恢复机制**：抓取失败、碰撞等错误无法被实时检测和纠正，容易级联放大。
  - **长程一致性缺失**：多步任务中误差逐步累积，导致计划崩溃。
  - **域迁移鲁棒性不足**：对观察变化、任务变化和实体（embodiment）变化敏感，sim-to-real 迁移脆弱。
- **现有方案痛点**：已有工作（如 Code-as-Monitor、DoReMi、SAFE 等）各自针对单一故障模式，缺乏通用统一框架。
- **研究类比**：LLM 从“文本生成器”演化为“通用智能体”的关键不是训练更大的模型，而是构建通用编排框架（如 LangChain、AutoGen）。作者主张 VLA 面临同样的瓶颈——缺失的不是更优策略，而是将策略提升为智能体的**通用编排框架**。

## 2. 方法论
### 核心思想
RoboBRIDGE 是一个**策略无关（policy-agnostic）** 的模块化编排框架，通过协调五个模块，将任意动作生成策略（不限于 VLA）包装为健壮的机器人智能体，且**无需重新训练或修改基座模型权重**。

### 五个核心模块
- **Perceptor（感知器）**：将原始传感器观测转换为对象中心的场景状态（身份、3D 位姿、语义属性如可操作性）。
- **Planner（规划器）**：结合场景状态与语言指令，将任务分解为有序的原始技能序列。
- **Controller（控制器）**：插件槽位，承载动作生成策略（如 VLA、IK 控制器等）。
- **Robot Interface（机器人接口）**：抽象实体相关的 API、时序、安全限制和坐标变换，使同一套上游逻辑可跨机器人/模拟器运行。
- **Monitor（监视器）**：闭环验证执行结果，失败时触发分层恢复。

### 三大力学机制
**（a）两阶段监控与分层恢复**
- **Phase 1—轻量级成功检查**：使用低成本检测器频繁检查 `(观测, 计划上下文) → (成功标志, 置信度)`，不阻塞执行。
- **Phase 2—失败诊断与恢复**：失败且高置信度时停机，诊断模型输出恢复目标，按计算范围升序选择四种策略：
  1. **retry**：重试当前原始技能；
  2. **regenerate**：重新生成轨迹，保留当前计划与感知状态；
  3. **replan**：基于最新异步感知重新规划；
  4. **re-perceive**：强制完整重新感知后再规划（感知状态不可靠时）。

**（b）异步感知 + 发散触发重规划**
- 感知线程持续更新线程安全的单槽缓冲区，隐藏感知延迟。
- 每个原始技能完成后，计算当前计划所用感知与最新感知的发散度：
  - `Δ = max(位移差异) + λ × 对象集合对称差`
- 当 `Δ ≥ τ` 时，保留高层动作序列（如 PICK→PLACE），仅重新生成当前及后续技能的空间参数，避免不必要的高层推理。

**（c）原始技能微调（Primitive Skill Fine-tuning）**
- 将操作分解为域不变原始技能集合：`P = {MOVE, GRIP, ROTATE, ...}`。
- 为每个原始技能配备**专用 LoRA 适配器**，共享冻结的 VLA 主干。
- 控制器切换采用两级解析器：存在对应适配器则使用之；否则回退到所有适配器的平均。
- 动作输出为 7-DoF delta 动作：`(δx, δφ, g)`；若有 IK 求解器则转为绝对目标，否则回退为笛卡尔速度指令。

### 算法流程
整个管线的核心循环为：异步感知启动 → 初始规划 → 按顺序执行每个原始技能 → 动作生成与执行 → 轻量级成功检查 →（失败则分层恢复）→ 发散度检查 →（超阈值则重规划）→ 继续下一技能。

## 6. 主要结论与发现
- **核心结论**：可靠的机器人智能体能力**并非源于扩大动作预测器规模，而是源于围绕它们的结构化编排**。
- **持续改进**：RoboBRIDGE 在所有 VLA 主干和基准上均一致优于独立部署，无需扩展或重训练基座模型。
- **量化效果**：
  - LIBERO：平均成功率从 35.5% 提升至 39.7%；
  - RoboCasa：平均从 3.7% 提升至 7.5%（排除抓放任务后从 6.2% 提升至 11.4%）。
- **监控与规划缺一不可**：规划器单独（无监控）时所有 LLM 主干差距不大（1.8%–8.0%）；启用监控后优劣分层明显，说明**推理能力强的 LLM 对失败诊断至关重要**。
- **框架优于模型内自校正**：CycleVLA 在框架内集成自校正仅达 7.5%，远低于 RoboBRIDGE 的表现，说明**外部编排优于模型内部机制**。
- **策略无关性验证**：经典 IK 控制器也能在框架内达到 22.1% 成功率，证实框架设计不受限于学习型策略。

## 7. 优点
- **通用性强**：策略无关的模块化设计，可包装任意动作生成器（VLA、IK、脚本），无需重新训练基座模型。
- **系统性解决三类瓶颈**：一个框架同时解决失败恢复、长程一致性和域鲁棒性，而非碎片化修补。
- **异步感知设计巧妙**：感知与执行并发，仅在场景实质变化时触发重规划，兼顾实时性与计算效率。
- **监控分层设计高效**：轻量级检查 + 深度诊断分离，避免不必要的计算开销。
- **原始技能微调创新**：LoRA 适配器分解操作阶段，减少领域迁移敏感度，且切换开销极小（原位换装）。
- **与 LLM 智能体发展类比有说服力**：将 LLM 编排框架的成功经验迁移到 VLA，视角新颖。
- **控制变量严谨**：主实验中仅改变部署方式（独立 vs 框架），确保增益确实来自框架本身。

## 8. 不足与局限
- **原始技能词汇有限**：当前覆盖单臂桌面操作行为，对**接触丰富交互、可变形物体、双臂任务**支持不足。
- **监控阈值与恢复规则手动设定**：依赖人工经验，未实现从交互数据中学习。
- **缺少验证与校验（V&V）层**：无法在控制器成功率极低时提前判断并切换策略或安全终止。
- **感知鲁棒性仍是瓶颈**：失败分析表明感知错误（尤其遮挡、相似物体混淆）是主导失败模式之一。
- **接触丰富操作的不可恢复性**：某些接触密集型失败会不可逆转地改变环境状态，导致重试失效。
- **成功率绝对值偏低**：特别是 RoboCasa 上整体成功率有限，距离实际部署仍有距离。
- **真实世界评估偏定性**：以案例展示为主，缺少系统性统计数据支撑。
- **算力与资源信息不透明**：未披露完整训练/推理算力成本，难以评估实际部署的经济性。
