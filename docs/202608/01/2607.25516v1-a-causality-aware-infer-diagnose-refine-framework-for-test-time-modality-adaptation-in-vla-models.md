## 摘要
视觉-语言-动作（VLA）模型基于视觉观察和本体感觉状态，预测序列动作以执行由语言指令指定的任务。然而，如何在VLA模型中融合模态仍然是一个开放问题，因为机器人操作涉及动态阶段，例如远距离移动和近距离交互，其中视觉观察的重要性可能随时间变化。在本文中，我们提出了一种推断-诊断-细化（IDR）框架，一种模型无关的框架，可与多种VLA架构集成，用于在测试时细化动作预测。IDR首先在视觉观察的事实和反事实场景下推断动作，然后将视觉观察的因果效应诊断为估计的动态重要性，最终以无需训练的方式用于细化动作预测。我们进一步设计了一个因果感知的动作细化器来实现IDR框架，包括用于推断反事实动作的零填充干预、用于诊断因果效应的基于范数的量化，以及用于细化动作的门控残差融合。在仿真基准和真实世界任务上的大量实验表明，多种VLA骨干网络的整体性能均有提升，证明了在测试时动态调整视觉重要性的有效性。

## Abstract
Vision-language-action (VLA) models predict sequential actions to execute tasks specified by language instructions, conditioned on visual observations and proprioceptive states. However, how to fuse modalities in VLA models remains an open problem, since robot manipulation involves dynamic phases, such as long-distance movements and close-range interactions, in which the importance of visual observations may vary over time. In this paper, we propose an infer-diagnose-refine (IDR) framework, a model-agnostic framework that can be integrated with diverse VLA architectures for refining action predictions at test time. IDR first infers actions under factual and counterfactual scenarios of visual observations, and then diagnoses the causal effects of visual observations as the estimated dynamic importance, which is finally used to refine the action predictions in a training-free manner. We further design a causality-aware action refiner to realize the IDR framework, including zero-padding interventions for inferring counterfactual actions, norm-based quantification for diagnosing causal effects, and gated residual fusion for refining actions. Extensive experiments on both simulation benchmarks and real-world tasks show improvements in overall performance across multiple VLA backbones, demonstrating the efficacy of dynamically adjusting visual importance at test time.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：在给定语言指令作为上下文的前提下，将视觉观察和本体感觉状态视为两个输入因子，通过对比“事实输出”和“反事实输出”（将某个模态置零）来估计该模态对动作的因果效应，动态反映当前时刻的视觉重要性，并用门控残差融合修正盲执行问题。
- **算法流程（三阶段）**：
  - **Infer（推断）**：
    - 用冻结模型计算事实基础动作：`abase,t = πθ*(vt, st, l)`。
    - 对视觉和本体感觉分别做零填充干预（`do(V=0v)`、`do(S=0s)`），得到反事实动作：
      `ano_img,t = πθ*(0v, st, l)`
      `ano_prop,t = πθ*(vt, 0s, l)`。
  - **Diagnose（诊断）**：
    - 计算动作偏差：`Δimg,t = abase,t − ano_img,t`，`Δprop,t = abase,t − ano_prop,t`。
    - 以L2范数量化因果效应强度：`Eimg,t = ||Δimg,t||2`，`Eprop,t = ||Δprop,t||2`。`Eimg,t` 越大表示模型当前越依赖视觉，反之则视觉重要性低。
  - **Refine（细化）**：
    - 定义门控：`gt = I[Eimg,t < τ]`，τ 设为基线模型视觉因果效应的均值；当视觉重要性低时激活修正。
    - 引入有界本体感觉正则器：`wprop,t = β·min(1, Eprop,t/(Eimg,t+ϵ))`，`uprop,t = clip(Δprop,t, −λ, λ)`，限制低层控制抖动。
    - 最终动作：`afinal,t = abase,t + gt·(αΔimg,t + wprop,t·uprop,t)`，其中 α=0.08, β=0.05, λ=0.1。
- **框架性质**：训练无关、模型无关，只需三次前向传播即可完成每一步的精炼。

## 6. 主要结论与发现

- **视觉重要性的动态性**：通过干预诊断发现，视觉重要性随模型架构、部署环境和操作阶段变化：不同架构呈现从视觉主导到本体感觉主导的差异；同一模型在不同 benchmark 上可能有完全不同的模式；任务执行中视觉重要性在夹爪开合等阶段转换点附近波动。
- **IDR 的有效性**：
  - 仿真中：LIBERO 上四种骨干均提升，最大增益 VLA-Adapter +1.40、π0.5 +1.25；SIMPLER Variant Aggregation 设置提升最大（+6.33）；CALVIN 平均完成长度从 4.22 提升到 4.44。
  - 真实世界中：平均成功率从 56.5% 提升到 75.3%，成功任务平均完成时间从 53.6s 下降到 41.5s；Organize Table 完全完成率从 0% 提升到 33.3%。
- **机制分析**：门控选择仅在视觉重要性低时干预是关键；均匀干预会损害性能；反向干预（Mode F）甚至低于基线，说明修正方向必须符合诊断出的因果效应方向。
- **模态不对称性**：即使对于本体感觉主导的 X-VLA，直接用本体感觉偏差做修正也会导致严重退化，说明视觉适合做任务级修正，本体感觉更多耦合低层控制。

## 7. 优点

- **训练无关、模型无关**：可直接用于任意冻结 VLA 模型，即插即用，无需修改训练流程或模型参数。
- **理论扎实**：从因果推断角度定义视觉重要性，通过反事实干预比较输出的分布变化，比单纯特征统计更能够反映因果贡献。
- **动态适应性**：能在每一步根据当前任务阶段动态调整视觉权重，适应了机器人操作的阶段性特征。
- **设计克制合理**：门控机制只激活低视觉依赖时刻，有界正则器限制低层抖动，保护了原模型的先验行为。
- **实验广泛**：覆盖多种骨干、多 benchmark、仿真到真实世界，并包含完整消融，验证了方法的普适性和各个组件的必要性。
- **实际效果显著**：真实世界不仅提升成功率，还通过减少不必要的动作降低了完成任务的平均时间，部分抵消了额外推理开销。

## 8. 不足与局限

- **推理效率**：每步需要三次前向传播，增加测试时计算负载；作者承认这是主要限制，并计划未来将诊断机制蒸馏到模型中。
- **超参数敏感**：α、β、λ、τ 需要手动设置；尽管在中等范围内鲁棒，但 τ 选择依赖基线统计量，可能在不同模型/环境需要重新调整。
- **适用范围有限**：主要面向视觉引导的动态矫正；本体感觉引导的变体表现很差，说明方法不适用于用本体感觉做主要修正信号的场景。
- **评估统计强度不足**：真实世界任务试验次数较少，缺乏多次重复的方差或显着性检验；仿真中部分结果依赖作者复现，可能引入复现偏差。
