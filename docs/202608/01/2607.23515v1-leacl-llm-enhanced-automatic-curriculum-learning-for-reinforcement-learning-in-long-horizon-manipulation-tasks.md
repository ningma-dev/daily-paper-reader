## 摘要
长时程操作任务由于稀疏的奖励信号和较长的任务周期，给强化学习带来了重大挑战。自动课程学习（ACL）通过逐步训练智能体处理从易到难的一系列任务，已被提出用于应对这些挑战。然而，ACL的成功高度依赖于任务相关的规范——例如定义良好的任务参数空间和难度度量——这些往往需要人工设计，且难以在不同任务间泛化。大语言模型（LLM）的最新进展提供了一种有前景的替代方案，使得能够利用LLM的网络规模常识知识将复杂任务分解为有意义的子任务。这种分解可以为长时程任务的高效学习提供自然的课程结构。然而，现有的基于LLM的方法通常依赖人工设计的稠密奖励函数来学习每个子任务，这可能会引入偏差，并且仍然需要大量的人工监督。在这项工作中，我们提出了大语言模型增强的自动课程学习（LEACL），这是一个融合LLM和ACL的框架，以解决上述局限性。具体来说，LLM既用于将任务分解为子任务，也用于为每个子任务生成任务相关的规范。然后，ACL算法使用这些规范，仅依靠稀疏奖励信号来指导学习，从而消除了对稠密奖励设计的需求。我们在LIBERO基准测试中的五个长时程操作任务上评估了LEACL。与人工设计的稠密奖励相比，LEACL在成功率方面取得了更好的渐近性能。

## Abstract
Long-horizon manipulation tasks pose significant challenges for reinforcement learning due to sparse reward signals and long horizons. Automatic curriculum learning (ACL) has been proposed to tackle these challenges by progressively training agents on a sequence of tasks, from easier to more difficult. However, the success of ACL depends heavily on task-dependent specifications-such as well-defined task parameter spaces and difficulty measures-which are often manually crafted and difficult to generalize across diverse tasks. Recent advances in large language models (LLMs) offer a promising alternative by enabling the decomposition of complex tasks into meaningful subtasks using the LLMs' web-scale common-sense knowledge. This decomposition can provide a natural curriculum structure for efficient learning of long-horizon tasks. However, existing LLM-based methods typically rely on hand-designed dense reward functions to learn each subtask, which can introduce bias and still requires significant human supervision.   In this work, we propose LLM-enhanced automatic curriculum learning (LEACL), a framework that integrates LLMs and ACL to address these limitations. Specifically, LLMs are used to both decompose tasks into subtasks and to generate task-dependent specifications for each subtask. These specifications are then used by ACL algorithms to guide learning using only sparse reward signals, eliminating the need for dense reward design. We evaluate LEACL on five long-horizon manipulation tasks from the LIBERO benchmark. LEACL achieves better asymptotic performance in terms of the success rates compared to human-designed dense rewards.

## 2. 论文提出的方法论

LEACL 包含三个依次执行的阶段（如图 1 所示）：

1. **LLM 任务分解（LLM-based task decomposition）**
   - 输入：自然语言描述的目标任务（如 "open the top drawer of the cabinet"）。
   - 过程：采用双层提示策略：
     - 高层：LLM 将目标任务分解为一系列自然语言描述的子任务（例如：1. 伸向抽屉；2. 抓住把手；3. 打开抽屉）。
     - 低层：另一个 LLM 将每个子任务转换为 PDDL（规划领域定义语言）规范。
   - 引入**反馈与迭代修正**机制（如语法检查、符号验证），提高 PDDL 生成的正确性和可执行性。
   - 输出：K 个子任务，每个子任务对应一个 PDDL 规范 τi = ⟨M, F, R, Pi, Ii, Gi⟩，其中 Pi 是谓词集合，Ii 和 Gi 分别是初始条件集合和目标条件集合。

2. **LLM 元任务生成（LLM-based meta-task generation）**
   - 为每个子任务生成两类任务相关规范，供 ACL 使用：
     - **任务参数空间（task parameter space）**：LLM 根据子任务的 PDDL 规范，识别出 Ni 维控制参数向量 ci，这些参数实例化子任务的具体变体（例如目标抽屉的初始位置、打开距离等）。LLM 通过生成 Python 函数模板，将控制空间映射到有效的 PDDL 规范集合。
     - **难度度量（difficulty measure）**：LLM 生成一组按难度排序的参数向量 (c1, ..., cD)，表示从易到难的任务序列，用于指导课程学习。

3. **自动课程学习（Automatic Curriculum Learning）**
   - 将生成的子任务参数空间和难度度量作为标准化接口，接入现有 ACL 算法（例如本文采用 Active Domain Randomization, ADR）。
   - ACL 根据智能体的训练历史（如回报、TD 误差）动态选择训练任务，逐步提升难度。
   - 依次求解每个子任务，并最终组合成完整任务策略。

**关键特性**：
- 全程不使用稠密奖励，仅使用稀疏任务完成奖励（R=1 表示达到目标状态，否则为 0）。
- ACL 算法采用“即插即用”设计，兼容多种 ACL 方法（如 ADR、ALP-GMM、PLR 等），通过 TeachMyAgent 框架集成。

## 6. 论文的主要结论与发现

1. **LEACL 显著优于稀疏奖励和仅任务分解的基线**，在所有任务上大幅领先，证明 LLM 生成的课程规范确实能解决稀疏奖励下的长时程学习难题。
2. **任务分解本身不足以解决接触丰富的子任务**，即使子任务较短，缺乏课程引导仍会失败（LEACL w/o ACL 大部分任务成功率为 0）。
3. **人工设计稠密奖励存在明显缺陷**：
   - 需要大量任务特定调参，不同物体间泛化差；
   - 奖励失衡会导致“贪图中间进度”而忽略最终任务完成，产生不精确行为；
   - LEAGUE 使用稠密奖励在 4/5 任务上显著不及 LEACL。
4. **LLM 生成的课程可接近甚至部分超越人类专家**：Human curriculum 在 3/5 任务上仍优于 LEACL，但人类专家需要多轮迭代设计；而 LEACL 的 LLM 在零样本情况下即可生成有效课程，无需人工监督。

## 7. 优点

- **无需稠密奖励设计**：彻底避免了人工/生成式稠密奖励带来的偏差与工程负担。
- **高度自动化**：LLM 以零样本方式完成任务分解和元任务生成，仅需自然语言任务描述和预定义谓词集合。
- **即插即用的 ACL 设计**：与多种现有 ACL 算法兼容，具备良好的扩展性。
- **结合符号规划与 RL**：利用 PDDL 结构化表示，使任务分解具备逻辑可验证性，并通过反馈机制提升可靠性。
- **实证优势**：在多个任务上达到或超过使用人工设计稠密奖励的方法，显示了方法的通用性和有效性。
