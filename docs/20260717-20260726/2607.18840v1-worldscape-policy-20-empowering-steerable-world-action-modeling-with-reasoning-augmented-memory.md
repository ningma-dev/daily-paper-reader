## 摘要
世界动作模型（WAMs）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了一种有前景的范式。然而，现有的WAMs受限于有限的时间上下文、粗粒度的任务级语言监督以及主要基于文本的条件设定，这阻碍了任务进度跟踪和细粒度语言-视频-动作对齐，同时限制了视觉上下文推理和跨实体迁移。在本文中，我们提出了WorldScape Policy 2.0，一种具有推理增强长短期记忆的可控WAM。其因果短期视觉记忆提供最近的观测作为DiT预填充，以保留局部交互动态，而其长短期事件记忆将历史VLM输出组织为全局历史、局部活跃和事件边界表示，用于进度感知检索。检索到的历史增强感知和自回归生成的规划令牌，为自主规划提供隐式子目标条件；语义强制进一步将事件级指令语义传递到这一潜在规划路径中。为了建立细粒度的多模态可控性，我们构建了ManipEvent-5M，一个事件基础的具体化预训练数据集，包含近500万个事件片段，带有对齐的动作轨迹、任务级指令、片段级子任务描述、目标图像和视频演示。这些设计提供了一个统一接口，用于从高层指令进行自主规划，以及从细粒度文本、目标图像或视频上下文提示进行可控执行。在仿真和真实世界平台上的实验展示了在长时域自主规划、细粒度指令遵循和上下文适应方面的卓越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有的世界动作模型（WAMs）在长时域机器人操作中面临三大限制：① 仅依赖当前观测或短时间窗口，缺乏对任务进度的感知（不同阶段类似视觉输入时无法区分）；② 语言监督粗粒度，通常一个整个任务只有一个任务级指令，无法指导细粒度的原子动作；③ 交互界面单一，仅支持文本指令，无法利用目标图像、视频演示等多模态线索，限制了视觉上下文推理和跨实体迁移。
- **整体含义**：本文旨在将WAM从短时域预测模型转变为可控的长时域策略，实现从高层指令自主规划、细粒度指令执行、视觉提示上下文适应等统一接口。关键洞察是长时域可控性需要两种互补的时间上下文：用于推理任务进度的语义事件记忆和用于保留局部交互动态的帧级视觉记忆。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出WorldScape Policy 2.0，一种带有推理增强长短期记忆的可控WAM。它耦合了：
  - **短期视觉记忆**：在因果DiT中保留最近观测作为视觉预填充，保持局部交互动态。
  - **长短期事件记忆**：在VLM推理分支中组织历史VLM输出为全局历史、局部活跃、事件边界三种视图，通过检索和门控融合增强当前推理令牌。
  - **隐式子目标规划**：通过语义强制（Semantic Forcing）将事件级子任务语义注入到自回归生成的规划令牌中，使模型在没有细粒度指令时也能自主推断当前子目标。
  - **统一的多模态控制接口**：支持文本（T5嵌入）、目标图像（VAE编码）、视频演示（VAE编码）作为条件。

- **关键技术细节**：
  - **动作表示**：每个动作块以相对于首帧的delta位置、6D相对旋转、绝对夹爪指令表示，双机械臂为20维。
  - **事件记忆构建**：对历史VLM输出（感知令牌+规划令牌）进行压缩（gist令牌），构建三个记忆视图：全局历史（压缩的完整历史池）、局部活跃（最近S_e个完成块）、事件边界（根据相邻块语义相似度变化最大的S_b个块，并保证最小时间间隔Δ）。检索时使用门控融合（token-wise sigmoid门控）。
  - **语义强制损失**：将VLM推理令牌的平均池化表示与对应事件级子标题的T5平均池化表示进行余弦相似度对齐，T5目标固定，只在推理侧训练投影器。
  - **三阶段训练**：
    - Stage1：事件级多模态WAM预训练（仅使用T5细粒度标题、目标图像、视频演示，不引入VLM事件记忆）。
    - Stage2：记忆感知中训练（引入VLM规划分支和事件记忆，使用语义强制损失，仅给高层指令，用子标题作语义监督）。
    - Stage3：下游任务后训练（根据任务选择交互模式，如自主规划、细粒度指令、上下文适应）。
  - **ManipEvent-5M数据集**：包含近500万事件段，来自真实机器人（自采+公共）、模拟器、无机器人UMI数据、人类第一人称视频。通过四阶段层次化标注（边界检测→层次化帧采样→具体化提示条件→多视图冲突解决）生成任务级指令、段级子标题、目标图像、视频演示。

- **公式/算法流程**（文字说明）：

## 7. 优点

- **方法创新**：首次将推理增强的长短期记忆集成到WAM中，实现进度感知的隐式子目标规划，而无需显式外部规划器。
- **数据集构建**：ManipEvent-5M大规模、多来源、事件级标注（含层级标题、目标图像、视频演示），支持多种交互模式，且标注流程设计细致（层次化采样、多视图冲突解决）。
- **三阶段训练策略**：从事件级可控预训练→记忆感知中训练→下游适应，逐步引入能力，语义强制使自主规划路径继承预训练的语言理解。
- **统一接口**：同一个模型支持自主规划、细粒度控制、视觉提示上下文适应，增强了实用性。
- **实验充分且公平**：仿真与真实世界结合，消融全面，对比方法包含多种VLA和WAM，评估指标包括不同设定下的成功率。
- **跨实体能力**：通过动作规范化（统一的delta姿态表示）和专用动作编码器-解码器，允许人类数据、模拟数据、不同机器人数据联合预训练。
