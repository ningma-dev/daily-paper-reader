## 摘要
测试时缩放通过增加计算量来改进基础模型推理，但机器人控制需要在执行动作前决定额外计算是否有效。世界动作模型（WAM）使这一决策变得自然：每次 rollout 都会同时产生一个动作块和预测的未来观测值。我们提出了一种无需训练的、基于选择性测试时缩放的框架 \methodgated，专为世界动作模型设计。首先实例化 \method，这是一种固定预算的 Best-of-N 选择器，通过冻结的几何基础模型计算预测未来观测的跨视图深度重投影一致性，从而对采样的 rollout 进行排序。\methodgated 增加了一个轻量级的动作-未来一致性门控，仅在初始 rollout 看起来内部不一致时调用 \method。在基于 RoboCasa、LIBERO Long 和 RoboTwin 2.0 的五个基准-主干设置中，固定预算的 \method 在每种设置下均提升了 N=8 的任务成功率，例如在 Cosmos Policy 下将 RoboCasa 组平均成功率从 66.3% 提升至 68.4%，在 X-WAM 下从 80.8% 提升至 82.5%。启用门控后，\methodgated 平均恢复了 74.8% 的始终启用模式下的成功率提升，同时仅在 26.2% 的决策点上触发额外采样。离线诊断表明，跨视图重投影是一个强大的、无需任务标签的选择器，并且我们识别出错误的低分选择是一种失效模式，这有助于解释为什么随着 N 的增加性能可能饱和或下降。

## Abstract
Test-time scaling improves foundation-model inference by spending additional computation, but robot control requires deciding whether extra compute is useful before executing an action. World Action Models (WAMs) make this decision natural: each rollout exposes both an action chunk and predicted future observations. We propose \methodgated, a training-free selective test-time scaling framework for WAMs. We first instantiate \method, a fixed-budget Best-of-$N$ selector that ranks sampled rollouts by cross-view depth reprojection consistency of their predicted futures, computed with a frozen geometry foundation model. \methodgated\ adds a lightweight action--future consistency gate that invokes \method\ only when the initial rollout appears internally inconsistent. Across five benchmark--backbone settings on RoboCasa, LIBERO Long, and RoboTwin~2.0, fixed-budget \method\ improves $N{=}8$ task success in every setting, e.g., raising the RoboCasa group average from $66.3\%$ to $68.4\%$ with Cosmos Policy and from $80.8\%$ to $82.5\%$ with X-WAM. With gating enabled, \methodgated\ recovers on average $74.8\%$ of the always-on success gain while triggering additional sampling on only $26.2\%$ of decision points. Offline diagnostics show that cross-view reprojection is a strong task-label-free selector, and we identify false low-score selections as a failure mode that helps explain why performance can saturate or degrade as $N$ increases.

### 1. 论文的核心问题与整体含义（研究动机和背景）

**研究动机**  
- 测试时扩展（Test-time Scaling）通过增加推理时的计算量（如采样多个候选轨迹并选择最佳者）可提升基础模型（如 LLM、机器人策略）的性能。但在机器人控制场景中，执行前必须判断额外计算是否值得，因为每次动作决策都有实时性要求。
- 世界动作模型（World Action Models, WAM）是一种新型视觉运动策略范式，它不仅输出动作块，还同时预测未来多视角视觉观测，这使得在执行前可以检查“想象未来”的内部一致性。
- 现有测试时扩展方法要么在每个决策点固定采样预算（浪费计算），要么依赖训练好的奖励模型、置信信号或模型特定接口，缺乏通用且高效的动态选择机制。

**核心问题**  
如何利用 WAM 本身暴露的未来预测信号，实现训练免费、选择性的测试时扩展：  
- 在什么情况下机器人应该花费额外计算采样更多候选轨迹？  
- 如何在不同视角预测的未来帧之间选择最一致的轨迹？

### 2. 论文提出的方法论：核心思想、关键技术细节、流程说明

**核心思想**  
设计一个两阶段一致性检查框架：  
1. **轻量门控（Action-Future Gate）**：基于当前视野帧与预测帧之间的光流，评估动作与预测视觉运动的一致性。若一致则直接执行，避免额外采样。  
2. **几何评估器（GeoBoN）**：当门控触发时，采样多个候选轨迹，并使用冻结的几何基础模型（VGGT-Ω）计算跨视图深度重投影不一致性，选择最低不一致性的候选执行。

**关键技术细节**  
- **动作-未来门**  
  - 对初始轨迹 τ₁，计算稠密光流 F₁（主视角当前帧→预测帧）。  
  - 通过运动学将机械臂末端执行器位移投影到主视角图像平面得到动作运动 ∆u。  
  - 在末端轨迹附近的胶囊形区域内平均光流得到视觉运动 f̄。  
  - 计算余弦相似度 c = cos∠(f̄, ∆u)。若任何移动臂 c < τgate（阈值设为 -0.2），则认为不一致，触发采样。  
- **几何评估器（GeoBoN）**  
  - 对每个候选轨迹 τᵢ，预测的主视角和腕部视角帧输入冻结的 VGGT-Ω，获得主视角直接深度 d_vggt 以及通过腕部三维点云投影到主视角的深度 d_proj。  
  - 定义跨视图深度重投影不一致性：edepth(τᵢ) = 1/|Ωᵢ| ∑_{p∈Ωᵢ} log(d_proj(p)/d_vggt(p))，仅计算高置信度像素。  
  - 选择 edepth 最小的候选执行其动作块。  
- **Gated GeoBoN**  
  - 初始轨迹若门控未触发 → 直接执行  
  - 若触发 → 额外采样 Nmax-1 个候选，形成大小为 Nmax 的集合，使用 GeoBoN 选择。

**算法流程**（文字描述）  
1. WAM 生成初始 rollout τ₁。  
2. 计算动作-未来一致性分数 c；若 c ≥ τgate，执行 a₁；否则进入步骤3。  
3. 再采样 Nmax-1 个 rollout，组成候选集。  
4. 对每个候选，用 VGGT-Ω 提取跨视图深度重投影不一致性 edepth。  
5. 选择 edepth 最小的候选的动作块执行。
