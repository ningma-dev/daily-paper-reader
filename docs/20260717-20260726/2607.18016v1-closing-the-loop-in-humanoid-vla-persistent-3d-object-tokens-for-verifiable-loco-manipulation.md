## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长时程的类人移动操作要求机器人将任务对象视为跨越运动、接触、遮挡和恢复的持久物理实体。我们将此问题研究为对象状态发散：用于调节全身动作的对象状态与用于判断该动作是否达到预期物理关系的状态可能不同。我们提出了持久对象标记化（POT），该方法从RGB-D观测中维护按角色索引的3D对象记录，并将其转换为用于全身动作专家的对象标记。实例化为POT-VLA，相同的对象记录调节动作生成并支持几何谓词检查，从而形成一个闭环执行系统，其中对象状态既可操作又可验证。在Unitree G1上，POT-VLA在八个真实世界任务家族中将匹配的直接GR00T-N1.7基线从39/80成功率提升至71/80。在外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上实现了44/50的成功率，而Being-0论文报告的成功率为37/50。最大的提升出现在需要维持3D关系的任务上，这表明以对象为中心的持久状态是可验证类人VLA执行的一个有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：长时程人类化移动操作（loco-manipulation）中，物体状态会在运动、接触、遮挡、恢复等过程中发生**状态发散（object-state divergence）**——即策略用于调节全身动作的物体状态，与用于判断动作是否达到预期物理关系的物体状态不一致。这导致动作预测与验证脱节，产生错误的目标、抓取、放置或过早的步骤转换。
- **研究动机**：现代VLA策略通常将物体状态隐式编码在视觉-语言特征中，难以在接触后刷新或与验证器共享；而现有验证系统多依赖符号化或技能级反馈，与动作流分离。作者提出需要一种**以物体为中心的持久化物理记忆**，既可用于动作生成，也可用于执行后验证。
- **整体含义**：通过闭环共享物体状态，可以显著提升人类化VLA在真实世界的任务成功率，尤其是在需要维持3D关系的任务上。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：Persistent Object Tokenization（POT）——从RGB-D观测构建按角色索引的3D物体记录，序列化为**持久3D对象标记（Persistent 3D Object Tokens）**，这些标记同时输入给动作专家进行动作预测，并在执行后用于几何谓词验证，从而在**共享物体记忆上形成“生成–执行–刷新–验证–恢复”闭环**。
- **关键技术细节**：
  - **任务角色对象记录**：根据指令和当前观测，由VLM或任务文件生成带类型的子任务计划，每个子任务定义实体集。POT为每个实体构建记录 `m_e^t`，包含角色、短语、2D框、3D质心/范围、置信度、可见性、关系特征等。
  - **持久标记模式**：将对象记忆 `M_t^{τ_i}` 映射为固定长度的特征张量 `x_obj^t ∈ R^{K×F}`，默认K=8个槽位，F=33个特征。每个槽位包含角色ID（TARGET、DESTINATION等）、可见性、置信度、2D框、3D质心、3D范围、可选朝向、关系特征。未用槽位填充为PADDING并掩码。**持久性**体现在：任务实体始终绑定到固定角色槽，但每次执行块后刷新度量证据；即使对象被遮挡或低置信度，角色槽依然保留，只是标记不确定状态。
  - **对象标记投影**：将标记张量通过一个小型网络（LayerNorm → Linear → GELU → Dropout → Linear）投影到DiT隐藏维度，然后与角色嵌入、上下文嵌入结合，插入到动作头的自注意力序列中：`S_t = [Z_state^t, Z_obj^t, Z_action^t]`，图像和语言特征通过交叉注意力提供。
  - **训练与适配**：POT-VLA使用与基础动作专家相同的动作块预测损失，无额外辅助损失。在微调时，演示数据附带通过相同RGB-D模式生成的对象标记，使动作头学习对齐。
  - **谓词级验证与恢复**：几何谓词监督器使用与动作策略相同的刷新后对象记忆，检查子任务的前提和目标谓词（包含、支持、末端-目标距离、目标-目的地位移、双手分配、交接距离等）。谓词结果为进度/完成/阻塞/失败/不确定，并输出诊断信息（如物体未抓取、放置超出目标区域等），触发继续、重试、重新观测、重新接地或重新规划。
- **公式/算法流程**：文字描述见图1：维护对象记忆 → 序列化为标记 → 动作专家预测块 → 执行 → RGB-D刷新记忆 → 谓词验证 → 根据状态选择恢复/继续。
