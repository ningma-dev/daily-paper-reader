## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在紧公差、高接触的装配任务中常因长视野信用分配和子任务耦合而失败：当前技能在几何上成功的状态可能对后续技能是脆弱的。我们展示了在冻结的VLA基础策略上进行残差强化学习（RL）时的这种失败模式：恒定的稀疏成功奖励在隔离情况下改善每个子任务，但当技能串联时却几乎没有增益，因为终端状态质量不受控。我们提出预见性残差强化学习，通过用离线估计的预见值（即当前子任务终端状态下未来子任务成功的概率）增强每个子任务的稀疏成功奖励，来优化交接质量。具体来说，我们(i)从基础策略的终端状态图像训练视觉预见预测器，并使用下游滚动的统计数据进行标注；(ii)通过逆向预见归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三相扳手式螺母拧紧装配任务（抓取、移动插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差强化学习（54.5%）和VLA基线，同时保持每个子任务成功率不变。这些结果强调，提高长视野性能需要塑造每个子任务产生的成功状态，而不仅仅是是否成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：机器人长视野、高接触的装配任务（如使用扳手拧紧螺母）需要顺序执行多个子技能，但子技能之间存在**因果耦合**：前一个子技能的终端状态质量直接影响后续子技能的成功率。标准做法是将任务分解为独立的子任务，各自训练策略再串联，但这种方法忽略了子任务间的依赖关系——一个几何上成功的子任务终端状态可能对下游任务很脆弱（例如抓取姿态虽然成功但后续插入困难）。
- **核心问题**：现有残差强化学习（Residual RL）在冻结的VLA基础策略上训练，使用恒定的稀疏成功奖励。虽然每个子任务的单独成功率会提升，但串联后的全任务成功率几乎无增益，因为终端状态质量不受控。
- **整体含义**：提出**Foresight Residual RL**，通过离线学习一个“远见预测器”来估计当前子任务终端状态导致下游成功的概率，并将该概率作为奖励乘数，引导残差策略产生更优的交接状态，从而提升长视野组合任务的性能。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 为每个子任务（除最后阶段）训练一个视觉远见预测器 \(p_\phi(o)\)，预测从当前子任务终端状态 \(s\)（对应观测 \(o\)）出发，下游子任务（下一阶段）的成功概率。
- 在训练第 \(k\) 个子任务的残差策略时，将其奖励设置为 \(\beta_k(s_{t+1}) \cdot p_\phi(o_{t+1})\)，其中 \(\beta_k\) 是子任务 \(k\) 的成功谓词。这样即激励子任务成功，又鼓励终端状态具有高远见值。
- 训练顺序：**逆向归纳**——先训练最后一个子任务（\(k=K\)），使用标准成功奖励；然后反向训练 \(k=K-1\)，……，直到 \(k=1\)。这样下游策略固定后，再为上游策略估计远见值。

### 关键技术细节
- **残差策略结构**：在冻结的VLA基础策略 \(\pi^0_k\) 上加一个小幅度残差 \(\pi^{\text{res}}_k\)，最终动作 \(a_t = \pi^0_k(o_t) + \alpha \cdot \pi^{\text{res}}_k(o_t)\)，\(\alpha \ll 1\)（如0.1）。残差策略仅使用腕部图像，通过DINOv2提取特征，经过CNN、LSTM和MLP输出，actor输出层零初始化以保持初始行为。
- **远见预测器训练**（Algorithm 2）：
  1. 使用基础策略 \(\pi^0_k\) 收集 \(N\) 个成功的终端状态（观测 \(o_i\)）。
  2. 对每个终端状态，使用固定下游策略 \(\pi_{k+1}\) 进行 \(K_{\text{rep}}\) 次独立 rollout，统计成功次数 \(\kappa_i\)。
  3. 训练视觉预测器 \(p_\phi\)（基于DINOv2+LoRA）最小化二项式负对数似然损失：\(\mathcal{L}(\phi) = -\sum_i [\kappa_i \log p_\phi(o_i) + (K_{\text{rep}}-\kappa_i)\log(1-p_\phi(o_i))]\)。
- **远见值近似**：采用单步近似，即只考虑下一子任务的成功概率 \(V_{k+1}(s)\) 作为远见值，忽略更下游的累积回报。作者认为这在 \(k=K-1\) 时精确，且当更下游成功率条件独立于当前终端状态时也合理。

### 算法流程
Algorithm 1（逆向远见驱动学习）：
- 输入：基础策略 \(\{\pi^0_k\}_{k=1}^K\)，残差尺度 \(\alpha\)。
- 对于 \(k = K, K-1, \dots, 1\)：
  - 若 \(k=K\)：用标准奖励 \(\beta_K(s_{t+1})\) 训练残差策略（PPO）。
  - 否则：先固定下游策略 \(\pi_{k+1}\)，调用 Algorithm 2 训练远见预测器 \(p_\phi\)；然后使用奖励 \(r_t = \beta_k(s_{t+1}) \cdot p_\phi(o_{t+1})\) 训练第 \(k\) 阶段的残差策略。

该奖励是唯一的奖励信号，没有额外塑造奖励。

## 6. 论文的主要结论与发现

1. **标准残差RL在子任务耦合情况下无效**：尽管它提高了孤立子任务的成功率（如插入从45.7%提升到92.2%），但全任务成功率仅54.5%，与端到端π0（54.9%）相当。说明单纯提高成功率而不控制终端状态质量无法转化出组合优势。
2. **远见残差RL显著提升全任务性能**：达到85.6%全任务成功率，比标准残差RL（54.5%）提高31.1%，比端到端π0（54.9%）提高30.7%。增益主要集中在抓取→插入边界（+31.8%）。
3. **终端状态质量是关键**：标准残差RL实际上降低了终端状态的远见值得分（抓取终端从0.64降至0.32），而远见校正恢复并提高了得分（0.73）。说明奖励塑造有助于产生更有利于下游的状态。
4. **子任务分解+远见校正优于端到端训练**：端到端π0分解后（chain π0）反而更差（41.4%），但远见校正使其大幅超越端到端（85.6%），证明了分解+远见优化的价值。

## 7. 优点

- **问题定义清晰**：准确识别了长视野操作中“子任务成功却不组合”的关键问题，即终端状态质量被忽略。
- **方法简洁且实用**：利用离线学习的远见预测器作为奖励乘数，与现有残差RL框架兼容，不需要在线值函数分解或联合训练。逆向归纳保证了训练稳定性。
- **实验结果有力**：通过定量和定性证据展示改善机制，特别是表III中远见值得分的下降/回升直接解释了性能差异。
- **理论基础扎实**：与MAXQ完成函数和奖励尊重子任务的理论联系，使方法有理论支持。
- **实用设计**：采用单步远见近似，大大简化实现；使用基础策略而不是增强策略收集数据来训练预测器，避免了分布漂移问题（由于α小，分布漂移有限）。

## 8. 不足与局限

- **实验覆盖有限**：仅在单一仿真环境（Isaac Gym）的单一任务上验证，缺乏跨不同任务（如其他装配、日常操作）和不同VLA骨干（如Octo、RT-2）的评估。
- **远见单步近似可能不充分**：在更复杂依赖链中，仅考虑下一阶段成功率可能丢失长程信息。作者承认可通过链式多个阶段扩展，但未实验。
- **对残差尺度α敏感**：α=0.1限制分布漂移，但若任务需要较大纠正，可能不足。未进行灵敏度分析。
- **现实世界部署挑战**：作者指出主要障碍是残差策略的在线RL成本，而非接触动力学差距。但仿真到现实的转移问题未验证，远见预测器是基于仿真图像训练的，可能面临域漂移。
- **计算开销**：虽然远见预测器是离线训练，但收集标注数据需要大量下游rollout（N=2560，Krep=5），在每个边界都需要重复，随着子任务数量增加线性增长。
