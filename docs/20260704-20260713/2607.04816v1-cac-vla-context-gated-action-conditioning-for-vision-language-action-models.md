## 摘要
视觉-语言-动作（VLA）模型已成为通用机器人操作的一种有前景的范式，其中视觉-语言表示被用于条件化连续动作生成。然而，这些表示并未针对动作条件化进行显式优化，使得动作专家需要弥合多模态理解与精确运动控制之间的差距。最近的动作推理方法引入额外模块来生成显式动作规划或动作空间推理信号，展示了动作级引导的益处，但通常需要独立的动作生成框架。我们提出CAC-VLA，一种上下文门控动作条件化框架，它直接在VLM内学习轻量化的潜在动作接口。CAC-VLA并非生成可执行的轨迹，而是训练VLM预测从粗到细的潜在动作（即从未来动作片段编码的结构化表示），并通过上下文门自适应地利用这些表示来条件化动作专家。这使得VLM原生的动作条件化成为可能，同时校准潜在动作引导对专家动作生成的影响。在LIBERO和LIBERO-Plus上的实验证明了CAC-VLA的有效性，在LIBERO上达到98.3%的平均成功率，在LIBERO-Plus上达到89.5%，表明上下文门控潜在动作条件化是连续专家控制的有效接口。

## Abstract
Vision-Language-Action (VLA) models have become a promising paradigm for generalist robot manipulation, where visual-language representations are used to condition continuous action generation. However, these representations are not explicitly optimized for action conditioning, leaving the action expert to bridge the gap between multimodal understanding and precise motor control. Recent action-reasoning methods introduce additional modules to generate explicit action plans or action-space reasoning signals, demonstrating the benefit of action-level guidance but often requiring separate action-generation frameworks. We propose CAC-VLA, a Context-Gated Action Conditioning framework that learns a lightweight latent-action interface directly within the VLM. Instead of generating executable trajectories, CAC-VLA trains the VLM to predict coarse-to-fine latent actions, which are structured representations encoded from future action segments, and adaptively leverages them to condition the action expert via a context gate. This enables VLM-native action conditioning while calibrating the influence of latent-action guidance on expert action generation. Experiments on LIBERO and LIBERO-Plus demonstrate the effectiveness of CAC-VLA, achieving 98.3% average success rate on LIBERO and 89.5% LIBERO-Plus, suggesting that context-gated latent-action conditioning is an effective interface for continuous expert control.

*   **背景**：近期一些工作通过引入视觉推理、语言规划或动作推理模块来提供中间指导信号，但这往往依赖额外的动作生成框架，或将这些信号作为固定条件输入，忽视了其在不同场景、任务阶段下的可靠性差异。
*   **核心问题**：能否在VLM内部原生地建立一个显式的“潜在动作接口”，使得动作专家能够自适应地利用这些动作结构化的指导信号，从而更高效地生成控制指令？

## 2. 方法论：核心思想与技术细节

*   **核心思想**：作者提出 **CAC-VLA（Context-Gated Action Conditioning）** 框架。其核心是训练VLM预测“潜在动作”，即从未来动作片段编码而成的结构化、粗到细的表示，这些表示不直接执行，而是作为对动作专家的中间指导。同时，引入一个**上下文门控**机制，让动作专家根据自身状态自适应地调节这种指导的强度。
*   **关键技术细节**：
    1.  **VLM原生潜在动作预测**：
        *   使用**有序动作分词器（OAT, Ordered Action Tokenizer）** 将未来一段动作序列 $a_{t:t+H_l-1}$ 编码为原始的潜在向量 $z^{oat}_t$，作为监督目标。
        *   在VLM输入中附加可学习的 **潜在查询令牌（Latent Query Tokens）**。VLM在处理视觉-语言上下文后，产生查询隐状态，并通过一个轻量级预测头映射到OAT潜在空间，输出预测的潜在动作 $\hat{z}_t$。
        *   训练时使用 **Smooth-L1损失** 对齐预测值与目标值。
    2.  **上下文门控动作条件化**：
        *   **训练/推理分离**：训练时用真实OAT目标 $z^{oat}_t$ 作为条件源，推理时替换为VLM预测的 $\hat{z}_t$。
        *   **条件化注入**：将潜在动作投影为专家兼容的条件令牌 $c_t$，然后通过**交叉注意力（Cross-Attention）** 让动作专家根据自身当前隐状态 $x_l$ 从 $c_t$ 中检索有用信息，得到更新 $u_l$。
        *   **上下文门控**：设计一个**上下文门（Context Gate）** $g_l$，通过计算当前专家状态 $x_l$ 与检索到的更新 $u_l$ 的平均池化，通过一个小型神经网络（Tanh + Sigmoid）生成一个通道级门值。最终通过**门控残差连接** 注入：$x_{l+1} = x_l + g_l \odot u_l$。这使得注入的强度是自适应、随专家状态变化的。
    3.  **损失函数**：总损失 $L = L_{act} + \lambda_{align}L_{align}$，其中 $L_{act}$ 是动作专家的流匹配损失，$L_{align}$ 是潜在对齐损失。

## 6. 主要结论与发现

1.  **性能提升**：CAC-VLA在LIBERO上平均成功率98.3%，在LIBERO-Plus微调下平均89.5%，显著优于几乎所有对比方法，验证了上下文门控潜在动作条件化的有效性。
2.  **门控的重要性**：消融实验表明，移除上下文门控（即固定融合）导致性能下降（从98.3%降至97.9%），证明自适应调节比固定强度更好。
3.  **潜在动作长度的权衡**：潜在动作长度Hl=20在平均性能上最佳，说明中等长度的未来信息更具指导性。
4.  **真实世界可行性**：在真实桌面任务上，CAC-VLA在完整任务成功率上大幅领先π0.5基线（拾放：64% vs 16%；堆叠：52% vs 36%），证明了从仿真到真实的潜力。

## 7. 优点

*   **方法轻量化**：无需引入独立的动作推理或生成模块，仅在VLM内添加少量可学习查询令牌和门控网络，保持了VLA架构的简洁性。
*   **设计巧妙**：将动作条件化解耦为“潜在动作预测”和“自适应调节”两个阶段。前者提供了结构化的指导，后者通过门控机制避免了固定强注入可能带来的噪声或错误，对性能提升至关重要。
*   **实验扎实**：在多个仿真基准（含分布偏移）和真实任务上进行了全面评估，消融实验清晰，并提供了门控行为的深入可视化分析，增强了工作的可信度。
