## 摘要
主流视觉-语言-动作（VLA）模型在马尔可夫假设下主要根据当前观测预测动作，因此难以处理长时程、时间依赖的任务。现有记忆增强型VLA要么扩展观测窗口，要么从记忆库中检索历史作为辅助策略端上下文。然而，它们将记忆置于VLA推理的原始潜在嵌入空间之外，阻碍了历史经验与多模态推理和动作形成的流畅交织。为此，我们提出LaMem-VLA，一种原生潜在记忆框架，将历史经验重构为潜在记忆标记，并直接将其与VLA推理交织。LaMem-VLA的核心引入了四个协调组件：（i）一个策展人，将历史经验组织到两个互补的短期和长期记忆库中；（ii）一个搜索者，利用多模态认知查询两个记忆库以检索上下文相关证据；（iii）一个压缩者，将检索到的证据重构为紧凑的短期和长期潜在记忆标记；以及（iv）一个编织者，将这些记忆标记与当前观测和指令注入到连续的嵌入序列中。通过完全在同一连续潜在空间中表示、检索和消费历史经验，LaMem-VLA使记忆能够直接参与VLA推理，并在有限上下文中指导动作生成。在SimplerEnv和LIBERO上的大量实验证明了我们的LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

## 2. 论文提出的方法论

### 2.1 核心思想
- 将机器人历史经验组织为两类互补的记忆：**短期记忆**（视觉主导，保存当前 episode 的感知证据）和**长期记忆**（语义主导，保存任务进度和动作连续性），两者在潜在空间中统一表示为紧凑的记忆token，并直接与当前观测、语言指令和动作查询拼接，参与自注意力计算，使记忆成为VLA推理的一部分而非外部条件。

### 2.2 关键技术细节

#### 模型整体架构
- 骨干网络：7B参数的Prismatic VLM（视觉编码器+DINOv2/SigLIP + LLaMA-7B），预训练于Open X-Embodiment数据集。
- 动作专家：约300M参数的扩散变换器（Diffusion Transformer），以生成的记忆接地动作token为条件，通过DDIM采样输出7-DoF动作序列（动作块大小16）。

#### 四个核心模块
1. **潜在记忆策展人（Latent Memory Curator）**：
   - 短期记忆库：存储每个时间步的视觉令牌（经SE-bottleneck压缩），键为均值池化向量，值为Ns个隐藏表示。
   - 长期记忆库：存储每个时间步的动作隐藏状态（直接写入），键为均值池化向量。
   - **更新策略**：当记忆单元数超过容量L时，合并最相似的相邻单元（按余弦相似度），用平均替换。

2. **潜在记忆搜索者（Latent Memory Seeker）**：
   - 从当前视觉令牌和指令令牌中提取多模态上下文查询Q_con，附加可学习查询槽Q_init，通过轻量Transformer构建器更新得到Qt。
   - 使用均值池化后的全局查询向量qt，分别从短期和长期记忆库检索Top-K个最相关单元（余弦相似度），得到Z_short和Z_long。

3. **潜在记忆压缩者（Latent Memory Condenser）**：
   - 引入可学习的短期记忆槽Ts（Ls个）和长期记忆槽Tl（Ll个）。
   - 使用轻量Transformer记忆形成器（Fv和Fc），以Qt、检索证据和记忆槽为输入，更新后取最后Ls/Ll个token作为压缩后的潜在记忆令牌M_short和M_long。
   - 固定长度，独立于检索大小，兼容VLA嵌入空间。

4. **潜在记忆编织者（Latent Memory Weaver）**：
   - 构建记忆增强输入序列：St = [ M_short + bias_short ; M_long + bias_long ; Xt ; I ; Q_action ]。
   - 送入VLM骨干，输出的动作查询隐藏状态Z_action作为记忆接地的动作表示。
   - 扩散动作专家以Z_action为条件，通过噪声预测损失L_action训练，推理时使用DDIM采样10步。

#### 公式（文字说明）
- 短期记忆库写入：vs = Cs(Xt), ks = MeanPool(vs)
- 长期记忆库写入：ml = H_action
- 检索：Is = Top-K(cos(qt, k_s)), Z_short = Concat(v_s for i in Is)
- 压缩：M_short = Fv([Qt; Z_short; Ts])[-Ls:], M_long = Fc([Qt; Z_long; Tl])[-Ll:]

## 6. 论文的主要结论与发现
- LaMem-VLA在SimplerEnv上达到**73.9%**平均成功率（超过CogACT 16.6点，π0 4.7点）；在LIBERO上达到**97.6%**平均成功率（超过MemoryVLA 1.1点，CogACT 4.4点）。

- 潜在原生记忆集成优于策略端条件或原始检索条件，验证了在相同潜在空间内融合记忆的必要性。
- 双记忆互补：短期视觉证据提供细粒度状态变化，长期语义证据提供任务进度和动作连续性。

## 7. 优点
- **范式创新**：首次将机器人的历史经验完全置于VLA模型的潜在嵌入空间内部，实现记忆与感知、推理、动作的统一表示和交互。
- **模块化设计**：策展人、搜索者、压缩者、编织者四个组件解耦明确，各司其职，且均采用轻量Transformer，不会显著增加推理成本。
- **高效压缩**：通过可学习记忆槽和记忆形成器，将检索到的多单元证据压缩为固定少量token，保持上下文长度可控。
- **消融充分**：对每个设计选择（记忆类型、注入方式、检索数、token数）进行了系统分析，证明各自有效性。
- **性能优越**：在多个基准上超越现有SOTA，特别是在长时程任务上。

## 8. 不足与局限
- **仿真局限**：所有实验仅在模拟环境（SimplerEnv和LIBERO）中验证，未在真实机器人上部署和测试。作者在结论中承认这一点，并说明正在扩展到真实平台，但当前版本缺乏真实世界泛化证据。
- **记忆容量限制**：虽通过压缩和合并策略控制，但记忆库容量L（16）和检索数K（8）仍需要调参，可能在不同任务最佳值不同。
- **计算开销**：尽管压缩后token少，但每个时间步都需要检索、压缩和推理，相比于无记忆模型增加了额外计算（4个轻量Transformer前向），在资源受限设备上可能受限。
- **依赖多模态骨干**：VLA骨干（7B Prismatic）较大，训练和推理资源需求高，实际部署需考虑量化或蒸馏。
- **长期记忆的语义性**：长期记忆仅存储动作隐藏状态，是否足以捕捉高阶任务语义（如子步骤完成状态）值得进一步探讨。
