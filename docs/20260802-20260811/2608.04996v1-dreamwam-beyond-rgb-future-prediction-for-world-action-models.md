## 摘要
世界动作模型（WAMs）通过预测观察到的世界将如何演变来学习动作相关的表征。大多数现有的WAMs在RGB空间中定义这种未来，其中任务相关的状态转换与纹理、光照、背景和视角的干扰变化纠缠在一起。我们认为WAMs应显式预测动作相关的未来状态，而不是仅仅依赖RGB预测。我们引入了DreamWAM，它将未来预测重新构建为超越RGB的结构化世界建模，通过外观、运动、几何和语义的互补视图来表示未来状态。在训练过程中，DreamWAM将RGB和运动的联合潜在去噪与用于几何和语义的轻量级门控残差分支相结合。VideoDiT和ActionDiT之间的共享注意力使动作分支能够从这些未来状态预测中学习，而在推理时所有超出RGB的监督分支都被禁用，部署仍然仅使用RGB。在无展开和联合视频-动作推理中，DreamWAM在LIBERO上一致优于匹配的仅RGB基线，分别从97.30%提升到98.40%和从98.00%提升到98.90%。在未见过的LIBERO-Plus扰动下，增益更大，从51.36%提升到63.44%，从69.16%提升到75.47%。同样的鲁棒性延伸到真实世界的操作中，DreamWAM在光照、背景和物体布局的未见变化中达到74.4%的平均成功率，而Fast-WAM-Joint为55.6%。这些结果表明，稳健的世界动作学习不仅依赖于预测未来，还依赖于以对动作重要的形式来表示未来。代码和模型已在https://github.com/hustvl/DreamWAM公开。

## Abstract
World Action Models (WAMs) learn action-relevant representations by predicting how the observed world will evolve. Most existing WAMs define this future in RGB space, where task-relevant state transitions are entangled with nuisance variations in texture, illumination, background, and viewpoint. We argue that WAMs should explicitly predict action-relevant future state rather than relying on RGB prediction alone. We introduce DreamWAM, which reformulates future prediction as structured world modeling beyond RGB, representing future states through complementary views of appearance, motion, geometry, and semantics. During training, DreamWAM combines joint latent denoising of RGB and motion with lightweight gated residual branches for geometry and semantics. Shared attention between VideoDiT and ActionDiT allows the action branch to learn from these future-state predictions, while all beyond-RGB supervision branches are disabled at inference and deployment remains RGB-only. Across both no-rollout and joint video-action inference, DreamWAM consistently improves the matched RGB-only baselines on LIBERO, from 97.30\% to 98.40\% and from 98.00\% to 98.90\%, respectively. The gains become larger under unseen LIBERO-Plus perturbations, from 51.36\% to 63.44\% and from 69.16\% to 75.47\%. The same robustness extends to real-world manipulation, where DreamWAM attains an average success rate of 74.4\% across unseen changes in lighting, background, and object layout, compared with 55.6\% for Fast-WAM-Joint. These results show that robust world-action learning depends not only on predicting the future, but on representing it in a form that matters for action. The code and models are publicly released at https://github.com/hustvl/DreamWAM.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现有世界动作模型（WAMs）几乎完全在 **RGB 观测空间**中定义“未来预测”，但 RGB 预测将任务相关的状态转换（如物体位移、接触、目标完成）与纹理、光照、背景、视角等与动作无关的外观变化纠缠在一起。作者认为，**未来预测的表征形式**本身是一个被忽视的核心设计变量——预测什么（what to predict）比如何预测（how to predict）更基本。
- **整体含义**：一个有用的“未来想象”不应该是像素级的完美渲染，而应保留对动作成功至关重要的内容——包含什么实体、如何变化、在哪里发生。DreamWAM 的核心主张是：**稳健的世界动作学习不仅取决于预测未来，还取决于以对动作重要的形式来表示未来**。
- **具体场景**：以“将白色杯子放在左盘、黄白杯子放在右盘”为例，RGB-only WAM 在原始场景中成功但在未见过的背景、变暗光照和布局变化下失败，而 DreamWAM 在所有四种设置下均能完成任务——说明结构化未来监督能更好地保持与动作相关的状态转换。

## 2. 论文提出的方法论

### 2.1 核心思想

将未来预测从“RGB 重建”重新定义为**结构化世界建模**，通过四种互补视图表征未来状态：

| 视图 | 来源 | 语义 |
|---|---|---|
| 外观（Appearance） | RGB 序列经 Wan2.2 视频 VAE 编码 | 未来看起来什么样 |
| 运动（Motion） | RAFT 估计相邻帧光流，经同一 VAE 编码 | 时间变化是显式的 |
| 几何（Geometry） | Depth Anything V3 提取深度特征 | 空间组织与深度结构 |
| 语义（Semantics） | DINOv2 提取 patch 级特征 | 物体和区域级一致性 |

### 2.2 两种注入路径（关键设计）

- **联合潜空间去噪（用于 RGB 与运动）**：二者共享同样的稠密时空结构，在相同 flow-matching 时间步加噪后沿通道维度拼接：
  \[
  x_t^q = (1-t)z^q + t\epsilon^q,\quad q \in \{\text{rgb}, \text{mot}\},\quad x_t^{\text{joint}} = \text{Concat}_C[x_t^{\text{rgb}}, x_t^{\text{mot}}]
  \]
  VideoDiT 在单一去噪流中同时学习两个视图，使时间变化成为显式预测目标。

- **门控残差注入（用于几何与语义）**：由于深度/DINO 特征不是 VAE 潜在空间的“原生”表示，直接通道拼接会使整个 VideoDiT 流暴露于外部编码器的目标统计中，干扰预训练视频生成先验。因此采用轻量门控残差分支，在第 ℓ 层的更新为：
  \[
  \bar{h}^\ell = B^\ell(h^{\ell-1}), \quad h^\ell = \bar{h}^\ell + \sum_j g_j^\ell(\bar{h}^\ell, c) \odot R_j^\ell(\bar{h}^\ell)
  \]
  加性路径保留骨干原始输出，门控控制各视图修正的幅度，实现“精炼而非替代”预训练视频表征。

### 2.3 世界-动作耦合

- 采用 **VideoDiT–ActionDiT 双专家架构**（基于 Fast-WAM）：两个专家保留独立参数，但在配对层通过**共享注意力**交换信息——视频 token 和动作 token 在各自输出投影和 FFN 之前贡献到同一注意力上下文。因此 ActionDiT 能间接利用 VideoDiT 学到的多视图未来表征，而无需直接消费光流、深度或 DINO 特征。

### 2.4 训练目标与推理

- 总损失：
  \[
  \mathcal{L} = \lambda_{\text{rgb}}\mathcal{L}_{\text{FM}}^{\text{rgb}} + \lambda_{\text{mot}}\mathcal{L}_{\text{FM}}^{\text{mot}} + \lambda_{\text{geo}}\mathcal{L}_{\text{pred}}^{\text{geo}} + \lambda_{\text{sem}}\mathcal{L}_{\text{pred}}^{\text{sem}} + \lambda_{\text{act}}\mathcal{L}_{\text{FM}}^{\text{act}} + \lambda_g\mathcal{L}_{\text{gate}}
  \]
  其中 \(\mathcal{L}_{\text{gate}}\) 是对门控激活的 ℓ1 正则。
- **推理时：运动输入通道填充零、残差分支/预测头/RAFT/DA3/DINOv2 全部移除**，退化为 RGB-only Fast-WAM 部署接口，只输出去噪后的动作块。训练部分匹配该边界条件（条件帧的流通道也为零，流去噪目标仅应用于未来潜在步骤）。

## 3. 实验设计

### 3.1 模拟基准：LIBERO 与 LIBERO-Plus

- **LIBERO**：包含 Spatial、Object、Goal、Long 四个 10 任务套件，每套 500 个演示，仅在原始演示上训练，每任务评估 50 次 rollout（每种子共 2,000 次）。
- **LIBERO-Plus**：在同一技能上评估 7 种未见扰动——相机视角、机器人外观、语言、光照、背景、图像噪声、物体布局；无任何 LIBERO-Plus 数据参与训练，每种子评估 10,030 个 episodes，报告七个维度分数的未加权均值。

### 3.2 推理模式

- **Fast-WAM（无 rollout）**：仅保留第一帧视频输入，直接去噪动作——对应 DreamWAM-uncond。
- **Fast-WAM-Joint（联合推理）**：联合去噪未来 RGB 潜在和动作——对应 DreamWAM。

### 3.3 真实机器人

- 平台：**AgileX PiPER 双臂机器人**。
- 标准任务（4 个）：Dish Stack（叠盘子）、Dual-Object Pick（双物体放入篮中）、Strawberry Selection（挑草莓）、Block Stack（叠方块）。
- 鲁棒性测试（3 类扰动）：背景彩色贴片、填充光改变光照、任务无关干扰物——均只在 Strawberry Selection 任务上，保持指令和成功标准不变。
- 每种设置 30 次试验，每模型共 210 次真实 rollout。

### 3.4 对比方法

- LIBERO 主表对比：OpenVLA、π0、π0.5、Motus、LingBot-VLA、Fast-WAM、Fast-WAM-Joint。
- LIBERO-Plus 对比：UniVLA、OpenVLA-OFT、π0、π0-FAST、WorldVLA、Fast-WAM、Fast-WAM-Joint。
- 论文特别强调：由于骨干网络、预训练和数据不同，其他方法仅作基准背景参照，**匹配对比的 Fast-WAM 对才是主要受控证据**。

### 3.5 消融实验

在 LIBERO 上进行组件与路由消融，8 个变体 + RGB-only 基线 + 完整模型：

- 单视图注入（Motion/Geo/Sem 分别用 R 或 D 路由）
- 留一剔除（w/o Mot、w/o Geo、w/o Sem）
- 全去噪控制（Denoise，D/D/D）
- 完整混合（Hybrid，D/R/R）

符号：D = 全去噪（通道拼接），R = 门控残差注入，– = 不注入。

## 6. 主要结论与发现

1. **结构化未来监督有效**：DreamWAM 在 LIBERO 上从不带 rollout 的 97.30% 和联合推理的 98.00% 分别提升至 98.40% 和 98.90%。
2. **鲁棒性增益更大且全面**：在 LIBERO-Plus 的 7 个扰动维度上，两种推理模式均全部提升——无 rollout 从 51.36%→63.44%，联合推理从 69.16%→75.47%。真实机器人上，标准任务均值从 90.8%→96.7%，扰动场景从 55.6%→74.4%。
3. **训练时结构化未来与测试时想象互补而非替代**：DreamWAM 训练后的 no-rollout 到 joint 的差距从 17.80 个点缩小到 12.02 个点——部分本来要在线提供的动作相关未来结构已被内化到策略中。
4. **视图互补性**：在各自偏好路由下，单一辅助视图均优于 RGB-only；运动是最关键的信号（剔除后下降最多），且运动为几何/语义提供时间支架。
5. **路由必须与表征匹配**：全去噪 D/D/D 反而低于 RGB-only 基线（97.85% vs. 98.00%），而 D/R/R 达到 98.90%——说明增益来自“VAE 对齐的运动走去噪状态、异构特征走受控残差校正”的路由匹配，而非监督信号数量本身。

## 7. 优点

- **问题定位精准**：将“未来预测的表征形式”从“未来预测的架构/效率”中独立出来，指出 RGB-only 预测与动作无关变化纠缠不清的根本局限，是一个具有普遍意义的设计洞察。
- **训练-推理解耦的工程优雅性**：所有超越 RGB 的监督仅用于训练，推理时完整退化为 RGB-only Fast-WAM 接口——不增加任何部署时计算成本、不引入在线教师网络，零推理开销获得鲁棒性提升。
- **异构目标的分而治之**：根据目标与 VAE 潜在空间的兼容性选择不同注入路由（运动走全去噪、几何/语义走门控残差），并通过 D/D/D vs. D/R/R 对照实验证明了路由设计的重要性，而非盲目堆叠监督。
- **实验设计层次分明**：模拟 → 真实机器人、标准 → 扰动、无 rollout → 联合推理、组件消融 → 路由消融，形成了完整证据链；LIBERO-Plus 排除了“适应新技能”的混淆只测鲁棒性。
- **量化细节完整**：附录提供了光流通道推理时零填充的线性代数证明（\(W_{\text{flow}} \cdot 0 = 0\)）、目标构建的分辨率和 PCA 降维细节、真实机器人成功标准等实现细节，可复现性强。

## 8. 不足与局限

- **运动表征的非度量性**：RAFT 光流经颜色编码后再经 VAE 编码，是“可视化的运动序列”而非度量级 3D 场景流；论文也承认不声称度量 3D 场景流。几何与语义目标同样来自离线预训练编码器（DA3、DINOv2），可能存在编码器领域的偏差。
- **真实世界鲁棒性覆盖有限**：3 类扰动仅施加于 Strawberry Selection 单任务上，未在其他 3 个标准任务上测试扰动；真实机器人未评估 LIBERO-Plus 中更困难的相机视角、机器人外观、语言变化等扰动类型。
- **统计严谨性不足**：两个随机种子不足以确定小幅度提升的显著性；未报告标准差、置信区间或显著性检验；LIBERO 标准任务上约 1 个百分点的提升是否在噪声范围内不明确。
- **消融变体训练成本**：10 个消融变体 × 4 套件 × 2 种子的训练量很大，但论文未报告每个变体的单独方差，无法判断变体间差异的显著性。
- **计算资源与训练时长未完整披露**：未说明每个模型训练了多少 epoch、多长时间，也未报告推理延迟或参数量的变化——尽管推理时零开销是一个卖点，但训练开销的变化没有量化。
- **对比方法的公平性局限**：LIBERO-Plus 表中其他方法（UniVLA、π0 等）使用了具身预训练（表中 Emb. 列标记 ✓），而 DreamWAM/Fast-WAM 没有，论文也明确说明这些仅作基准背景——但在总表中 DreamWAM 占据“最高平均分”的位置，容易造成跨方法比较的误导。
- **泛化边界未探索**：未讨论结构化未来监督在更长 horizon、更复杂接触操作、多智能体场景下的表现；未分析运动/几何/语义视图质量下降（如传感器噪声）时方法的退化行为。
