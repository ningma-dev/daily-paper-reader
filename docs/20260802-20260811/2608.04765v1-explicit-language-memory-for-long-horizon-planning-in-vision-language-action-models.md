## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家演示限制了跨任务的组合泛化；长时程任务的非马尔可夫特性使得仅基于当前观测的条件策略难以维持时间一致性；有限的闭环纠错能力导致执行误差累积；并且端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的分层长时程VLA架构。核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA则根据子任务指令和视觉观测执行精确的连续控制。高层VLM以先前记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态修正。我们在多个仿真环境中评估了所提出的方法，并在真实机器人平台上进行了仿真到现实的迁移实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义描述。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 2. 方法论

### 2.1 核心思想

- 将策略分解为**两级结构**（公式1）：
  - **高层VLM（π_HL）**：根据全局指令 `l`、当前观测 `o_t` 和上一时刻记忆 `m_{t-1}`，输出更新后的语言记忆 `m_t` 与当前子任务指令 `s_t`；
  - **低层VLA（π_LL）**：根据当前观测 `o_t` 与子任务指令 `s_t`，输出固定视界 `H=30` 的连续动作块 `a_{t:t+H}`；
  - 整体概率分解：`π(a, s_t, m_t | o_t, m_{t-1}, l) = π_LL(a | o_t, s_t) · π_HL(s_t, m_t | o_t, m_{t-1}, l)`。

### 2.2 递归语言记忆（Recursive Language Memory）

- **记忆内容**：自然语言形式的滚动摘要，包含已完成里程碑（过去时）、当前任务状态、相关对象属性、已观察失败和下一待办目标；
- **滚动压缩规则**：子任务完成前保存有助于识别的细节（对象类别、颜色、位置）；完成后压缩为一句简短过去式陈述，注意力转移到下一步；
- **更新条件**：仅当当前观测提供"主动里程碑已改变"的证据时才更新记忆，避免逐帧无意义刷新；
- 示例（公式2）：`"I am moving to the red radio on the coffee table."` → `"I moved to the radio, and I am going to pick up the red radio."`

### 2.3 自动化记忆监督（Automated Memory Supervision）

- 输入：专家视频 + 手工技能级标注（技能名称、描述、起始/结束时间戳）；
- 方法：通用VLM读取当前帧与完整技能标注，生成两个字段：
  1. 简洁子任务（`动作 + 目标物体 + 上下文`，无代理主语）；
  2. 第一人称语言记忆（以过去时描述已完成技能，以未来导向语句过渡到下一步）；
- 工具/模型：托管Gemini 3.5 Flash API 或本地Qwen3.5-9B模型，并明确提示注释器使用自然物体名称和可见属性，禁止"帧""序列""索引"等实现术语。

### 2.4 分支独立训练

- **高层VLM**：使用PaliGemma（与π0.5基线共享VLM家族），自回归预测记忆和子任务（公式3）；
- **低层VLA**：沿用π0.5的动作专家，采用流匹配（flow-matching）动作目标优化（公式4）；
- **独立训练的优点**：避免在单一目标中人为平衡语义生成与连续控制的损失权重。

### 2.5 闭环推理流程

- 记忆初始化为空 → 循环执行：获取观测 → 高层更新 `(m_t, s_t)` → 低层生成动作块 → 执行H步 → 根据记忆判断是否终止；
- 额外产出**可解释日志**：记忆与子任务均为可见文本，便于对齐动作失败点。

- **总体效果**：显式语言记忆在不同场景下都提升了平均阶段成功率：
  - BEHAVIOR-1K：30.0% → 40.0%（最大增益在PickUp阶段：10%→30%，PressOn阶段仍极低：0%→10%）；
  - Genie Sim单包裹：41.7% → 63.9%（Follow和PickUp-1翻倍，Inside-1从50%→83.3%）；
  - Genie Sim连续分拣：31.3% → 46.9%（基线从未完成第3/4个包裹，记忆模型12.5%完成全部4个）；
  - 真实XLeRobot：62.5% → 66.3%（每个阶段各提升5个百分点）。
- **阶段一致性**：记忆机制有效抑制"跳过步骤"——无记忆基线在拾取收音机后直接预测"放置于桌上"，跳过按压按钮；记忆模型的阶段推进以观测到完成证据为条件。
- **语义规划 vs 运动控制**：语言记忆解决"该做什么"和"处于哪个阶段"，**不能直接改善接触丰富动作的执行精度**（PressOn阶段的低成功率即是例证）；该区分有助于将失败分类为高层语义错误或低层控制错误。
- **上下文失败恢复**：真实机器人日志显示记忆可记录抓取失败状态并促使重试，无需专门的恢复控制器；但当前训练数据中失败轨迹稀缺，该能力尚不稳定。

## 7. 优点

1. **架构设计清晰**：分层VLM-VLA解耦了语义推理与连续控制，各自可用适合的目标独立优化，避免了单一大模型的损失平衡困境；
2. **记忆表征创新**：以自然语言作为记忆载体，利用滚动压缩规则实现有界上下文，避免拼接全部历史帧带来的计算和上下文长度问题；
3. **可解释性**：记忆和子任务均为显式文本，决策过程可以被人类直接检查和对齐到具体失败点；
4. **自动化数据管线**：从专家视频+技能时间戳自动生成对齐的记忆/子任务监督信号，降低了标注成本；
5. **多场景验证**：仿真（家庭、人形操作）+ 真实机器人迁移，且阶段级指标比终点成功率更具诊断性；
6. **通用性**：方法可适配不同VLA骨干（以π0.5为例）与不同低层策略，有较好的即插即用潜力。

## 8. 不足与局限

1. **真实实验规模有限**：真实机器人仅做了短程pick-and-place（25条训练轨迹、20次评估），未构建分钟级多物件、多交互或环境变化的任务，真实长时程价值尚未充分证明；
2. **统计严谨性不足**：未报告多种子结果、置信区间或显著性检验，提升幅度的稳健性未知；
3. **缺少系统消融**：未验证记忆模态选择（文本 vs 图像摘要 vs 特征向量）、记忆更新频率、监督生成模型（Gemini vs Qwen3.5-9B）等设计决策的独立贡献；
4. **高延迟与较高复杂度**：每次决策都需要一次额外的高层VLM调用，增加了计算消耗、端到端延迟和部署复杂度，对实时控制可能构成挑战；
5. **接触丰富动作仍困难**：语言记忆无法弥补低层控制精度或数据不足的问题（如PressOn仅10%），不能解决力控、精确对齐等物理交互问题；
6. **失败恢复依赖数据**：有效的上下文失败恢复需要包含丰富失败和纠正轨迹的演示数据，当前数据覆盖不足，恢复能力不稳定；
7. **记忆可能漂移**：依赖VLM的记忆生成质量，若高层VLM产生错误的记忆摘要和状态判断，会误导后续的低层策略——文中未讨论此类复合误差的传播与回避机制。
