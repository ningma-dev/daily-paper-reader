## 摘要
近期的视觉-语言-行动（VLA）模型几乎普遍将机器人本体感觉状态作为输入，但以不兼容的方式进行连接——序列化为文本提示、投影到视觉-语言前缀中，或直接馈送给动作专家——且几乎总是作为单一当前帧。三个问题仍然悬而未决：（1）当前状态是否以及在哪些任务上确实改善了闭环控制；（2）状态历史有多大帮助，其益处是否反映了真实的时序变化，而非仅仅是增加的条件容量；（3）状态应进入模型的哪一部分——视觉-语言骨干还是动作生成模块。我们通过在一个流匹配VLA上进行受控实验来回答这些问题，整个过程固定骨干网络、训练数据、动作表示和评估协议。我们在匹配的实现细节下实现了五种代表性接口——离散状态提示、VLM前缀、动作前缀、状态专家和特征调制——并在涵盖三个任务族的45个原子任务以及20个复合任务上对它们进行评估；然后我们扫描状态历史长度从1到96帧，以检查历史状态信息如何影响模型性能。实验对这三个问题给出了系统性的答案，并提炼为对状态感知VLA的可测试设计原则。

## Abstract
Recent Vision-Language-Action (VLA) models almost universally take robot proprioceptive state as input, yet wire it in incompatible ways -- serialized into text prompts, projected into the vision-language prefix, or fed directly to the action expert -- and almost always as a single current frame. Three questions remain open: (1) whether, and on which tasks, current state actually improves closed-loop control; (2) how much state history helps, and whether its benefit reflects genuine temporal variation rather than added conditioning capacity; and (3) where state should enter the model -- the vision-language backbone or the action-generation module. We answer these questions through controlled experiments on a flow-matching VLA, fixing the backbone, training data, action representation, and evaluation protocol throughout. We implement five representative interfaces -- discrete state prompt, VLM prefix, action prefix, state expert, and feature modulation -- under matched implementation details, and evaluate them on 45 atomic tasks spanning three task families plus 20 composite tasks; we then sweep the state-history length from 1 to 96 frames to examine how historical state information affects model performance. The experiments yield systematic answers to all three questions, distilled into testable design principles for state-aware VLAs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**研究背景：**
- 视觉-语言-行动（VLA）模型已在机器人操作领域取得显著进展，能够以单一权重集执行数百种操作任务。
- 受生物运动控制启发（动物依赖本体感觉产生平滑、协调、稳健的运动），机器人本体感觉状态（关节角度、末端执行器位姿、夹爪开度等）被普遍视为 VLA 的重要输入。
- 然而，现有 VLA 模型对本体感觉状态的使用方式**高度不一致且彼此不可比**：π0.5 将状态离散化为文本 token 拼接到语言提示中；OpenVLA-OFT 和 GR00T N1 将其连续投影为嵌入；有的注入 VLM 侧，有的直接送入动作专家；绝大多数仅使用单一当前帧。
- 这些设计差异与骨干网络、预训练、数据、动作表示等变量纠缠在一起，导致无法回答最基础的问题。

**三大开放问题（RQ1–RQ3）：**
1. **当前状态是否真的改善闭环控制？在哪些任务上有效？**
2. **状态历史有多大帮助？其收益来自真实的时序变化，还是仅仅来自增加的条件容量？**
3. **状态应注入模型的哪一侧——视觉-语言骨干（VLM）还是动作生成模块？**

**核心贡献：**
- 首次在**固定骨干网络、训练数据、动作表示和评估协议**的统一框架下，系统比较状态表示方式、注入位置和历史长度三个设计维度。
- 在 45 个原子任务 + 20 个复合任务上评估五种代表性状态接口，提炼出可测试的设计原则。

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想：**
- 以流匹配（flow-matching）VLA（采用 π0.5 作为基础策略）为测试平台，将所有无关变量固定，**唯一变化的是状态信号的表示形式、注入位置和历史长度**，从而将任何性能差异归因于状态设计本身。

**状态表示：**
- 每个原始状态帧 $s_q \in \mathbb{R}^{16}$，包含基座坐标系下的末端执行器位置和四元数、世界坐标系下的移动基座位置和四元数、以及两个夹爪关节位置。
- 除离散状态提示外，所有连续接口使用相同的数值内容、时序顺序和历史长度。
- 每帧独立通过两层投影器形成一个连续状态 token：
  $$h_i = \phi_2(\text{Swish}(\phi_1(s_i)))$$
  其中 $\phi_1$ 将状态从 16 维（零填充至 32 维）提升到宽度 $d$，$\phi_2$ 保持宽度不变。VLM 前缀使用 $d=2048$，其余使用 $d=1024$。

**五种状态接口：**

| 接口 | 缩写 | 机制 | 参数量（单帧） |
|------|------|------|----------------|
| 状态提示（State Prompt） | sp | 状态量化为 256 个 bin，序列化为约 66 个文本 token，与语言指令拼接 | 0（无新增参数） |
| VLM 前缀（VLM Prefix） | vp | 状态 token 插入双向 VLM 前缀，参与多模态上下文建模 | 4.26M |
| 动作前缀（Action Prefix） | ap | 状态 token 放入因果动作后缀，直接参与动作专家的速度场预测 | 1.08M |
| 状态专家（State Expert） | se | 专用状态处理流，拥有独立的 Transformer 堆栈，在生成过程中与动作模块交换信息 | 199.30M |
| 特征调制（Feature Modulation） | fm | 状态作为独立条件记忆，动作专家每层通过交叉注意力读取并预测逐特征缩放 $\gamma$ 和平移 $\beta$：$\text{Mod}(z;S) = (1+\gamma(z,S)) \odot z + \beta(z,S)$ | 123.84M |

**关键实验设计：**
- 使用**槽位匹配的重复当前帧对照**（slot-matched repeat-current control）来区分"真实时序变化"与"额外条件槽位/容量"的贡献。
- 对比独立训练的系统以评估完整接口的效用，而非抽象意义上的"注入位置"。

## 3. 实验设计：数据集、基准与对比方法

**基准平台：RoboCasa365**
- 基于 RoboCasa 仿真平台，包含多样厨房场景、机器人初始构型、物体实例和操作任务。
- 视觉观测：三个视角（左外部相机、右外部相机、腕部相机）。
- 所有方法使用相同的视觉输入、语言指令、动作空间和评估程序。

**原子任务基准（Atomic benchmark）：**
- 按操作语义（而非事后按模型性能）将 45 个原子任务预分为三个任务族：
  - **A（重排与抓放）**：探测末端执行器和移动基座的大范围定位能力（15 个任务）。
  - **B（铰接物体交互）**：探测持续接触和运动相位建模（15 个任务）。
  - **C（旋钮/开关/电器控制）**：小工作空间要求高局部精度（15 个任务）。
- 每个任务族训练独立的类别专家，每个任务用**50 次闭环 rollout** 评估（固定任务列表和 episode 种子计划）。

**复合任务基准（Composite benchmark）：**
- 使用 `lifelong_learning_phase2` 设置：20 种任务类型，每类在一个 episode 中串联 2–3 个原子子目标。
- 每个接口在所有 20 种类型上联合训练一个策略；评估仅保留新 episode，衡量分布内复合控制。
- 每种复合任务用**25 次闭环 rollout** 评估。
- 额外进行关节角度状态与末端执行器位姿状态的对照实验（动作表示保持末端执行器增量不变）。

**对比方法：**
- 无状态基线（NS）+ 五种状态接口（sp1、vp1、ap1、se1、fm1）。
- 历史长度扫描：1、4、8、16、32、48、64、96 帧。
- 所有模型从同一预训练 π0.5 检查点初始化，在共享优化方案下全量微调。

**统计方法：**
- 配对任务自助法（paired task-bootstrap）95% 置信区间。
- 固定种子计划控制场景初始化、物体实例、物体放置等随机性。
- 槽位匹配实验固定图像、语言、状态槽数、专家动作和初始流噪声。

## 6. 论文的主要结论与发现

**RQ1：当前状态是否改善控制？**
- 总体有益：无状态基线宏成功率为 54.6%，五种接口的增益为 +1.1 至 +3.1 点。
- **sp 是唯一获得统计支持（95% CI 排除零）的接口**，达到 57.7%。
- **不存在任务无关的最佳接口**：任务族层面的排序发生反转。
  - 家族 A（重排）：sp 领先（68.7%，+7.0），连续接口增益有限。
  - 家族 B（铰接）：vp 领先（68.8%，+6.1），se/fm 接近（+5.8/+5.5），sp 掉到中游（+1.6）。
  - 家族 C（旋钮/开关）：最困难（无状态基线 39.5%）且最具选择性，se 领先（42.8%，+3.3），vp 是唯一下降的接口（−1.2）。

**RQ2：状态历史是否有用？需要多长？**
- **短历史有益，长原始历史有害**：性能随历史深度呈非单调变化；家族 C 在长历史下下降尤为严重（尤其通过 VLM 前缀注入时）。
- **8 帧是实用操作点**：提供时序信息与上下文冗余之间的最佳平衡。
- **复合任务确认收益可迁移**：单帧 → 8 帧时，动作侧接口增益最大（ap +10.8），VLM 前缀则不一致（vp −0.6）。
- **收益来自真实时序结构而非额外 token**：槽位匹配的重复当前帧对照显著落后于真实有序历史（30.8% vs 39.0%，Δ=+8.2，CI 排除零）。
- **结论对状态表示稳健**：关节角度与末端执行器位姿两种表示均保持相同的定性结论。

**RQ3：状态应注入哪一侧？**
- **单帧（K=1）时，VLM 侧占优**：复合任务上 vp1 达 34.4%，ap1 仅 28.2%（EEF 位姿状态）；关节角度下 33.6% vs 31.4%。
- **短历史（K=8）时，优势转向动作侧**：ap 从最弱/接近最弱的单帧接口变为每个面板的最佳入口（原子 59.6%，复合 39.0%）。
- **设计规则**："单帧状态注入 VLM，多帧历史路由到动作头（action head）"。该规则在两种状态表示和两套任务套件中均成立。
- 探针实验表明机制差异：VLM 侧状态在动作生成前改变多模态上下文；动作侧状态直接在动作专家内部作用。

**总体设计默认：**
> "将当前帧注入 VLM，将短历史路由到动作头，更深的历史需验证后再使用。"

## 7. 优点：方法或实验设计上的亮点

1. **高度受控的统一实验框架**：固定骨干、数据、动作表示和评估协议，使性能差异可清晰归因于状态设计本身——这是此前研究缺失的关键。
2. **三维度系统分解**：将"如何使用状态"这一模糊问题分解为表示（representation）、时间深度（temporal depth）、注入路线（injection route）三个可测量轴，逻辑清晰。
3. **槽位匹配的重复当前帧对照**：巧妙区分"真实时序变化"与"额外条件容量"的混淆，方法学严谨。
4. **任务族预分区**：按控制语义（大范围定位 vs. 持续接触 vs. 局部精度）预先划分任务族，而非事后按性能分组，避免了选择偏差，并揭示了宏平均掩盖的重要反转模式。
5. **统计推断的使用**：配对任务自助法置信区间支持核心论断（如 sp 的增益、槽位匹配对照的差异），比单纯点估计更可靠。
6. **计算成本透明化**：提供了理论边际 FLOPs 的详细推导（Appendix C），明确区分活动 token 数、参数容量和实测吞吐量等易混淆概念。
7. **探针实验与案例研究互补**：固定检查点探针追踪状态如何影响注意力和动作生成；PrepareToast 配对案例研究将收益定位到特定的子任务转换边界，多层次验证主结论。
8. **结论可操作性强**：提炼出清晰、可测试的设计原则和可复用的评估协议。

## 8. 不足与局限

1. **缺乏真实机器人验证**：所有实验均在 RoboCasa 仿真平台进行，作者明确承认这是主要局限之一；仿真与真实世界之间存在 sim-to-real 差距。
2. **状态模态单一**：仅研究纯运动学状态（关节角、位姿、夹爪），**未覆盖力、触觉等其他感知模态**——而这些模态在接触丰富的操作中可能至关重要。
3. **统计效力有限**：绝大多数对比为单种子点估计，作者承认排序是"方向性模式"而非"既定因果机制或统计排序"；界面×深度扫描未做多重性校正。
4. **接口间固有混淆**：五种接口在投影宽度、参数量、计算路径上存在系统性差异（se/fm 容量大得多），无法将"注入位置"与"容量/拓扑"完全解耦；作者也声明 se/fm 不用于容量匹配的论断。
5. **聚合结论可能掩盖任务差异**：虽然任务族分区部分缓解了这一点，但宏平均仍可能受任务选择影响；作者自己也指出"单一基准范围平均值会完全隐藏"家族间的反转模式。
6. **关节角度 vs. 末端执行器位姿的结论趋于保守**：在 K=8 时两种表示下的 vp/ap 差异落在配对自助法噪声带内（≈），该维度的区分度有限。
7. **因果机制未完全确立**：案例研究显示策略在进度边界处对状态变化最敏感，但作者明确承认这是"描述性证据"而非"因果中介论断"。
8. **通用性边界**：所有实验基于单一基础策略（π0.5 流匹配 VLA），设计规则"单帧入 VLM、短历史入动作头"是否适用于其他架构（如扩散策略、其他 VLM 骨干）尚待验证。
