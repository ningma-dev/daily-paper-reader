## 摘要
稳健的机器人控制受益于显式地对状态转换建模，但视频生成世界动作模型（WAMs）会引入大量的部署成本。现有的潜在WAM避免了显式地生成未来，但常常压缩预测表示或将预测建模与用于动作生成的表示分离开来。我们引入了JEPA-WAM，一个建立在预训练V-JEPA空间中的潜在WAM，通过共享预测器将潜在转换预测与连续动作生成耦合起来。JEPA-WAM预测一个空间结构化的联合当前-未来目标，该目标捕获当前与未来观测之间任务共享的视觉时间结构，同时保持密集的patch级对应关系。通过共享预测器，转换监督直接塑造主干网络，从中提取专门用于动作预测的表示。同样的设计也可以在预训练的VLA策略中实例化，同时保留其原始的感知和动作路径。在LIBERO-Plus上，JEPA-WAM达到了79.2%，这是没有大规模机器人策略预训练的最佳结果，而其预训练的π_{0.5}实例达到了86.3%，实现了最佳整体性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间变化下的强大泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

# JEPA-WAM 论文总结

## 1. 核心问题与整体含义

- **背景与动机**：视觉-语言-动作（VLA）策略在多种操作任务上表现优异，但其动作预测目标仅隐式地建模状态转换，在分布偏移下鲁棒性有限。世界动作模型（WAM）通过显式建模未来状态来提高鲁棒性，但基于视频生成的 WAM 因迭代式未来预测导致部署成本过高。
- **现有潜在 WAM 的不足**：已有的潜在 WAM 虽然避免了显式未来帧生成，但往往压缩预测表示（如少量潜在 token 或子目标），丢失细粒度空间结构；或者将预测建模与动作生成用的表示分离，使预测监督无法直接塑造策略主干。
- **本文目标**：提出 JEPA-WAM，在预训练 V-JEPA 表示空间中构建潜在世界模型，通过**共享预测器**将潜在转换预测与连续动作生成直接耦合，在保持部署效率的同时提升 OOD 泛化能力。

## 2. 方法论

- **核心思想**：
  - 使用冻结的预训练 V-JEPA 2.1 编码器定义视觉潜在空间，既表示当前观测，也构造联合当前-未来目标。
  - 共享预测器（Qwen2.5-0.5B）同时承担两个任务：预测空间结构化的联合当前-未来目标，以及为动作专家生成专用的条件表示。
  - 转换监督直接优化主干的共享参数，使动作生成受益于学习到的视觉时间结构。

- **关键技术细节**：
  1. **当前视觉表示**：每个视角独立经冻结 V-JEPA 编码，按固定相机顺序拼接得到 \(Z_t \in \mathbb{R}^{N_{vis}\times d_J}\)，保留 patch 级空间结构。
  2. **联合当前-未来目标**：将当前帧 \(O_t^v\) 与未来帧 \(O_{t+\delta}^v\) 沿时间维堆叠后联合编码得到 \(Y_{t,t+\delta}\)。由于 V-JEPA 的 tubelet 大小为 2，两帧输入产生与单帧相同的空间 token 网格，从而与当前表示保持 patch 级对应。该目标捕获稳定/变化区域、物体关系变化等转换信息，而非要求重构唯一未来观测。
  3. **共享预测器**：输入为投影后的视觉 token、任务指令和动作 placeholder，输出两部分：视觉位置的隐藏状态 \(Q_t^{wm}\) 用于预测目标，动作 placeholder 的隐藏状态 \(C_t\) 用于动作生成。
  4. **转换预测损失**：预测头 \(G_\phi\) 将 \(Q_t^{wm}\) 映射回 V-JEPA 空间，采用 patch 级余弦距离：
     \[
     L_{wm} = \frac{1}{BN_{vis}}\sum_{b,n}\bigl(1-\cos(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n})\bigr)
     \]
  5. **动作生成**：使用 DiT 动作专家和条件流匹配，默认速度预测目标；总损失 \(L = L_{act} + \lambda_{wm} L_{wm}\)（\(\lambda_{wm}=0.5\)）。
  6. **部署时**：移除目标分支和预测头，仅保留当前观测的 V-JEPA 编码、投影器、共享预测器和动作专家，因此不增加额外推理负担。
  7. **迁移到预训练 VLA**：在 π0.5 中增加 64 个可学习 future tokens，其输出隐藏状态 reshape 为 \(8\times8\times2048\) 粗特征图，经 MLP 和双线性上采样到 \(24\times24\)，与冻结 V-JEPA 的联合目标对齐；不改变原始感知/动作路径。

## 6. 主要结论与发现

- **JEPA-WAM 在 LIBERO-Plus 上达到 79.2%**，是无大规模机器人策略预训练方法中的最佳结果；在标准 LIBERO 上保持 96.7% 的竞争性 ID 性能。
- **在预训练 π0.5 上添加转换监督**（π0.5+JEPA Obj.）将 LIBERO-Plus 从 84.5% 提升到 86.3%，达到综合最佳；标准 LIBERO 也从 96.9% 提升到 97.8%。
- 在 RoboTwin 2.0 上，JEPA-WAM Clean/Random 为 79.9%/36.9%，显著优于无预训练方法，Random 性能与预训练 π0.5 相当；π0.5+JEPA Obj. 将 Clean 从 75.4% 提升到 84.6%。
- 真实世界中 JEPA-WAM 的 OOD 性能（54.2%）远高于 π0（22.5%）；π0.5+JEPA Obj. 将 ID/OOD 从 77.5%/72.5% 提升到 90.3%/84.7%。
- 消融表明：V-JEPA 表示自身比 DINOv2+SigLIP 更强；联合当前-未来目标优于 future-only 和端点差分；patch 级监督优于卷积对齐；最终层监督优于中间层；专用动作 placeholder 优于全隐藏状态。
- 探针实验证明：联合编码包含超出端点差分的转换结构信息，能更好地预测时间间隔和去端点位移后的轨迹结构，但**不擅长**直接预测端点位移（这是端点差分表示的优势）。

## 7. 优点

- **部署高效**：无需显式未来帧生成，推理时移除预测分支，RoboTwin 上仅 85 ms，比同类 WAM 快。
- **设计巧妙**：利用 V-JEPA 的 patch 级空间结构和时序一致性定义联合当前-未来目标，既保留细粒度空间信息，又避免重构唯一未来。
- **耦合更紧**：共享预测器让转换监督直接作用于动作生成主干，避免预测模型与动作模型分离带来的信息瓶颈。
- **可迁移性**：同一目标公式可无缝嵌入预训练 VLA（π0.5），不改变原有感知/动作路径，且带来明显提升。
- **分析深入**：除策略性能外，还用冻结探针从表征层面解释了联合目标的优势，实验说服力较强。
- **全面评估**：跨仿真和真实世界、ID/OOD、多种扰动类别，验证了泛化结论。

## 8. 不足与局限

- **方法本身的局限**：作者指出，JEPA-WAM 学习的是与语言无关的通用视觉时间结构；当同一观测在不同语言指令下导致显著不同转换时，该监督表达力不足，可考虑语言条件化或多模态目标。
- **实验覆盖有限**：真实世界任务仅 5 个，每个任务 10 次 rollout；场景复杂度、物体多样性有限，不足以证明通用性。
- **公平性风险**：大量 baseline 引用原始论文结果，未在同一代码库/训练配置下复现，比较结果可能受实现差异影响。
- **算力报告不完整**：未给出 GPU 型号、显存、训练时长等关键信息，复现成本不透明。
- **超参数敏感性**：时间偏移 δ、损失权重 λwm、LoRA 设置等可能依赖 benchmark，未见详细的敏感度分析。
- **个别任务仍失败**：如 RoboTwin 中 Place Bread Basket 成功率仅 38%（Clean），说明 OOD 泛化仍有明显短板。
