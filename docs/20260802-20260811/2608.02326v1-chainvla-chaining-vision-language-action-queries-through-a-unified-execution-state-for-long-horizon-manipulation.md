## 摘要
人类通过保留先前动作所建立的知识，同时持续调整正在进行的运动，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时从当前输入重复重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作复用和集成保留短期运动，导致跨查询交接不完整。我们引入了ChainVLA，一个1.2B参数的VLA策略，通过联合且可修订的执行状态来链接连续查询。进度上下文结合循环工作状态与稀疏事件记忆，以携带源自观察的任务进度，而运动尾部则将先前预测中未执行的续段馈送到状态构建和动作生成中。这两个组件共同调节一个解码器，该解码器在最新观察下重新生成每个动作时域，使得携带的状态能够指导下一次预测而不使其固定。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文则分别将RMBench成功率降至11.2%和3.0%。这些不对称的消融结果与运动连续性有助于保持推断任务进度所需的观察流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 1. 论文的核心问题与整体含义（研究动机和背景）

**研究背景：**
- 长时程操作（Long-Horizon Manipulation）是机器人操作领域的关键挑战。人类在执行这类任务时，能够同时做到两点：**保留此前动作已建立的任务进展**，以及**持续调整当前正在进行的运动**。
- 现有动作分块（action-chunked）VLA 策略采用"严格前缀-再规划"（strict-prefix receding-horizon）机制：每次查询预测一个有限长度的动作序列，执行其中一段严格前缀，然后基于当前观测重新规划。
- 这种机制存在**跨查询交接不完整（incomplete cross-query handoff）** 的问题，体现为两个层面：
  - **任务层面**：先前查询推断出的任务进展，可能无法从当前观测中恢复（例如 RMBench 的 Put Back Block 任务中，相同的观测和指令可能对应不同的历史，需要不同的后续决策）；
  - **运动层面**：重新规划时完全丢弃前次预测中未执行的续段，导致新预测的动作为即使当前位姿相似，仍可能与被替代的运动产生不一致。

**核心问题：**
> 如何在保持每次新预测对最新观测响应的前提下，让 VLA 策略跨查询链接任务进度（task progress）与运动延续（motion continuation）？

**相关工作的不足：**
- 记忆增强策略（如 MemoryVLA）只保留观测衍生的记忆，不携带策略自身此前"意图"；
- 时序集成（Temporal Ensemble）、实时执行、原生延续等方法只保留短期运动，无法回溯更早的任务证据；
- 两种路线互相补充但无法兼顾，没有方法将两者统一在一个跨查询状态中。

## 2. 论文提出的方法论

### 2.1 核心思想

ChainVLA 构建一个**联合且可修订的执行状态（joint and revisable execution state）**，记为 $s_k = (g_k, u_k)$，其中包含两个互补组件：

| 组件 | 类型 | 功能 |
|------|------|------|
| **Progress Context（进度上下文）** $g_k$ | 回顾性（retrospective） | 携带观测衍生的任务进度，由循环 Working State 与稀疏事件记忆检索结果融合而来 |
| **Motion Tail（运动尾部）** $u_k$ | 前瞻性（prospective） | 承载前一次预测中未执行的后缀，直接跨查询传递未完成的运动延续 |

**核心等式：**

$$\Pi_\theta(\cdot | x_k, s_k) \approx \Pi^*(\cdot | H_k), \quad s_{k+1} = F_\theta(s_k, x_k)$$

即：用当前输入 $x_k$（观测、本体感受、语言指令）加上携带状态 $s_k$ 来逼近最优历史条件策略；查询结束后执行前缀并更新状态传递到下一查询。

### 2.2 关键技术细节

**（1）查询转移机制（Query Transition）：**

$$(A_k, W_k, C_{k+1}) = F_\theta(x_k, D_k, W_{k-1}, C_k, u_k), \quad u_{k+1} = \text{Tail}(A_k)$$

其中 $A_k$ 是预测的完整动作时域，$D_k$ 是已执行动作历史，$W_k$ 是循环工作状态，$C_k$ 是稀疏事件记忆，$\text{Tail}(A_k) = (a_{k,h_{exec}+1}, \ldots, a_{k,H})$ 是未执行后缀。

**（2）Progress Context 的构建——循环工作状态（Recurrent Working State）：**

- 状态 $W_k = (L_k, B_k)$：$L_k$ 为当前实时令牌（live tokens），$B_k$ 为有界 FIFO 缓存；
- 更新过程使用 8 个学习的工作查询（working queries）对当前多模态令牌做交叉注意力，并通过掩码循环注意力与前一轮 live tokens 递归融合；
- 池化摘要 $\bar{W}_k$ 驱动事件检索和阶段估计。

**（3）稀疏事件记忆与检索（Sparse Event Memory & Retrieval）：**

- 事件记录 $(k_i, E_i, b_i)$ 存储视觉特征、阶段信息和时间特征，容量 16 条，最旧非锚点被淘汰；
- 检索采用**年龄感知余弦相似度**：

$$\rho_{k,i} = \cos(\text{LN}(q_k^e), \text{LN}(\kappa_i + \text{Emb}_{age}(\text{clip}(k - b_i))))$$

- 首个合法事件保留为锚点（anchor），之后选择最高得分的高非锚点记录进行交叉注意力融合形成读出版本 $Z_k^e$。

**（4）Motion Tail 的两条模型侧通路：**

- **通路一**：将规范化后的未执行后缀编码为 tail tokens $U_k$，参与 Working State 构建；
- **通路二**：将后缀对齐到完整时域动作表示，作为条件初始化：

$$\tilde{A}_{k+1}^{(0)} | u_{k+1} \sim \mathcal{N}(\mu_{k+1}, \sigma_u^2 I)$$

解码器在每个位置都基于最新观测重新生成，携带的状态是可修订的先验而非固定计划。

**（5）训练策略：**

- 按回合顺序展开训练（rolled out in episode order），分类标签不进入动作解码器；
- 训练时携带的 tail 经过 detach 后以概率 0.5 条件化下一查询；
- 损失包括：条件流的动作目标 + 阶段监督（有标注时）+ 重叠一致性正则化项（权重 0.2）。

## 6. 论文的主要结论与发现

1. **联合执行状态显著有效**：ChainVLA（1.2B）在 RMBench 达到 **62.8%** 平均成功率，超越最强完整覆盖方法 Mem-0（52.8%，8B+2B），并在每个任务上最优或次优；LIBERO 四套件平均 **98.8%**，包括 Long 套件 98.2%。

2. **两个组件缺一不可，且作用不对称**：
   - 移除 Motion Tail → 11.2%；移除 Progress Context → 3.0%；两者全移除 → 1.6%；
   - 移除 Progress Context 的模型"流畅地走向错误的子目标"，而移除 Motion Tail 则破坏了记忆通路所依赖的观测流；
   - 说明运动连续性帮助保留用于任务进展推断的观测序列，两者是**串联环节**而非并行能力。

3. **后解码平滑无法替代模型侧条件化**：Linear Continuation 和 Temporal Ensemble 虽能降低边界指标，但成功率分别只有 0-2% 和 0%，对比 Full 的 96%/74%，证明"何时使用后缀"（解码前条件化 vs.解码后平滑）是关键。

4. **阶段标注并非必要**：固定三查询写入仍达 53.4%，说明链不依赖阶段标注的可用性。

5. **现有替代方案不足**：FIFO 历史 + 时间集成只有 35.6%，低于完整模型 27.2 个百分点，无法捕捉"前一次预测条件化下一次生成"的关键机制。

## 7. 优点

- **问题识别精准**：清晰定义了"任务进度"与"运动延续"两个正交的跨查询信息维度，并给出形式化的决策不充分性判别准则（式 1），理论基础扎实；
- **架构设计优雅**：将两类互补信息统一为单一可修订执行状态，解码器在最新观测下重新生成每个位置，携带状态作为**先验而非硬约束**，保留了灵活性；
- **消融设计极具启发**：不对称消融结果的解释（运动连续性保护观测流）不仅验证了方法，还揭示了动作分块策略中一个此前被忽视的因果关系；
