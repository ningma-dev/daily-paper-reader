## 摘要
世界动作模型（WAMs）联合学习环境动态和机器人动作，将物理演化的先验引入具身控制。然而，有限时域的预测和动作生成对于需要全局规划、跨阶段状态维护、执行验证和故障恢复的复杂具身任务来说是不够的。我们将这种不匹配称为WAMs的预测-深思差距。为了解决这一差距，我们提出了HarnessWAM，一个面向WAMs的智能体框架。HarnessWAM采用基于视觉语言模型的任务管理器来维护基于证据的场景信念和结构化任务图。能力条件下的可执行空间投影进一步将开放式的语义计划约束为原子技能序列，这些序列满足任务依赖、具身状态约束以及底层WAM的能力边界。在执行过程中，HarnessWAM通过事件驱动的双时间尺度反馈循环运行：轻量级进度估计器持续提供高频执行证据，而任务管理器在关键里程碑处进行深思，通过联合考虑当前观察、任务状态和交互历史来决定是推进任务、获取额外观察、修改计划还是启动局部恢复。该机制使机器人能够在子任务失败后恢复其状态，并在不丢弃先前获取的场景知识的情况下继续执行。HarnessWAM在RoboMemArena上实现了最先进的全任务和子任务成功率，分别为59.6%和69.9%，在RoboCerebra Ideal上实现了23.7%的SR。这些结果表明，模型外部的结构化状态维护和闭环智能体决策可以有效地将WAMs的局部控制能力扩展到可规划、可验证和可恢复的具身任务执行中。

## Abstract
World Action Models (WAMs) jointly learn environmental dynamics and robot actions, introducing priors over physical evolution into embodied control. However, finite-horizon prediction and action generation are insufficient for complex embodied tasks that require global planning, cross-stage state maintenance, execution verification, and failure recovery. We refer to this mismatch as the prediction-deliberation gap of WAMs. To address this gap, we propose HarnessWAM, an agentic framework for WAMs. HarnessWAM employs a vision-language-model-based Task Manager to maintain an evidence-grounded scene belief and a structured task graph. A capability-conditioned executable-space projection further constrains open-ended semantic plans into sequences of atomic skills that satisfy task dependencies, embodiment-state constraints, and the capability boundary of the underlying WAM. During execution, HarnessWAM operates through an event-driven, dual-timescale feedback loop: a lightweight progress estimator continuously provides high-frequency execution evidence, while the Task Manager deliberates at salient milestones by jointly considering the current observation, task state, and interaction history to determine whether to advance the task, acquire additional observations, revise the plan, or initiate local recovery. This mechanism enables the robot to recover its state after a subtask failure and resume execution without discarding previously acquired scene knowledge. HarnessWAM achieves state-of-the-art full-task and subtask success rates of 59.6% and 69.9% on RoboMemArena, and an SR of 23.7% on RoboCerebra Ideal. These results demonstrate that model-external structured state maintenance and closed-loop agentic decision making can effectively extend the local control capabilities of WAMs into embodied task execution that is plannable, verifiable, and recoverable.

## 1. 核心问题与整体含义

- **研究背景**：世界动作模型（WAM）联合建模未来观测、环境状态和机器人动作，能够提供有限时域的预测和局部操作技能。然而，复杂具身任务要求全局规划、跨阶段状态维护、执行验证以及失败恢复，这些超出了 WAM 直接输出动作的能力。
- **核心问题**：论文指出 WAM 存在 **“预测-深思差距”（prediction-deliberation gap）**——即模型只擅长局部物理演化的预测与控制，却无法持续维护任务级状态、验证中间结果或在失败后做出恢复决策。
- **整体含义**：要发挥 WAM 的能力，不能只改进模型本身，还需要一个**模型外部的智能体框架**（harness）来组织其调用，实现“可规划、可验证、可恢复”的具身任务执行。HarnessWAM 正是为此提出的解决方案。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体框架

- HarnessWAM 是一个“模型外部”的决策过程，包含：
  - **VLM Task Manager**：基于视觉语言模型（Qwen3-VL-32B）进行高层推理，维护场景信念与任务图。
  - **确定性可执行空间投影**：将开放式语义计划编译为底层 WAM 支持的原子技能序列。
  - **轻量级进度估计器**：高频感知当前子任务完成情况。
  - **事件驱动的双时间尺度反馈循环**：快速执行回路（WAM 控制）与慢速深思回路（Task Manager）协作。

### 2.2 问题形式化

- WAM 输出动作块：  
  \( A_t = W_\theta(o_{\le t}, q_t, g_k) = (a_t, \dots, a_{t+H-1}) \)
- 框架定义为递归状态更新：  
  \( (z_{k+1}, g_{k+1}) = H(x, z_k, o_{\tau_k}, e_k) \)，  
  其中 \( z_k = (B_k, G_k, M_k, r_k) \) 包含场景信念、任务图、记忆、执行状态。

### 2.3 证据驱动的场景信念

- 场景事实表示为五元组：`(subject, predicate, object, value, epistemic status, confidence, evidence reference)`，区分“未观察”和“观察为假”。
- 记忆分为任务记忆和证据记忆，保存已完成/失败的节点、重试次数、变量绑定和视觉证据。
- 任务图是有向图，节点含操作、参数、前置条件、预期效果、终止条件、恢复策略；包括**运动节点**和**认知节点**（观察、验证、绑定变量等）。
- 未解析的实体保持为符号变量，直到有足够视觉证据才绑定。

### 2.4 能力条件化的可执行空间投影

- 定义可扩展原语本体：\( P^\star = P_{\text{motion}} \cup P_{\text{grasp}} \cup P_{\text{contact}} \cup P_{\text{articulation}} \cup P_{\text{assembly}} \cup P_{\text{tool}} \)。
- 对一个 WAM，其可执行原语集合为已验证能力的子集：\( P_W = \{ p \in P^\star \mid p \text{ has a validated realization under } W_\theta \} \)。
- 投影公式：\( G^{\text{exec}}_k = \Pi_{L(P_W) \cap F(z_k)}(G^{\text{vlm}}_k) \)，通过确定性编译器检查参数类型、依赖、前置条件、单臂持有状态、图无环性等。
- 若无法投影则返回 ⊥，并报告违反的约束给 Task Manager 以进行重规划。
- 历史不变性约束：只允许修改未执行的任务图后缀。

### 2.5 进度条件化事件控制

- 快速回路中，进度估计器 \( F_\phi \) 从最近 L 帧双视角 RGB 图像和文本预测连续进度、完成概率和进度区间分布。
- 训练目标包括回归、区间分类、时序排序、端点锚定、完成预测和局部单调性等多项损失。
- 进度本身从不直接推进任务图；只有 Task Manager 给出 `advance` 决策时才完成当前节点。
- 事件触发条件包括：进度里程碑、技能预算耗尽、条件变化等。

### 2.6 恢复与终止

- 每个运动节点开始时记录手臂关节状态和夹爪状态，作为恢复目标。
- 局部失败后，通过多步控制恢复机械臂与夹爪到子任务初始状态，但保留场景知识和记忆。
- 终止条件：任务成功需所有节点完成并经过最终视觉验证；失败包括图无法满足目标、无可行计划或预算耗尽。

## 3. 实验设计

### 3.1 基准与数据集

- **RoboMemArena**：26 个长时程操作任务，平均轨迹长度 1076 步，68.9% 的子任务依赖历史信息。包含四类任务族：多物体转移、遮挡、计数、顺序执行。
- **RoboCerebra Ideal**：长时程组合操作与高层推理基准，静态且完全可观测。

### 3.2 指标

- RoboMemArena：全任务成功率（所有阶段验证谓词全部满足）和子任务成功率（宏平均阶段完成率）。
- RoboCerebra：官方 SR，即关键物体状态转换的平均完成率。

### 3.3 对比方法

- RoboMemArena：π0.5、HiF-VLA、MemoryVLA、MemER、PrediMem，以及两个同 WAM 对照：`WAM + Whole Task`（直接输入全局指令）和 `WAM + Static Plan`（一次性生成固定子任务序列）。
- RoboCerebra：π0.5、OpenVLA、GPT-4o Planner + OpenVLA、HPE Framework。

### 3.4 实现细节

- 底层 WAM 为 **LingBot-VA**，在不同基准上分别微调，架构不变。
- Task Manager 使用 **Qwen3-VL-32B-Instruct**（无任务特化微调），输入仅有多视角 RGB，无深度/分割/特权状态。
- 进度估计器使用 SigLIP2 编码器 + 四层因果 Transformer。

### 3.5 评估协议

- 每个任务 20 次 rollout，初始状态、随机种子、观测接口和任务预算保持一致。
- 不使用预定切换时间，由任务状态动态决定子任务边界。

## 6. 主要结论与发现

- HarnessWAM 在 RoboMemArena 上取得 **59.6% 全任务成功率**和 **69.9% 子任务成功率**，超过 PrediMem 21.1 和 14.7 个百分点，达到最先进水平。
- 在 RoboCerebra Ideal 上 SR 为 **23.7%**，优于 GPT-4o Planner + OpenVLA（21.92%）和 HPE Framework（21.10%）。
- 消融显示：
  - **可执行空间投影贡献最大**：去除后全任务成功率从 59.6% 降至 18.5%（-41.1）。
  - **事件驱动控制** 次之：去除后下降 21.3 点。
  - **结构化任务状态** 对遮挡类任务尤其重要。
  - **纯进度切换** 会提高子任务成功率但降低全任务成功率，说明语义验证不可替代。
  - **局部恢复** 主要影响顺序执行类任务。
- 计划级诊断表明：仅靠词汇规范化可提升可执行性至 42.3%，而完整投影可提升至 72.9%。
- 结论：模型外部的结构化状态维护和闭环智能体决策能将 WAM 的局部控制能力扩展为持久、可验证、可恢复的任务级行为。

## 7. 优点

- **问题定义清晰**：首次明确命名并形式化了 WAM 的“预测-深思差距”，具有启发性。
- **模块化架构**：将规划、记忆、验证、恢复统一在一个事件驱动框架中，无需修改底层 WAM，通用性强。
- **证据驱动的状态表示**：区分观察到/推断/未知，支持延迟绑定，能处理部分可观测环境。
- **可执行空间投影**：用确定性约束桥接 VLM 开放式语言计划与 WAM 实际能力，有效提高计划可用性。
- **双时间尺度控制**：避免频繁调用 VLM，实现高频进度监控与低频深思的合理折衷。
- **实验设计严谨**：设置同 WAM 对照、多组件消融和计划级诊断，结论归因较为扎实。

## 8. 不足与局限

- **算力与训练细节缺失**：未报告 GPU 型号、数量、训练时间等，重复实现成本高，资源可复现性不明确。
- **依赖强 VLM**：Task Manager 使用 32B 参数模型，推理成本高，且未见对 VLM 失败、幻觉或错误概率的鲁棒性分析。

  - 全部为仿真/基准测试，未在真实机器人上验证。

- **投影依赖手工定义原语**：原语本体和约束需要人工设计，扩展新技能时需额外工程，泛化能力受限。
- **恢复机制简单**：仅恢复到子任务初始位姿，对于复杂物理损坏或非可逆状态变化的恢复有限。
