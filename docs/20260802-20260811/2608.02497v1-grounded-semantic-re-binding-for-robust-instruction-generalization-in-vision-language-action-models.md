## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当标准指令仅被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探究揭示，其根本原因在于架构而非缺乏语义理解。具体而言，我们证明当前VLA模型在内部确实成功保留了正确的任务身份。失败实际上源于动态视觉观测与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构性瓶颈，我们提出了一种优雅的干预方法——基于语义重绑定（GSR），它通过将独立提取的任务语义与原生视觉特征显式融合，从零开始训练一个完全重新初始化的动作专家，从而绕开不稳定的联合路由。这种有针对性的干预仅使用标准演示即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6个百分点。它使轻量级模型能够媲美大规模扩展的基线，并将最先进模型的PRIDE分数推至70.4的新纪录，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义基础，而无需依赖低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

### 2. 方法论

#### 2.1 核心思想

作者提出 **Grounded Semantic Re-binding（GSR，基于语义重绑定）**：将任务指令的语义提取与动态视觉观测解耦，使用独立的冻结T5编码器提取稳定的任务语义，再将其重新注入模型的本地视觉-状态计算通路中，并用重新初始化的动作专家从零开始学习语义到动作的映射。

#### 2.2 关键组成与技术细节

- **稳定语义源**：使用**冻结的T5-large**编码器对真实任务指令进行编码，T5不接收任何图像或机器人状态输入，保证提取的语义特征**完全稳定、不受视觉动态变化影响**。
- **架构感知的注入策略**：GSR不是固定修补，而是**根据各模型的架构特点**选择合适的注入点——在模型执行核心多模态融合（任务信息、视觉场景、机器人状态）的阶段注入T5语义：
  - **VLA-Adapter**（拥有独立的Bridge-Attention策略组件）：将T5投影特征作为sidecar K/V源注入每个动作块，Qwen主路径改为接收固定中性文本"perform the task"。
  - **SmolVLA**（早期视觉-语言交互）：将T5特征投影后，通过8头 grounding attention 注入SmolVLM原生语言槽位，使其在原有计算层中与图像深度交互。
  - **π0.5**（大规模多模态协同训练）：原生PaliGemma路径泛化已可靠，T5作为**补充语义源**注入，保留原生指令作为主要控制源。
- **动作专家重新初始化**：所有GSR变体均从随机初始化开始训练动作专家，而非微调预训练权重，以切断原有的有缺陷的语义-动作映射路径。

#### 2.4 诊断分析的关键证据

- **目标性因果干预**：在VLA-Adapter释义执行过程中，仅将最终Bridge-Attention块的语言特征替换为canonical运行时的对应特征，成功率从60%飙升至96%，证明任务信息在模型中得以保留但被下游误处理。
- **视觉解耦实验**：将辅助Qwen分支接收的图像替换为固定虚拟图像，释义成功率从46.82%提升至61.58%，证明**动态视觉输入的联合编码放大了释义引起的特征变异**。
- **措辞子空间消融**：通过任务不相交交叉验证估计32个措辞方向并移除，将canonical与paraphrase的动作差距从0.4361降至0.2282，破坏性验证了措辞变化引入的是**可分离的系统性特征偏移**。

### 3. 实验设计

#### 3.1 数据集与基准

- **LIBERO-Goal**：训练数据集，所有GSR变体仅使用10个规范指令任务的标准演示（428个episode，52,042个transition）。
- **LIBERO-Para**：核心评估基准，包含4,092个episode（870个Act动作措辞改写、259个Obj物体指代改写、2,963个Comp组合改写），严格保持物理条件、初始状态和成功判据不变，仅改写文本指令。
- **Goal-100诊断集**：100个固定观测，每个观测配对10种canonical指令、10种人工paraphrase和10种循环错误任务指令。
- **真实机器人实验**：6个任务（4个抓取、2个堆叠），同一场景共享4个物体初始布局，2个相机视角，基于AgileX PiPER双臂平台。

#### 3.2 对比方法

- **基线模型**：VLA-Adapter（0.51B）、SmolVLA（0.45B）、π0.5（3.6B）、Xiaomi-Robotics-0、OpenVLA-OFT、X-VLA。
- **消融变体**：Native（原生指令）、Native + T5（保留原生指令并额外添加T5）、GSR（按GSR方案改造）、Native control（无T5、无GSR的对照）。
- **实验结果**：GSR在Full Para SR上分别达到VLA-Adapter 70.94%（基线46.82%）、SmolVLA 49.12%（基线4.47%）、π0.5 75.59%（基线73.60%），其中π0.5+GSR的PRIDE分数达70.4，刷新最高纪录。

### 6. 主要结论与发现

- **根因判定**：VLA对释义失败的根因是**架构性**的（视觉-语言联合编码导致特征偏移），而非语义理解不足——模型内部保留了正确任务身份。
- **GSR有效性**：仅使用canonical演示，无需任何释义训练数据，GSR即在LIBERO-Para上显著提升所有模型的释义成功率：
  - VLA-Adapter从46.82%→70.94%（提升24.12个百分点）
  - SmolVLA从4.47%→49.12%（提升44.6个百分点）
  - π0.5从73.60%→75.59%，PRIDE达70.4（超越Xiaomi-Robotics-0的69.2）
- **架构差异**：不同模型对任务信息的融合方式不同——VLA-Adapter存在严格的动作控制瓶颈（最后一个Bridge-Attention块），SmolVLA和π0.5则是分布式处理，不存在单一控制点。这验证了GSR作为**架构感知方法**而非固定修补的必要性。
- **解耦范式的潜力**：ParaVLA（0.33B）实现了92.0%的canonical和91.0%的paraphrase成功率（差距仅1.0个百分点），证明原生解耦的架构本身就可实现近完美的释义不变性。

### 7. 优点

- **洞察深刻**：通过精细的探针分析、因果干预和子空间消融，系统性地定位了VLA中指令失败的真实机制（不是语义丢失而是架构翻译失败），具有方法论启示意义。
- **优雅高效**：GSR不依赖任何释义数据或大规模数据扩展，仅通过架构干预（重新初始化动作专家 + 独立语义注入）即获得显著收益，证明了结构设计是解决鲁棒性的更优路径。
- **架构兼容性广**：GSR不仅是针对某一特定模型的修补，而是总结出架构感知的通用原则，适用于独立策略、早期融合、大规模协同训练等不同设计范式。
- **实验严谨性**：全面使用配对对照、固定观测、种子控制、McNemar检验等手段，确保结果的统计可靠性；确保证明各性能提升不是由额外参数量或训练预算引起的。
- **多维度验证**：模拟+真实机器人、多个参数量级、多种训练机制，完整覆盖了从机制理解到实际部署的整个链条。

### 8. 不足与局限

- **可扩展性瓶颈（ParaVLA）**：原生解耦架构在视觉基础模型升级时（如更大的DINO变体）未能表现出VLM级别的扩展能力，是纯解耦范式的重要限制。
- **π0.5的初始化性能下降**：在标准匹配训练预算下，π0.5+GSR的canonical Goal成功率从93.0%略降至91.0%，需要将训练步数翻倍才能恢复至96.0%。论文承认大参数动作专家的重新初始化需要进一步优化策略。
- **真实机器人实验规模有限**：仅6个任务（全部为右臂操作）、单一场景、5次重复试验，且部分任务（任务3、5、6）GSR的成功率为0%，未能在更复杂任务中验证。
- **语言覆盖范围有限**：仅在英文指令上验证，未覆盖多语言、混合表述或高度口语化的指令。
- **无需释义数据的前提限制**：GSR的核心优势在于不使用释义训练数据，但对于本身已具备较强鲁棒性的大规模模型（如π0.5），收益幅度相对有限（约2个百分点），其增量价值更多体现在轻量模型上。
