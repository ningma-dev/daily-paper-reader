## 摘要
视觉-语言-动作（VLA）模型将预训练视觉-语言模型（VLM）的表征转换为机器人动作，然而将中间VLM特征路由到动作解码器的接口仍未得到充分探索。现有设计要么仅暴露表征层次中狭窄的一部分，要么将每个解码器块严格匹配到一个VLM层，限制了跨深度访问互补任务证据的能力。我们提出LIRA，一种局部跨层动作条件机制，将VLM到动作的条件化建模为深度感知的信息路由。LIRA作用于任务令牌特征和从中间VLM状态导出的LIRA查询特征，然后为每个并行融合块分配一个以其对应VLM层为中心的深度对齐局部窗口。并行融合块聚合相邻的LIRA查询特征，并将其与任务令牌特征和本体感觉输入整合，然后进行动作预测。这种路由接口保持骨干架构、动作解码器和监督训练方案不变。在LIBERO、LIBERO-Plus、CALVIN ABC$\rightarrow$D以及真实世界操作中，在同一0.5B参数配置下，LIRA相对于VLA-Adapter基线提升了主要聚合指标。在向LIBERO-Plus的零样本迁移中，LIRA将平均成功率从59.1%提高到78.0%，提升了18.9个百分点，表明在受控分布偏移下鲁棒性增强。

## Abstract
Vision-Language-Action (VLA) models transform representations from pretrained vision-language models (VLMs) into robot actions, yet the interface that routes intermediate VLM features into action decoders remains underexplored. Existing designs either expose only a narrow part of the representation hierarchy or rigidly match each decoder block to one VLM layer, restricting access to complementary task evidence across depths. We introduce LIRA, a local cross-layer action-conditioning mechanism that formulates VLM-to-action conditioning as depth-aware information routing. LIRA operates on task-token features and LIRA Query features derived from intermediate VLM states, then assigns each Parallel Fusion Block a depth-aligned local window centered on its corresponding VLM layer. Parallel Fusion Blocks aggregate neighboring LIRA Query features and integrate them with task-token features and proprioceptive inputs before action prediction. This routing interface leaves the backbone architecture, action decoder, and supervised training recipe unchanged. Across LIBERO, LIBERO-Plus, CALVIN ABC$\rightarrow$D, and real-world manipulation, LIRA improves the principal aggregate metrics over the VLA-Adapter baseline under the same 0.5B-parameter configuration. In zero-shot transfer to LIBERO-Plus, LIRA increases average success from 59.1% to 78.0%, an 18.9-point gain indicating improved robustness under controlled distribution shifts.

# LIRA：用于视觉-语言-动作解码的局部跨层信息路由 —— 论文深度总结

## 1. 核心问题与研究动机

- **研究背景**：视觉-语言-动作（VLA）模型复用预训练的视觉-语言模型（VLM）表征，将视觉观测和语言指令映射为机器人动作。虽然已有大量工作聚焦于扩大数据规模、改进动作表示或训练策略，但 **VLM 到动作解码器的中间特征路由接口** 这个关键环节却长期被忽视。
- **核心问题**：中间 VLM 特征应该如何被路由到动作解码器？具体而言，解码器每一层该从 VLM 的哪些深度层获取信息？
- **现有方法的三大局限**：
  1. **仅暴露最终层表征**（如 OpenVLA、OpenVLA-OFT）：损失了中间层的丰富语义与结构信息；
  2. **刚性的一对一层匹配**（如 VLA-Adapter）：每一个并行融合块（PFB）只能访问一个固定匹配的 VLM 层，无法利用相邻层中互补的任务证据；
  3. **全局聚合**：不加区分地混合所有层特征，破坏了 VLM 深度的局部结构信息。
- **作者的核心假设**：**VLM 的相邻层提供互补的任务证据**，局部邻近层的信息对动作预测最有益，既不应只取单层，也不应全局混合。基于此假设提出了 **LIRA（Local Cross-Layer Information Routing）**。

## 2. 方法论

### 2.1 核心思想

LIRA 将 VLM 到动作的条件化重新建模为一个 **"深度感知的信息路由"** 问题，并提出一个 **"深度局部性先验"**：每个动作解码块应访问以它匹配的 VLM 层为中心的局部邻域窗口，而非仅限于单层或整个 VLM 层次结构。

### 2.2 技术细节

- **基础框架**：LIRA 构建在 VLA-Adapter 架构之上，使用 Prismatic 风格的 VLM（Qwen2.5-0.5B 语言骨干）+ L 个并行融合块（PFB）组成的动作解码器。
- **两种特征流**：
  - **任务令牌特征** \(T_t^{(\ell)}\)：包含视觉-语言表征，与匹配的 VLM 层深度对齐，作为语义锚点；
  - **LIRA 查询特征** \(R_t^{(\ell)} \in \mathbb{R}^{M \times d_v}\)：通过学习得到的 LIRA Query 令牌在各 VLM 层的特征，作为 VLM 与动作解码器之间的条件化接口。
- **本地跨层路由机制**：对于第 \(i\) 个 PFB，选择以匹配层 \(i\) 为中心的窗口 \(W_r(i) = \{\ell \mid |\ell - i| \le r\}\)，然后沿令牌维度拼接窗口内所有 LIRA Query 特征：
  \[
  \tilde{R}_t^{(i)} = \text{Concat}_{\text{tok}}\left(\{R_t^{(\ell)}\}_{\ell \in W_r(i)}\right)
  \]
  默认 \(r=1\)，即内部 PFB 使用三层窗口，边界 PFB 裁剪为两层。
- **融合方式**：第 \(i\) 个 PFB 接收三种输入：
  \[
  X_t^{(i)} = \text{PFB}_i\left(X_t^{(i-1)};\, T_t^{(i)},\, \tilde{R}_t^{(i)},\, E_t^p\right)
  \]
  即 Action Query 特征 + 深度对齐任务令牌特征 + 局部聚合的 LIRA Query 特征 + 本体感觉投影嵌入。
- **关键优势**：由于只沿令牌维度拼接特征，不引入任何新的投影层或可训练参数——**相比 VLA-Adapter 基线参数完全相同**。
- **训练目标**：使用监督连续动作回归的 L1 损失：
  \[
  \mathcal{L}_{\text{act}} = \mathbb{E}_{\mathcal{D}}\left[\frac{1}{H}\sum_{h=0}^{H-1} \|\hat{a}_{t+h} - a_{t+h}\|_1\right]
  \]
  骨干架构、动作解码器和训练策略均保持不变。

2. **模拟基准全面超越基线**：

## 7. 方法优点

- **概念创新清晰**：首次将 VLM→动作的条件化明确建模为"深度感知信息路由"，提出"深度局部性先验"，概念简洁而具有解释力。
- **工程开销极小**：不引入任何额外可训练参数，只改变特征路由的拓扑，直接在已有 cross-attention 中消费拼接特征，是"免费"的架构改进。
- **保持训练管线不变**：骨干、解码器、损失函数、训练流程均无需改动，易于在现有 VLA 系统中即插即用。
- **消融实验逻辑严密**：通过路由拓扑、窗口宽度、查询预算三组消融，系统排除了"token 数量增多"、"任意跨层聚合"等混淆解释，使结论具有很强的因果支撑。
- **评估维度全面**：从短程单任务（LIBERO）到长程顺序任务（CALVIN），从受控扰动（LIBERO-Plus）到真实物理机器人，多层次验证了方法有效性。
- **计算效率具吸引力**：相对 7B 级别方法，以 1/14 的骨干参数实现更优性能，且吞吐量提升 2.6 倍，对于机器人实时部署有实际价值。

## 8. 不足与局限

- **骨干与架构泛化性未知**：仅在 0.5B Qwen2.5 骨干 + PFB 解码器上验证，未在更大 VLM 或不同动作解码器（如扩散模型、流匹配专家）上测试，跨架构适用性尚未证明。
- **真实世界证据偏弱**：每任务仅 10 次试验，无统计显著性检验；仅单一机器人平台、单一场景，不足以支撑"普遍适用于真实操作"的结论。
- **LIBERO-Plus 的"鲁棒性"边界需谨慎解读**：该基准是在训练分布上的**受控扰动**，并未覆盖完全开放世界的分布偏移；作者也明确承认这一点。
- **窗口宽度敏感性问题**：查询预算消融显示 LIRA 在 256 tokens 时成功率降至 93.0%，低于 64 tokens 的 97.6%，说明该方法对超参数存在一定敏感性，未充分探讨其原因。
- **未见接触丰富/力敏感任务**：论文的任务集中于空间关系、抓取放置，未涵盖插孔、组装、织物操作等力敏感场景，局部跨层路由在这些任务中是否有效未知。
- **未与其他微型 VLA 方法做规模对齐对比**：如 SmolVLA、Nora 等同尺度方法未纳入比较，削弱了对"小参数高性能"这一主张的独立验证。
- **缺少失败案例分析**：论文未对 LIBERO-Plus 中仍然失败的 22% 任务做归因分析，未能揭示路由机制的边界条件。

## 总结

LIRA 是一个**概念简洁、零额外参数、即插即用**的 VLA 解码接口改进方案。其核心洞察——"相邻 VLM 层提供互补任务证据"——通过精心设计的消融实验得到了有力验证。在受控对比（同参数同管线）下，LIRA 在模拟基准尤其是零样本迁移场景中表现出显著优势（LIBERO-Plus +18.9 点），在真实世界中亦有初步验证。然而，其骨干规模单一、真实实验样本有限、跨架构和跨具身泛化性未知等问题，是后续研究需要弥补的关键缺口。
