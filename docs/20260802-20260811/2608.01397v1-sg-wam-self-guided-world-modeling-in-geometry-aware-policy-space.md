## 摘要
世界动作模型（WAM）将动作生成与未来状态预测相结合。其有效性取决于未来动态是否在一个既与动作生成对齐、又具备足够几何感知能力以捕捉动作在何处以及如何改变场景的空间中被建模。现有的WAM通常仅满足这一要求的一部分，要么依赖于感知负担较重的观测空间目标，要么依赖于未针对动作相关性和几何性进行联合结构化的辅助潜在空间。我们提出了SG-WAM，一种自引导框架，直接在策略派生的表示空间中学习几何感知的动作条件动态。SG-WAM引入了可学习的动态令牌和自引导世界预测器，该预测器基于干预机器人动作的条件预测其未来潜在状态。预测目标由同一策略骨干的指数移动平均副本生成，从而在动作专家所使用的表示族内提供稳定的监督。几何监督进一步结构化策略图像令牌表示，为动态令牌提供空间上下文化的基础，并产生一个既与动作相关又具有几何感知的未来对齐空间。潜在未来预测、几何基础化和流匹配动作生成在统一框架中以端到端方式联合优化。基于0.9B模型且无需大规模具身预训练，SG-WAM在LIBERO上实现了98.5%的平均成功率，在LIBERO-Plus上达到了73%，同时在分布内和分布外的真实世界评估中均优于强基线。

## Abstract
World Action Models (WAMs) couple action generation with prediction of future states. Their effectiveness depends on whether future dynamics are modeled in a space that is both aligned with action generation and sufficiently geometry-aware to capture where and how actions change the scene. Existing WAMs typically satisfy only part of this requirement, relying on either perceptually heavy observation-space targets or auxiliary latent spaces that are not jointly structured for action relevance and geometry. We propose SG-WAM, a self-guided framework that learns geometry-aware action-conditioned dynamics directly in the policy-derived representation space. SG-WAM introduces learnable dynamics tokens and a Self-Guided World Predictor that forecasts their future latent states conditioned on intervening robot actions. Prediction targets are generated by an exponential moving average copy of the same policy backbone, providing stable supervision within the representation family used by the action expert. Geometric supervision further structures the policy image-token representations, providing spatially grounded context for the dynamics tokens and yielding a future-alignment space that is both action-relevant and geometry-aware. Latent future prediction, geometric grounding, and flow-matching action generation are jointly optimized end-to-end in a unified framework. Built on a 0.9B model without large-scale embodied pretraining, SG-WAM achieves 98.5% average success on LIBERO and 73% on LIBERO-Plus, while outperforming strong baselines in both in-distribution and out-of-distribution real-world evaluations.

- 世界动作模型（World Action Models, WAMs）将动作生成与未来状态预测耦合在一起，其核心假设是：显式预测“动作如何改变环境”能够为策略学习提供超越纯动作模仿的监督信号。
- 现有 WAM 的瓶颈在于**未来动态应在何种表示空间中建模**：
  - 在**观测空间**（图像、视频、深度图）中预测未来，需要重建纹理、背景、光照、视角等大量与操控无关的视觉细节，造成感知负担大、模型容量浪费。
  - 在**辅助潜在空间**中预测未来，虽然避免了像素重建，但目标表示通常由外部编码器或预训练特征定义，无法保证与动作生成所使用的策略表示直接对齐，存在“目标-策略不匹配”。
- 理想的世界建模空间需要同时满足两个条件：**（a）与动作生成直接耦合**；（b）**保留足够的几何/空间结构**，以捕捉“动作在哪里、如何改变场景”。
- SG-WAM 的核心回答：直接在**策略自身派生出的表示空间**中，通过**自引导（self-guided）**方式学习几何感知的动作条件动态，从而同时解决动作相关性和几何感知问题。

## 2. 方法论

### 2.1 核心思想
- SG-WAM 不再重建未来观测，也不使用独立编码器构造未来目标，而是：
  - 在 VLM 的 token 序列中插入**可学习动态 token（learnable dynamics tokens）**；
  - 用**自引导世界预测器（SGWP）**根据当前动态状态和干预动作序列预测未来动态状态；
  - 用同一政策骨干的 **EMA 副本**从未来观测生成预测目标，形成“自引导”监督；
  - 用**冻结的 VGGT 几何教师**对主视图图像 token 施加几何监督，使动态 token 的上下文具备空间结构。
- 训练时联合优化：流匹配动作生成、几何监督、潜在未来预测；推理时移除几何教师、SGWP 和 EMA 路径，仅保留在线 VLM+动态 token+动作专家。

### 2.2 关键技术细节
- **动态 token**：\(Q \in \mathbb{R}^{N_q \times D}\)，默认 \(N_q=8\)，与视觉和语言 token 一起输入 VLM 骨干（Qwen3.5-0.8B），在每层 transformer 中参与上下文交互。
- **几何监督**：
  - 冻结 VGGT-1B 提取主视图几何特征，空间池化后得到 \(Z_t^G\)；
  - 将策略主视图视觉 token \(H_t^{V,m}\) 通过几何投影器映射为 \(\hat{Z}_t^G\)，使用余弦相似度损失 \(L_{geo}\)；
  - 该损失不直接作为未来预测目标，而是用于**塑造视觉上下文**，为动态 token 提供操作相关的空间信息。
- **自引导世界预测器（SGWP）**：
  - 在线路径：\(z_t^Q = P_\phi(H_t^Q)\)，动作序列 \(A_t^{(\Delta)}\) 经动作编码器得到 \(e_t^A\)；
  - 预测：\(\hat{z}_{t+\Delta}^Q = F_\psi(z_t^Q, e_t^A)\)；SGWP 由自注意力+交叉注意力构成，动作 token 作为键值，动态状态作为查询。
  - 目标路径：EMA 策略处理未来观测和语言指令，得到 \(\bar{z}_{t+\Delta}^Q = P_{\bar\phi}(\bar H_{t+\Delta}^Q)\)；EMA 参数 \(\mu=0.999\) 更新。
  - 预测损失：MSE \(L_{pred}=\frac{1}{N_q d}\|\hat{z}_{t+\Delta}^Q - \mathrm{sg}(\bar{z}_{t+\Delta}^Q)\|_F^2\)，目标侧 stop-gradient。
- **动作生成**：
  - 采用条件流匹配（conditional flow matching），给定动作块 \(A_t\)、噪声 \(\epsilon\)、时间 \(\tau\)，定义 \(A_t^\tau = \tau A_t + (1-\tau)\epsilon\)，优化 \(L_{act}=\mathbb{E}[\|v_\omega(A_t^\tau, \tau, H_t) - (A_t-\epsilon)\|_2^2]\)。
  - 动作专家以完整策略上下文 \(H_t=[H_t^V, H_t^L, H_t^Q]\) 为条件，因此动态 token 既被预测目标优化，也参与动作生成。
- **总损失**：\(L = L_{act} + \lambda_{geo} L_{geo} + \lambda_{pred} L_{pred}\)，其中 \(\lambda_{geo}=0.1\)、\(\lambda_{pred}=0.1\)。
- **训练阶段**：单阶段端到端联合训练，无需预训练或分阶段微调；推理时所有辅助分支移除。

## 6. 主要结论与发现

- SG-WAM 在 **LIBERO 上平均成功率 98.5%**，与最强基线相当，但模型规模更小（0.9B vs 2B–7B），且无需大规模具身预训练。
- 在 **LIBERO-Plus 上达到 73.0%**，显著优于所有对比方法，尤其在相机、语言、光照和布局扰动下表现最强。
- **真实世界**：SG-WAM 在 ID 和 OOD 设置下均优于 VPP 和 VLA-JEPA，尤其在长时程 Toolbox Organization 任务中优势更明显，说明其表示更少依赖表面视觉线索、能更好保持任务进度信息。
- 消融实验表明：
  - 同时使用几何监督和世界建模取得最佳性能（98.5% vs 无两者时的 95.3%），两者互补；
  - 世界建模的贡献在 LIBERO-Long 上最显著（92.2% → 96.2%）；
  - 8 个动态 token 是最优配置，过少或过多都会降低性能；
  - 干预动作序列提供有效信息，替换为零动作后平均成功率下降至 97.6%。
- 注意力可视化显示：几何监督使动态 token 更一致地关注与机器人交互相关的区域，而非孤立显著物体。

## 7. 优点（方法与实验亮点）

- **自引导目标构造**：使用 EMA 同一策略生成未来目标，从根源上避免了目标-策略表示不匹配，且目标稳定（BYOL 风格）。
- **几何感知与动作相关的统一**：通过 VGGT 教师塑造视觉 token 空间，再让动态 token 在其上下文化，既保留空间结构又不增加推理额外组件。
- **轻量高效**：0.9B 参数无大规模预训练，在 LIBERO 上达到与 7B 模型相当甚至更优的性能，显示出较好的计算效率优势。
- **单阶段端到端训练**：几何监督、潜在预测和动作生成共享同一策略表示，避免多阶段训练带来的分布漂移。
- **推理简洁**：辅助分支全部移除，部署时仅需当前观测和指令，不增加推理开销。
- **消融设计恰当**：对每个核心组件、token 数量、动作条件信息都做了验证，注意力可视化提供了定性支持。

- **真实世界实验规模有限**：每任务 10–20 次试次，统计功效有限；且仅两个基线对比，缺少与更强 WAM 基线的真实平台比较。
- **LIBERO-Plus 基线比较的公平性**：部分基线结果来自原论文，可能存在训练数据、步骤数、超参等不一致，严格意义上并非完全同配置对比。
- **辅助目标依赖 VGGT 教师**：几何监督依赖 VGGT-1B 的 3D 特征，若测试场景与 VGGT 训练分布差异较大（如极端视角、非真实场景），监督信号可能退化。
- **动态 token 数量的非单调性未完全解释**：论文只给出经验结果，未从理论上说明为何 16 个 token 反而下降。
- **跨具身泛化未验证**：仅使用单一真实机械臂平台，未在多种机器人本体上验证；未来工作虽提及，但当前版本不足。
- **对象类别有限**：真实世界任务仅覆盖刚性物体和单一类型可变形物体，未涉及液体、多材质等更复杂物理交互。
