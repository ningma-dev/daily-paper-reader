## 摘要
世界-动作建模已成为机器人控制的一种有前景的范式，因为它使模型能够超越对观察的反应，并预测场景将如何演变。然而，现有的WAM（世界-动作模型）通常会产生大量的计算开销。像素空间方法通常将大量容量分配给可能与控制不直接相关的视觉细节，而一些潜在空间方法则需要多阶段训练来构建推理空间。由此产生的训练成本可能使这些方法在适度的计算预算下难以训练。在这项工作中，我们提出了LiLa-WAM，一种轻量级世界-动作模型，它在紧凑的潜在空间中推理未来，并且可以在单个24GB GPU上进行端到端训练。其核心设计是一个紧凑的潜在推理空间，由未来状态预测和动作生成共同塑造，这使模型保持轻量化的同时与控制保持良好的对齐。对于任务规范，我们进一步提出了视觉过渡令牌（VTT），一种无语言的任务表示，将每个任务编码为视觉特征空间中的一个方向。在RoboTwin 2.0、LIBERO和真实机器人任务上的实验证明了LiLa-WAM的有效性，在50个RoboTwin任务中通过单GPU训练实现了90.48%的成功率。

## Abstract
World-action modeling has emerged as a promising paradigm for robotic control, as it empowers models to go beyond reacting to observations and anticipate how a scene will evolve. However, existing WAMs often incur substantial computational overhead. Pixel-space methods often allocate substantial capacity to visual details that may not be directly relevant to control, while some latent-space methods require multi-stage training to construct the reasoning space. The resulting training cost can make such methods difficult to train under modest computational budgets. In this work, we propose LiLa-WAM, a lightweight world-action model that reasons about the future in a compact latent space and can be trained end-to-end on a single 24GB GPU. Its core design is a compact latent reasoning space jointly shaped by future-state prediction and action generation, which keeps the model lightweight while remaining well aligned with control. For task specification, we further propose the Visual Transition Token(VTT), a language-free task representation that encodes each task as a direction in visual feature space. Experiments on RoboTwin~2.0, LIBERO, and real-robot tasks demonstrate LiLa-WAM's effectiveness, achieving 90.48\% success across 50 RoboTwin tasks with single-GPU training.

# LiLa-WAM：用于机器人操作的轻量级潜在推理世界-动作模型 —— 论文总结

## 一、核心问题与研究动机

世界-动作模型（World-Action Model, WAM）旨在让机器人策略不仅对当前观测做出反应，还能预测场景在干预下如何演变，从而提升操作任务的鲁棒性。然而，现有 WAM 普遍面临严重的计算开销问题：

- **像素空间方法**（如视频/图像生成）将大量模型容量分配给与控制无关的外观细节（纹理、光照、背景），训练和推理均昂贵且耗内存。
- **潜在空间方法**虽避免像素合成，但常需多阶段训练管线（如先训练预测组件再耦合到策略），整体训练负担依旧很高。
- 现有 WAM 大多基于大规模预训练骨干（VLM 或视频生成模型），其参数容量大量服务于语言建模或视觉细节合成，与精细控制所需的线索并不匹配。

论文因此提出**在紧凑潜在空间中联合未来状态预测与动作生成、可单 GPU 端到端训练的轻量级 WAM**，以降低训练门槛并保持与控制目标的对齐。

## 二、方法论

### 2.1 总体框架

LiLa-WAM 学习如下条件分布：

```
p_θ(a_{t:t+H}, ẑ_{t+Δ} | o_t, q_t, c_τ)
```

其中 `a_{t:t+H}` 为动作块，`ẑ_{t+Δ}` 为未来状态的紧凑潜在表示，`c_τ` 为视觉任务提示（VTT），替代语言指令。未来状态以紧凑潜在形式表达，不依赖任何重型生成骨干。

### 2.2 Foresight-Aware Action Expert（前瞻感知动作专家）

- **视觉编码**：使用**冻结的 DINOv3-ViT-L/16** 作为视觉骨干，取第 17 和 21 层的补丁特征沿通道拼接并投影，融合细粒度空间细节与高层语义。
- **查询式适配器（Adapter）**：通过 `N_q=64` 个可学习查询与融合特征交叉注意力，将密集补丁特征压缩为紧凑视觉潜在 `Z_v`，使潜在规模与输入分辨率解耦。
- **动作专家**：堆叠 12 层 Diffusion-Transformer（DiT）块，输入为单一 token 序列 `[Z_a; Z_q; c_τ; Z_v]`（噪声动作、本体感受、VTT 任务 token、压缩视觉潜在）。最后一层线性头在动作 token 位置读出预测速度 `v̂_s`，在观测侧输出读出未来潜在 `ẑ_{t+Δ}`。
- **未来状态预测**：训练时通过轻量 Q-Former 式解码器将 `ẑ_{t+Δ}` 解码回冻结编码器的特征空间，与真实未来观测 `o_{t+Δ}` 的补丁特征计算逐 token 余弦损失；推理时解码器被丢弃，零额外测试开销。

### 2.3 Visual Transition Token（VTT，视觉过渡令牌）

- 对任务 τ 的每个演示片段 e，取初始帧与最终帧的全局图像嵌入之差，再对所有片段取平均：

```
u_τ = (1/|E_τ|) Σ_e (g_T^e − g_0^e)
```

- VTT 将任务编码为**视觉特征空间中的一个"过渡方向"**，经 MLP 投影后作为任务 token 注入网络。
- 测试时**无需文本、无需目标图像**，仅需按任务选择固定向量，是一种极简的视觉任务规范方式。

### 2.4 训练目标

联合优化两个目标：

```
L = L_fm + λ_ff · L_ff
```

- **L_fm**：条件流匹配损失，训练专家预测线性插值轨迹的常速度 `v* = x₁ − x₀`。
- **L_ff**：未来状态预测的前瞻损失（特征空间中的余弦损失）。
- 两目标梯度流入同一共享潜在表示，使潜在空间保持紧凑且控制相关。超参数 `λ_ff = 0.5`。

## 六、主要结论与发现

1. **轻量 WAM 可行**：LiLa-WAM 以 0.5B 参数在 RoboTwin 2.0 上达到 90.48%（干净）/ 89.04%（随机化）的平均成功率，超越 8B Motus 和 5B GigaWorld-Policy，略超 3B Being-H0.7；在 LIBERO 上平均 97.1%，与 OpenVLA-OFT 持平。
2. **前瞻监督是关键**：去除 L_ff 后成功率从 70.0% 降至 54.4%（10 任务子集），验证了"预测性世界建模对控制有意义"。
3. **VTT 优于语言指令**：在相同骨干下，VTT（70.0%）比 CLIP 编码语言指令（61.4%）高 8.6 个百分点，且无需文本处理开销。
4. **轻量专用骨干胜过大型通用骨干**：DINOv3（0.5B）在相同训练预算下优于 Qwen3VL-2B（2.2B），说明模型容量服务于错误目标时反而有害。
5. **特征层选择重要**：中低层特征（17 层）显著优于最后层（24 层），融合 17+21 层最佳，印证了操作任务对空间细节的需求。
6. **任务与动作的注意力分工**：VTT 关注任务作用对象（如风扇和目标垫），动作 token 关注机械臂和夹爪，二者互补。
7. **未来特征是动作条件化的**：替换动作块会显著改变未来特征预测（余弦相似度降至约 0.85），证明模型学到的是"动作-未来"耦合的动态而非静态视觉推断。
8. **真实世界验证**：前瞻损失在实物机器人上带来 8 个百分点平均提升（74.0% → 82.0%）。

## 七、优点与亮点

- **真正的单 GPU 端到端训练**：无需多阶段管线或分布式集群，显著降低 WAM 的使用门槛。
- **紧凑潜在推理空间**：将未来预测从像素域搬入语义特征域，避免外观冗余，同时通过共享 token 流实现控制对齐。
- **VTT 设计巧妙**：无语言、无目标图像的任务规范方式，计算成本极低（仅需演示首末帧嵌入之差），且经验上比

且经验上比语言指令带来更稳定的注意力分布与更高的任务成功率（70.0% vs. 61.4%）。

5. **推理零额外开销**：未来状态预测器仅在训练阶段启用，推理时被整体丢弃，不增加任何采样延迟，完美契合轻量部署需求。
6. **动作条件化的未来建模**：通过扰动探针实验证明，模型并非简单地从静态观测外推未来，而是真正对“动作-未来”联合动态进行建模，这为后续在线规划或模型预测控制提供了可扩展的基础。

## 八、局限与潜在改进方向

- 当前前瞻范围有限（单一短期 Δ 步），缺少对多步未来潜在状态的滚动预测能力，长程任务中的误差累积问题尚未解决。
- VTT 通过简单平均演示片段获得，若同一任务存在多种视觉表现截然不同的成功示范（如不同起始布局），平均向量可能削平关键运动线索；如何自适应地生成任务 token 仍待探索。
- 与大型基线方法的对比主要依赖论文报告的数字，各方训练数据规模、硬件资源、超参调整程度不完全透明，缺乏同一实验条件下严格公平的横向比较。
- 真实机器人验证任务仅 4 个，且只与自身消融变体比较，缺少与外部 SOTA 策略的实物对照，实物性能的泛化结论需谨慎解读。
- 后续可探索的方向包括：学习可更新的任务过渡过程、扩展多步潜在世界模型、与扩散策略解耦实现真正的模型预测控制，以及应用于更复杂的灵巧手操作。

## 九、总体启示

LiLa-WAM 的核心启示在于：机器人操作中的“世界模型”并不一定要建在像素生成或大型视觉语言模型之上。只要在紧凑、控制相关的潜在空间中引入轻量的未来预测监督，就可以同时提升决策质量与训练效率。该工作以 0.5B 参数、单张 24GB 显卡训练为标杆，证明了“轻量、专用、联合优化”的具身智能研究路径切实可行，也为算力有限的研究团队提供了极具参考价值的新范式。
