## 摘要
体现式视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，在机器人操作基准测试中展现出有前景的性能。然而，其潜力仍从根本上受限于大规模体现式轨迹数据的稀缺性，导致在分布外（OOD）场景中的组合泛化能力不足，且捕获可复用技能结构的能力有限。为解决这一局限，我们提出了基于技能的記憶（SkillMemo）框架，该框架将长时间跨度的演示隐式分解为潜在原子技能，并将技能级特征集成到动态情节记忆库中，以解决组合任务。具体而言，我们首先引入一个基于专家混合（MoE）架构的专家引导轨迹分割模块，该模块通过学习的门控系数将轨迹隐式划分为不同的技能原语。我们进一步设计了一种技能级情节记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理过程中，记忆库检索最相关的技能原语，随后将其与模型当前的门控分布融合，提供稳健的上下文先验以优化动作预测。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo持续增强DP和VLA骨干模型，实现最先进的性能并超越π₀.₅，同时展现对未见任务配置的强大组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 2. 方法论：SkillMemo 框架

SkillMemo 由两大核心模块构成，其宏观流程为：**演示轨迹 → 隐式技能分解 → 技能记忆存储 → 推理时检索与融合 → 动作预测修正**。

### 2.1 专家引导轨迹分割（Expert-Guided Trajectory Segmentation, EGTS）

**核心思想：**
- 摒弃显式切分轨迹的方式（显式切分难以捕捉所有真实的技能边界），采用**基于混合专家（MoE）的隐式技能分解**。
- 让不同的专家网络隐式地专精于不同的局部运动原语，由门控网络通过时间维度的激活变化自动定义技能边界。

**关键技术细节：**
- 对时刻 t 的中间特征 $h_t$，MoE 层输出为：
  $$y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)$$
  其中 $E_i$ 为第 i 个专家网络，$g_i(h_t)$ 为其门控权重。
- **门控系数在时间轴上的动态变化**隐式定义了轨迹的分段边界，使专家在不同动作阶段被选择性激活。

**正则化机制：**
- 引入基于**部分信息分解（Partial Information Decomposition, PID）**的协同信息损失：
  $$L_{PID} = -[I(\{A,B\};G) - I(A;G) - I(B;G)]$$
  该损失鼓励两个专家的联合表示携带超过各自独立表示之和的任务相关信息，驱动专家学习**互补、不重叠**的技能。
- 同时采用**专家负载均衡损失**和 **Top-k 路由**策略，防止专家坍缩。

### 2.2 技能级情景记忆架构（Skill-Level Memory Architecture, SLMA）

**记忆存储：**
- 对分割出的每个技能段，通过**时间聚合**计算紧凑的质心特征作为**记忆键（Key）**：
  $$k_m = \frac{1}{L}\sum_{t \in \tau_m} h_t$$
- 将段内**完整门控权重序列**作为**记忆值（Value）**，以保留技能执行的详细时序动态。
- 记忆库组织为键值对集合：$M = \{(k_m, v_m)\}_{m=1}^{M}$。

**记忆检索：**
- 推理时，计算当前观测特征 $q_t$ 与所有记忆键的**余弦相似度**，选取 Top-N 最相关记忆条目。
- 引入**可靠性检查**：若检索到的记忆条目平均相似度超过预置阈值 δ，才执行记忆增强。
- 门控融合方式：
  $$g'(q_t) = \lambda g(q_t) + (1-\lambda)\frac{1}{N}\sum_{n=1}^{N} v_n[t']$$
  将检索到的历史专家激活分布与当前预测门控分布加权融合，为动作预测提供上下文先验。

**记忆更新（持续学习）：**
- 记忆库容量有限（默认 1000 条），设计了**优先级剪枝策略**：
  1. 时间戳最久远（模拟人类遗忘）；
  2. 从未被成功检索；
  3. 在检索时持续低于可靠性阈值（低质量条目）。
- 该机制使记忆库在有限容量下保持**相关性**与**多样性**的平衡，支持终身学习场景。

## 7. 优点与亮点

### 方法设计层面
- **隐式技能分解**：避免了显式动作标签/段标注依赖（无需额外的技能标注），通过 MoE 门控自适应发现数据驱动的技能边界。

- **通用性与即插即用性**：不修改骨干网络的核心架构，可灵活适配 DP 和多种 VLA 模型，具备较强的工程实用价值。

### 方法论层面补充局限

- **门控分布作为记忆内容的语义粒度仍偏粗**：虽然门控权重序列保存了技能执行的时序动态，但门控本身只是专家选择的概率分布，而非实际的运动生成参数；记忆在多大程度上保留了“可执行的动作细节”（如关节力矩、夹爪开合宽度等），论文未做深入分析。
- **时间对齐假设的脆弱性**：检索到的记忆值 $v_n[t']$ 在拼接时隐含了“当前轨迹时间步与记忆段内时间步可对齐”的假设。对于速度变化明显、存在暂停或插入动作的真实任务，这种对齐可能失真。
- **技能边界与语义技能的对应关系缺乏强验证**：虽然门控激活可视化显示专家在抓取、开炉等阶段出现峰值，但未通过客观的动作相位标注（如接触事件、目标接近事件）定量验证隐式分割出的段与真实技能边界的一致性。

## 9. 延伸思考与启发

SkillMemo 的价值不仅在于其报告的性能增益，更在于它所开辟的研究方向，值得从以下几个角度进一步思考：

1. **记忆单元粒度的再讨论**：本文主张以“技能”为记忆单元，介于“整体轨迹”和“单步观察”之间。这一粒度选择背后是记忆的表达效率与检索灵活性之间的权衡——“技能级记忆”能否进一步推广为“层级化记忆”（如将复合任务的技能序列作为高阶记忆），是值得探索的延伸方向。
2. **从门控记忆到参数记忆**：当前方法记忆的是门控分布，即对专家组合的选择策略；下一步自然的发展方向是记忆专家网络本身的可微参数（如低秩适配器或残差权重），使记忆不仅能“选择”已有能力，还能“写入”新的能力。
3. **记忆与元学习的统一视角**：SkillMemo 的记忆检索与融合机制，本质上可以看作一种非参数化的元学习——在测试时通过检索历史经验快速调整策略行为。若能结合参数化元学习（如 MAML 类方法），有望进一步提升少样本适应能力。
4. **在线技能库的自主演化**：当前的记忆剪枝策略基于“时间戳、从未被检索、低可靠性”等启发式规则；未来可考虑基于任务成功率信号的闭环评价，让智能体自主判断哪些技能值得长期保留、哪些应被遗忘或合并，从而形成真正自主演化的技能库。
5. **与多模态大模型的协同**：SkillMemo 的检索特征完全来自模型自身中间层。若将记忆键构建为融合语言指令、视觉场景与本体感觉的多模态联合嵌入，可能使记忆检索对指令语义更敏感，进一步提升组合泛化中对指令变化的响应能力。
